Oil Pump Assembly (2AZ-FE) Reassembly

Print

Preparation List



1. Install Oil Pump Relief Valve

  1. Apply engine oil to the oil pump relief valve.

  2. Assemble the oil pump relief valve and spring.




  3. Using a socket wrench (27mm), install the oil pump relief valve plug.

    Standard
    T = 49 N/m{ 500 kgf/cm }



2. Install Oil Pump Strainer Set



  1. Install the oil pump strainer set with a new gasket and the 2 nuts.

    Standard
    T = 8.8 N/m{ 90 kgf/cm }
