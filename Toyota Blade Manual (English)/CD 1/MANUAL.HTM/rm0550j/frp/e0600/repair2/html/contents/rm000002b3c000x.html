Oil Pump Assembly (2GR-FE) Reassembly

Print

Preparation List



1. Install Oil Pump Relief Valve

  1. Apply engine oil to the oil pump relief valve.

  2. Install the oil pump relief valve.

  3. Install the oil pump relief valve spring.




  4. Using a socket wrench (27mm), install the oil pump relief valve plug.

    Standard
    T = 49 N/m{ 500 kgf/cm }



2. Install Oil Pump Rotor Set

  1. Apply engine oil to the oil pump rotor set.




  2. Install the oil pump rotor set to the timing chain (belt) cover with the marks facing the oil pump cover side.



3. Install Oil Pump Cover



  1. Install the oil pump cover to the timing chain (belt) cover with the 8 bolts.

    Standard
    T = 9.1 N/m{ 93 kgf/cm }
    Type
    		Bolt Length Under Head [mm]
    Bolt A
    		22
    Bolt B
    		40
