HDD Navigation USB Audio Mode Functions

●
By connecting a USB memory or "iPod" to the USB port, music files can be played by operation from the multi-display screen.
●
Not only USB memories with audio functions, but any USB memory storing music files with WMA or MP3 extensions can play music files.
●
The multimedia interface computer is equipped with "iPod" control software, so song selection from lists, shuffle mode switching, etc. can be operated from the multi-display screen.
