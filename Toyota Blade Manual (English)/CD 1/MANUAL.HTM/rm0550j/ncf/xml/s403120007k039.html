ETC System Outline

●
An ETC on-board unit (ETC unit with ETC antenna function / integrated antenna) compatible with the ETC (Electronic Toll Collection) system has been adopted and is available as a manufacturer option set with the HDD navigation system.
●
A dedicated panel for the ETC on-board unit is provided and the ETC unit is built into the instrument panel, giving a good appearance when not in use. In addition, models with the HDD navigation system adopt an integrated antenna in which the ETC antenna is integrated with the GPS antenna and VICS antenna, reducing the number of parts.
●
The ETC system performs the exchanges necessary for toll collection through wireless communication between the "ETC on-board unit" and the "ETC roadside wireless unit", eliminating the need to stop to pay at toll road toll gates; its purpose is "improved convenience through cashless payment" and "contributing to the reduction of toll gate congestion by reducing the time required for toll collection".

Related Parts


ETC On-board Unit

●
The ETC on-board unit consists of the ETC unit, integrated antenna (with built-in ETC antenna function), etc. When using the ETC system, a setup card* 1and an ETC card* 2must also be prepared.
HINT
*1
The setup card must be applied for at a registered setup store and created separately.
*2
The ETC card is issued upon application to an ETC card issuer such as a credit card company.

Initial Processing Function


•
As initial processing, the ETC unit indicator lights (green light and orange light) illuminate for approximately 5 seconds when ACC is turned ON.
•
By checking that the indicator lights illuminate during initial processing, they can be checked for open circuits.


Preparation for First Use


•
Before using the ETC system for the first time, registration processing of the ETC unit must be performed.
•
When ACC is turned ON before setup, the orange light illuminates together with the voice guidance "Beep beep, not set up". Setting the volume to "0" mutes the voice guidance when not set up.
•
With the power (ACC or IG) ON (after initial processing is completed), insert the "setup card" into the ETC unit. When the setup card is inserted, the green light in the ETC unit blinks together with the guidance sound "Beep", and registration processing starts automatically. When registration processing is completed, the green light goes off together with the voice guidance "Bong, setup completed".
•
If registration processing cannot be performed due to improper card insertion, etc., the green light goes off and the orange light blinks together with the voice guidance "Beep beep, cannot read card, error *** ". (In this case, remove the setup card, check the card type and insertion direction, and then insert the setup card into the ETC unit again)
•
If the on-board unit management numbers of the setup card and ETC unit differ and initialization cannot be performed, the green light goes off and the orange light blinks together with the voice guidance "Beep beep, management number error, check the card, error 05". (In this case, remove the setup card and check the on-board unit management number of the setup card.)
•
If a blocked setup card (a setup card that has already been used for setup processing) is inserted and initialization cannot be performed, the green light goes off and the orange light blinks together with the voice guidance "Beep beep, card error, check the card, error 05". (In this case, remove the setup card and check the setup card information.)
•
After registration processing is completed, press the card eject button and remove the setup card.
•
When the ETC menu is displayed on the HDD navigation system display, "Not Set Up" → "Setup Completed" is displayed in the ETC card message display area.
HINT
*
One of error 02, error 03 or error 05 is announced as a unified error code.


Setting the ETC Card


•
To use the ETC system, the ETC card must be set (authenticated).
•
With the power source mode ON (IG) (after initial processing is completed), insert the "ETC card" into the ETC unit. When the ETC card is inserted, the green light of the ETC unit blinks together with the guidance sound "Beep", and the ETC card is authenticated. When ETC card authentication is completed, the green light illuminates together with the voice guidance "Bong, ETC card inserted".
•
If authentication cannot be performed due to improper card insertion, etc., the green light does not illuminate and the voice guidance "Beep beep, cannot read card, error *** ". (In this case, remove the ETC card, check the insertion direction of the ETC card, and then insert the ETC card into the ETC unit again.)
•
If the ETC unit has not been initialized (setup processing), the green light does not illuminate and the orange light blinks together with the voice guidance "Beep beep, not set up". (In this case, remove the ETC card, perform registration processing of the ETC unit, and then insert the ETC card into the ETC unit again.)
•
When using the ETC system, leave the ETC card inserted in the ETC unit.
•
When the ETC menu is displayed on the HDD navigation system display, "Authenticating" → "ETC Card Authentication Completed" is displayed in the ETC card message display area.
HINT
*
One of error 02, error 03 or error 05 is announced as a unified error code.


ETC On-board Unit When Passing Entrance Gate


•
When the vehicle passes through a toll road entrance gate (ETC system compatible gate) with the ETC card set in the ETC unit and the green light illuminated, entrance information (gate, date and time, etc.) is written to the ETC card.
•
If a communication error occurs for some reason, the orange light of the ETC unit blinks and at the same time the voice guidance "Beeeep, ETC cannot be used, error *** " is given, indicating that the ETC system cannot be used.
HINT
*
One of error 01, error 06 or error 07 is announced as a unified error code.

Toll Charging


•
The toll is charged when the vehicle passes through an exit gate or an entrance gate with a flat-rate toll. At the same time, the voice guidance "Bong, the toll is ○○ yen* 1" is given.
•
If the toll cannot be charged by the ETC system for some reason, the orange light of the ETC unit blinks and at the same time the voice guidance "Beeeep, ETC cannot be used, error *** 2" is given, indicating that the ETC system cannot be used.
HINT
*1
If the toll exceeds 10 × 10,000 yen, the guidance "10 × 10,000 yen or more" is given.
*2
** is a unified error code; one of error 01, error 06 or error 07 is announced.

ETC System Usage History Display Function


•
When there is ETC system usage history, touching the "History Information Display" button* 1on the ETC menu screen of the display shows the usage history display* 2on the display. Touching the details button displays information such as usage time and usage section.
•
On the ETC unit, pressing the usage history check button while the vehicle is stopped gives voice guidance of the date of use and toll. Each time the usage history check button is pressed, the history moves from the most recent to older entries in order. If there is no usage history, the voice guidance "No usage history" is given.
HINT
*1
Do not perform operations near ETC gates, as communication with the roadside radio unit may become impossible.
*2
Up to 100 entries can be displayed.


ETC System Registration Information Display Function


•
Touching the "Registration Information Display" button on the ETC menu screen of the HDD navigation system display allows the registration information for the ETC on-board unit (on-board unit management number, on-board unit registration number, setup card issue date, setup card information expiration date and unified error code* ) to be displayed.
HINT
*
If there are error codes, the last 1 error(s) that occurred are displayed. Even if the system is normal, the last recorded error code may be displayed, so the display does not necessarily indicate the current status.

Various settings related to the ETC system can be made on the HDD navigation system display.

Card Left Prevention Function


•
If ACC is turned OFF with the ETC card still inserted in the ETC unit, the ETC unit gives the voice guidance "Beeeep, a card remains in the unit"* to notify the user that the card has been left in the unit.
HINT
*
If "Mute" is selected with the volume adjustment function, only the buzzer ("Beeeep") sounds.

Card Left Prevention Buzzer ON/OFF Setting Function


•
While the vehicle is stopped (with ACC or IG ON and the ETC card inserted), each time the usage history check button and the volume switch "Up" are pressed simultaneously for 2 seconds or more, the card left warning is switched between enabled and disabled. The card left warning can also be enabled/disabled in the ETC settings using the HDD navigation system.

Volume Adjustment Function


•
With the power (ACC or IG) ON, operating the volume adjustment buttons ("Up" or "Down" buttons) allows the volume of the voice guidance from the ETC unit to be adjusted (8 levels) or muted. When no voice guidance is being given, the voice guidance "Volume ** " or "Voice guidance stopped" is given; when some voice guidance is being given, the current voice guidance is repeated at the adjusted volume so the volume can be checked.
•
Even when voice guidance is stopped, guidance is given at volume 1 when an error occurs.
HINT
*
1 (minimum) to 8 (maximum) is announced.

Error Code Display Function


•
If there is a malfunction in the ETC unit or ETC card, a unified error code as shown in the table (Unified Error Code List) is displayed on the display (registration information screen or interrupt display) to notify the user of the malfunction.
•
The ETC unit stores the last unified error code that occurred (1 only); with the power (ACC or IG) ON, the unified error code can be announced by displaying the registration information on the display, or by pressing the usage history check button on the ETC unit for 2 seconds or more with no ETC card inserted.
