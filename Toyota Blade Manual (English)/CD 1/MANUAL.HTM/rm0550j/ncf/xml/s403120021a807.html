HDD Navigation System Operation




Panel Switch Operation
•
The display screens of the HDD navigation system consist of the TV mode screen, information mode screen, navigation mode screen, etc., and each mode screen can be called up using the panel switches located around the multi-display.


Touch Switch Operation
•
After each mode screen (TV, information, etc.) is called up, operations are performed with touch switches, which allow input by directly touching the switch frames displayed on the display screen with a finger.


Steering Switch Operation
•
TV/audio volume adjustment, etc. can be performed with the steering switches located on the steering wheel.


Voice Operation
•
By pressing the talk switch to display the voice recognition mark on the screen and then speaking a voice command toward the voice recognition microphone, navigation and other operations can be performed, providing excellent operability.
•
Voice operation has a "Standard Mode" and an "Extended Mode", which can be switched as desired according to purpose.
