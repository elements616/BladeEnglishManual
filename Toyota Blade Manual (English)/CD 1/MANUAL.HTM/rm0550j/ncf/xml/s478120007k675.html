ETC On-board Unit

●
The ETC on-board unit provides voice guidance about tolls and records information on the ETC card; when the vehicle passes through a toll road toll gate with an ETC card inserted in the toll collection (ETC) computer assembly, the toll is charged automatically.
●
The ETC on-board unit consists of the toll collection (ETC) computer assembly, an integrated antenna (navigation antenna assembly), etc. When using the ETC system, a setup card* 1and an ETC card* 2must also be prepared.
HINT
*1
The setup card must be applied for at a registered setup store and created separately.
*2
The ETC card is issued upon application to an ETC card issuer such as a credit card company.

Initial Processing Function


•
As initial processing, the indicator lights (green light and orange light) of the toll collection (ETC) computer assembly illuminate for approximately 5 seconds when ACC is turned ON.
•
By checking that the indicator lights illuminate during initial processing, they can be checked for open circuits.

Preparation for First Use


•
Before using the ETC system for the first time, the toll collection (ETC) computer assembly must be registered.
•
If ACC is turned ON before setup, the orange light illuminates together with the voice guidance "Beep beep, not set up". Setting the volume to "0" mutes the voice guidance when not set up.
•
With ACC or IG ON (after initial processing is complete), insert the "setup card" into the ETC unit. When the setup card is inserted, the green light in the toll collection (ETC) computer assembly blinks together with a "beep" guidance sound, and registration starts automatically. When registration processing is completed, the green light goes off together with the voice guidance "Bong, setup completed".
•
If registration processing cannot be performed due to improper card insertion, etc., the green light goes off and the orange light blinks together with the voice guidance "Beep beep, cannot read card, error *** ". (In this case, remove the setup card, check the type of card and the insertion direction, and then insert the setup card into the toll collection (ETC) computer assembly again)
•
If the on-board unit management numbers of the setup card and the toll collection (ETC) computer assembly differ and initialization cannot be performed, the green light turns off and the orange light blinks together with the voice guidance "Beep beep, management number error, please check the card, error 05". (In this case, remove the setup card and check the on-board unit management number of the setup card)
•
If a blocked setup card (a setup card that has already been used for setup processing) is inserted and initialization cannot be performed, the green light goes off and the orange light blinks together with the voice guidance "Beep beep, card error, check the card, error 05". (In this case, remove the setup card and check the information on the setup card)
•
After registration processing is completed, press the card eject button and remove the setup card. At this time, the voice guidance "Chime, ETC card not inserted" is given from the vehicle speakers, and the message "ETC card not inserted" is displayed as an interrupt on the display.
HINT
*
One of error 02, error 03 or error 05 is announced as a unified error code.

Setting the ETC Card


•
To use the ETC system, the ETC card must be set (authenticated).
•
With ACC or IG ON (after initial processing is complete), insert the "ETC card" into the toll collection (ETC) computer assembly. When the ETC card is inserted, a "beep" voice guidance from the vehicle speakers* 1is given together with blinking of the green light of the toll collection (ETC) computer assembly, and the ETC card is authenticated. When authentication of an ETC card within its expiration date is complete, "Chime, ETC card inserted" or "Chime, the ETC card expires at the end of this month. Please check the card."* 4is given as voice guidance and the green light illuminates. At this time, "ETC card inserted" or "The ETC card expires at the end of this month. Please check the card."* 5" is displayed as an interrupt message on the display. When authentication of an expired ETC card is complete, "Chime, the ETC card has expired"* 4is given as voice guidance and the green light illuminates. At this time, "The ETC card has expired"* 5" is displayed as an interrupt message on the display.
•
If authentication cannot be performed due to improper card insertion, etc., the green light does not illuminate, and the toll collection (ETC) computer assembly continuously sounds a "beep beep, beep beep, beep beep..." notification sound* 2, and the orange light blinks. In addition, the voice guidance "Chime, cannot read ETC card, please check the card" is given from the vehicle speakers* 1, and the message "Cannot read ETC card, please check the card*** 3" is displayed as an interrupt* 1on the display. (In this case, remove the ETC card, check the insertion direction of the ETC card, and then insert the ETC card into the ETC unit again)
•
If initialization (setup processing) of the toll collection (ETC) computer assembly has not been performed, the green light does not illuminate and the orange light blinks together with the voice guidance "Beep beep, not set up, error 05". (In this case, remove the ETC card, register the toll collection (ETC) computer assembly, and then insert the ETC card into the toll collection (ETC) computer assembly again)
•
When using the ETC system, leave the ETC card inserted in the toll collection (ETC) computer assembly.
HINT
*1
Voice guidance from the vehicle speakers and interrupt displays are not given until approximately 20 seconds or more have elapsed after ACC or IG ON.
*2
The notification sound of the toll collection (ETC) computer assembly continues until the ETC card is removed.
*3
** is a unified error code; one of error 02, error 03 or error 05 is announced.
*4
Voice guidance is given even if ETC voice guidance in the ETC settings function is set to "Off".
*5
The interrupt display is shown even if ETC interrupt display in the ETC settings function is set to "Off".
■ NOTICE ■
The ETC card expiration notification function at completion of ETC card authentication is a function that gives a simple notification of the card's expiration date. Always check the expiration date on the card before using the ETC on-board unit.


ETC Mark Display Function


•
With an ETC card inserted in the toll collection (ETC) computer assembly, selecting the "Info/G" button on the HDD navigation receiver switches to the Info/G screen, and the "ETC" mark is displayed at the top of the screen (both the information screen and G-BOOK screen), allowing confirmation that the ETC card is inserted.
■ NOTICE ■
The ETC mark does not indicate that the vehicle can pass through ETC gates.
The ETC mark is displayed even if the ETC card has expired.


ETC On-board Unit When Passing Through Entrance Gate


•
When the vehicle passes through a toll road entrance gate (ETC system compatible gate) with an ETC card set in the toll collection (ETC) computer assembly and the green light illuminated, information about the entrance (gate, date and time, etc.) is written to the ETC card. When communication between the ETC roadside radio unit and the toll collection (ETC) computer assembly is performed normally, the toll collection (ETC) computer assembly sounds a "ding-dong" notification sound.
•
If an ETC card insertion error occurs, the orange light of the toll collection (ETC) computer assembly blinks and at the same time a "beep" notification sound is given, the voice guidance "Chime, ETC card not inserted" or "Chime, cannot pass through ETC gate" is given from the vehicle speakers, and the message "ETC card not inserted01" or "Cannot pass through ETC gate01" is displayed as an interrupt on the display, informing the driver that the ETC system cannot be used.
•
If an information error occurs in the toll collection (ETC) computer assembly, the orange light of the toll collection (ETC) computer assembly blinks and at the same time a "beep" notification sound is given, the voice guidance "Chime, communication with the ETC gate failed" is given from the vehicle speakers, and the message "Communication with the ETC gate failed06" is displayed as an interrupt on the display, informing the driver that the ETC system cannot be used.
•
If a communication error occurs in the toll collection (ETC) computer assembly, the orange light of the toll collection (ETC) computer assembly blinks and at the same time a "beep" notification sound is given, informing the driver that the ETC system cannot be used.
•
If a problem occurs at a toll gate, inform the toll gate attendant of the problem using the intercom installed at the toll gate, and receive a ticket according to the attendant's instructions. In this case, ETC cannot be used, so at the exit toll gate use a mixed lane or general lane and submit the ticket received at the entrance toll gate together with the ETC card or cash, etc.
■ NOTICE ■
Even when passing a roadside antenna without an ETC card inserted, an error is considered to have occurred and a warning is given, but this is to inform the driver that ETC cannot be used and does not mean that the toll collection (ETC) computer assembly has malfunctioned.


Toll Charging


•
When the vehicle passes through an exit gate or a flat-rate entrance gate, the toll is charged. At the same time, the toll collection (ETC) computer assembly sounds a "ding-dong" notification sound, the voice guidance "Chime, ○○ yen* " is given from the vehicle speakers, and the message "Toll paid: ○○ yen* " is displayed as an interrupt on the display. If a refund occurs, the voice guidance "Chime, refund amount is ○○ yen* " is given from the vehicle speakers, and on the display "Refund amount is ○○ yen* " is displayed as an interrupt on the display.
•
If an ETC card insertion error occurs, the orange light of the toll collection (ETC) computer assembly blinks and at the same time a "beep" notification sound is given, the voice guidance "Chime, ETC card not inserted" or "Chime, cannot pass through ETC gate" is given from the vehicle speakers, and the message "ETC card not inserted01" or "Cannot pass through ETC gate01" is displayed as an interrupt on the display, informing the driver that the ETC system cannot be used.
•
If an information error occurs in the toll collection (ETC) computer assembly, the orange light of the toll collection (ETC) computer assembly blinks and at the same time a "beep" notification sound is given, the voice guidance "Chime, communication with the ETC gate failed" is given from the vehicle speakers, and the message "Communication with the ETC gate failed06" is displayed as an interrupt on the display, informing the driver that the ETC system cannot be used.
•
If a communication error occurs in the toll collection (ETC) computer assembly, the orange light of the toll collection (ETC) computer assembly blinks and at the same time a "beep" notification sound is given, informing the driver that the ETC system cannot be used.
•
If a problem occurs at a toll gate, inform the toll gate attendant of the problem using the intercom installed at the toll gate, and follow the attendant's instructions.
HINT
*
In units of 1 yen. If the toll exceeds 10 × 10,000 yen, the guidance "10 × 10,000 yen or more" is given.

ETC System Usage History Display Function


•
When the usage history check button on the toll collection (ETC) computer assembly is pressed while the vehicle is stopped, voice guidance of the date of use and toll is given. Each time the usage history check button is pressed, the history moves from the most recent to older entries in order. If there is no usage history, the voice guidance "No usage history" is given.
•
When there is ETC system usage history, select the "Display History" button on the ETC menu screen of the display* 1and the usage history is displayed on the display* 2can be performed. In addition, selecting the details button displays information such as the time of use and section used.
HINT
*1
Do not perform operations near ETC gates, as communication with the roadside radio unit may become impossible.
*2
Up to 100 entries can be displayed.

ETC System Registration Information Display Function


•
Selecting the "Display Registration Information" button on the ETC menu screen of the navigation system display shows registration information about the ETC on-board unit (on-board unit management number, on-board unit registration number, setup card issue date, setup card information valid date, unified error code* ) to be displayed.
HINT
*
If there are error codes, the last 1 error(s) that occurred are displayed. Even if the system is normal, the last recorded error code may be displayed, so the display does not necessarily indicate the current status.

Card Left Prevention Function


•
If the power is turned OFF with the ETC card left inserted in the toll collection (ETC) computer assembly, the voice guidance "Beep, card is still inserted" is given from the toll collection (ETC) computer assembly* is performed to notify the user that the card has been left in the unit.
HINT
*
If "Mute" has been selected with the volume adjustment function, only the notification tone is output.

Card Left Warning "On"/"Off" Setting Function


•
While the vehicle is stopped (with ACC or IG ON and an ETC card inserted), each time the usage history check button and the volume switch "Up" are pressed simultaneously for 2 seconds or more, the card left warning can be switched between "On" and "Off". It can also be set from the "Setup/Edit" screen of the navigation system.

Volume Adjustment Function


•
With ACC or IG ON, operating the volume adjustment buttons ("Up" or "Down" button) allows the volume of the voice guidance from the Toll Collection (ETC) Computer Assembly to be adjusted (8 levels) or muted. When the volume adjustment button is pressed while voice guidance is not being given, the voice guidance "Volume ** 1" or "Voice guidance canceled"* 2is given; when the volume adjustment button is pressed while voice guidance is being given, the voice guidance is repeated at the adjusted volume so that the volume can be checked.
•
Even when voice guidance is stopped, guidance is given at volume 1 when an error occurs.
HINT
*1
1 (minimum) to 8 (maximum) is announced.
*2
When set to volume 0.

Error Code Display Function


•
The Toll Collection (ETC) Computer Assembly stores the last unified error code that occurred (only 1), and the unified error code can be announced by displaying the registration information on the display with ACC or IG ON, or by pressing the usage history check button of the Toll Collection (ETC) Computer Assembly for 2 seconds or more with no ETC card inserted.
•
If there is a malfunction in the Toll Collection (ETC) Computer Assembly or the ETC card, a unified error code such as those in the table (Unified Error Code List) is shown on the display (registration information screen/interrupt display) to notify the user of the malfunction.

ETC Card Expiration Notification Function


•
The "expiration date information" in the ETC card data is sent to the navigation system and compared with the clock function of the navigation system to notify the user that the card has expired.
•
The green LED on the on-board unit and the ETC mark (Information/G screen), which indicate that a card is inserted, illuminate and display even if the card has expired.
•
This function operates in conjunction with a navigation system that supports the ETC card expiration notification function, so it does not operate with the on-board unit alone.
