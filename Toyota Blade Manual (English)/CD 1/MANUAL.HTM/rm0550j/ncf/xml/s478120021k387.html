Hands-free Calling Function

●
By using the voice recognition microphone, telephone switch and a Bluetooth compatible mobile phone* , a convenient hands-free call function can be used.
●
After making or receiving a call, the conversation is carried out using the voice recognition microphone and the vehicle speakers.
●
The voice recognition microphone is a unidirectional box-type microphone installed in the map light assembly.
●
The voice recognition switch and telephone switch are located on the right side of the steering pad so that switch operations can be performed without taking the hands off the steering wheel.
HINT
*
Check the G-BOOK site for cellular phone models whose operation has been confirmed.
About Bluetooth Compatible Mobile Phones


•
Bluetooth is a low-power wireless communication system using the 2.4GHz frequency band, whose technology is being standardized by the Bluetooth SIG (Special Interest Group), an organization joined by the world's leading manufacturers in the fields of electrical signals, computers and networks.
•
In this vehicle, a Bluetooth compatible unit is built into the HDD navigation system, so that when a Bluetooth compatible mobile phone supported by this vehicle* is used, hands-free calls and HELPNET can be used.
HINT
*
Check the G-BOOK site for cellular phone models whose operation has been confirmed.


Outgoing Calls


•
While the vehicle is stopped, pressing the off-hook switch of the telephone switch, or touching "Telephone" in the information screen displayed by pressing the "Information/G" panel switch, changes to the phone number input screen, and calls can be made by the following methods.
Dialing Methods


Item
Method
Dial Call
Enter a telephone number to make a call.
Phonebook Call
Call up a telephone number from the phonebook to make a call.
Call from Outgoing Call History
Calls up a number previously called (up to 10) and makes a call.
Call from Incoming Call History
Calls up a number from which a call was previously received (up to 10, including missed calls) and makes a call.
One-touch Dial Call
Select a pre-registered telephone number (one-touch dial) to make a call.
Voice Recognition Call
Press the voice recognition switch of the steering switch and make a call by voice.

HINT
In addition to the basic calling functions above, calls can be made from navigation facility information (when phone number data is available), supporting calling in various situations.


Incoming Calls


•
When a call is received, a ringtone sounds* 1and the incoming call screen is displayed.
•
A call can be answered by touching "Talk (telephone mark)" on the incoming call screen or by pressing the off-hook switch of the telephone switch.
•
While the ringtone is output and during a call, the audio sound and navigation guidance voice are muted.* 2
HINT
*1
With some Bluetooth compatible mobile phones, the ringtone may not sound.
*2
For ETC voice guidance, the ringtone and call are temporarily interrupted, the ETC voice guidance is given, and they resume as soon as the voice guidance ends.

Hands-free Call Function Settings


•
Touching the "Telephone" TAB on the Setup/Edit screen switches to the telephone settings screen, where various hands-free settings can be made. For details, refer to Telephone in Setup/Edit.

Transferring/Registering Phonebook Data


•
The memory of the mobile phone itself can be transferred to and registered in the phonebook of the hands-free system.
•
Each piece of information is transferred/registered from "Phonebook Editing" on the Setup/Edit screen.

■ NOTICE ■
This function cannot be used with mobile phones that do not support OPP. The data transfer method also differs depending on the mobile phone. For details, refer to the instruction manual supplied with the mobile phone.

HINT
*
Object Push Profile: a function for data communication between a mobile phone and a car navigation system, PC, etc.
