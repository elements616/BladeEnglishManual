Wireless Remote Control System

●
A wireless remote control system has been adopted, enabling remote locking/unlocking of all doors with the electronic key.
●
An encrypted code has been adopted for the weak radio waves (identification code) used between the electronic key and the door control receiver for improved security.
●
A customize function using the diagnostic tool (TaSCAN) enables adjustment and setting of various functions.

List of Wireless Remote Control Main Functions


Main Function
Function Outline
Wireless Lock & Unlock Function
Pressing the lock/unlock button locks/unlocks all doors.
Wireless Security Function
After the Certification ECU receives the encrypted code transmitted from the electronic key via the door control receiver, it verifies the code, and when it recognizes the code as that of its own vehicle, door unlocking, etc. becomes possible.
30-second Auto Lock Function
If the doors are left unlocked for approximately 30 seconds after being unlocked by pressing the unlock button, all doors are locked automatically to prevent the vehicle from being left unlocked.*1
Door Ajar Warning Function
If the lock button is pressed to lock the doors while any door is ajar or open, the wireless answer-back buzzer sounds for approximately 10 seconds to warn that a door has not been closed.*2
Answer-back [Buzzer Sounding & Hazard Flashing] Function
When the doors are locked/unlocked using the wireless remote control, the wireless answer-back buzzer sounds and the hazard warning lights flash 1 time(s) when locking and 2 time(s) when unlocking.*3
Illumination Function
When the doors are unlocked by the wireless remote control with the room light switch in the "DOOR" position, the room light, etc. illuminates for approximately 15 seconds.

HINT
*1
If any door is opened or all doors are locked within 30 seconds, the 30-second auto lock function is cancelled.
*2
The buzzer stops sounding when the power is turned ON (ACC/IG ON), all doors are closed, the door lock control switch (key-linked) is operated, or the doors are unlocked by the wireless/smart unlock function.
*3
The answer-back function also operates when locking is performed by the 30-second auto lock function.

Wireless Door Lock (Unlock) Operation


•
When the lock button 〈unlock button〉 is pressed, the vehicle identification code and function code are transmitted by weak radio waves. When the door control receiver receives these, it sends them to the Certification ECU.
•
The Certification ECU verifies the identification code and determines the function code; when it recognizes that the identification code matches that of its own vehicle and that the function code is door lock/〈unlock〉, it outputs this as code data to the Main Body ECU.
•
When the Main Body ECU receives the lock 〈unlock〉 signal, it turns ON the lock relay 〈unlock relay〉 and locks 〈unlocks〉 all doors, in the same way as manual lock 〈unlock〉 operation of the power door lock system.*
HINT
*
When the Main Body ECU receives the door lock position switch OFF 〈ON〉 state signal from each door lock assembly and confirms lock 〈unlock〉, it performs answer-back output. For door unlock operation, if no door is opened (door courtesy light switch ON) for approximately 30 seconds, all doors are locked (auto lock control starts).
