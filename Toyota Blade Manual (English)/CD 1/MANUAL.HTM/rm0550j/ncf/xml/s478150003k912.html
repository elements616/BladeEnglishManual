LIN Communication System

●
LIN communication (LIN: Local Interconnect Network)* has been adopted on all models.
●
LIN communication is used for sending and receiving security signals between the certification ECU and the main body ECU, steering lock ECU, ID code box, etc., and for sending and receiving air conditioning signals between the air conditioning control panel and air conditioning ECU.
●
Multiplex communication is a system in which multiple ECUs are connected to 1 communication line and can exchange data with each other. This makes it possible to suppress the increase in wiring when systems are integrated or functions are added.
●
LIN communication uses a single communication wire and transmits digital signals conforming to a dedicated communication protocol (communication rules) at a speed of 20kbps.
●
It is equipped with a diagnosis function that informs the technician of system malfunctions and a fail-safe function that ensures minimum performance of each ECU and protects the system when a communication malfunction occurs between ECUs.
●
A single-master method is adopted, in which the main body ECU controls sleep (low current mode), wake-up (standby mode), etc. of the ECUs it communicates with.
HINT
*
LIN communication is a multiplex communication network intended mainly for data communication between body control ECUs.

LIN Communication Protocol


•
The LIN communication system is a time-division multiplex bidirectional communication system in which all ECUs making up the network use 1 communication line, sending data by staggering the timing at which each ECU uses the communication line while also being able to receive. For this reason, each ECU communicates according to a common communication protocol (communication rules) so that communication is performed smoothly and reliably.
•
Data used in the LIN communication system consists of digital signals containing information such as the identification ID of each ECU (node ID) and the communication data contents.
•
As the communication rule for sending onto the communication line, so that all ECUs can share 1 communication line based on a defined transmission schedule, a single-master method is adopted in which the main body ECU controls the communication timing, sleep (low current mode), wake-up (standby mode), etc. of the ECUs it communicates with.
