Automatic Light Control System

●
An automatic light control system has been adopted, which detects the ambient brightness and automatically turns on the taillights and headlights when the light control switch is moved to the AUTO position with the power switch (IG) ON.
●
The circuit that controls the system is built into the main body ECU (instrument panel junction block assembly) installed on the front passenger side inside the instrument panel.
●
A function has been adopted that, through control by the automatic light control system, extends the off delay time to prevent momentary headlight illumination when the headlights are repeatedly turned on again immediately after turning off.
●
By adopting a customize function using the diagnostic tool (TaSCAN), the automatic light control sensitivity, automatic light control delay time, etc. can be set. For details of the customize function, refer to the control system.

Automatic Light Control System Operation


•
The automatic light control system controls turning on/off of the taillights and headlights as shown in the table. The following operations are explained using the No. in the Light Operation List by Automatic Light Control System.
Automatic Light Control System Operation List


Operating Conditions
Basic Operation
When Ambient Condition Is Bright (No.4)
•
When the ambient condition is brighter than the taillight off illuminance and headlight off illuminance, both the taillights and headlights are turned off.
When It Momentarily Becomes Dark While the Ambient Condition Is Bright (No.5)
•
When the ambient condition changes from headlight off illuminance to on illuminance while it is bright, the taillights illuminate because the taillight on illuminance has already been reached, but the headlights do not illuminate. If it is still darker than the on illuminance after the delay time has elapsed, the headlights illuminate; if it is brighter than the on illuminance after the delay time has elapsed, the headlights remain off, which prevents momentary headlight illumination when it becomes momentarily dark while passing under an overpass or along a tree-lined road in bright conditions. However, if it becomes as dark as the headlight rapid-on illuminance, the headlights illuminate.
When Ambient Condition Is Dim, Dark or Momentarily Bright (No.6 to No.8)
•
When the ambient condition is dim and becomes darker than the taillight on illuminance, the taillights illuminate. (No.6)
•
When it becomes even darker than the headlight on illuminance, the headlights also illuminate. (No.7)
•
Even if the ambient condition momentarily becomes bright due to street lights, etc. while the headlights are illuminated, the headlights do not turn off. (No.8)
When Power Switch (IG) Is Turned OFF (No.9)
•
When the power switch (IG) is turned OFF from the above state (No.6 to No.8), both the taillights and headlights remain illuminated. If the light control switch is then turned OFF once and set to AUTO again from this state, both the taillights and headlights turn off.
When the Power Switch (IG) Is Turned OFF and the Driver Side Door Is Opened, and Then Closed (No.10, No.11)
•
When the driver side door is opened (driver side door courtesy light switch ON) from the above state (No.9), both the taillights and headlights turn off. (No.10)
•
When the driver side door is closed (driver side door courtesy light switch OFF) from the above state, both the taillights and headlights remain off. (No.11)
When the Power Switch (IG) Is Turned ON Again with the Driver Side Door Closed (No.12)
•
When the power switch (IG) is turned ON again from the above state (No.10, No.11) and the ambient condition is dark, both the taillights and headlights illuminate.
When the Driver Side Door Is Opened Again from the Above State (No.12) (No.13)
•
Even if the driver side door is opened again (driver side door courtesy light switch ON) from the above state (No.12), both the taillights and headlights remain illuminated if the ambient condition is dark.




Fail-safe Function of Automatic Light Control System


•
When the output frequency from the light control sensor falls below 30Hz, the main body ECU (instrument panel junction block assembly) determines that the light control sensor has failed or that there is an open or short in the wire harness, and performs fail-safe.
•
If an input malfunction from the light control sensor is detected when the light control switch is in the AUTO position and the power switch (IG) is ON, and the headlights and taillights are illuminated, the main body ECU (instrument panel junction block assembly) keeps them illuminated until the headlights and taillights are turned OFF by the light auto turn off system or the light control switch is turned OFF. If the headlights and taillights are off, control by the automatic light control system is not performed and they remain off. If the output frequency from the light control sensor returns to normal during fail-safe, control by the automatic light control system automatically resumes.

Related Parts


Light Control Sensor

●
Detects the illuminance around the vehicle with the scanner section (integrated optical sensor) and outputs it as a frequency signal to the main body ECU (instrument panel junction block assembly). It is installed on the right side of the upper part of the instrument panel.
