Shift Lock System Outline

●
A shift lock system has been adopted to prevent incorrect operation of the shift lever.
●
The shift lock system is electric on all models, simplifying the construction.
●
A shift lock release button is provided on the shift lever housing so that the shift lock mechanism can be released manually when moving the vehicle by towing, etc., allowing for emergencies.

Main Components Table


Components
Function
Shift Lock Computer
Controls the operation of the shift lock solenoid based on various signals.
Shift Lock Release Button
Manually releases the lock applied by the shift lock solenoid.
Stop Light Switch
Outputs the brake signal to the shift lock computer.
Reverse Position Warning Buzzer
Informs the driver by a buzzer that the vehicle is in reverse.
