Multi-information Display Operation


•
Signals from each vehicle system are input to the meter computer in the combination meter; based on these signals, the meter computer calculates each value displayed in cruise information mode, displays information via the multi-information display, and controls illumination and blinking of the master warning indicator light. In addition, the signal from the DISP (display item selection) switch is input to switch between each display item and display mode.
