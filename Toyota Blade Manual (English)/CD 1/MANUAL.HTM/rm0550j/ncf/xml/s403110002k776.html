Radar Cruise Control System Control

●
The control performed by the radar cruise control system differs depending on the selected control mode (vehicle-to-vehicle distance control mode or constant speed control mode).
Vehicle-to-vehicle Distance Control Mode
A mode in which the system recognizes and judges the driving lanes of the preceding vehicle and own vehicle, and follows the preceding vehicle while maintaining an appropriate vehicle-to-vehicle distance according to vehicle speed.
Constant Speed Control Mode
A mode in which the vehicle speed is kept constant according to the set vehicle speed.


Glossary

Low Speed Limit
The lower limit speed of the controllable range. It is set to approximately 40km/h.
Minimum Set Vehicle Speed
The lower limit speed of the settable range. It is distinguished from the low speed limit. It is set to approximately 45km/h.
High Speed Limit
(Constant speed control mode only)
The upper limit speed of the controllable range. It is set to approximately 100km/h.
Maximum Set Vehicle Speed
The upper limit speed of the settable range. It is set to approximately 100km/h.

Vehicle-to-vehicle Distance Control Mode


•
The radar cruise control system performs the following controls in vehicle-to-vehicle distance control mode.
Set Control


•
When the - SET switch is turned ON while driving at or above the minimum set vehicle speed (approximately 45km/h) with the main switch ON, the vehicle speed when the switch is turned OFF is stored as the set vehicle speed and control starts.
•
If the - SET switch is turned ON while driving at or above the maximum set vehicle speed (approximately 100km/h), the maximum set vehicle speed (approximately 100km/h) is stored as the set vehicle speed and control is performed.


Constant Speed Control


[Reference scenario] When there is no preceding vehicle
•
The vehicle travels at the constant speed set by the driver.
•
The current vehicle speed is compared with the set vehicle speed, and the throttle control motor is driven to adjust the throttle control valve opening so that the vehicle speed approaches the set vehicle speed.



Deceleration Control


[Reference scenario] When a slower preceding vehicle (e.g. 80km/h) appears while driving at a constant set vehicle speed (e.g. 100km/h)
•
The vehicle decelerates to the target following speed (e.g. 80km/h) by driving the throttle control motor in the direction that closes the throttle control valve.
•
If greater deceleration is required, brake control is performed. If the vehicle approaches the preceding vehicle when sufficient deceleration cannot be achieved, the skid control buzzer sounds to warn the driver that driver operation (braking, etc.) is required.

•
If the - SET switch is held ON while driving in vehicle-to-vehicle distance control mode, the vehicle speed is reduced by driving the throttle control motor in the direction that closes the throttle control valve, and the vehicle speed at the moment the switch is turned OFF is stored as the new, lower set vehicle speed.
•
If the updated set vehicle speed is lower than the speed of the preceding vehicle, the system changes directly to constant speed control; if it is higher than the speed of the preceding vehicle, follow-up control continues.
•
If the vehicle speed reaches the high speed limit (approximately 100km/h) or more on a downhill slope, etc. while the - SET switch is being operated and the switch is then turned OFF, the high speed limit (approximately 100km/h) is stored as the set vehicle speed and the system changes to constant speed control.


Follow-up Control


[Reference scenario] When following a preceding vehicle (e.g. 80km/h) slower than the set vehicle speed (e.g. 100km/h)
•
The current vehicle speed is compared with the target follow-up acceleration data, and the throttle control motor is driven to adjust the throttle control valve opening so that an appropriate vehicle-to-vehicle distance is maintained in accordance with changes in the preceding vehicle's speed.



Acceleration Control


[Reference scenario] When the preceding vehicle (e.g. 80km/h) slower than the set vehicle speed (e.g. 100km/h) is no longer present
•
The vehicle accelerates slowly to the set vehicle speed (e.g. 100km/h) by driving the throttle control motor in the direction that opens the throttle control valve.
•
To accelerate quickly, turn ON the + RES switch or depress the accelerator pedal. (When the accelerator pedal is released, the previous control state resumes.)

•
If the + RES switch is held ON while driving in vehicle-to-vehicle distance control mode, the vehicle speed is increased by driving the throttle control motor in the direction that opens the throttle control valve, and the set vehicle speed is updated to a higher value.
•
If the + RES switch is held ON during follow-up control while there is a preceding vehicle, follow-up control takes priority, so the vehicle speed is not increased and follow-up control continues. However, the set vehicle speed is updated to a higher value.


Auto Cancel Control


•
When any of the following conditions (No.1 to 11) occurs while driving in vehicle-to-vehicle distance control mode, control is cancelled.
•
In conditions No.1, 2 and 4, control is prohibited until the main switch is turned ON again.
•
In conditions No.5 to 7, control is prohibited until the engine switch is turned ON (IG) again.
•
In conditions No.8 and 9, control is prohibited until the system recovers from condition No.8 or 9* or the main switch is turned ON again.

•
When any of the following conditions (No.1 to 5) occurs while driving in vehicle-to-vehicle distance control mode, control is cancelled while the set vehicle speed is retained in memory.

Resume Control


•
If control is cancelled by the above manual cancel control (except when the main switch is OFF) or auto cancel control (No.3 and No.8 to 11) while driving in vehicle-to-vehicle distance control mode, and the vehicle speed is at or above the low speed limit (approximately 40km/h), turning ON the + RES switch resumes control at the set vehicle speed at the time control was cancelled.


Downshift Control


•
The distance control computer assembly sends a shift control request to the engine control computer to suppress excessive speed increase when driving downhill and to reduce the frequency of brake control.


Brake Control


•
When greater deceleration is required while driving in vehicle-to-vehicle distance control mode, the distance control computer assembly sends a brake control request signal to the skid control computer, which applies the brakes by driving the brake actuator. At this time, the stop lights are illuminated.



Constant Speed Control Mode


•
The radar cruise control system performs the following controls in constant speed control mode.
Set Control


•
When the - SET switch is turned ON while driving at or above the minimum set vehicle speed (approximately 45km/h) and at or below the high speed limit (approximately 100km/h) with the main switch ON, the vehicle speed when the switch is turned OFF is stored as the set vehicle speed and control starts.
•
If the vehicle speed is below the minimum set vehicle speed or above the high speed limit, the set operation cannot be performed.


Constant Speed Control


•
The current vehicle speed is compared with the set vehicle speed, and the throttle control motor is driven to adjust the throttle control valve opening so that the vehicle speed approaches the set vehicle speed.


Acceleration Control


•
If the + RES switch is held ON, the vehicle speed is increased by driving the throttle control motor in the direction that opens the throttle control valve, and the vehicle speed at the moment the switch is turned OFF is stored as the set vehicle speed and the system changes to constant speed control.
•
If the vehicle speed reaches the high speed limit (approximately 100km/h) or more while the + RES switch is being operated, control is performed with the high speed limit as the set vehicle speed.
•
When the + RES switch is turned ON momentarily (approximately 0.6 seconds or less), the set vehicle speed increases by 1.6km/h for every 1 switch operation(s). (Tap-up function) However, if the difference between the set vehicle speed and the actual vehicle speed is 5km/h or more, the set vehicle speed is not changed by the tap-up function.


Deceleration Control


•
If the - SET switch is held ON, the vehicle speed is reduced by driving the throttle control motor in the direction that closes the throttle control valve, and control is performed with the vehicle speed at the moment the switch is turned OFF as the set vehicle speed.
•
If the vehicle speed reaches the high speed limit or more on a downhill slope, etc. while the - SET switch is being operated and the switch is then turned OFF, control is performed with the high speed limit as the set vehicle speed.
•
When the - SET switch is turned ON momentarily (approximately 0.6 seconds or less), the set vehicle speed decreases by 1.6km/h for every 1 switch operation(s). (Tap-down function) However, if the difference between the set vehicle speed and the current vehicle speed is 5km/h or more, control is performed with the vehicle speed at the moment the switch is turned OFF as the set vehicle speed.

When any of the following conditions (No.1 to 6) occurs while driving in constant speed control mode, control is cancelled.
•

Resume Control


•
If, while driving in constant speed control mode, control is cancelled by No.6 of the above auto cancel control or by manual cancel control (except when the main switch is OFF), and the vehicle speed is still at or above the low speed limit (approximately 40km/h), turning ON the + RES switch performs resume control at the set vehicle speed at the time control was cancelled. If the vehicle speed drops to or below the low speed limit (approximately 40km/h) even once after cancellation, control cannot be resumed even if the speed is increased to the low speed limit (approximately 40km/h) or more again.


Downshift Control


•
The distance control computer assembly sends a shift control request to the engine control computer to suppress excessive speed increase when driving downhill and to reduce the frequency of brake control.



Display of Diagnosis Results for System Malfunction Areas


•
When a system malfunction warning is displayed, etc., starting the diagnosis allows the system malfunction areas stored in the engine control computer to be displayed.
•
System malfunction areas are displayed on the multi-information display or by using the check mode of the diagnostic tool (TaSCAN). For details, refer to the Repair Manual.
