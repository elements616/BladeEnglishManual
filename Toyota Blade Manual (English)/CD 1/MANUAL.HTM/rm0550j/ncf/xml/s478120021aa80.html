Settings/Edit

●
Pressing the "Setup/Edit" panel switch changes to the Setup/Edit screen, where each function can be selected with the TABs at the bottom of the screen. Note that some functions cannot be operated while driving.
Setup/Edit Screen




Common Settings


Beep notification, operation screen continuous display, accent color switching, personal information initialization




Beep Notification
•
The response tone when a touch switch is touched can be set to "On" or "Off".


Operation Screen Continuous Display
•
Continuous display of the audio operation screen can be set to "On" or "Off".


Accent Color Switching
•
The accent color can be switched.


Personal Information Initialization
•
Information such as navigation memory point information, the hands-free phonebook and music recorded in the sound library can be deleted or returned to the initial state.

Hint Mode


•
When "?" is displayed on the screen, touching "?" enters hint mode, in which descriptions of the switches shown on that screen can be displayed.


Navigation


Volume setting, guidance cancel, route change, memory point registration/editing, map update, navigation detailed settings




Volume Settings
•
The guidance voice volume can be adjusted or muted, and automatic volume switching at high speed can be set.


Stop Guidance/Resume Guidance
•
The route being guided can be deleted to stop route guidance. After guidance is canceled, the display changes to "Resume Guidance", and touching it resumes guidance.


Route Change
•
Search conditions can be changed, entrance/exit ICs can be specified or canceled, destinations can be added, reordered or deleted, roads to pass through can be specified, modified or canceled, Smart ICs can be taken into account, and detour routes around seasonally restricted sections can be searched.


Memory Point Registration/Editing
•
Memory points (including home and special memory points) and detour memory points can be registered, modified and deleted, and the destination history can be deleted.


Map Update
•
Map data can be updated in two ways: "full update", which updates all nationwide map data, and "differential update (Map on Demand)", which partially updates map data via communication* or media (CD-R/DVD-R). For details, refer to Map Update Function.
HINT
*
Bluetooth compatible mobile phone.


Navigation Detailed Settings
•
Map display settings, automatic display switching settings, guidance display settings, voice settings, route-related settings and other settings can be made.


Telephone


Volume setting, telephone selection, phonebook editing, Bluetooth settings, telephone detailed settings




Volume Settings
•
The receiving volume and ringtone volume can be adjusted, the automatic volume switching volume at high speed can be set, and these settings can be initialized.


Phone Selection
•
The mobile phone to be used can be selected from the registered mobile phones. Normally, the most recently registered mobile phone is selected as the device to be used. When using multiple mobile phones, select the communication device as necessary.


Phonebook Editing
•
Phone numbers (phonebook data) can be registered by any of the following methods.
• Transfer the phonebook registered in the mobile phone to the phonebook of the on-board unit.
• Newly register in the phonebook of the on-board unit.
• Register from the outgoing or incoming call history.


Bluetooth Settings
•
The following Bluetooth setting information for the on-board unit can be displayed, and the settings changed and checked.
• The device name (name of the on-board unit in the Bluetooth network) can be changed to any name.
• The passkey (password used when registering a mobile phone to the on-board unit) can be changed to any number of 4 to 8 digits.
• The device address (unique address registered in the on-board unit) can be checked. It cannot be changed.


Telephone Detailed Settings
•
Security, automatic call answering, Bluetooth connection check display at ACC ON, incoming call interrupt display, automatic telephone connection and initialization of telephone detailed settings can be set.


Audio


Audio player switching, Bluetooth audio settings, sound library editing, CD to HDD recording settings




Audio Player Switching
•
The portable device to be used can be selected. Normally, the most recently registered portable device is selected as the device to be used with the on-board unit. When using multiple portable devices, select the device as necessary.


Bluetooth Audio Settings
•
Bluetooth audio devices can be registered or deleted, the device name and passkey changed, the device address checked, and automatic Bluetooth connection switched "On"/"Off".


Sound Library Editing
•
My Best playlists can be created/edited, album information modified/deleted, tracks deleted and HDD detailed information displayed.


CD to HDD Recording Settings
•
"Automatic recording", which automatically starts recording at the same time as CD playback, can be switched "On"/"Off"; when automatic recording is "Off", "select and record", which records selected songs, can be switched "On"/"Off". Recording quality can be switched between "High Quality" and "Normal" regardless of whether automatic recording is "On" or "Off".

G-BOOK


Communication settings, My Request editing, G-SOUND deletion, privacy settings, G-BOOK detailed settings




Communication Settings
•
Various communication settings can be made for data communication using a mobile phone.


My Request Editing
•
My Request content can be selected and its display position changed.


G-SOUND Deletion
•
Unnecessary G-SOUND can be deleted by touching continuously for 10 seconds or more.


Privacy Settings
•
The communication lock function can be set, and bookmarks and browsing history can be deleted or modified.


G-BOOK Detailed Settings
•
Automatic browser reading, reading speed selection, word editing, fixed phrase modification, input history deletion, predictive conversion candidate display settings and contract cancellation procedures can be performed.


Driving Support


Safe/comfortable driving settings




Safe/comfortable driving settings
•
Stop sign guidance, railroad crossing guidance, merging guidance, curve guidance, lane warning, accident-prone location guidance and school zone guidance can be set to "On" or "Off".

Maintenance


Item settings, dealer settings, maintenance detailed settings




Item Settings
•
Various maintenance information such as oil change timing can be displayed and entered (timing, distance, dealer, etc.). Also, by touching "Personal Items" on the screen while the maintenance menu screen is displayed, the screen changes to the personal items screen, where personal information such as the license renewal date can be displayed and dates can be entered.



Personal Items
•
Personal items allow settings for items other than those shown in the maintenance items.



Dealer Settings
•
The dealer name, staff name, location and phone number can be set.



Maintenance Detailed Settings
•
Automatic notification (maintenance guidance) "On"/"Off", clear all settings and automatic full update can be set.


ETC


Notification settings




Notification settings
•
ETC interrupt display, ETC voice guidance, warning display at ACC ON, warning voice guidance at ACC ON and card left warning can be set to "On" or "Off". For details, refer to ETC Setting Function in ETC System.
