HDD Navigation System Operation




Panel Switch Operation
•
The HDD navigation display screens consist of the "Navigation Mode Screen", "Information/G Screen", "Setup/Edit Screen", etc., and each mode screen can be selected by pressing the respective panel switch.


Touch Switch Operation
•
After calling up each mode screen (audio, Information/G, etc.), operations are performed with touch switches, which allow input by directly touching the switch frames shown on the display screen with a finger.


Voice Operation
•
Navigation and other operations can be performed by pressing the voice recognition switch on the steering wheel to display the voice recognition mark on the screen and then speaking voice commands into the voice recognition microphone, providing excellent operability.
•
Voice operation is performed by speaking the commands shown on the voice operation screen exactly as displayed.
•
The voice recognition switch needs to be pressed only at the start of voice operation, providing excellent operability.
•
Voice operation can be canceled by pressing and holding the voice recognition switch, or by saying "Cancel" when "Cancel" is shown in the command list.

Related Parts


HDD Navigation Receiver

●
The HDD navigation receiver consists of a retractable display panel section and the main unit.
●
Map information, route information, voice guidance data, etc. are stored on the built-in hard disk to increase the amount of information and achieve faster response.
●
The display panel section incorporates a color LCD panel that supports pressure-sensitive touch panel operation and displays the navigation screen, audio screen, etc. In addition, panel switches are arranged around the display.
●
By adopting LEDs for the backlight that illuminates the LCD panel, a display with higher brightness than the conventional type has been achieved. In addition, startup performance (brightness recovery) at low temperatures, response and color reproduction have been improved. Furthermore, the display module is mercury-free, which is environmentally friendly.

Color LCD Panel


•
The display uses a TFT (Thin Film Transistor) type LCD panel with a 7-inch wide screen with an aspect ratio of 9:16 (height 91.44 x width 152.40mm). The liquid crystal cells are subdivided into pixels of 234 vertical x 1200 horizontal; each liquid crystal cell (pixel) corresponding to each color filter is controlled in an analog manner from fully closed to fully open by the RGB video signals, so that colors are mixed additively and all colors can be expressed.
