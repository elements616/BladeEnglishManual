NAVI/AI-SHIFT

●
Road conditions are judged 3-dimensionally based on road gradient information and road corner information from the navigation system, and the appropriate gear is selected from 6, 5, 4 and 3. This achieves smooth and comfortable driving. NAVI AI-SHIFT control is performed only in the D position. NAVI AI-SHIFT control is not performed when S mode is selected.
●
NAVI AI-SHIFT control is performed only on vehicles with the factory-option navigation system.

Configuration of NAVI AI-SHIFT


•
NAVI AI-SHIFT performs control based on mutual communication between the navigation system and engine control computer and information from various sensors.


NAVI AI-SHIFT Non-operating Conditions, Restrictions, etc.


•
Control is not performed under the following conditions.
When NAVI AI-SHIFT Is Not Performed


"Off" selected with the "NAVI AI-SHIFT On/Off" switch on the navigation screen
When the shift lever is in a position other than D
During cruise control operation
When the vehicle speed is outside the range of approximately 15 to approximately 100km/h while driving in 3 gear
While driving in 4 or higher gear, when the vehicle speed is other than approximately 15 to approximately 120km/h*(outside this range)
When the transmission control computer, engine control computer, automatic transmission parts (shift solenoids, vehicle speed sensor, etc.) or electronically controlled throttle malfunctions

HINT
*
Vehicle speeds are reference values.

When NAVI AI-SHIFT Downshifts Are Not Performed


When the vehicle is turning
When VSC or TRC is operating


NAVI AI-SHIFT may not operate correctly under the following conditions.


When a tire is punctured
When the tire size differs from the specified size
When the spare tire is installed
When the road information in the navigation system differs from the actual road shape


Under the following conditions, control is performed using only road gradient information, and control using corner information is not performed.


When the navigation system malfunctions
When there is a communication malfunction between the navigation computer and engine control computer
When the navigation system has no map information
When the positioning accuracy of the navigation system decreases
When GPS signals cannot be received
When there is a road adjacent to the road being driven on
When the road is narrow (excluding national and prefectural roads)
When the road information in the navigation system differs from the actual road shape


HINT
It may not operate correctly depending on the situation, so do not rely too heavily on NAVI AI-SHIFT; always pay attention to road conditions and drive at a safe speed.

NAVI AI-SHIFT Fail-safe Function


•
A fail-safe function that stops control if any malfunction occurs in the navigation system or ECT system is provided. When a malfunction occurs, control is immediately prohibited or switched to control using only road gradient information.

Related Parts


Hydraulic Control Section

●
Ultra-compact, high-flow linear solenoid valves that directly control each clutch and brake have been adopted for shift control.
●
A lightweight aluminum alloy valve body has been adopted with an upper/lower 3-piece construction, and the linear solenoid valves are mounted on the lower valve body.

Linear Solenoid Valve


•
Linear solenoid valves have been provided for clutch engagement pressure control (SL1/SL2), lock-up clutch control (SLU), line pressure control (SLT) and brake engagement pressure control (SL3/SL4).
•
By directly controlling the hydraulic pressure of each clutch and brake with high-flow linear solenoid valves (SL1,SL2,SL3,SL4), improved shift response and reduced shift shock through shorter oil passages, as well as a simplified structure through fewer components, have been achieved.
•
A filter has been installed at the tip of the ON/OFF solenoid valve (SL) to achieve excellent reliability.

Input/Output Shaft Speed Sensors

●
An input shaft speed sensor that detects the turbine speed signal (NT signal) and an output shaft speed sensor that detects the counter gear speed signal (NC signal) have been installed on the hydraulic valve body.
●
The No.2 clutch piston is used as the timing rotor for the input shaft speed sensor to detect the turbine speed. In addition, the counter drive gear is used as the timing rotor for the output shaft speed sensor to detect the counter gear speed. The transmission control computer detects shift timing based on the detection signals from each sensor, and controls the hydraulic pressure appropriately according to various conditions.
