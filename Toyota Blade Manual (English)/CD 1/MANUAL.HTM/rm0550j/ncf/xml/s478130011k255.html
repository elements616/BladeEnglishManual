Power Window System

●
"Power windows with one-touch auto function", equipped with a jam protection function, key-off operation, etc. for the door glass of all seats, have been adopted. The jam protection function works not only during auto up operation but also during manual up operation.
●
An X-arm type window regulator has been adopted for the front doors and a single-arm type for the rear doors.
●
Remote control of the door glass of each seat is performed using the LIN communication system.
●
The door glass position/movement direction required for system control is detected with a pulse sensor (Hall IC), simplifying the system. An initialization operation is required when the power window motor assembly or window regulator assembly has been replaced, etc.
●
To prevent the information required for power window control from being lost when the ECU power is OFF, the information is stored in the EEPROM* built into the power window ECU.
HINT
*
Abbreviation for Electronically Erasable and Programmable Read Only Memory. (Non-volatile memory)
Power Window System Function List


Function
Outline
Manual Up & Down Function
While the door glass switch of the driver seat or each seat is operated to the up side (pulled) or down side (pushed) to the 1 stage, the corresponding door glass moves up or down.
One-touch Auto Up & Down Function
When the door glass switch of the driver seat or each seat is operated to the up side (pulled) or down side (pushed) to the 2 stage, the corresponding door glass automatically moves up or down to the fully closed or fully open position.
Power Window Jam Protection Function
During up operation*1, if an object is caught by the door glass, the window automatically starts moving down approximately 50mm.
If the opening amount does not reach approximately 200mm, the window moves down until it reaches approximately 200mm.
Window Lock
By turning ON (pushing in) the window lock switch of the master switch, power window operation of all seats other than the driver seat can be disabled.
Key-off Operation Function
The power windows of all seats can be operated for approximately 45 seconds after IG ON → IG OFF, or until the driver side door is opened → closed. The jam protection function also operates.
Fail Mode LED Blinking
In the event of an initial fail (when the window position could not be read normally from the EEPROM when a CPU reset occurred) or a LIN communication fail (when the LIN communication signal could not be received normally for a certain period), the system enters fail mode through self-diagnosis*2and the indicator light (LED) built into the switch knob blinks.

HINT
*1
If the auto up operation of the door glass switch is held, the jam protection function does not operate.
*2
If a malfunction occurs in the Hall IC that detects the position, speed and direction of the door glass, or if the error between the position information detected by the Hall IC and the position information stored by the power window motor exceeds the specified value, the system enters fail mode through self-diagnosis (indicator light built into the switch knob blinks).

Power Window Initialization Operation


•
In this system, a pulse sensor electrically reads the door glass position from the rotation of the motor, and various functions are controlled based on this information.
•
When the power window motor assembly, window regulator assembly, etc. has been replaced, the current door glass position information stored by the system is lost, so an initialization operation must be performed to have the system "learn" the door glass position.
•
Note that if the system has not "learned" the current door glass position, some functions such as the jam protection function will not operate.

Initialization Operation

•
Turn the IG ON and move the door glass to any position. Next, hold the door glass switch in the auto up position, and continue holding it in the auto up position for approximately 1 seconds after the door glass is fully closed; the system then stores the fully closed state of the door glass as the reference position (origin 0)*.
•
After the initialization operation, always perform a function check of the power window system. For details of the initialization operation and function check, refer to the Repair Manual.

HINT
*
The reference position (origin 0) of the door glass is updated each time the fully closed state is detected.


Manual Up & Down Operation




Manual Operation by Each Seat's Door Glass Switch
•
When the driver side door glass switch in the master switch or the door glass switch of each seat is operated to the up <down> side to the 1 stage with IG ON, the "manual up <down> operation request signal" is sent to the power window motor (with built-in ECU) of the driver seat or each seat.
•
While the power window motor (with built-in ECU) of the driver seat or each seat is receiving the "manual up <down> operation request signal", it rotates the power window motor to the up <down> side.
•
When the driver side door glass switch in the master switch or the door glass switch of each seat turns OFF, transmission of the "manual up <down> operation request signal" stops at that point, and the power window motor (with built-in ECU) of the driver seat or each seat also stops operating.


Remote Control Operation by Master Switch
•
When the door glass switch for each seat in the master switch is operated to the up <down> side to the 1 stage with IG ON, the "remote control up <down>" signal is sent via LIN communication to the corresponding power window motor (with built-in ECU) of each seat.
•
While the corresponding power window motor (with built-in ECU) of each seat is receiving the "remote control up <down>" signal, it rotates its own power window motor to the up <down> side in the same way as manual operation by each seat's door glass switch.
•
When the door glass switch for each seat in the master switch turns OFF, transmission of the "remote control up <down>" signal stops at that point, and the corresponding power window motor (with built-in ECU) of each seat also stops operating.

Auto Up & Down Operation




Auto Operation by Each Door Glass Switch
•
When the driver door glass switch in the master switch or the door glass switch of each seat is operated to the 2 position on the up (down) side with the IG ON, an "auto up (down) operation request signal" is sent to the driver or each seat power window motor (with built-in ECU). When the driver or each seat power window motor (with built-in ECU) receives this signal, it rotates the power window motor of that seat in the same way as manual up (down) operation.
•
At this time, each power window motor (with built-in ECU) counts the pulse signals from its built-in Hall IC, and even after the "auto up (down) operation request signal" stops, it continues to rotate until it detects from the motor rotation count that the door glass has reached the fully closed (fully open) position.


Remote Control Auto Operation by Master Switch
•
When the door glass switch of a seat in the master switch is operated to the 2 position on the up (down) side with the IG ON, a "remote control auto up (down)" signal for the corresponding switch is sent to each seat power window motor (with built-in ECU) via LIN communication.
•
When each seat power window motor (with built-in ECU) receives the "remote control auto up (auto down)" signal, it rotates its own power window motor up (down) to the fully closed (fully open) position in the same way as auto operation by each door glass switch.


Stopping Auto Operation
•
Auto operation stops when any of the conditions below is met.

Auto Operation Stop Conditions

•
The power window motor (with built-in ECU) under auto operation control detects that the door glass is fully closed (fully open).
•
The power window motor (with built-in ECU) under auto operation control receives an ON input from the operation switch in the opposite direction.
•
Approximately 10 seconds have elapsed since auto operation started.
•
The power window motor (with built-in ECU) under auto operation control receives an opposite-direction "remote control" signal or a "window lock" signal via LIN communication. (Front passenger side / rear RH / rear LH only)


Power Window Jam Protection Function Operation




Operation Outline
•
For the jam protection function, the power window motor (with built-in ECU) of each door controls the corresponding door glass.
•
When all of the prerequisites below are met and any of the following occurs: power window motor lock, change in rotation speed, or pulse disturbance, the power window motor (with built-in ECU) determines that jamming has occurred and performs reverse operation. To prevent malfunction, jamming is not judged while the door glass position is within the specified range.

Prerequisites

•
Manual, auto or key-off operation is performing an up operation.
•
The power window motor (with built-in ECU) has "learned" the fully closed position of the door glass as the reference point (origin 0).
•
The door glass position is not just before the fully closed position or just after the start of up operation from the fully open position (specified range).
•
The power window motor (with built-in ECU) is not just after starting to operate.



Reverse Conditions and Lowering Amount after Jam Detection
•
When the jam protection function operates and the opening (clearance) of the door glass has not reached approximately 200mm after lowering for approximately 50mm or 1 seconds, reverse operation continues until approximately 200mm or 5 seconds have elapsed. However, if the door glass reaches the fully open position before the down operation reaches approximately 50mm, operation ends at that point.
•
During reverse operation, manual up and auto up switch signal inputs are prohibited. (Switch input is accepted after reverse operation ends.) Manual down and auto down switch signals during reverse operation are accepted, but down operation is performed after reverse operation ends.


Jam Protection Reverse Operation
•
When the power window motor (with built-in ECU) determines jamming, it reverses the power window motor (with built-in ECU) by having the built-in motor drive circuit (relay) send current to the down side.

Power Window Key-off Operation


•
When the IG is turned from ON to OFF, the main body ECU detects this, starts counting approximately 45 seconds of key-off operation, and sends a "power window operation permission signal" to each seat power window ECU via LIN communication. This permits power window operation at all doors.
•
When approximately 45 seconds have elapsed, or when the main body ECU receives driver door courtesy light switch 0N → OFF, the "power window operation permission signal" is turned OFF. However, if the "power window operation permission signal" turns OFF during auto operation or jam protection control, each operation is carried out to completion, and jam protection control is performed during auto operation as well.

Window Lock Operation


•
When the window lock switch is turned ON with the IG ON or during key-off operation, a window lock switch ON signal is sent from the master switch to the main body ECU and each seat power window motor (with built-in ECU) via LIN communication.
•
While each seat power window motor (with built-in ECU) is receiving the "window lock" signal, power window control of its own door glass is stopped.

Fail-safe for Door Glass Position Detection


•
When a malfunction is detected in the Hall IC that detects door glass position, speed and direction, or when there is an error of more than the specified amount between the position the power window motor (with built-in ECU) "learned" as the fully closed position and the actual door glass position, the system shifts to fail mode through self-diagnosis.

Fail-safe for Power Window Motor Drive Control


•
This prevents the motor from continuing to run for longer than the specified time during auto operation, protecting the motor and circuit. Also, if the door glass position information is incorrect and the jam protection function operates at the fully closed position so that the door glass cannot be fully closed, the position information is set to the "not learned" state so that the door glass can be fully closed.

Continuous Operation Limit Function

When the motor drive time (relay ON time) by each door glass switch is long, the relay is automatically turned OFF after approximately 10 seconds.


Related Parts


Power Window Motor Assembly

●
A power window ECU (computer) is built into the power window motor.
●
The power window motor assembly consists of the power window motor body, connector section, gear section and power window ECU (computer).
●
A pulse sensor for the jam protection function is integrated into the power window ECU (computer) and detects the rotation of the power window motor.

Hall IC


•
The 2 Hall ICs output pulse signals synchronized with motor rotation to the power window ECU (computer) of their own seat, using a magnet provided on the armature shaft of the power window motor.


Power Window Computer

●
The power window ECU (computer) detects the amount of door glass movement by counting the pulses output by the Hall IC, at 2 cycles per 1 rotation of the motor shaft. Together with this, it determines the motor rotation direction (door glass movement direction) from the rotation direction signal output by the Hall IC. Various functions are controlled based on the position and movement direction information obtained from this Hall IC.

●
At the same time, the power window ECU (computer) detects changes in the door glass movement speed by detecting changes in motor rotation speed from the intervals of the pulses output by Hall IC1. This allows it to recognize the load applied to the door glass and control the jam protection function and overload stop function.
