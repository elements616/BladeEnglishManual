Power Door Lock System

●
A power door lock system with a driver door key-linked door lock function, key lock-in prevention function, etc. is used.
●
The door lock assembly reduces the number of parts while also giving consideration to theft prevention, by using a housing integrated with the protector, a cable connection with the door inside handle, direct connection between the door key cylinder and door lock, and integration of the actuator housing and protector.
●
Grip type door outside handles are used for all doors, providing excellent operability.

Back Door Lock Assembly (with Built-in Courtesy Light Switch)
Locks/unlocks the back door by driving the built-in back door lock control motor.
Detects the opening and closing of the back door.

Manual Lock <Unlock> Operation


•
When the door lock control switch (for manual operation) in the master switch is operated to the lock <unlock> side, the driver side manual lock <unlock> switch signal is input to the main body ECU.
•
On receiving this signal, the main body ECU applies current to all door lock control motors, rotating them to the lock <unlock> side.

Door Key-linked Lock <Unlock> Operation


•
When the mechanical key is inserted into the driver door key cylinder and turned to the lock <unlock> side, the door lock control switch (for key-linked operation) turns ON to the lock <unlock> side.
•
As a result, the driver door key-linked lock <unlock> switch signal is sent to the main body ECU, and all doors are locked <unlocked> in the same way as with manual lock <unlock> operation.

Key Lock-in Prevention Operation


•
When the electronic key is in the cabin and a situation such as the following occurs, the main body ECU sends a door unlock request signal to the door lock control motor of each door.

Key Lock-in Prevention Function Operating Conditions

•
When the driver (front passenger) manual switch is operated to the lock side with ACC ON or IG ON and the driver (front passenger) door open.
•
When the driver (front passenger) lock position changes from unlock to lock with ACC ON or IG ON and the driver (front passenger) door open.

•
When the above operating conditions are met, the main body ECU drives each door lock control motor to the unlock side to unlock the doors.
