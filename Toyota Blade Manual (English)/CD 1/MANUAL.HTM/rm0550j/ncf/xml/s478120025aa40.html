Seat Belt Warning Buzzer Specifications


•
When the vehicle speed reaches approximately 20km/h or more with the power source mode ON and the driver or front passenger seat belt unfastened, the meter computer sounds the buzzer in the combination meter to prompt the occupant to fasten the seat belt.
•
For approximately the first 30 seconds, the seat belt unfastened warning buzzer sounds as level 1 with an intermittent tone of 1.2-second cycle. If the seat belt is not fastened within approximately 30 seconds, the buzzer sounds as level 2 with an intermittent tone of 0.4-second cycle for approximately 90 seconds.
•
If the driver and front passenger seat belts are fastened while the buzzer is sounding at level 1 or 2, the buzzer stops sounding.
•
Even if the vehicle speed drops below approximately 20km/h while the buzzer is sounding at level 1 or level 2, the buzzer continues to sound. In addition, after the buzzer has finished sounding (120 seconds after it starts), the buzzer will not sound even if the vehicle speed drops below 20km/h and then rises to 20km/h or more again.
•
The buzzer stops sounding when the shift position is moved to "R".

Single Tone Buzzer Operation




Reverse Warning Buzzer Operation
•
When the meter computer receives a shift position "R" signal from the engine control computer via the CAN communication system, it sounds the buzzer.


Key Reminder Warning Buzzer Operation
•
When the meter computer receives a key reminder warning buzzer sounding request signal from the Certification ECU via the CAN communication system with the power source mode OFF, it sounds the buzzer.


Smart Entry & Start System Warning Buzzer Operation
•
When the meter computer receives a warning buzzer sounding request signal from the Certification ECU and Main Body ECU via the CAN communication system, it sounds the buzzer.


Warning Mode Display-linked Buzzer Operation
•
For the operation of the warning mode display-linked buzzer, refer to "Multi-information Display Warning Display Mode".


Reject Warning Buzzer Operation
•
When the meter computer receives a downshift reject signal from the engine control computer via the CAN communication system, it sounds the buzzer.


Light Reminder Warning Buzzer Operation
•
When the meter computer receives a driver door courtesy light switch ON signal from the Main Body ECU via the CAN communication system with the taillights ON and the power source mode OFF, it sounds the buzzer.


Driver Seat Belt Unfastened Warning Buzzer Operation
•
When the driver seat belt is unfastened (driver seat belt inner buckle switch ON), the Main Body ECU outputs a driver seat belt unfastened warning signal to the meter computer. While receiving this signal, the meter computer sounds the buzzer when the vehicle speed signal from the skid control computer reaches approximately 20km/h or more.


Front Passenger Seat Belt Unfastened Warning Buzzer Operation
•
When the meter computer receives an occupant detection sensor ON and front passenger seat belt inner buckle switch ON (front passenger seat belt not fastened) signal and the vehicle speed reaches approximately 20km/h or more, it sounds the buzzer in the same way as the driver seat belt unfastened warning buzzer.
•
As with the driver seat belt unfastened warning buzzer, the buzzer stops when the seat belt inner buckle switch turns OFF (seat belt fastened) or the power source mode is turned OFF.

•

•
When the parking brake signal (not released) is ON and the vehicle speed is 5km/h or more, the meter computer sounds the buzzer upon receiving signals from the main body ECU and skid control computer via the CAN communication system.


Electric Power Steering Warning Buzzer Operation
•
When the meter computer receives a signal indicating a power steering system malfunction from the power steering computer via the CAN communication system, it sounds the buzzer.
