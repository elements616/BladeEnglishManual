Eco Drive Indicator

●
An eco drive indicator has been adopted, which informs the driver by illuminating an indicator light whether the accelerator is being operated in an environmentally friendly (fuel-efficient) manner.

Eco Drive Indicator Operation


•
The meter computer receives the engine speed signal, shift position signal, accelerator opening angle signal, etc. from the engine control computer, and the vehicle speed signal from the skid control computer, via CAN communication. Based on these signals, it determines whether the vehicle is in an eco drive state, and illuminates the eco drive indicator when it determines that the vehicle is in an eco drive state (an environmentally friendly driving state with low CO2 emissions = a fuel-efficient driving state).
