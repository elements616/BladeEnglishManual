●

HELPNET


•
By touching "HELPNET" on the information mode screen, the emergency call system HELPNET can be used. For details, refer to HELPNET System.

Main Menu


•
By touching "Main Menu" on the information mode screen, the total mobility service "G-BOOK" can be used. For details, refer to G-BOOK ALPHA System.

Amusement


•
By touching "Amusement" on the information mode screen, amusement applications (AUTOLIVE, G-SOUND, etc.) can be used. For details, refer to Amusement.

FM Multiplex


•
By touching "FM Multiplex" on the screen while the information mode screen is displayed, the screen changes to the FM multiplex screen and the text information of FM multiplex general text broadcasts is displayed. Some information cannot be displayed while driving.
FM Multiplex Screen





FM Multiplex Mode Function List

Item
Description
Contents
The contents of FM multiplex general text broadcasts are displayed, up to a maximum of 6 items (information is selected from "1" to "6" on the screen). On screens other than the contents screen, the contents screen can be called up by touching "Contents" on the screen.
Record/Recall/Delete
Touching "Record Memo" on the screen records the currently displayed text information in the navigation computer (up to 20 items). Touching "Recall Memo" on the screen recalls and displays the recorded text information. Also, touching "Delete" or "Delete All" on the screen deletes the recorded information. Touching "Delete" deletes the currently displayed text information, and touching "Delete All" deletes all text information stored in the HDD navigation.
Auto Advance/Stop
When the text information of an FM multiplex general text broadcast has multiple pages, touching "Auto Advance" on the screen automatically advances and displays each page. Also, touching "Stop" on the screen stops the auto advance. Auto advance cannot be used while driving.
Auto Station Select
Touching "Auto Station Select" on the screen tunes to a station broadcasting FM multiplex text information.
Emergency Broadcast Reception
When FM multiplex emergency information is received while text information is displayed, the display switches automatically.
Program Link
Touching "Program Link" on the screen switches to the linked information program.


TEL (Phonebook Display)


•
By touching "TEL" on the screen while the information mode screen is displayed and then touching "Traffic/Navi" on the telephone screen, the screen changes to the phonebook screen, where a list of telephone numbers of facilities (such as JAF and the Japan Road Traffic Information Center) stored in the hard disk drive (HDD) can be displayed.
•
If telephone numbers have been entered for the set destination or registered memory points and special memory points, the telephone numbers of those points can also be displayed.
Phonebook Screen





TEL (Hands-free Calling)


•
By touching "TEL" on the screen while the information mode screen is displayed, the screen changes to the telephone screen, and hands-free calls can be made with a Bluetooth-compatible cellular phone. For details, refer to Hands-free Calling.

Surrounding Monitor


•
By touching "Vehicle Surroundings Monitor" on the screen while the information mode screen is displayed, the screen changes to the vehicle surroundings monitor setting screen, where settings for the back guide monitor can be made.

Operation Guide


•
By touching "Operation Guide" on the screen while the information mode screen is displayed, the screen changes to the operation guide screen, where operating instructions for the navigation functions, audio functions, G-BOOK ALPHA and voice recognition functions can be viewed.

Maintenance


•
By touching "Maintenance" on the screen while the information mode screen is displayed, the screen changes to the maintenance menu screen, where various maintenance information such as oil change timing can be displayed and entered (timing, distance, dealer, etc.). Also, by touching "Personal Items" on the screen while the maintenance menu screen is displayed, the screen changes to the personal items screen, where personal information such as the license renewal date can be displayed and dates can be entered.

Calendar


•
By touching "Calendar" on the information mode screen, the screen changes to the calendar screen and a calendar can be displayed.
Calendar Screen





Facilities with Information


•
By touching "Facilities with Information" on the screen while the information mode screen is displayed, the screen changes to the facility information search screen, where detailed information on major facilities on the map stored on the hard disk (facility overview, opening hours, fees, exterior photos, maps, etc.) can be searched and displayed.
Facility Information Search Screen





ETC


•
Displayed when the factory-option ETC with navigation link function is installed; touching it changes the screen to the ETC screen, where ETC (Electronic Toll Collection) information (usage history, tolls, etc.) can be displayed.

Setting


•
By touching "Settings" on the screen while the information mode screen is displayed, the screen changes to the settings screen, where continuous display settings for each operation screen, such as the audio operation screen and information screen, can be made. Also, the switch color of the settings screens (screens other than the map) can be selected from 2 types (green and orange).
•
In addition to the above settings, when a Bluetooth-compatible cellular phone is connected, settings for using the communication functions (G-BOOK ALPHA, hands-free and HELPNET) can also be made.
•
The personal information delete switch can delete information such as navigation memory point information, the hands-free phonebook and music recorded in the sound library.
Settings Screen
