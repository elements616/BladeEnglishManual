CVT Control (Computer)

●
A transmission control computer integrated with the engine control computer has been adopted. Various signals are communicated between the engine and transmission control computers to perform integrated engine control, achieving both smooth shift characteristics and excellent shift response at a high level.
●
Acceleration control (linear feel improvement control), NAVI AI-SHIFT and uphill/downhill shift control have been adopted to achieve smooth shift characteristics and excellent shift response, and neutral control has been adopted to improve fuel economy while the vehicle is stopped.
●
Diagnosis and fail-safe functions are provided for serviceability in the event of a system malfunction.

Engine Integrated Control


•
By integrating the control of CVT speed and engine torque, fine control is performed so that the engine operates on its optimum fuel economy line.

Basic Control


Determination of Target Driving Force
The target engine output is determined from the target driving force requested by the driver, based on the accelerator opening and wheel speed.
Determination of Target Speed
The target primary pulley speed is determined so that the target engine output can be achieved on the engine's optimum fuel economy line, and shift control is performed.
Determination of Target Torque
The target engine torque is determined from the target engine output and the primary pulley speed, and throttle opening control is performed.



Acceleration Control (Linear Feel Improvement Control)


•
The driver's acceleration request is determined from changes in vehicle speed and accelerator opening, and control shifts to driving force control that provides a good acceleration feel. In this case, the acceleration generated for a constant accelerator opening is kept constant, and the engine speed increases as the vehicle speed increases. This improves the linear acceleration feel and the feel of increasing vehicle speed in response to the driver's accelerator operation.


Neutral Control


•
Neutral control reduces engine load and improves fuel economy while the vehicle is stopped (in the D position) by disconnecting the engine from the transmission (partially releasing the starting clutch inside the automatic transmission using linear solenoid SLS). In addition, the gradient is detected by the G sensor, and neutral control is not performed on gradients above a certain level.

Control System





Uphill / Downhill Shift Control


•
When driving on winding roads with ups and downs, uphill/downhill shift control restricts upshifting when it determines that the vehicle is going uphill, achieving smooth driving.
•
In addition, when driving downhill, if a downhill is determined from the throttle opening and vehicle acceleration and brake operation is detected, the transmission downshifts to generate an appropriate engine braking force. The system consists of the throttle position sensor and vehicle speed sensor.

•
Slope determination is made by comparing the reference acceleration stored in the computer with the actual acceleration calculated from the speed sensor signal. When the actual acceleration is less than the reference acceleration, an uphill road is determined, and when the actual acceleration is greater than the reference acceleration, a downhill road is determined.


CVT Shift Control


•
Shift control sets the target input shaft speed based on information such as accelerator opening, vehicle speed and brake signal so that the optimum gear ratio and shift speed are obtained. Furthermore, a signal is output to the shift control duty solenoid (DS1,DS2) so that the speed obtained from the primary pulley speed sensor matches the target input shaft speed, optimizing the gear ratio.
•
In the D position, control is performed through integrated engine control to maximize fuel economy and driving performance.

•
In the M position of sport sequential Shiftmatic mode, M1 to M7 indicate the respective gears as shown in the illustration below. When the set vehicle speed is reached during acceleration, the transmission automatically upshifts.


Shift and Lock-up Control


•
Lock-up operation is performed based on a determination from the throttle opening and vehicle speed.
•
The lock-up operating range has been expanded compared to conventional A/T models, enabling lock-up from the low speed range. In addition, by expanding the lock-up operating range down to the low speed range during deceleration as well, the fuel cut range has been expanded, achieving excellent fuel economy.


Diagnosis Function


•
If a malfunction is detected in the speed sensors, solenoids, etc., the check engine warning light in the combination meter assembly illuminates to warn the driver. A new diagnosis system has been adopted for serviceability. By connecting TaSCAN to DLC3, diagnosis results for malfunctioning areas can be displayed. For the list of diagnosis items, refer to the Repair Manual.

Fail-safe Function


•
This function prevents a significant loss of drivability even if a malfunction occurs in the sensors or solenoids. For details, refer to the Repair Manual.
Fail-safe Function List


Components
Function
Primary Pulley Speed Sensor (NIN)
The input shaft speed is calculated from the signal from the turbine speed sensor and normal control is performed.
Secondary Pulley Speed Sensor (NOUT)
The output shaft speed is calculated from the signal from the speed sensor and normal control is performed.
Turbine Speed Sensor (NT)
The turbine speed is calculated from the signal from the primary pulley speed sensor and normal control is performed.
Shift Control Duty Solenoid No.1 (DS1)
Stops current to the solenoid. The gear ratio is shifted further toward the reduction side than normal.
Shift Control Duty Solenoid No.2 (DS2)
Stops current to the solenoid. The gear ratio is at the highest overdrive side.
Lock-up Solenoid (SL)
Stops current to the solenoid and releases lock-up.
Lock-up Engagement Pressure Control Duty Solenoid (DSU)
Stops current to the solenoid and fully releases lock-up.
Belt Clamping Force Control Linear Solenoid (SLS)
After the control current to the solenoid is stopped, the belt clamping force is set to the maximum hydraulic pressure and the gear ratio is fixed at a predetermined value.
Fluid Temperature Sensor
The engine control computer fixes the fluid temperature at a predetermined value and performs normal control.
G Sensor
When a malfunction is detected, neutral control is stopped.
