Multi-information Display Clock Setting Mode

●
The clock is shown on the multi-information display.
●
The clock can be set by operating the DISP switch as follows.
●
When setting the minute digits, the hour digits do not carry over even if the minutes exceed 60.
●
If a vehicle speed of approximately 1.75km/h or more is detected, clock setting mode is not entered. If vehicle speed is detected during clock setting, clock setting mode ends, the display changes to the setting guidance screen, and timekeeping resumes from the time displayed immediately before clock setting mode ended.

●
While the date/clock is displayed (except in clock setting mode), the clock can be adjusted to the nearest hour by operating the DISP switch as follows.
●
If the clock is adjusted to the hour when the minute digits are "30 to 59", the hour digits carry over. (Example: "1:30" → "2:00")
●
If the clock is adjusted to the hour when the minute digits are "00 to 29", the hour digits do not carry over. (Example: "1:29" → "1:00")
