Electric Power Steering Computer

●
Calculates the assist current from the steering torque and vehicle speed, and drives the motor.
●
A fail-safe function and diagnosis function are provided in case a malfunction occurs in the system.

Assist Control Function


•
Power assist control has the following functions.
Item
Function
Basic Control
Calculates the assist current and assist direction from the torque sensor signal and drives the drive circuit to output drive current to the motor.
Inertia Compensation Control
Increases the responsiveness of the assist force during steering to improve steering feel.
Friction Compensation Control
Eliminates the feeling of friction during steering to improve steering feel.
Return Control
Optimizes the return characteristics during steering.
System Overheat Protection Control
Provides overheat protection for the motor and electric power steering computer.


Fail-safe Function


•
If a malfunction occurs in the system, the fail-safe function operates. The electric power steering warning light in the combination meter illuminates, and the output current is cut off or gradually reduced to put the system in manual steering mode, or the output current is limited.
Fail-safe List


Item
Fail-safe Function
Torque Sensor System Malfunction
Assist is prohibited.
Motor Overheat
Assist force is limited until the motor temperature drops.
Motor Short (Including Drive System Malfunction)
Assist is prohibited.
Motor Overcurrent

Temperature Sensor System Malfunction in Electric Power Steering Computer
Electric Power Steering Computer System Malfunction (Including Booster Circuit System Malfunction)

Vehicle Speed System Malfunction

Power Supply Voltage Malfunction
Assist is temporarily limited. (Normal assist after voltage recovers)
