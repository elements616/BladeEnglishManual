Starter

●
A compact, lightweight, high-output, high-efficiency PS (Planetary reduction-Segment conductor motor) starter has been adopted.
●
A rectangular conductor armature coil has been adopted to reduce size and weight.

Starter Specifications


Type
PS Starter
Rated Voltage [V]
12
Rated Output [kW]
1.7


Armature Coil


•
By using bare rectangular wire for the armature coil, the space factor has been improved, increasing starter torque.
•
The cylindrical commutator has been eliminated, shortening the armature shaft length.


Field Coil


•
Interpolar magnets have been adopted between the field coils. This improves the magnetic circuit and increases the magnetic flux. As a result, the same magnetic flux as the conventional type can be achieved with a smaller size, so the yoke axial length has been shortened.
