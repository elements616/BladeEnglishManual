Rear Axle

●
As with the front, double-row angular ball bearings have been adopted.
●
A unit type axle hub is mounted on the axle carrier for easier servicing.
●
In the unit type axle hub, one side of the bearing inner race is integrated with the axle shaft, and the bearing and shaft shape have been optimized to achieve light weight, high rigidity, high reliability and durability.
●
The oil seal is integrated with the unit type axle hub to reduce rotational torque.
●
2WD models use a wheel speed sensor & rotor integrated with the axle hub.
●
As with the front, the axle hub nut on 4WD models uses a 12-point nut + staked type.
