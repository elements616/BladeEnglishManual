Multi-display

●
The multi-display has a structure that integrates a modular display section and navigation section. The display section contains the display panel that shows the screen, the main computer that controls the display, and the TV tuner that receives TV broadcast signals and outputs TV video signals to the display panel. Also, the navigation section consists of the main computer that controls the navigation system, the GPS receiver that demodulates signals from the GPS antenna and outputs them to the main computer, and the gyro sensor that detects the yaw rate and outputs it to the main computer.

Display Section


The display uses a TFT (Thin Film Transistor) liquid crystal panel, with a display screen of 79.8 high × 143.8mm wide and an aspect ratio of 9:16 (wide screen). The liquid crystal cells are subdivided into 234 vertical × 1200 horizontal pixels, and all colors can be expressed by additive color mixing, with each liquid crystal cell (pixel) corresponding to each color filter controlled in analog fashion from fully closed to fully open by the RGB video signals.

HDD Update Connector


•
A IEEE1394-standard HDD update connector has been adopted, allowing map updates, etc. to be performed by connecting a dedicated HDD map update tool to the connector. This allows work such as map information updates to be performed without removing the map HDD (hard disk) from the vehicle.
