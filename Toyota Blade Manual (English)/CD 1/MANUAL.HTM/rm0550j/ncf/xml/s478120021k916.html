Information Mode Functions

●
Pressing the "Information/G" panel switch changes to the Information/G screen, where each information display can be selected. In addition, the information page can be displayed by touching the "Information" TAB on the Information/G screen.

Telephone


•
By touching "Telephone" in the "Information" screen, the screen changes to the phone number input screen and hands-free calls can be made.
•
By touching "Traffic/Navigation" on the phone number input screen, the phone numbers of JAF, the Japan Road Traffic Information Center, etc. can be displayed.


Congestion Prediction


•
Congestion forecast information can be obtained from the G-BOOK center, and traffic information can be displayed around the current location and along the route on roads shown on the expressway route map. When a route has been set, the congestion information on the route can be read aloud.
•
Touching "Congestion Forecast" in the "Information" screen connects to the G-BOOK center, and the obtained congestion forecast information is displayed on the expressway route map.

■ NOTICE ■
Congestion forecast information is provided based on the area around the current location, and only routes for which travel time data is provided for "congested" and "crowded" are displayed.


VICS


•
By touching "VICS" in the "Information" screen, the screen changes to the VICS screen, where FM graphic information, FM text information and interrupt information can be displayed and VICS stations selected.


FM Multiplex


•
By touching "FM Multiplex" in the "Information" screen, the screen changes to the FM multiplex screen and FM multiplex general text information is displayed. Some information cannot be displayed while driving.

FM Multiplex Mode Function List


Item
Description
Contents
The contents of FM multiplex general text broadcasts are displayed, up to a maximum of 6 items (information is selected from "1" to "6" on the screen). On screens other than the contents screen, the contents screen can be called up by touching "Contents" on the screen.
Recall/Record/Delete
Touching "Recall Memo" on the screen recalls and displays the recorded text information. Touching "Record Memo" on the screen records the currently displayed text information in the navigation computer (up to 20 items). Also, touching "Delete" or "Delete All" on the screen deletes the recorded information. Touching "Delete" deletes the text information currently displayed, and touching "Delete All" deletes all text information stored in the navigation computer.
Auto Advance/Stop
When the text information of an FM multiplex general text broadcast has multiple pages, touching "Auto Advance" on the screen automatically advances and displays each page. Also, touching "Stop" on the screen stops the auto advance. Auto advance cannot be used while driving.
Program Link
Touching "Program Link" on the screen switches to the linked information program.
Auto Station Select
Touching "Auto Station Select" on the screen tunes to a station broadcasting FM multiplex text information.
Emergency Broadcast Reception
When FM multiplex emergency information is received while text information is displayed, the display switches automatically.



ETC


•
By touching "ETC" in the "Information" screen, the ETC screen is displayed and ETC card messages can be checked. For details, refer to ETC System Status Display Function in ETC System.


Calendar


•
By touching "Calendar" in the "Information" screen, the screen changes to the calendar screen and the calendar can be displayed.


Operation Guide


•
By touching "Operation Guide" in the "Information" screen, the screen changes to the operation guide screen, where operating instructions for the navigation, audio, G-BOOK, hands-free and voice recognition functions can be viewed.
