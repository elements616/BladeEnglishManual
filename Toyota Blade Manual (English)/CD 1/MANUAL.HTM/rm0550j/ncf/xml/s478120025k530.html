Shift Position Indicator Lamp



6 Super ECT models
●
A D (temporary S) mode indicator light and an S (sequential shift) mode indicator light have been provided.
●
When the shift position is moved to "S", the S mode indicator light "S" illuminates and the current shift range is displayed.
●
When an UP/DOWN shift range operation is performed with the transmission shift switch while shift position "D" is selected, the D mode indicator light "D" illuminates and the current shift range is displayed.

Shift Position Indicator Operation



S (Sequential Shift) Mode {6Super ECT Models}

•
When the shift position "S" signal is input, the engine control computer also receives the shift switch operation (UP/DOWN) signal from the shift lever or transmission shift switch, and sends the "shift range signal" and "'S' illumination signal" to the meter computer as CAN communication signals.
•
Upon receiving these signals, the meter computer illuminates the S mode indicator light "S" and displays the currently selected shift range on the display LCD.


D (Temporary S) Mode {6Super ECT Models}

•
When the shift switch operation (UP/DOWN) signal from the transmission shift switch is input while the shift position "D" signal is input, the engine control computer sends the "shift range signal" and "'D' illumination signal" to the meter computer as CAN communication signals.
•
Upon receiving these signals, the meter computer illuminates the D mode indicator light "D" and displays the currently selected shift range on the display LCD.
