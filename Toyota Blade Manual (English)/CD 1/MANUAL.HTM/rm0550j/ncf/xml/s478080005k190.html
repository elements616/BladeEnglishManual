Diagnosis Control

●
Panel diagnosis is used, which stores any malfunction that occurs in the display, sensors, actuators, etc., and informs the technician of diagnostic trouble codes through the air conditioning control section.
●
By connecting and operating a diagnostic tool (TaSCAN) to the vehicle external terminal (DLC3), diagnostic trouble code output, various data output, etc. can be performed.
Panel Diagnosis Function


Check Item
Description
Indicator Check
The indicators of each mode switch and the temperature setting display blink, and the buzzer sounds. (The buzzer sounds on models with HDD navigation system only)
Sensor Check
Checks the malfunction status of sensors (past and present).
Clears past malfunction data.
Actuator Check
Outputs the actuator check pattern.


TaSCAN Supported Functions


Function Name
Description
Diagnosis Output Function
Outputs the display codes for normal and current malfunctions determined by the sensor check of the diagnosis control.
Diagnosis Information Clear Function
Clears past malfunctions from the sensor check of the diagnosis control.
Data Output Function
Input values from the outside air and coolant temperature sensors, and the outside temperature display value.
Blower level.
Outputs the set temperature (driver side and front passenger side) and the external variable output current.
Actuator Check Function
Performs control output according to individual operation commands.
Customize Function
For details, refer to the customize function in the communication section.
