Disposal Function

●
Communication with a disposal tool and a disposal function are provided for disposing of the airbags when the vehicle is scrapped.
Batch Deployment Connector


•
A batch deployment connector is provided on the center airbag sensor (computer).
•
By connecting a special tool to this connector, batch deployment of the airbag system is possible.


Batch Deployment Indication Label


•
An information label indicating the mounting location of the center airbag sensor (computer) is affixed above the front passenger door lock striker. For this vehicle, it indicates that the center airbag sensor (computer) is mounted on the floor tunnel at the front of the center console.
