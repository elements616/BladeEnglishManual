●

In particular, approximately 140 songs such as classical music can be used free of charge.

Features of the G-BOOK System




Real-time Information Acquisition
•
By accessing the G-BOOK Center via the customer's cellular phone connected by Bluetooth, new map data (Map On Demand), route searches that take congestion into account (G Route Search), news and various other information can be obtained.


Text-to-speech
•
In consideration of safety while driving, text data can be read aloud.* This allows news, e-mail, etc. to be checked through the vehicle speakers.
HINT
*
If there is an incoming call on the customer's cellular phone connected by Bluetooth, or ETC or navigation voice guidance, while G-BOOK content is being read aloud, the reading of the G-BOOK content is temporarily suspended and the telephone, ETC or navigation voice is played. When playback ends, the reading of the G-BOOK content resumes.

Obtaining Information (Contents) in the Vehicle


•
G-BOOK mX information (contents) is obtained by data communication from the G-BOOK network, centered on the G-BOOK Center, using the customer's Bluetooth compatible cellular phone.

G-BOOK Settings


•
To use G-BOOK, various settings matching the connected communication device (the customer's Bluetooth compatible cellular phone) are required.
•
Settings for using the G-BOOK service are made from the screen displayed by touching the "G-BOOK" TAB on the settings/edit screen. For details, refer to G-BOOK under settings/edit.


G-BOOK.com


•
G-BOOK.com is a user's own menu folder in which convenient preset contents can be viewed and executed, and which can be customized by adding G-BOOK's extensive contents to create the user's own G-BOOK.
•
The G-BOOK.com screen is displayed by touching "G-BOOK.com" on the main menu screen; touching the touch switch frame of each menu displayed there moves to that menu.


G Memory Point Information


•
Facilities, etc. saved on G-BOOK.com or GAZOO.com can be displayed in a list.
•
Registered G memory point information can also be recalled from the memory points in navigation mode and set as a destination.

Browsing History


•
The titles of contents viewed in the browser are saved in order from newest date, making it easy to search when you want to view previously used contents again.

Bookmark


•
By registering the page displayed in the browser as a bookmark, a page you want to view again can be easily displayed from the bookmark screen.
•
The titles of registered bookmarks can also be edited (changed) as desired.

About the Browser


•
The browser is an application that displays the various contents provided by G-BOOK.com.
•
The browser screens consist of a screen displayed while viewing contents and a screen displayed while contents are being read aloud.
•
Automatic reading by the browser can be set to "On"/"Off" from "G-BOOK Detailed Settings" on the settings/edit screen. When set to "On", the reading speed can be set to "Normal"/"Slow".

HELPNET System


•
HELPNET, an emergency notification system connected manually by screen operation, has been adopted.* 1
•
When trouble such as an accident or sudden illness occurs while driving, the HELPNET system sends the customer's location information together with voice to the HELPNET Center via the public network from a cellular phone connected by Bluetooth* 2. Upon receiving this report, the HELPNET Center refers the case to the appropriate rescue agencies (police, fire) as necessary.
HINT
*1
By performing Web registration on the PC site G-BOOK.com, it can be used as standard for 3 years from the new vehicle registration date. From the 4th year onward, and for re-registration after canceling G-BOOK or HELPNET registration, a registration fee of 1050 yen (tax included) is required every 2 year.
*2
Bluetooth compatible cellular phone (check the G-BOOK site for cellular phone models whose operation has been confirmed.)
Emergency Notification Flow






Preparation for First Use
•
To use the HELPNET system, it is necessary to start the G-BOOK online service on the on-board unit and then complete the HELPNET service start operation.


HELPNET Service Start Operation
•
A communication test with the HELPNET Center, confirmation of member registration with the HELPNET Center and inspection of the system equipment can be performed manually.*
HINT
*
The service start operation must always be performed by the contract holder.


Means of Notification
•
Notification is made by pressing the "INFO/G" switch on the panel switches and touching "HELPNET" on the displayed G-BOOK screen.
G-BOOK Screen






In the following cases, the emergency notification service may not be available or its quality may be reduced.
•
When the G-BOOK online service contract is not established or has expired, or when the service start operation has not been performed after application and registration.
•
When communication is not possible due to a malfunction of HELPNET compatible equipment or vehicle-related equipment.
•
When a center position determination error occurs.
•
When communication is not possible due to a malfunction of the center system.
•
When communication is not possible due to the communication network used by the emergency notification system.
•
When service is interrupted or suspended for reasons of the emergency notification provider.


Precautions
•
During emergency notification, HELPNET has priority, so the cellular phone cannot be used from the HDD navigation system.
•
If emergency notification starts while the cellular phone is in use, use of the cellular phone is stopped.
•
Depending on radio wave conditions, emergency notification and calls may not be possible.
•
Outside the cellular phone service area, emergency notification is not possible even if the emergency notification operation starts. If emergency notification is not possible, make the report from the nearest public telephone, etc.
•
In a vehicle collision, if equipment necessary for communication malfunctions or is damaged, emergency notification and calls may not be possible.
•
Emergency notification may not be possible if the battery voltage drops or the connection to the battery is cut.
•
While waiting for rescue after emergency notification, move to a safe place where conversation with the center is possible.
•
Perform emergency notification by button operation after stopping the vehicle in a safe place.
•
Do not use functions that restrict outgoing or incoming calls (dial lock, etc.) as they will interfere with emergency notification. The functions that interfere with emergency notification differ depending on the telephone or communication carrier used.

G-BOOK and Navigation Linked Functions




Function Outline
•
By linking the navigation with the G-BOOK online service, road conditions such as congestion are provided in real time. Main functions include G Route Search (with probe information) and congestion prediction information.


G Route Search (with Probe Information)
•
Comprehensively predicts future road conditions from the latest road traffic information by VICS information and probe communication traffic information and from past statistical data, and searches for and guides an optimal route that avoids congestion.


Congestion Prediction Information
•
Displays predicted congestion time, predicted congestion increase/decrease, etc. based on congestion prediction information from the G-BOOK Center.
Congestion Prediction Information


Service Name
Service Contents
Area Check
Predicts the latest road traffic information for expressways around the current location and road conditions up to 90 minutes ahead, displays future congestion on an easy-to-understand simplified map on the navigation screen and provides voice guidance.
Route Check
Predicts the latest road traffic information for expressways, main toll roads and some general roads on the route to the destination and road conditions up to 90 minutes ahead, displays it on an easy-to-understand simplified map on the navigation screen and provides voice guidance.
Time Required Check
Simulates, based on congestion prediction, the time required to the next expressway exit when taking a break (30 or 60 minutes) at an expressway service area, and clearly displays the difference in driving time for each break time.
