Related Parts


DLC3 (Data Link Connector No.3)

●
By connecting the diagnostic tool "TaSCAN" to the vehicle side connector (DLC3: Data Link Connector No.3), each ECU can be accessed via the gateway computer and the various multiplex communication lines. This allows output of DTCs, data monitoring (checking ECU data, etc.), Active Test (driving actuators as desired), customization (setting control programs), etc. For details, refer to the Repair Manual.
