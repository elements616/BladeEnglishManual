HDD Navigation System

●
An HDD (hard disk drive) is installed in the multi-display, and a newly adopted sound library function can record approximately 100 CDs to the hard disk by inserting CDs.
●
By adopting a CD text display function, information pre-entered on the CD being played (artist name, track name, etc.) can be displayed. In addition, a built-in MDLP (Long Play) compatible MD player enables playback of MDs recorded on MDLP compatible decks, etc., providing excellent functionality.
●
CDs recorded in WMA (Windows Media Audio) and MP3 (MPEG Audio Layer 3) formats can be played, improving marketability.
●
An automatic sound levelizer function has been adopted, providing excellent usability.
●
Serviceability has been improved by adopting a IEEE1394 standard HDD update connector.
HINT
*
Depending on the device used for recording, some CD-Rs and CD-RWs may not play.
