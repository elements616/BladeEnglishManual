Outside Temperature Display Specifications


Display Range
-40~50℃
Function
The outside temperature data input from the ambient temperature sensor is corrected using the vehicle speed signal data input from the skid control computer, and a more accurate outside temperature is calculated and displayed.
When the outside temperature is below -40°C, -40°C is displayed.
When the outside temperature is 50°C or higher, 50°C is displayed.
If a communication malfunction or input signal malfunction occurs, bars (--) are displayed.
