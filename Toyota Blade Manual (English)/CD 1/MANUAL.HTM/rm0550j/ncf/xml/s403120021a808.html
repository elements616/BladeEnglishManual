HDD Navigation Functions

●
GPS (Global Positioning System) voice navigation determines the vehicle's position and displays it on the map, and provides route guidance information to the destination by screen display and voice guidance.
●
The navigation of the 05 model year HDD navigation system has high marketability through improved map screen appearance, shorter processing time for searches, etc., and the adoption of new functions.
Current Position Display Function


•
The vehicle position detected by GPS navigation is combined with the vehicle speed signal from the combination meter and road map data from the navigation computer, etc., and is displayed as a mark on the map screen.
•
When position information from GPS satellites is being used, a "GPS" mark is displayed below the direction mark at the upper left of the screen.
•
When VICS information to be displayed on the map is received, the information provision time can be displayed below the "VICS" mark as a VICS time stamp.

•
An "inclination angle sensor" has been adopted, enabling determination of entering/exiting elevated roads and entering/exiting multi-level or underground parking garages, for which accurate map matching was difficult with conventional navigation systems. In addition, urban expressway entrance gradient data and underground parking garage road data have been newly added to the HDD (hard disk) map data, improving current position display accuracy.


Main Map Display Functions




Map Scale
•
Maps from 1/20480,000 to 1/5000 scale can be displayed, and in areas with city maps, city maps at 1/2500 scale can be displayed.
•
The scale is changed by touching the "Detail" or "Wide" switch displayed on the screen. In addition, the scale can be selected directly by touching the 13-step scale gauge that appears when the "Detail" or "Wide" switch is touched.


Map Movement (Scrolling)
•
On the current position display screen, touching an area where no touch switch is displayed displays the cursor keys; touching the cursor key in the direction in which the map is to be viewed scrolls the map. The name of the place near the center of the screen can be displayed while the map is scrolling.


Map Orientation
•
The map orientation can be switched between north-up display (north is always at the top regardless of the direction of travel) and heading-up display (the direction of travel is always at the top). The display is switched by touching the direction mark displayed on the map screen.


Front Wide Display
•
The map in the direction of vehicle travel can be displayed over a wider area. The display can be switched in "Settings" on the menu screen.


Map Color Change
•
The map color can be selected from 5 types (Normal, Fresh, Cool, Chic and Warm).


3D Display
•
The map can be displayed three-dimensionally. The viewing angle in 3D display can also be adjusted. Switching to 3D display can be done with "Change Display" on the map display screen.


2 Screen Display
•
The screen can be split into 2 parts, left and right, and the left and right screens can show maps of different scales, or 3D display and north-up display, etc. In addition, settings such as map orientation and facility display can be switched independently on the left and right screens. The display can be switched with "Change Display" on the map display screen.


City Map Display
•
When the current position is within a city map display area and the 1/5000 scale screen is displayed, touching "City Map" on the screen displays a detailed city map (1/5000 scale or 1/2500 scale). When the display is switched to the 1/2500 scale city map during 3D display, a real city map display showing buildings three-dimensionally can be shown in addition to the city map display.


Visual Map
•
In the map display, the width of roads on the map changes according to the actual road width, and landmarks on the map are displayed three-dimensionally in multiple colors. The display can be turned ON/OFF from "Settings" on the menu screen.


3D Landmark Display
•
Three-dimensional facility marks can be displayed while a map screen at 1/80,000 scale or more detailed is displayed.


Prefecture Border Guidance Display
•
When a prefectural border is crossed, the prefecture mark can be displayed on the map screen with voice guidance.


Parking Lot Map Display
•
If parking lot map information exists in the road map data, it can be displayed when entering that parking lot.


Facility Display
•
Facilities selected while a map screen at 1/80,000 scale or more detailed is displayed can be shown on the map screen as marks and text. Touching "All Genres" on the screen allows up to 5 facility genres to be displayed at the same time.


Urban Expressway Highway Map
•
When a map at 1/20,000 scale or wider and 1/160,000 scale or more detailed is displayed, the roads shown can be limited to urban expressways (Metropolitan Expressway, Hanshin Expressway, Nagoya Expressway), and interchanges, junctions and route numbers can be displayed.
•
The display is turned ON/OFF with "Change Display" on the map display screen.


Seasonal Leisure Landmarks
•
While a map screen at 1/80,000 scale or more detailed is displayed, seasonal leisure landmarks (e.g. famous cherry blossom spots from 2 to 4, famous autumn foliage spots from 9 to 11) can be displayed on the map screen.


Expressway Route Map
•
When driving on an expressway, a simplified route map of the road can be displayed. It is also displayed for entry/exit IC designation and traffic congestion prediction.

Screen Display Settings




Switch Display Settings
•
The touch switches displayed on the map screen can be shown or hidden by touching the "ON" and "OFF" switches. Touch switches not to be displayed can be selected individually.
•
The display is switched from "Settings" on the menu screen.

Registration


•
500 memory entries (400 memory points and 100 G memories) and 10 detour memory points can be registered, modified and deleted. In addition, names and telephone numbers can be entered and the mark display can be selected.

Main Route Guidance Functions


•
When a destination is set, the guidance route from the current position to the destination is displayed and route guidance is provided by voice.
•
To start route guidance, touch "Start Guidance" on the screen after the route search is completed. Alternatively, if the vehicle is driven for approximately 3 seconds without any operation after the entire route display screen ends, route guidance to the destination starts.


Destination Setting
•
Pressing the "Destination" panel switch changes to the destination setting screen, and the destination can be set by searching for it using the methods in the "List of Map Call-up Methods" above. In addition, multiple destinations (up to 5) can be set, and the order of the multiple destinations can be changed.
Destination Setting Screen






5-route Simultaneous Search
•
5 routes are searched at the same time, and the guidance route can be selected from recommended route, toll road priority, ordinary road priority, distance priority and alternative route. The 5 searched routes are each color-coded and displayed together on the screen, and touching "Entire Route List" on the screen displays the toll (approximate minimum toll), total distance (km) and required time (approximate) when each of the 5 routes is selected.


Route Learning
•
If the driver always takes a road other than the route being guided to the destination (other than narrow streets: roads 5.5m or wider), after passing along the same other road 3 times, that route is learned and guidance can be given using the learned route in the next route search.


Waypoint Setting
•
Waypoints for route guidance can be set, added, modified and deleted; toll road/ordinary road priority can be set, the departure point can be specified, and the entry/exit interchanges can be specified.


Traffic Congestion Prediction Display Function
•
Displays traffic congestion prediction information obtained by communication from the G-BOOK center.
•
Displays traffic congestion prediction information from now to 90 minutes later on the expressway route map, shows increasing or decreasing congestion trends with icons, and reads out the required travel time, etc.


Detour Area Search
•
By setting areas to be avoided in advance, a route search that avoids those areas can be performed. Up to 10 detour memory points can be registered.


Congestion Bypass Search
•
Searches taking detour roads into account during a surrounding area detour search. The road traffic center database is used for the search.


Surrounding Detour Search
•
When congestion, restrictions, etc. occur ahead and are to be avoided, the route can be changed to one that detours around the 2km ahead of the current position. In addition to roads for which VICS provides congestion information, routes estimated to be more comfortable based on actual vehicle driving data from the road traffic center, etc. are guided.


Intersection Guidance
•
Determines when the vehicle is approaching an intersection during route guidance and displays an enlarged view of the area around the intersection for guidance. Narrow-angle branches such as grade-separated intersections and interchange entrances are shown in 3D for easy understanding.


Real Intersection Enlarged View
•
Displays three-dimensional illustrations for intersections in government-designated cities with narrow-angle branches that are difficult to understand from voice guidance alone.


Turn List
•
The branch points and intersections for which voice guidance is given on the route from the current position to the destination can be displayed as a list.


Frontage Road Guidance
•
Dedicated guidance can be displayed when entering a frontage road from the main lane of an ordinary road. Dedicated guidance can also be displayed when returning from the frontage road to the main lane.


Seasonal Restriction Section Guidance
•
When a route including a section with long-term traffic restrictions (such as winter closures) is searched, the corresponding part of the guidance route is displayed in a different color and a message can be displayed on the screen. The message ON/OFF setting is made in "Settings" on the menu screen.


Highway Treatment of Ordinary Roads
•
For motorways on ordinary roads that lie between expressways or toll roads, guidance such as the expressway schematic, direction guidance and exit guidance is provided in the same way as for expressways.


Highway Mode
•
During route guidance on an expressway, the screen switches to the highway mode screen, on which information on service areas, parking areas and interchanges can be viewed. Also, before an expressway exit interchange or junction (approximately 1km before on intercity expressways and on metropolitan/urban expressways), a junction diagram is displayed for guidance.
•
Even when route guidance is not being performed, the highway mode screen can be displayed on intercity expressways only.


Entry/Exit IC Designation
•
After setting a destination, the exit ICs and entrance ICs displayed on the entire route map screen can be designated one at a time. Also, if an IC with time restrictions on entry/exit is designated, a notification screen is displayed.


Illustration Guidance
•
At the entrances and exits of urban expressways (Shuto Expressway, Nagoya Expressway and Hanshin Expressway), a three-dimensional guidance screen (illustration) is displayed to provide easy-to-understand guidance.


Voice Repeat
•
During route guidance, voice guidance is provided according to the distance to the next junction. Also, by pressing the "Current Position/Voice Guidance" panel switch, the previous voice guidance can be heard again.


VICS Consideration for Estimated Arrival Time
•
For the average vehicle speed used to calculate the estimated arrival time, an estimated arrival time that takes traffic congestion and traffic regulations into account can be displayed, based on the VICS congestion information on the map, the link travel times of beacon information and the predicted information on expressways during G-route guidance (predicted link travel times).


Destination Arrival Guidance
•
When the vehicle approaches the vicinity of the destination, destination arrival guidance is provided by voice.


Continuous Lane Guidance
•
During route guidance, the lanes that can be driven at every intersection on roads with 2 or more lanes can be displayed continuously.


Lane Warning
•
Lane warning provides voice guidance on ordinary roads and urban expressways as follows.
•
Ordinary roads: Voice guidance is provided when the lanes before the intersection ahead include a right-turn-only or left-turn-only lane. However, during destination guidance, voice guidance is provided only when going straight through the intersection.
•
Urban expressways: Voice guidance is provided when there is a lane reduction ahead. (Because lane data is available only for urban expressways.)


G-route Guidance
•
"Traffic information around the current position" and "expressway congestion prediction information" are obtained from the G-BOOK center as wide-area congestion prediction information. Based on this information, the optimum route to the destination is searched.


JUST Guidance
•
During destination guidance, a "♪ding-dong" sound is given just before the intersection at which junction guidance is provided.


Destination Direction Arrow Display
•
During route guidance, if the vehicle position deviates from the guidance route, the direction of the destination is displayed with an arrow.


Frequent Accident Location Warning
•
During route guidance, when the vehicle approaches a location where traffic accidents occur frequently, a frequent accident location mark is displayed on the map screen.


Road Shape Warning
•
During route guidance, when the vehicle approaches a merge, sharp curve or railroad crossing, a road shape warning is given by voice and a road shape mark is displayed on the map screen.


Roundabout Guidance
•
If there is a roundabout on the guidance route, guidance is provided treating the entrance and exit of the roundabout as junctions.


Toll Guidance
•
By setting the vehicle number category (1/3/5/7) in advance, the toll for toll roads is displayed and payment guidance is provided before the tollgate or ticket checkpoint.


On-route Scroll
•
By touching the cursor keys displayed on the screen, the map can be scrolled automatically along the guidance route to the next destination or the next facility (selectable from categories such as gas stations, convenience stores, restaurants, parking lots, banks and post offices). The entire route display is selected with "Change Display" on the map display screen.


Entire Route
•
The entire set guidance route can be displayed together with information on the guidance route such as the total distance and tolls. The entire route display is selected with "Change Display" on the map display screen.


Route Re-search
•
Re-search of the guidance route from around the current position, re-search of the entire guidance route, search condition setting (recommended, toll road, ordinary road, distance priority, alternative route) and alternative road re-search (only when on the guidance route) can be performed.


Automatic Route Re-search
•
During route guidance, if the vehicle position deviates from the guidance route, the guidance route is automatically re-searched and a new guidance route from the current position can be displayed.


Driving Track Display
•
The driving track is displayed on the map as a series of dots. Up to 1000km can be saved at 50m intervals.

Menu


•
By pressing the "Menu" panel switch, the screen changes to the menu screen, where each function can be selected. Note that some functions cannot be operated while driving.

•
The route being guided can be deleted to stop route guidance. Also, after guidance is stopped, the display changes to "Resume Guidance", and guidance can be resumed by touching it.


Volume Settings
•
Voice guidance ON/OFF, volume adjustment and automatic volume switching at high speed can be set.


VICS
•

Congestion Prediction
•
Based on congestion prediction information obtained from the G-BOOK center, congestion prediction marks are displayed on the route.


Memory Point
•
Memory points (including home and special memory points) and detour memory points can be registered, modified and deleted, and the destination history can be deleted.

•

Other Functions




Heartful Voice
•
Voice messages such as "Thank you for driving. ", "Today is ○ month × day, △ day of the week. " can be given when arriving home or getting into the vehicle. The heartful voice ON/OFF setting is made in "Settings" on the menu screen.
•
Voice guidance can be given even while a screen other than the navigation mode is displayed, as long as route guidance is in progress.
•
Under the following conditions, voice guidance may not be given even if the heartful voice is turned ON in the settings.
HINT
*1
When arriving home, if the heartful voice has already been output once, voice guidance is not given unless ACC is turned OFF and then ON.
*2
If ACC is turned ON within a 500m radius of home, voice guidance is not given.
*3
If home is set as an intermediate destination, voice guidance is not given.
