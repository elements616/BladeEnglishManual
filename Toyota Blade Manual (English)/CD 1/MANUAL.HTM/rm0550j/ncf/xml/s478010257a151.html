Oil Filter

●
A replaceable element type oil filter has been adopted. The element uses high-performance filter paper to ensure sufficient filtration performance and is fully combustible.
●
The cap is made of aluminum alloy for longer life.
●
A drain structure is provided to prevent oil from splashing when the oil filter element is replaced, improving serviceability.
