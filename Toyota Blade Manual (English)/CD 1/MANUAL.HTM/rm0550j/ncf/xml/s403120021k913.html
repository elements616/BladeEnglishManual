HDD Navigation System Outline

●
The 05 model year HDD navigation has been adopted.
●
The HDD navigation has a variety of multimedia functions made possible by the adoption of a large-capacity HDD (30GB) to improve convenience, and achieves a clearer display by rendering the screen in 32000 colors.
●
A Bluetooth* -compatible antenna is built into the multi-display, allowing hands-free calling without connecting a cable or cradle when a Bluetooth-compatible cellular phone is used, for excellent usability.
HINT
*

Bluetooth is a registered trademark of Bluetooth SIG, Inc.

●
The HDD navigation links with the network using a Bluetooth-compatible cellular phone, allowing use of the next-generation telematics service "G-BOOK ALPHA" and hands-free calling. Also, a variety of functions have been adopted for the navigation, information mode, etc., realizing a highly convenient audio & visual system.
●
By installing a G sensor in the HDD navigation, more precise position correction is possible.
●
A sound library function that can store up to 13.9GB minutes of music data on the built-in HDD has been installed to improve marketability.
●
By adopting a IEEE1394-standard HDD update connector, map data and other updates can be performed without removing the map hard disk drive (HDD) from the vehicle, for excellent convenience.

HDD Navigation System Main Components


Components
Main Functions
HDD Navigation
Integrated with the navigation computer; controls the HDD navigation system and displays various screens on the multi-display.
Built-in Parts
Display Panel
Displays the map screen and operation screens using video signals from the main computer, and the TV broadcast screen using video signals from the TV tuner.
Outputs input operation signals to the main computer.
Main Computer
Adjusts the color balance of the display screen.
Controls each display and function of the HDD navigation system according to the input operation signals.
Calculates the vehicle position, direction of travel and distance traveled using the "position signal" from the GPS receiver, the "vehicle acceleration/deceleration data" from the G sensor, the "vehicle angular velocity data" from the gyro sensor and the "vehicle speed signal" from the combination meter.
Converts FM multiplex broadcast signals (DGPS signals) and VICS road traffic information with the built-in FM multiplex decoder and then performs calculation processing.
Outputs the map information data in the HDD and the calculated vehicle position, etc. to the display panel as video signals.
Outputs navigation voice guidance signals to the front speaker RH.
TV Tuner
Receives and tunes the TV broadcast signals output from the TV antenna amplifier with selector, and outputs video signals to the main computer and audio signals to the speakers via the built-in amplifier.
GPS Receiver
Demodulates signals from the GPS antenna and outputs them to the main computer.
G Sensor
Detects vehicle acceleration/deceleration and outputs it to the main computer.
Gyro Sensor
Detects vehicle angular velocity and outputs it to the main computer.
HDD (Hard Disk) Unit
Reads the data stored on the map HDD (hard disk) and outputs it to the main computer.
HDD Update Connector
Map data updates, etc. can be performed by connecting an update tool to the connector.
Integrated Antenna
Receives the orbit signals and signal transmission time signals continuously transmitted from GPS satellites placed in orbits surrounding the earth at an altitude of approximately 2 × 10,000 km, and outputs them to the GPS receiver.
Transmits and receives ETC system radio waves.
TV Antenna
TV broadcast signals are received by 4 pattern antennas, with 2 systems each located in the back window glass and in the rear spoiler.
TV Antenna Amplifier with Selector
Switches to the 4 TV antenna signals with good reception, amplifies the 1 TV antenna signals with good reception sensitivity and outputs them to the TV tuner.
Speaker
Outputs navigation voice guidance and audio/TV sound.
Combination Meter
Outputs the vehicle speed signal (pulse signal) to the multi-display.
Taillight Relay
Outputs the taillight ON signal to the multi-display.
Parking Brake Switch
Outputs the parking brake ON signal to the multi-display.


HINT
*
Factory option on all models. GPS antenna (GPS function only) as standard equipment.
