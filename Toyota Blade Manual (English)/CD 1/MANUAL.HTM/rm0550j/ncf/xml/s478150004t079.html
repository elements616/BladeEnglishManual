Smart Back Door Open Control

•
With the power OFF (ACC and IG OFF), driver door closed and driver door unlocked, the key cancel function can be set by performing the operations below.

Key Cancel Operation Procedure

Procedure
Operation
Prerequisites
Driver door closed and unlocked, power OFF (IG and ACC OFF)
Operation 1
Perform wireless unlock 1 times
Operation 2
Open the driver door within 5 seconds of operation 1
Operation 3
Perform wireless unlock 2 times within 5 seconds of performing operation 2*1
Operation 4
Within 30 seconds of performing operation 3, repeat driver door "open" → "closed" 2 times and open it again (driver door "open" → "closed" → "open" → "closed" → "open")
Operation 5
Perform wireless unlock 2 times within 30 seconds of performing operation 4*1
Operation 6
Within 30 seconds of performing operation 5, repeat driver door open → closed 1 times and open it again (driver door "open" → "closed" → "open")
Operation 7
Close the driver door within 5 seconds after performing operation 6*2

HINT
*1
If a driver door "open" → "closed" operation occurs during operations 3 and 5, the cancel function is aborted.
*2
To return from the key cancel state to a state in which the Smart Entry & Start System can be used, perform the above "key cancel operation procedure" again.

Related Parts


DLC3 (Data Link Connector No.3)

●
By connecting the diagnostic tool "TaSCAN" to the vehicle side connector (DLC3: Data Link Connector No.3), each ECU can be accessed via the gateway computer and the various multiplex communication lines. This allows output of DTCs, data monitoring (checking ECU data, etc.), Active Test (driving actuators as desired), customization (setting control programs), etc. For details, refer to the Repair Manual.
