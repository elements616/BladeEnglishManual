HDD Navigation System Outline

●
The 05 model year HDD navigation system has been discontinued and the 09 model year HDD navigation system has been adopted.
●
Navigation, information, audio and other screens are switched and displayed on the 7-inch wide-screen multi-display, and those operations can be performed with the HDD navigation system.
●
Building the navigation computer and a 40GB large-capacity HDD (hard disk drive) into the HDD navigation receiver assembly simplifies the system and makes it possible to provide a wide variety of multimedia functions.
●
Wireless communication system "Bluetooth"* 1is supported, and when using a Bluetooth compatible cellular phone, hands-free calls can be made without connecting a cable or cradle, providing excellent usability.
●
The HDD navigation works with a Bluetooth* 1compatible cellular phone connected to the hands-free system, allowing use of "G-BOOK mX" and hands-free calls.
●
Door to Door guidance has been adopted, providing voice guidance up to the end point of the route on narrow streets. In addition, at the end point of the route, the location of the destination is announced by voice guidance.* 3
●
Convenience has been improved by adopting "Map On Demand", which can update new map information (only data for areas where roads, etc. have changed) in real time.
●
"Probe Communication Traffic Information", which can display road congestion information not provided by conventional VICS information on the navigation map screen in real time, has been adopted, enabling more optimal route guidance.
●
IEEE1394 standard* 2HDD update connector has been adopted, allowing map data to be updated without removing the HDD from the vehicle, providing excellent serviceability.
●
The analog TV tuner has been discontinued.
●
The system is compatible with the diagnostic tool and outputs diagnostic trouble codes (DTCs), making system inspection easier in the event of a malfunction.

HDD Navigation System Components


No.
Name
Main Functions
①
HDD Navigation
(Manufactured by Panasonic Corporation)
(Navigation Receiver Assembly)
Inputs and processes data from the main built-in parts (display panel, navigation computer, etc.) and components located throughout the vehicle, and displays various information and operating conditions on the multi-display with images and sound.
Multi-display
(Built into HDD navigation)
Displays map screens and operation screens according to video signals from the navigation computer.
Outputs each input operation signal to the navigation computer.
DVD (CD) Player
(Built into HDD navigation)
Plays DVD video, DVD-VR (VR: Video Recording Format, a format for recording copy-protected video), video CDs or CDs.
Navigation Computer
(Built into HDD navigation)
Calculates the vehicle position, traveling direction and distance traveled using the "position signal" from the GPS receiver, the "vehicle acceleration/deceleration data" from the G sensor, the "vehicle angular velocity data" from the gyro sensor and the "vehicle speed signal" from the combination meter.
Converts FM multiplex broadcast signals and VICS road traffic information with the built-in FM multiplex decoder, then performs calculation processing.
Outputs map information data from the map HDD, the calculated vehicle position, etc. to the display panel.
Outputs navigation guidance voice signals to the speakers.
G Sensor
(Built into HDD navigation)
Detects vehicle acceleration/deceleration and outputs it to the navigation computer.
Gyro Sensor
(Built into HDD navigation)
Detects vehicle angular velocity and outputs it to the navigation computer.
GPS Receiver
(Built into HDD navigation)
Demodulates the orbit signals received by the GPS antenna, calculates the vehicle position and outputs the position signal to the navigation computer.
Map HDD
(Built into HDD navigation)
Stores map information data, guidance voice data and destination search data on the HDD.
②
Integrated Antenna
(Manufactured by DENSO Corporation)
(Navigation Antenna Assembly)
Receives orbit signals from GPS satellites placed in orbit around the earth at an altitude of approximately 2 × 10,000 km and outputs them to the GPS receiver.
Transmits and receives ETC system radio waves.
③
Speakers
Output navigation guidance voice and audio sound.
④
Parking Brake Switch
Outputs the parking brake ON signal to the HDD navigation.
⑤
Combination Meter
Outputs the vehicle speed signal to the HDD navigation.
⑥
Neutral Start Switch
Outputs shift position "R" to the HDD navigation.
⑦
Steering Switch
(Steering Pad Switch Assembly)
Outputs signals for volume adjustment, mode switching, hands-free operation, etc. to the HDD navigation.
⑧
Voice Recognition Microphone
Built into the map lamp; picks up spoken voice during hands-free calls and voice operation.
⑨
Toll Collection (ETC) Computer Assembly
Outputs ETC system usage status and other information to the HDD navigation.
⑩
Radio Antenna
Receives FM and AM radio broadcast waves and outputs them to the HDD navigation.
⑪
USB Terminal and AUX Input Terminal
(Stereo Jack Adapter Assembly NO.1)
Outputs audio signals to the HDD navigation when a portable audio device is connected.
Performs USB communication with the multimedia interface computer when a USB memory or "iPod" is connected.
⑫
Multimedia Interface ECU
When a USB memory or "iPod" is connected, communicates with the connected device via the USB terminal and outputs audio signals to the HDD navigation.
⑬
DLC3
Diagnoses the system in the event of a malfunction using the diagnostic tool.
