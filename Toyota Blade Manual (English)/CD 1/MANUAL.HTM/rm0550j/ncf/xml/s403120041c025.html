Intelligent Parking Assist System Function Outline

●
Intelligent parking assist is a system that assists reversing by synthesizing guide lines such as distance guide lines, vehicle width extension lines and estimated course lines onto the image from the rear view monitor camera installed at the rear of the vehicle and displaying it on the display screen of the HDD navigation system, while outputting voice guidance and controlling the steering.
●
When the shift position is moved to "R" (reverse) with the power source position (IG) ON, the screen changes to the intelligent parking assist screen (when intelligent parking assist is selected with the touch switch on the display screen), and the image behind the vehicle from the rear view monitor camera is displayed on the display screen.
●
By pressing the touch switch on the HDD navigation display, intelligent parking assist mode and back guide monitor mode can be switched.
■ NOTICE ■
Intelligent parking assist is not an automatic parking device but a device that assists steering operation when reverse parking, so always drive while directly visually checking the safety behind and around the vehicle.

Intelligent Parking Assist Display Range


•
The area behind the vehicle is displayed within the range shown in the illustration. The displayed range may differ depending on the vehicle and road surface conditions.
•
Note that the range displayed on the screen by the rear view monitor camera is limited, and objects near either corner of the bumper or under the bumper are not displayed.


Intelligent Parking Assist Operation


•
By pressing the assist mode ON/OFF switch located at the upper left of the display screen of the HDD navigation system, switching between the intelligent parking assist function and the back guide monitor function* can be performed.
HINT
*
When the intelligent parking assist function is active, the indicator light in the assist mode ON/OFF switch illuminates yellow.


Modes and Selection Operations


•
Intelligent parking assist has 3 types: "course display mode", which displays the reversing course and guide lines on the display screen of the HDD navigation system, and "parallel parking assist mode" and "garage parking assist mode", which display the reversing course and guide lines and assist steering operation according to the display on the screen; the function can be selected according to the purpose.

Course Display Mode


•
When the shift position is moved to "R" (reverse) with the power source position (IG) ON, the image behind the vehicle and each mode switch are displayed on the display screen of the HDD navigation system, and the lines needed for guidance are synthesized and displayed on the screen.

Parallel Parking Assist Mode


•
In intelligent parking assist mode, touching "Parallel Parking" on the screen while the course display mode screen is displayed switches to parallel parking assist mode, in which the image behind the vehicle and the lines needed for parallel parking are synthesized and displayed on the screen, and steering operation is assisted to support parallel parking.


When Setting Target Parking Position
•
After parallel parking assist mode is selected, the screen changes to the target position setting screen, and the parking position is set by operating the arrow switches on the screen, referring to the image behind the vehicle and the displayed guide lines.
•
If the confirm switch is touched when the target parking position is (too far/too close), the message "Please start a little (closer to/farther from) the parking space" is displayed. When the vehicle is moved to a position where the target parking position can be set, a beep sounds to prompt the driver to stop the vehicle. Check the target parking frame and, if there is no problem, touch the reconfirm switch.

During System Operation
•
After the target parking position is confirmed, touching "OK" on the displayed precautions screen switches to the system operation screen, and parking assist by intelligent parking assist is performed. During system operation, keep your hands on the steering wheel, directly check the safety behind and around the vehicle, and reverse slowly while adjusting the speed by depressing the brake pedal. Also, when the vehicle enters the target parking position, voice guidance is output and system operation ends. For safety, the voice guidance is output before the target parking position is reached. Since system operation also ends at that time, firmly grip the steering wheel and reverse slowly while adjusting the speed by depressing the brake pedal to park in the desired position.

Garage Parking Assist Mode


•
In intelligent parking assist mode, touching "Garage Parking" on the screen while the course display mode screen is displayed switches to garage parking assist mode, in which the image behind the vehicle and the lines needed for garage parking are synthesized and displayed on the screen, and voice guidance and steering operation assistance are provided to support garage parking.


When Setting Target Parking Position
•
After garage parking assist mode is selected, the screen changes to the target parking position setting screen, and the parking position is set by operating the arrow switches on the screen, referring to the image behind the vehicle and the displayed guide lines.

During System Operation
•
The basic operation and screen display contents after the target parking position is confirmed are the same as in parallel parking assist mode.

Help Function


•
In intelligent parking assist mode, touching "Help" on the screen while the parallel parking mode screen or garage parking mode screen is displayed switches to help mode, where explanation screens for "How to stop the vehicle" and "How to align the parking frame" for each parking mode can be displayed.

Intelligent Parking Assist Setting Screen


•
Touching "Vehicle Surroundings Monitor" on the information mode screen of the HDD navigation system switches to the intelligent parking assist setting screen, where settings related to intelligent parking assist can be made.

Message Display Function


•
In situations where intelligent parking assist cannot be used, a message such as "IPA currently unavailable" is displayed in the center of the screen to inform the driver that the system cannot be used.
•
In situations where the target parking position cannot be set, a help message for setting it properly is displayed in the center of the screen to inform the driver.

Diagnosis Function


•
A diagnosis function is provided to make system inspection easier. Diagnosis results are output as diagnostic codes using a service tool.
