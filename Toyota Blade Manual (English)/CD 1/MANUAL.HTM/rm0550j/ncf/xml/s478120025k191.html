Tachometer

Tachometer Specifications


Indication Range
0 to 8000r/min (200r/min increments)
Red Zone Range
6400~8000r/min
Movement
Stepper Motor


Tachometer Operation


•
Based on the engine speed signal (CAN communication) input from the engine control computer, the meter computer controls the rotation angle, speed and direction of the pointer with the stepper motor driver circuit to indicate the engine speed.
•
The meter computer performs initialization control that returns the pointer to the zero position each time power is supplied to the combination meter.
