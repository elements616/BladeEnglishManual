Smart Entry & Start System

●
The Smart Entry & Start System is used to dramatically improve convenience and to showcase advanced technology.
●
The Smart Entry & Start System allows various controls to be performed without handling the electronic key, based on the result of electronic ID code verification by wireless communication between the electronic key and the vehicle.
●
A warning function is provided to warn in advance of several problems that can occur when the user becomes less conscious of carrying the electronic key, providing excellent usability.
●
A key cancel function is provided so that the user can stop the Smart Entry & Start System control as desired. When canceled, Smart Entry & Start System control stops, but door lock/unlock by the wireless door lock/unlock function does not stop.
●
An identification code registration function is used, allowing multiple electronic keys to be used.
■ NOTICE ■
The electronic key emits weak radio waves. Persons using a pacemaker should check the instruction manual of the pacemaker before use.
Persons using an implanted cardiac pacemaker or implanted defibrillator should not come within approximately 22cm of the outside antennas or inside antennas. The radio waves may affect the operation of implanted cardiac pacemakers and implanted defibrillators.
The smart function does not operate under the following conditions.
When smart control has been canceled with the key cancel function
When the electronic key battery is depleted (the indicator light does not blink/illuminate when any button on the key is pressed)

Smart Entry & Start System Outline


•
Based on the result of ID code verification between the electronic key and the vehicle, etc., the certification ECU communicates with the main body ECU, ID code box, steering lock ECU, etc. via LIN communication to control the system.
•
Depending on the function to be performed, the certification ECU outputs request signals to the inside/outside antennas to perform "ID code verification with the electronic key" and "position confirmation of the electronic key (or key holder)". Then, when it receives the ID code including the response code from the electronic key that received this request signal, it performs identification/verification and sends operation command signals to each ECU according to the function.


Smart Entry & Start System Detection Areas


•
Request signals sent from the certification ECU are transmitted from the antennas via each oscillator, forming the electronic key detection areas. The detection areas formed by the outside antennas and the luggage room outside antenna extend approximately 0.7 to 1.0m from the front door outside handles and the center of the rear bumper.
•
The detection area of the outside antennas is formed by request signals transmitted periodically approximately every 0.25 seconds while parked (engine switch OFF, doors locked), sensing the approach of the electronic key (key holder). In addition, when locking the doors, it is formed when the lock switch is ON, detecting that the electronic key (key holder) is outside the cabin.
•
The detection area of the luggage room outside antenna is formed when the back door lock/opener switch is ON.
•
The cabin detection area is formed when the driver/front passenger door is opened or closed, when the brake is depressed, when the power mode changes, when the conditions for various warnings are met, and when the lock switch is ON, detecting that the electronic key (key holder) is in the cabin.
•
Using the customize function, either "engine can be started in the detection area of the indoor antennas (front and rear)" or "engine can be started in the detection areas of the indoor antennas (front and rear) and the luggage room inside antenna" can be selected.
■ NOTICE ■
Depending on the vehicle body shape, there are places where the electronic key does not operate easily.
Even if the electronic key is within the outside key detection area, it may not be detected properly if it is near the windows, door outside handles, center of the rear bumper, etc.
Even if the electronic key is within the cabin key detection area, it may not be detected properly if it is on the instrument panel, in the glove box or on the floor.
Depending on how the electronic key is held, it may not operate easily.
Under the following conditions, the electronic key detection area may become narrower or the electronic key may not be detected properly.
When the electronic key battery is depleted
When there are facilities that generate strong radio waves nearby, such as a TV tower, power plant, broadcasting station or gas station
When carrying the electronic key together with a wireless communication device such as a radio transceiver or cellular phone
When the electronic key is covered by or in contact with a metal object
When a radio wave type keyless entry system is being operated nearby
When placed near equipment that generates high voltage or noise




Ignition Function


•
When carrying the electronic key in the cabin detection area, the power mode can be changed by pressing the engine switch in combination with brake operation. In addition, if the electronic key battery is depleted, the same function operates by touching the key ornament to the engine switch and operating the brake pedal and engine switch within 5 seconds after a beep sounds.
•
When the engine switch is pressed without depressing the brake pedal, the power mode changes in the order OFF → ACC → IG ON → OFF → (repeat).
•
When the engine switch is pressed while depressing the brake pedal with the shift position in "P" or "N", the engine starts.
•
When the vehicle is stopped and the engine switch is pressed with the shift position in "P" while the engine is running, the power mode changes to OFF. When the shift position is in any position other than "P", it changes to ACC.



Emergency Start Control
•
If the engine start conditions are not met due to a malfunction such as a blown stop light fuse or a faulty stop light switch, the engine can be started by moving the shift position to "P", setting the power mode to "ACC" with the engine switch, then depressing the brake pedal and pressing and holding the engine switch for approximately 15 seconds or more.
■ NOTICE ■
Do not start the engine using the above method except in an emergency.


Warning Function


•
Because of its convenience, the Smart Entry & Start System may cause the driver to become unaware of the key. As a result, problems such as "not noticing that the electronic key has been taken outside the cabin (taken out by a passenger)", "the driver exiting the vehicle with the engine running" and "the driver exiting the vehicle with the shift position in a position other than "P"" may occur.
•
The warning function prevents these problems by warning the driver and passengers with the meter display, the built-in single-tone buzzer in the meter and the wireless answer-back buzzer before such situations arise.

Power Saving Function


Vehicle Battery Power Saving Function


•
Because the Smart Entry & Start System forms the outside detection area by periodically transmitting request signals every 0.25 seconds, the vehicle battery may become discharged if the vehicle is left unused for a long time. Therefore, the following controls are provided to prevent battery discharge.
•
If there is no response from the electronic key for 5 days or more, the periodic transmission interval of request signals is extended to 0.75 seconds.
•
If there is no response from the electronic key for 14 days or more, periodic transmission of request signals (formation of the detection area) is stopped.


Electronic Key Battery Power Saving Function


•
Even if the lock or unlock button on the electronic key is held down, transmission stops automatically after approximately 20 seconds.
•
If the electronic key is left in the outside detection area for a long time, the electronic key continues to transmit the ID code to the indoor tuner, which may discharge the electronic key battery. Therefore, the following controls are provided to prevent battery discharge.
•
If the electronic key is in the outside detection area for 10 minutes or more, periodic transmission of request signals (formation of the detection area) is stopped.


Return Conditions


•
When any of the following conditions is met, the system returns from power saving control to normal Smart Entry & Start System control.
•
Door lock/unlock by the wireless remote control function.
•
Door lock/unlock by inserting the mechanical key into the driver door key cylinder.
•
Door lock by the smart door lock function.

Immobiliser Function




Setting the Immobiliser System
•
When the power is changed from ON (ACC or IG ON) to OFF (ACC and IG OFF), the security indicator light in the air conditioning control panel blinks continuously at an interval of approximately 2.0 seconds (0.2 seconds ON, ON/1.8 seconds OFF), indicating that the immobiliser system is set. The security indicator light is controlled by the certification ECU.


Unsetting the Immobiliser System
•
As a result of verification* , only when the ID code matches is the immobiliser system unset; when the engine switch is pressed, the security indicator light turns off and engine starting is permitted.
HINT
*
When the key battery is depleted, touching the electronic key to the engine switch causes electromagnetic waves to be generated (a magnetic field to be formed) around the engine switch. This causes the electronic key to transmit its ID code, and the certification ECU verifies it against the registered ID codes.

Key Set Specifications


•
The standard key set includes 2 electronic keys.

Auto Power OFF


•
Even if a button on the electronic key is held down, transmission of the weak radio waves stops after approximately 20 seconds.

Identification Code Registration Function


•
By registering the transponder ID code, electronic key ID code and transmitter identification code in the verification ECU, the system can accommodate the use of multiple electronic keys, etc. (For the methods of adding, rewriting, checking and prohibiting identification codes, refer to the Repair Manual.)

Transmitter Operation Indicator Light


•
The operation indicator light (LED) illuminates not only during button operation but also during communication (transmission) for ID verification, allowing the operating condition and battery depletion to be checked.

Engine Switch

●
The switch has a built-in indicator light, and the current power mode can be checked by its illumination state and color.
