Spark Plug

●
High-ignitability iridium spark plugs have been adopted.
●
A thin needle-shaped iridium alloy is used for the center electrode and a thin needle-shaped platinum alloy for the ground electrode. Because iridium alloy has extremely high wear resistance, the center electrode can be made thinner, enabling more reliable ignition.
●
A long-reach type* is used to improve ignition performance and optimize the cylinder head coolant passages around the spark plugs.
HINT
*
Conventional spark plugs can also be installed, but they are not interchangeable. In addition, if long-reach plugs are installed in an engine that uses conventional spark plugs, they may interfere with the pistons, so always install the specified spark plugs when replacing the plugs.
