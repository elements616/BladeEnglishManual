Warning Indicator Active Circuit

●
An "active circuit" has been adopted, which illuminates the operation/warning light of the relevant system under the control of the meter if a wiring malfunction or communication malfunction occurs in the connection between the combination meter and some computers.
●
If a wiring malfunction, such as a partially engaged connector, pinched wire harness or open circuit, or a communication malfunction occurs between the combination meter and each system, the active circuit indicates the malfunction by illuminating the operation/warning light of the relevant system under the control of the meter.

Warning Indicator Active Circuit Operation


•
Normally, each computer detects the operating state of or a malfunction in its own system and sends an operation/warning light illumination request signal to the meter computer via CAN communication to illuminate the warning light of the relevant system.
•
If a communication malfunction is detected in the transmission path of the operation/warning light illumination request signal, the meter computer itself illuminates each operation/warning light according to the malfunction detection state.
