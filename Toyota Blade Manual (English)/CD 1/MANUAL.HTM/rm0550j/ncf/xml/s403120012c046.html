Non-standard Size AM/FM Electronic Tuner with Integrated In-dash CD Changer

●
An irregular-size in-dash CD changer integrated AM/FM electronic tuner has been adopted and combined with the 6 speaker system.
●
Tone control memory has been adopted. Tone control (bass and treble) values can be stored for each mode (CD, AM, FM, etc.).
●
By adopting a CD text display function, information pre-entered on the CD being played (artist name, track name, etc.) can be displayed.
●
CDs recorded in WMA (Windows Media Audio) and MP3 (MPEG Audio Layer 3) formats can be played* , improving marketability.
●
An automatic sound levelizer function has been adopted, providing excellent usability.
●
Noise has been reduced by digital signal processing of AM/FM reception.
HINT
*
Depending on the device used for recording, some CD-Rs and CD-RWs may not play.
