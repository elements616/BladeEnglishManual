Rear Window Defogger System

●
A rear window defogger has been adopted on cold area specification models. In addition, a rear window defogger with a timer function (approximately 15 minutes) has been adopted.
●
The rear window defogger switch is located in the air conditioning control panel.

Rear Window Defogger Operation


•
When the rear window defogger switch is turned ON with IG ON, the operation request signal is sent to the air conditioning computer via LIN communication. When the air conditioning computer that receives this signal turns the rear window defogger relay ON, the rear window defogger heats up.
