HELPNET


•
The emergency call system HELPNET can be used by touching "HELPNET" on the G-BOOK screen. For details, refer to HELPNET System.


Main Menu


•
By touching "Main Menu" on the G-BOOK screen, the following items can be operated.

Main Menu Item List


Item
Description
G-BOOK.com
G-BOOK.com contents can be viewed and executed.
G Memory Point Information
Facilities saved on G-BOOK.com can be searched and displayed.
Browsing History
The browsing history screen can be displayed.

The bookmark screen can be displayed.
Maintenance Check
A manual maintenance check of HELPNET can be performed.
Disconnect
Data communication with the G-BOOK center can be disconnected.



G-SOUND


•
G-SOUND is a service that makes songs stored on the on-board unit's hard disk (G-SOUND songs) playable by obtaining a license from the G-BOOK center through a usage procedure.
•
Free capsules preinstalled in the on-board unit can be used free of charge.


My Request


•
With My Request, news, weather forecasts, etc. can be requested with a simple operation and the information read aloud by voice.
•
When requests are made by voice recognition, all registered content can be requested even while driving.
•
When using G-BOOK mX without Web registration, the menu is fixed; with Web registration, the menu can be changed, so frequently used services can be registered in advance.


Operator


•
Operator Service* 1is a service that allows the user to talk directly with an operator at the G-BOOK center to request navigation destination setting, facility searches, etc.
•
By touching "Operator" on the screen while the G-BOOK page is displayed, the user is connected to an operator and can talk.* 2
HINT
*1
Use requires Web registration with a paid option of 210 yen/month (tax included). The operator service cannot be used during a HELPNET emergency call or maintenance check.
*2
If ETC voice guidance is given while talking with an operator, the call with the operator is temporarily interrupted and the ETC voice guidance is given. The operator service resumes as soon as the voice guidance ends. If navigation voice guidance is given while talking with an operator, the navigation guidance voice is canceled.


Information Check


•
When the operator service is used from a mobile phone or landline, a message notifying receipt of information is displayed on the on-board unit the next time ACC or IG is turned ON; if it is not displayed, the information can be obtained manually.


Drive Plan


•
If a drive plan is created on the G-BOOK.com or GAZOO.com site from a PC or mobile phone, waypoints and destinations can be set simply by downloading it to the on-board unit. In addition, in conjunction with the map information service* 1, spots searched for using a PC or mobile phone can be registered as G-memory points and set as destinations.* 2
•
Touching "Drive Plan" on the G-BOOK screen and selecting the desired drive plan downloads the drive plan and starts the route search.

HINT
*1
For details, check the G-BOOK site (http://g-book.com/).
*2
When using G-BOOK mX without Web registration, GAZOO membership registration is required.

Map Update


•
Map data can be updated in two ways: "full update", which updates all nationwide map data, and "differential update (Map on Demand)", which partially updates map data via communication* or media (CD-R/DVD-R). For details, refer to Map Update Function.
HINT
*
Bluetooth compatible mobile phone
