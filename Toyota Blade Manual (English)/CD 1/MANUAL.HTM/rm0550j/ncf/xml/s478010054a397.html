Cranking Hold Control

●
Cranking hold control has been adopted on all models.
●
When the start signal (STSW) from the start switch is input, the engine control computer sends a signal (STAR) to the starter relay through the neutral start switch (determining P or N position) to operate the starter. At this time, the engine control computer turns ON the ACC cut (ACCR) to prevent flickering of the meter, clock, audio, etc.
●
After the starter starts operating, the engine control computer continues to output a signal to the starter until it detects that the engine has started running. When it determines that the engine has started running, the engine control computer stops outputting the signal to the starter relay.

Starter

●
A compact, lightweight, high-output, high-efficiency PS (Planetary reduction-Segment conductor motor) starter has been adopted.
●
A rectangular conductor armature coil has been adopted to reduce size and weight.

Armature Coil


•
By using bare rectangular wire for the armature coil, the space factor has been improved, increasing starter torque.
•
The cylindrical commutator has been eliminated, shortening the armature shaft length.


Field Coil


•
Interpolar magnets have been adopted between the field coils. This improves the magnetic circuit and increases the magnetic flux, allowing size reduction and shortening the yoke axial length.
