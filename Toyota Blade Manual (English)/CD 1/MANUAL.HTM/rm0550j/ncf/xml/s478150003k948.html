Outline of In-vehicle Multiplex Communication System

●
As in-vehicle multiplex communication systems intended to simplify the vehicle wire harness and speed up communication, 3 types have been adopted: CAN (Controller Area Network) communication enabling high-speed communication, LIN (Local Interconnect Network) communication enabling low-cost multiplex communication, and AVC-LAN (Audio Visual Communication-Local Area Network) communication for the audio system.

Related Parts


DLC3 (Data Link Connector No.3)

●
By connecting the diagnostic tool "TaSCAN" to the vehicle side connector (DLC3: Data Link Connector No.3), each ECU can be accessed via the gateway computer and the various multiplex communication lines. This allows output of DTCs, data monitoring (checking ECU data, etc.), Active Test (driving actuators as desired), customization (setting control programs), etc. For details, refer to the Repair Manual.
