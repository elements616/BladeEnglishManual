Map Update Function

●
Convenience has been improved by allowing map data to be updated in two ways: "full update", which updates all nationwide map data, and "differential update (Map on Demand)", which partially updates map data via communication or media (CD-R/DVD-R).
●
Differential distribution (Map on Demand) distributes changed road data from the G-BOOK center so that the navigation map data can be updated to the latest information.

*
Bluetooth compatible mobile phone.

Full Update


•
Nationwide map data can be updated at Toyota dealers. For details, refer to HDD Update Connector.
HINT
When a full update is performed, only information that is older than the previous differential update data is updated, and the latest information is retained as is.
■ NOTICE ■
Publication of the latest map software may end without notice. For details, consult a Toyota dealer.
Perform a full update with the navigation system having positioned via GPS and the time determined.


Differential Update (Map on Demand)


•
Differential update (Map on Demand) is a system that distributes data only for changed road sections of expressways/toll roads nationwide, major national roads, and roads around the registered home and set destinations, via communication* or media (CD-R/DVD-R).
•
For differential update, the area that is updated differs depending on the update method.
HINT
*
Bluetooth compatible mobile phone.


Update via Communication
•
Updated manually when using G-BOOK mX (mobile phone connection). However, the first update must always be performed with media (CD-R/DVD-R).


Update via Media (CD-R/DVD-R)
•
Download the data from the G-BOOK.com PC site and copy it to media (CD-R/DVD-R), or order it from the Map on Demand support desk by telephone, and insert the prepared media (CD-R/DVD-R) into the on-board unit.

■ NOTICE ■
After the data download or copy is completed and the map update is ready, the voice message "Map update preparation is complete. " is output. The map is then updated by touching "Map Update" on the map screen. If the power (ACC or IG) is turned OFF before touching it, the map is automatically updated the next time the power (ACC or IG) is turned ON.
If there is a large amount of update data, map update preparation may take 10 hours or more.
If other navigation operations are performed during the map update, it may take even longer.
If operations such as HDD audio playback are performed during the update, the update process may take longer. In particular, the update process is temporarily stopped while recording from a CD to HDD audio, so it takes longer by that amount.
Associated costs such as media (CD-R/DVD-R), shipping and mobile phone/PC communication charges are borne by the customer.
The differential update service is available for 3 years after purchase of the new vehicle. To continue using the service after that, the service can be used for a further 2 years by purchasing the latest map software.


HDD Update Connector


•
An HDD update connector conforming to the IEEE1394 standard, which allows map updates, etc. to be performed by connecting a dedicated HDD map update tool to the connector,* has been adopted. This allows work such as map information updates to be performed without removing the map HDD (hard disk) from the vehicle.
HINT
*
A serial bus standard standardized by the 1394 committee of the IEEE (Institute of Electrical and Electronic Engineers).
