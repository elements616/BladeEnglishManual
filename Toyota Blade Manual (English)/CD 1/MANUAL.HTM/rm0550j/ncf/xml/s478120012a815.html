HDD Navigation System

●
The HDD navigation system has been changed to a 09 model year HDD navigation receiver with audio functions, combined with a 6-speaker system.
●
An HDD (hard disk drive) is installed, and a sound library (music server function) that can record up to 2000 songs to the hard disk by inserting CDs has been adopted.
●
A database function that can obtain song data (album title, artist name, genre name, etc.) using the Gracenote Media Database has been adopted, and linked with the sound library function and text display function to provide excellent functionality.
●
Playback of CDs recorded in WMA (Windows Media Audio) and MP3 (MPEG Audio Layer3) formats* 1is supported.
●
Bluetooth* 2With the audio function, songs stored in Bluetooth portable audio players, including cellular phones,* 3can be played through the vehicle speakers via wireless communication. In addition, songs can be played/stopped, etc. by operating the on-board unit without directly operating the portable audio player.
●
A disc slot-in type DVD player compatible with DVDs and CDs has been adopted, providing excellent usability.
●
A USB terminal for connecting a USB memory or "iPod" and an AUX terminal for connecting portable audio devices have been adopted, improving marketability.
HINT
*1
Depending on the device used for recording, some CD-Rs and CD-RWs may not play.
*2
Bluetooth is a low-power wireless communication system using the 2.4GHz frequency band, whose technology is being standardized by the Bluetooth SIG (Special Interest Group), an organization joined by the world's leading manufacturers in the fields of electrical signals, computers and networks.
*3
Depending on the device, the Bluetooth audio function may not be usable or its functions may be limited.
