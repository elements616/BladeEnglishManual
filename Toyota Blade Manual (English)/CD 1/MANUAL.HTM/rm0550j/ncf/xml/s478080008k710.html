Neural Network Flow

●
The neural network consists of neurons in the input layer, intermediate layer and output layer; the input layer (neurons) processes information such as outside air temperature, solar radiation and room temperature from the switches and sensor outputs and outputs it to the intermediate layer (neurons), the intermediate layer (neurons) adjusts the strength of the connections (weighting) between neurons based on this, and the output layer (neurons) calculates the sum as control values for the required outlet temperature, solar correction, target airflow and outlet mode. Accordingly, the air conditioning computer controls each servo motor and the blower motor according to the control values calculated by the neural network.
