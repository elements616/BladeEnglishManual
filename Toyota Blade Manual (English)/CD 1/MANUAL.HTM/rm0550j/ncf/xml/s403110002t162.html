Radar Cruise Control System Outline

●
A "radar cruise control system" that allows driving with 2 types of control, constant speed control mode and vehicle-to-vehicle distance control mode, has been adopted and provided according to specification.
●
Constant speed control mode is a mode in which the vehicle is driven while keeping the vehicle speed constant.
●
Vehicle-to-vehicle distance control mode is a mode in which, in addition to the function of keeping the vehicle speed constant, the millimeter wave radar sensor assembly determines the presence of a preceding vehicle and the vehicle-to-vehicle distance, and the vehicle follows the preceding vehicle while maintaining an appropriate vehicle-to-vehicle distance according to vehicle speed.
●
Switching between constant speed control mode and vehicle-to-vehicle distance control mode is done by operating the "cruise control main switch" mounted on the right side of the steering wheel.
●
The set vehicle-to-vehicle distance (time) when following a preceding vehicle can be set to 3 levels, "Long", "Middle" and "Short", using the vehicle-to-vehicle distance switch on the steering wheel.
●
The operating status, control mode, etc. of the radar cruise control system are displayed on the "multi-information display" in the combination meter assembly.
●
Brake control is performed automatically when the vehicle gets too close to the preceding vehicle, improving follow-up controllability in vehicle speed control mode. In addition, if the vehicle approaches the preceding vehicle when sufficient deceleration cannot be achieved, the skid control buzzer sounds to warn the driver that driver operation (braking, etc.) is required.
●
In constant speed control mode, the engine control computer controls all system functions; in vehicle-to-vehicle distance control mode, the engine control computer and distance control computer assembly control all system functions.

How to Switch Between Vehicle-to-vehicle Distance Control Mode and Constant Speed Control Mode



Operating Procedure for Using Vehicle-to-vehicle Distance Control Mode

No.
Operation
1
Turn ON the main switch of the cruise control main switch


Operating Procedure for Using Constant Speed Control Mode

No.
Operation
1
Turn ON the main switch of the cruise control main switch
2
Turn ON the MODE switch of the cruise control main switch for approximately 1 seconds or more

●
Switching to constant speed control mode is not possible once any other operation has been performed after the main switch is turned ON, to prevent incorrect operation during control.
●
It is not possible to switch from constant speed control mode to vehicle-to-vehicle distance control mode. Turn the main switch OFF once and operate it again.

Radar Cruise Control System Components Location3




List of Main Functions of Radar Cruise Control System Components3

Components
Main Function
Millimeter Wave Radar Sensor Assembly
Millimeter Wave*Emits radio waves in the band forward, and when a preceding vehicle, etc. is present, receives the radio waves reflected from the rear surface of that vehicle. Based on the frequency change of the received radio waves and electronic scanning, calculates the presence of a preceding vehicle in the own vehicle's lane, the distance to the preceding vehicle, the relative speed, etc., and outputs this data to the distance control computer assembly.
Engine Control Computer
Controls the functions of the radar cruise control system based on signals from each computer and sensor.
Drives the throttle control motor to accelerate/decelerate.
Outputs the system control status to the meter computer.
Throttle Control Motor (Built into Throttle Body Assembly)
Adjusts the throttle control valve to the set opening angle according to signals from the engine control computer.
ABS & Traction Actuator Assembly (Skid Control Computer)
Drives the brake actuator based on signals from the distance control computer assembly to perform brake control.
Outputs a stop light illumination request signal during the above brake control to illuminate the stop lights.
Sounds the skid control buzzer based on signals from the distance control computer assembly.
Neutral Start Switch Assembly
Detects the shift position and outputs a shift position signal to the engine control computer.
Speed Sensor
Detects the wheel speed and outputs a signal to the engine control computer.
Clutch Control Solenoid
Performs shifting according to signals from the engine control computer.

HINT
*
Millimeter waves are radio waves in a very high frequency band from 30GHz to 300GHz, with an extremely short wavelength in a vacuum of 1 to 10mm. Millimeter waves are not easily affected by conditions such as rain, fog or snow, and provide excellent object recognition performance. The millimeter wave radar sensor assembly uses radio waves in the 76GHz band.
