Light Auto Turn Off System

●
A light auto turn off system, which prevents the headlights and taillights from being left on, is standard on all models.
●
The circuit that controls the system is built into the main body ECU (instrument panel junction block assembly).
Light Auto Turn Off System Function


•
When the power switch is turned OFF and the driver side door is opened while the headlights or taillights (including front fog lights and rear fog light) are illuminated with the power switch (IG) ON and the light control switch (HEAD or TAIL) ON or in the AUTO position, the headlights and taillights are automatically turned off.
•
Even if the driver side door is opened with the power switch (IG) ON and then the power switch is turned OFF, the headlights and taillights are automatically turned off.
•
After automatic turn off, the light auto turn off system can be canceled by moving the light control switch from a position other than OFF to OFF, or by turning the power switch (IG) ON.*
HINT
*
If a flashing operation is performed during automatic turn off, the headlights illuminate but the light auto turn off system is not canceled.


Light Auto Turn Off System Operation


•
For the wiring diagram, refer to the operation of the automatic light control system.
Light Auto Turn Off System Operation List


Operation Name
Condition
Basic Operation
Normal Illumination Operation
When the light control switch is turned ON with the power switch (IG) ON.
When the light control switch is turned ON (TAIL or HEAD) with the power switch (IG) ON, the light control switch ON signal is input to the main body ECU (instrument panel junction block assembly). As a result, the main body ECU (instrument panel junction block assembly) outputs the taillight ON signal and, when the headlight switch is ON, drives the headlight relay.
Automatic Turn Off Operation
When the power switch (IG) is turned OFF and the driver side door is opened from the normal illumination operation state.
When the power switch (IG) is turned OFF from the above normal illumination operation state, the main body ECU (instrument panel junction block assembly) keeps each light illuminated. When the driver side door is opened from this state (driver side door courtesy light switch ON signal input), the main body ECU (instrument panel junction block assembly) stops driving the headlight relay and stops the taillight ON signal.
