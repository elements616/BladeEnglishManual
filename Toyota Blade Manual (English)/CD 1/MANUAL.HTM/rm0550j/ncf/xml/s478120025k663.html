Current Fuel Consumption Display Mode



Current Fuel Consumption Specifications


Display Range
•
0.0~30.0km/L
•
Bar Graph Display
Function
•
The meter computer calculates and displays the current fuel consumption from the driving distance and fuel consumption for every 20 engine revolutions.
•
If a communication malfunction or input signal malfunction occurs, the display is blank (no display).



Cumulative Average Fuel Consumption Display Mode



Cumulative Average Fuel Consumption Specifications


Display Range
•
0.0~99.9km/L
Function
•
The meter computer calculates and displays the average fuel consumption from the accumulated driving distance and accumulated fuel injection volume since +B connection or reset.
•
With the power source mode ON, the previous data is displayed. (After +B reconnection, 0.0km/L is displayed.)
•
If a communication malfunction or input signal malfunction occurs, the display is blank (no display).
Reset Operation
•
Pressing the DISP switch for approximately 0.8 seconds or more resets the cumulative average fuel consumption data.



Cruising Range Display Mode



Cruising Range Specifications


Display Range
•
0~999km
Function
•
The meter computer calculates the fuel consumption from the engine speed, fuel injection volume, etc., and calculates and displays the cruising range from the current fuel level signal.
•
With the power source mode ON, the previous data is displayed.
•
If a communication malfunction or input signal malfunction occurs, the display is blank (no display).



Average Vehicle Speed Display Mode



Cumulative Average Vehicle Speed Specifications


Display Range
•
0~300km/h
Function
•
The meter computer calculates and displays the cumulative average vehicle speed from the accumulated engine running time and accumulated driving distance since +B connection or reset.
•
With the power source mode ON, the previous data is displayed. (After +B reconnection, 0km/h is displayed.)
•
If a communication malfunction or input signal malfunction occurs, the display is blank (no display).
Reset Operation
•
Pressing the DISP switch for approximately 0.8 seconds or more resets the cumulative average vehicle speed data.



Cumulative Driving Time Display Mode



Cumulative Driving Time Specifications


Display Range
•
0:00~99:59
Function
•
The clock in the combination meter accumulates and displays the time during which the engine is running.
•
When 99:59 is reached, the display continues from 0:00.
•
With the power source mode ON, the previous data is displayed. (After +B reconnection, 0:00 is displayed.)
•
If a communication malfunction or input signal malfunction occurs, the display is blank (no display).
Reset Operation
•
Pressing the DISP switch for approximately 0.8 seconds or more resets the cumulative driving time data.
