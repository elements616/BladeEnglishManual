Ignition System General

●
TDI (TOYOTA Direct Ignition System) has been adopted to improve ignition timing accuracy and make ignition timing completely adjustment-free.
●
ESA (Electronic Spark Advance) has been adopted. The engine control computer controls the ignition timing according to the engine condition based on the signals from each sensor.
●
Knock control using knock sensors and ECT shift torque control, which reduces shock during A/T shifting, have been adopted for high-precision control.
