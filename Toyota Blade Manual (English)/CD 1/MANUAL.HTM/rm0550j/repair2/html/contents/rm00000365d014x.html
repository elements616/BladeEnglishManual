DTC B15F1 ETC Communication Information Malfunction

Print

Function Description


This DTC is output when a malfunction occurs in road-to-vehicle communication at a toll gate.


DTC No.
Diagnosis Description
Inspection Area
B15F1
  1. Authentication error (SAM response malfunction) detected in DSRC communication
  2. Charging information (amount/unit) in the communication data is abnormal
-


Inspection Procedure


■ NOTICE ■
When making an inquiry to the road operator, ask the customer for the toll gate, date and time of the occurrence, etc., obtain the customer's consent to inquire about the travel record with the road operator, and then make the inquiry, explaining that there was an error in the communicated data.


Step 1Check DTC

  1. Check Error Code

    1. Start diagnosis mode 1. (see)

    2. Take the following action based on the error code.

      Error Code
      		Action
      42
      		Notify the road operator responsible for the toll gate where the problem occurred that there was a malfunction in the ETC security communication
      51
      		Notify the road operator responsible for the toll gate where the problem occurred that the charged amount during toll payment was incorrect
      52
      		Notify the road operator responsible for the toll gate where the problem occurred that the charging unit during toll payment was incorrect
