Airbag Sensor Rear RH Installation

Print

Preparation List



1. Install Airbag Sensor RR RH

  1. Make sure that the ignition switch is OFF.

  2. Check that the battery negative terminal is disconnected.

    ■ WARNING ■
    1. If work is performed without disconnecting the battery negative terminal, the airbag may deploy even if an impact is applied only to the airbag sensor rear RH by itself, so always confirm that the battery negative terminal is disconnected before performing work.
    2. After disconnecting the battery negative terminal, do not start work for 90 seconds.




  3. Install the airbag sensor rear RH with the nut.

    Standard
    T = 9.0 N/m{ 92 kgf/cm }

    ■ NOTICE ■
    1. Securely insert the pin on the back of the airbag sensor rear RH into the body hole.
    2. Do not reuse any part that has been dropped or subjected to a strong impact during work.

  4. Connect the connector to the airbag sensor rear RH.

    ■ NOTICE ■
    Insert the connector until it clicks.

  5. Check that there is no looseness in the airbag sensor rear RH.



2. Install Rear Seat Side Garnish RH



  1. Pass the rear seat outer belt assembly RH through the guide of the rear seat side garnish RH.

  2. Engage the 6 claws and 2 clips, and install the rear seat side garnish RH.



3. Install Rear Seatback Hinge Sub-assembly



  1. Install the rear seatback hinge with the bolt.

    Standard
    T = 18 N/m{ 184 kgf/cm }



4. Install Rear Door Opening Trim Weatherstrip RH



  1. Align the paint mark (white) of the weatherstrip with the arrow part on the body side shown in the illustration, and install the rear door opening trim weatherstrip RH.

    ■ NOTICE ■
    After installation, check that the corners are not lifted.



5. Install Rear Door Scuff Plate RH



  1. Engage the 8 claws to install the rear door scuff plate RH.



6. Install Rear Seat Outer Belt Assembly Center (RH Seat Position)



  1. Install the rear seat outer belt assembly center, rear seat inner belt assembly and washer with the bolt.

    Standard
    T = 41 N/m{ 420 kgf/cm }

    ■ NOTICE ■
    1. Pay attention to the installation direction of the floor anchor.
    2. Be careful that the floor anchor does not ride up onto the locator.



7. Install Rear Seat Assembly RH



  1. Set the rear seat assembly RH in the vehicle, and install the 2 rear side bolts in the order inner → outer.

    Standard
    T = 42 N/m{ 428 kgf/cm }




  2. Raise the seatback, and install the 2 front side bolts of the rear seat assembly RH in the order inner → outer.

    Standard
    T = 42 N/m{ 428 kgf/cm }



8. Install Rear Seat Cushion Hinge Cover NO.2 (RH Seat Position)



  1. Engage the 4 claws and install the rear seat cushion hinge cover NO.2.



9. Install Rear Seat Cushion Hinge Cover NO.1 (RH Seat Position)



  1. Engage the 4 claws and install the rear seat cushion hinge cover NO.1.



10. Install Rear Seat Headrest Assembly CTR (Seat Position RH Side)


11. Install Rear Seat Headrest Assembly (RH Seat Position)


12. Connect Battery Negative Terminal
Standard
T = 5.4 N/m{ 55 kgf/cm }
