DTC C1516/16 Torque Sensor 0-point Calibration Incomplete

Print

DTC C1526/18 Rotation Angle Sensor Output Calibration Incomplete


Function Description


The power steering computer assembly outputs this DTC when it determines that the torque sensor 0 point calibration or rotation angle sensor output calibration is incomplete.


DTC No.
Detection Condition
Action
C1516/16
Torque sensor 0 point calibration was not performed correctly, for example because the steering wheel was touched
After clearing the DTCs and sensor calibration values, perform the torque sensor 0 point calibration; if no DTC is output, there is no malfunction
C1526/18
Rotation angle sensor output calibration was not performed correctly
After clearing the DTCs and sensor calibration values, perform the rotation angle sensor output calibration; if no DTC is output, there is no malfunction
