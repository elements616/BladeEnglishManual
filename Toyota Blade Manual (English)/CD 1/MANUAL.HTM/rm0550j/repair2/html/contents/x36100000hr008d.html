Active Torque Control 4WD System Precautions

Print



    Precautions for 1.ABS and VSC System

    1. If a malfunction occurs in the Active Torque Control 4WD system, a malfunction in the ABS and VSC systems is also possible, so read the precautions for the ABS with EBD & TRC & VSC & BA system.

      □ HINT □
      For the precautions for the ABS with EBD & TRC & VSC & BA systemfor reference.

    2. Since the Active Torque Control 4WD system performs control using signals input from the ABS with EBD & TRC & VSC & BA system, if there is a malfunction in the ABS and VSC systems, repair the ABS and VSC systems first.



      2. Precautions for Handling and Operation

      1. Unless otherwise specified in the inspection method, be sure to remove and install the 4WD computer assembly, sensors, etc. with the ignition OFF.

      2. After removing and installing the 4WD computer assembly, sensors, etc., be sure to check the DTCs, and if a normal code is not output, clear the DTCs and check that the normal code is output.

      3. Before starting work, check that the correct tires are installed and that parts other than the transmission coupling assembly and 4WD control related parts are normal.
