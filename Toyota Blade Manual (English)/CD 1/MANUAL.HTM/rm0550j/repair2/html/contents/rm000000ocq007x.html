Intelligent Parking Assist System DTC Check/Clear

Print



  1. Read DTC (Read Using TaSCAN)

    1. Turn IG OFF.

    2. Connect SST (TaSCAN) to DLC3.

      SST
      09991-70200  

    3. Start the engine, select "Diagnosis" → "Vehicle Diagnosis/All DTCs" or "System Diagnosis/Chassis" → "System Name/IPA" → "DTC" on the SST (TaSCAN) screen to display the DTC check screen.

    4. Check the diagnostic trouble codes.

      ■ NOTICE ■
      As some DTCs are output even with no malfunction when inspecting with IG ON, always perform the inspection with the engine running.

      □ HINT □
      1. If a malfunction code is displayed, refer to the Diagnostic Trouble Code Chart ().
      2. After repair, check the DTCs again and confirm that no malfunction code is output.



    1. Clear DTC Memory (Clear Using TaSCAN)

      1. Turn IG OFF.

      2. Connect SST (TaSCAN) to DLC3.

        SST
        09991-70200  

      3. Start the engine, select "Diagnosis" → "Vehicle Diagnosis/All DTCs" or "System Diagnosis/Chassis" → "System Name/IPA" → "DTC" on the SST (TaSCAN) screen to display the DTC check screen.

      4. Select "Clear" and clear the DTCs following the screen instructions.
