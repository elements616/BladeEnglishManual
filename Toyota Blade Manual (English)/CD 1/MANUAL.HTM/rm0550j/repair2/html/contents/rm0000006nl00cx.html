Parking Brake Cable Assembly NO.3 Installation

Print

Preparation List



1. Install Parking Brake Cable Support Clamp Sub-assembly (Drive Type FF)



  1. Engage the 2 claws to install a new parking brake cable support clamp sub-assembly to parking brake cable assembly No.3.



2. Install Parking Brake Cable Assembly NO.3 (Drive Type FF)



  1. Pass the nipple end of parking brake cable assembly No.3 from under the floor into the cabin.



  2. Install parking brake cable assembly No.3 with the 5 bolts.

    Standard
    T = 6.0 N/m{ 61 kgf/cm }






  3. Pass parking brake cable assembly No.3 through the guide of the disc brake cylinder.

    ■ NOTICE ■
    Securely hook the clip onto the guide as shown in the illustration.




  4. Install the cable end to the operating lever of the disc brake cylinder.



3. Install Parking Brake Cable Assembly NO.3 (Drive Type 4WD)



  1. Pass the nipple end of parking brake cable assembly No.3 from under the floor into the cabin.



  2. Install parking brake cable assembly No.3 with the 5 bolts.

    Standard
    T = 6.0 N/m{ 61 kgf/cm }



    □ HINT □
    The bolt positions of parking brake cable assembly No.2 are symmetrical to those of parking brake cable assembly No.3, except for part [A].




  3. Pass parking brake cable assembly No.3 through the guide of the disc brake cylinder.

    ■ NOTICE ■
    Securely hook the clip onto the guide as shown in the illustration.




  4. Install the cable end to the operating lever of the disc brake cylinder.



4. Connect Parking Brake Cable Support Clamp Sub-assembly (Drive Type FF)



  1. Connect the parking brake cable support clamp sub-assembly with the clamp.



5. Install Front Floor Heat Insulator NO.2 (Drive Type FF)



  1. Install front floor heat insulator No.2 with the 3 nuts.

    Standard
    T = 5.5 N/m{ 56 kgf/cm }



6. Install Front Floor Heat Insulator NO.1 (Drive Type FF)



  1. Install front floor heat insulator No.1 with the 3 nuts.

    Standard
    T = 5.5 N/m{ 56 kgf/cm }



7. Install Front Floor Heat Insulator NO.2 (Drive Type 4WD)



  1. Install the front floor heat insulator No.2 with the 4 bolts.

    Standard
    T = 5.5 N/m{ 56 kgf/cm }



8. Install Exhaust Pipe Assembly CTR (Drive Type FF)



  1. Compression Spring Inspection

    1. Using a vernier caliper, measure the free length of the compression spring.

      Limit
      38.5mm

      ■ NOTICE ■
      If it is less than the minimum, replace the spring with a new one.




  2. Gasket Installation

    1. Insert a new gasket into the exhaust center pipe assembly as far as it will go by hand.

      ■ NOTICE ■
      1. Do not install the gasket in the wrong direction.
      2. Do not reuse a gasket once it has been removed.
      3. Do not damage the gasket by dropping it, etc.
      4. Do not damage the gasket sliding surface.
      5. Never push the gasket in by installing the exhaust pipe without first pressing it in sufficiently by hand.

    2. Install a new gasket to the exhaust pipe assembly front.

  3. Install the exhaust center pipe assembly with the 3 exhaust pipe supports.




  4. Install the exhaust center pipe assembly to the exhaust pipe assembly front with the 2 bolts.

    Standard
    T = 43 N/m{ 439 kgf/cm }




  5. Install the exhaust center pipe assembly to the exhaust tail pipe assembly with the bolts and 2 compression springs.

    Standard
    T = 43 N/m{ 439 kgf/cm }

    ■ NOTICE ■
    After installation, check that there is no significant difference in the clearance between the flanges of the exhaust center pipe assembly and exhaust tail pipe assembly at the front, rear, left and right.



9. Install Front Floor Brace Center (Drive Type FF)



  1. Install the front floor brace center with the 4 bolts.

    Standard
    T = 51 N/m{ 520 kgf/cm }



10. Install Exhaust Pipe Assembly CTR (Drive Type 4WD)



  1. Compression Spring Inspection

    1. Using a vernier caliper, measure the free length of the compression spring.

      Limit
      38.5mm

      ■ NOTICE ■
      If it is less than the minimum, replace the spring with a new one.




  2. Gasket Installation

    1. Insert a new gasket into the exhaust center pipe assembly as far as it will go by hand.

      ■ NOTICE ■
      1. Do not install the gasket in the wrong direction.
      2. Do not reuse a gasket once it has been removed.
      3. Do not damage the gasket by dropping it, etc.
      4. Do not damage the gasket sliding surface.
      5. Never push the gasket in by installing the exhaust pipe without first pressing it in sufficiently by hand.

    2. Install a new gasket to the exhaust pipe assembly front.

  3. Install the exhaust center pipe assembly with the 3 exhaust pipe supports.




  4. Install the exhaust center pipe assembly to the exhaust pipe assembly front with the 2 bolts.

    Standard
    T = 43 N/m{ 439 kgf/cm }




  5. Install the exhaust center pipe assembly to the exhaust tail pipe assembly with the bolts and 2 compression springs.

    Standard
    T = 43 N/m{ 439 kgf/cm }

    ■ NOTICE ■
    After installation, check that there is no significant difference in the clearance between the flanges of the exhaust center pipe assembly and exhaust tail pipe assembly at the front, rear, left and right.



11. Temporarily Tighten Propeller Shaft with Center Bearing Assembly (Drive Type 4WD)



  1. Align the matchmarks on the transfer assembly and propeller shaft assembly.

  2. Temporarily tighten the propeller with center bearing shaft assembly with 4 new nuts and 4 washers.




  3. Align the matchmarks on the differential carrier assembly and propeller shaft assembly.

  4. Temporarily tighten the propeller with center bearing shaft assembly with 4 new nuts and 4 washers.




  5. Temporarily tighten the center support bearing assembly with the 2 bolts, with the center support bearing washers in place.



12. Fully Tighten Propeller Shaft with Center Bearing Assembly (Drive Type 4WD)

  1. Fully tighten the 4 nuts installing the propeller shaft assembly to the transfer assembly.

    Standard
    T = 35 N/m{ 357 kgf/cm }

  2. Fully tighten the 4 nuts installing the propeller shaft assembly to the differential carrier assembly.

    Standard
    T = 35 N/m{ 357 kgf/cm }




  3. Check that the housing center line of the center support bearing assembly is at a right angle to the propeller shaft axis.

  4. Fully tighten the 2 installation bolts of the center support bearing assembly.

    Standard
    T = 37 N/m{ 377 kgf/cm }



13. Install Parking Brake Lever Protector



  1. Install the parking brake lever protector to the parking brake cable assembly No.3.



14. Connect Parking Brake Cable Assembly NO.3



  1. Install parking brake cable assembly No.3 to the parking brake equalizer.



15. Adjust Parking Brake Lever Travel

  1. Fully release the parking brake lever.

  2. Loosen the lock nut and adjusting nut at the parking brake lever, and fully loosen the parking brake cable.

  3. With the engine OFF, depress the brake pedal firmly 3-5 times.




  4. Turn the adjusting nut to adjust the lever travel to the standard value.

    Standard
    5-8 notches [Operating force 200N{20kgf}]

  5. Using a wrench, hold the adjusting nut and tighten the lock nut.

    Standard
    T = 6.0 N/m{ 61 kgf/cm }

  6. Operate the parking brake lever 3-4 times, then check the lever travel.

  7. Check that the parking brake does not drag.




  8. When the parking brake lever is released, check that the clearance between the operating lever and the stopper of the rear disc brake cylinder is within the standard range.

    Standard
    0-0.5mm

  9. Check that the brake warning light comes on when the parking brake lever is operated.

    Specified Condition
    The light must come on reliably at the 1 notch from the start of pulling.



16. Install Console Box Mounting Bracket NO.2 (Drive Type FF)



  1. Install console mounting bracket No.2 with the 4 bolts.

  2. Return the floor carpet to its original position



17. Install Console Box Mounting Bracket NO.2 (Drive Type 4WD)



  1. Install console mounting bracket No.2 with the 3 bolts.

  2. Return the floor carpet to its original position



18. Install Indoor Electrical Key Oscillator



  1. Install the indoor electrical key oscillator with the clamp

  2. Connect the connector.



19. Install Console Box Assembly RR



  1. Engage the 4 claws.




  2. Install the console box assembly RR with the 4 bolts and 2 screws.



20. Install Console Box Carpet



  1. Install the console box carpet.



21. Install Console Box Cover RR

  1. Connect the connectors.




  2. Engage the 4 clips to install the console box rear cover.
