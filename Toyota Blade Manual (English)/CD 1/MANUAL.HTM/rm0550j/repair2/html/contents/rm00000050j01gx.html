SRS Airbag System DTC Check / Clear

Print



  1. Reading DTCs Using TaSCAN (Normal Mode)

    1. Turn IG OFF.

    2. Connect SST (TaSCAN) to DLC3.

      SST
      09991-70200  

    3. After turning the ignition switch ON, follow the prompts on the SST (TaSCAN) screen to display the "DTC Check" screen, select normal mode and read the DTCs.



    1. Reading DTCs Using TaSCAN (Check Mode)

      1. Turn IG OFF.

      2. Connect SST (TaSCAN) to DLC3.

        SST
        09991-70200  

      3. After turning the ignition switch ON, follow the prompts on the SST (TaSCAN) screen to display the "DTC Check" screen, select check mode and read the DTCs.

        ■ NOTICE ■
        When the "DTC Check" screen of the SST is displayed and check mode is selected, the DTCs output up to that point (current and past) are cleared.

        □ HINT □
        1. Check mode can increase the malfunction (abnormality) detection sensitivity compared to normal mode.
        2. Perform the check mode inspection when a malfunction (abnormality) is suspected in an inflator system, but a normal code is output when the DTCs are read in normal mode.
        3. Check whether each output DTC is supported in check mode in the Diagnostic Trouble Code Chart ().



      1. Clearing DTCs Using TaSCAN

        1. Turn IG OFF.

        2. Connect SST (TaSCAN) to DLC3.

          SST
          09991-70200  

        3. After turning the ignition switch ON, follow the prompts on the SST (TaSCAN) screen to clear the DTCs.
