Camshaft Timing Oil Control Valve Assembly (2GR-FE) Installation

Print

Preparation List



1. Install Camshaft Timing Oil Control Valve Assembly



  1. Install a new O-ring to the camshaft timing oil control valve assembly (bank 2 exhaust side).

  2. Install the camshaft timing oil control valve assembly (bank 2 exhaust side) with the bolt.

    Standard
    T = 10 N/m{ 102 kgf/cm }

  3. Connect the connector.



2. Install Camshaft Timing Oil Control Valve Assembly



  1. Install a new O-ring to the camshaft timing oil control valve assembly (bank 2 intake side).

  2. Install the camshaft timing oil control valve assembly (bank 2 intake side) with the bolt.

    Standard
    T = 10 N/m{ 102 kgf/cm }

  3. Connect the connector.



3. Install Camshaft Timing Oil Control Valve Assembly



  1. Install a new O-ring to the camshaft timing oil control valve assembly (bank 1 intake side).

  2. Install the camshaft timing oil control valve assembly (bank 1 intake side) with the bolt.

    Standard
    T = 10 N/m{ 102 kgf/cm }

  3. Connect the connector.



4. Install Camshaft Timing Oil Control Valve Assembly



  1. Install a new O-ring to the camshaft timing oil control valve assembly (bank 1 exhaust side).

  2. Install the camshaft timing oil control valve assembly (bank 1 exhaust side) with the bolt.

    Standard
    T = 10 N/m{ 102 kgf/cm }

  3. Connect the connector.



5. Install Intake Air Surge Tank Assembly



  1. Disconnect the vacuum hose from the throttle body assembly. (*1)

  2. Slide the 2 clips and disconnect the water bypass hose No.2 and water bypass hose No.3 from the throttle body assembly (*2).

  3. Disconnect the throttle motor connector from the throttle body assembly (*3).




  4. Disconnect the air control valve connector from the intake air surge tank.

  5. Remove the 2 bolts and surge tank stay No.1.

  6. Remove the 2 bolts and the throttle body bracket.




  7. Remove the 2 nuts from the intake air surge tank. (*1)

  8. Using a socket hexagon wrench (5mm), remove the 4 bolts. (*2)

  9. Remove the intake air surge tank and gasket.



6. Install Air Cleaner Cap w/ Air Cleaner Hose



  1. Install the hinge portion first, and then install the air cleaner cap w/ air cleaner hose with the 3 clamps.

  2. Install the clamp hose band. (*1)

  3. Connect ventilation hose No.2. (*2)

  4. Connect the air flow meter connector. (*3)



7. Add Coolant (Toyota Genuine Super Long Life Coolant)

  1. Close the radiator drain cock plug.

  2. Close the cylinder block drain cock plug.

    Standard
    T = 13 N/m{ 133 kgf/cm }




  3. Fill coolant of the specified concentration up to the B line of the radiator reserve tank.

    ■ NOTICE ■
    Do not add water as coolant

    □ HINT □
    Squeeze radiator hose NO.1 and radiator hose NO.2 by hand several times, and if the coolant level in the filler drops, add more coolant.

  4. After installing the reservoir tank cap, warm up the engine until the thermostat opens. (A)

    □ HINT □
    1. Squeeze radiator hose NO.1 and radiator hose NO.2 several times while warming up the engine.
    2. The valve opening timing can be checked by gripping radiator hose NO.2 by hand.

    ■ WARNING ■
    1. Wear protective gloves when working
    2. Be careful of cooling fan operation
    3. The engine and radiator become hot, so avoid the risk of burns.

  5. After warm-up, repeat the cycle of 3000rpm engine speed for 5 seconds ←→ idling for 45 seconds 8 times or more (7 minutes or more). (B)

  6. Stop the engine and wait until the coolant cools down, and if the level is below LOW, add coolant of the specified concentration through the filler again and adjust it to between FULL and LOW. (C)

  7. Repeat steps (A) to (C) until the coolant level in the radiator reservoir tank stops dropping.

  8. When the level stops dropping, add coolant of the specified concentration through the filler again to adjust the coolant level in the radiator reservoir tank to between FULL and LOW.



8. Inspect for Coolant Leaks

■ WARNING ■
To avoid the danger of being burned, do not remove the reservoir tank cap while the engine and radiator are still hot. Liquid and steam will spray out under pressure.




  1. Fill the radiator with coolant and install a radiator cap tester.

  2. Warm up the engine.

  3. 118kPa{1.2kgf/cm2Pump it to } and check that the pressure does not drop.

    □ HINT □
    If the pressure drops, check the hoses, radiator and water pump for leaks. If there are no external leaks, check the heater core, cylinder block and cylinder head.



9. Install Cowl Top Panel Outer



  1. Install the cowl top panel outer with the 8 bolts.

    Standard
    T = 8.8 N/m{ 90 kgf/cm }




  2. Bend the heater air duct splash shield seal No.2 and water guard plate RH as shown in the illustration, and engage each clamp.




  3. Engage the windshield deicer wire harness connector and 3 clamps, and attach them to the cowl top panel outer. (w/ Cold Area Specification)



10. Install Cowl Body Mounting Reinforcement RH



  1. Install the cowl body mounting reinforcement RH to the cowl top panel outer with the 3 bolts.

    Standard
    T = 8.8 N/m{ 90 kgf/cm }



11. Install Windshield Wiper Motor & Link Assembly



  1. Install the windshield wiper motor & link assembly with the 2 bolts.

    Standard
    T = 5.5 N/m{ 56 kgf/cm }

  2. Connect the connector.



12. Install Cowl Top Ventilator Louver RH



  1. Engage the 5 claws and install the cowl top ventilator louver RH as shown in the illustration.



13. Install Front Side Panel Protector NO.1 RH



  1. Engage the pin and install the front side panel protector NO.1 RH.



14. Install Cowl Top Ventilator Louver LH



  1. Engage the 11 claws and install the cowl top ventilator louver LH as shown in the illustration.



15. Install Front Side Panel Protector NO.1 LH



  1. Engage the pin and install the front side panel protector NO.1 LH.



16. Install Hood to Cowl Top Seal



  1. Engage the 7 clips and install the hood to cowl top seal.



17. Install Front Wiper Arm & Blade Assembly LH



  1. Stop the windshield wiper motor assembly at the automatic stop position.

  2. Using a round file or equivalent, clean the wiper arm serrations. (When reassembling)

  3. Using a wire brush, clean the wiper pivot serrations.




  4. Install the front wiper arm & blade assembly LH with the front wiper arm nut so that it is in the position shown in the illustration.

    Standard
    T = 26 N/m{ 265 kgf/cm }

    □ HINT □
    While holding the arm hinge by hand, tighten the front wiper arm nut.



18. Install Front Wiper Arm & Blade Assembly RH



  1. Using a round file or equivalent, clean the wiper arm serrations. (When reassembling)

  2. Using a wire brush, clean the wiper pivot serrations.




  3. Install the front wiper arm & blade assembly RH with the front wiper arm nut so that it is in the position shown in the illustration.

    Standard
    T = 26 N/m{ 265 kgf/cm }

    □ HINT □
    While holding the arm hinge by hand, tighten the front wiper arm nut.

  4. Operate the front wipers while spraying water or washer fluid on the glass, and check the wiping condition of the blades and that they do not interfere with the body.



19. Install Front Wiper Arm Head Cap



  1. Install the 2 front wiper arm head caps.



20. Connect Battery Negative Terminal
Standard
T = 5.4 N/m{ 55 kgf/cm }


21. Install V-bank Cover Sub-assembly



  1. Engage the 3 clips to install the V-bank cover.

    ■ NOTICE ■
    1. Make sure the clips are securely engaged.
    2. Engaging them with excessive force or striking the top of the clips may cause damage.
