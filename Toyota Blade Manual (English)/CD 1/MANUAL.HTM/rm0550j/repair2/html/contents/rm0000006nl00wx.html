Parking Brake Cable Assembly NO.3 Installation

Print

Preparation List



1. Install Parking Brake Cable Support Clamp Sub-assembly (Drive Type FF)



  1. Engage the 2 claws to install a new parking brake cable support clamp sub-assembly to parking brake cable assembly No.3.



2. Install Parking Brake Cable Assembly NO.3 (Drive Type FF)


  1. Install parking brake cable assembly No.3 with the 5 bolts.



    Standard
    T = 6.0 N/m{ 61 kgf/cm }




  2. Pass parking brake cable assembly No.3 through the guide of the disc brake cylinder assembly RR LH.

    ■ NOTICE ■
    Securely hook the clip onto the guide as shown in the illustration.




  3. Install parking brake cable assembly No.3 to the disc brake cylinder assembly RR LH.




  4. Engage the clamp to install parking brake cable clamp No.2 to the vehicle.



3. Install Parking Brake Cable Assembly NO.3 (Drive Type 4WD)


  1. Install parking brake cable assembly No.3 with the 5 bolts.



    Standard
    T = 6.0 N/m{ 61 kgf/cm }

    □ HINT □
    The bolt positions of parking brake cable assembly No.2 are symmetrical to those of parking brake cable assembly No.3, except for part [A].




  2. Pass parking brake cable assembly No.3 through the guide of the disc brake cylinder assembly RR LH.

    ■ NOTICE ■
    Securely hook the clip onto the guide as shown in the illustration.




  3. Install parking brake cable assembly No.3 to the disc brake cylinder assembly RR LH.



4. Install Parking Brake Lever Protector



  1. Install the parking brake lever protector to the parking brake cable assembly No.3.



5. Install Front Floor Heat Insulator NO.2 (Drive Type FF)



  1. Install front floor heat insulator No.2 with the 3 nuts.

    Standard
    T = 5.5 N/m{ 56 kgf/cm }



6. Install Front Floor Heat Insulator NO.1 (Drive Type FF)



  1. Install front floor heat insulator No.1 with the 3 nuts.

    Standard
    T = 5.5 N/m{ 56 kgf/cm }



7. Install Exhaust Pipe Assembly CTR (Engine Type 2AZ-FE (FF))



  1. Compression Spring Inspection

    1. Using a vernier caliper, measure the free length of the compression spring.

      Limit
      38.5mm

      ■ NOTICE ■
      If it is less than the minimum, replace the spring with a new one.




  2. Gasket Installation

    1. Insert a new gasket into the exhaust center pipe assembly as far as it will go by hand.

      ■ NOTICE ■
      1. Do not install the gasket in the wrong direction.
      2. Do not reuse a gasket once it has been removed.
      3. Do not damage the gasket by dropping it, etc.
      4. Do not damage the gasket sliding surface.
      5. Never push the gasket in by installing the exhaust pipe without first pressing it in sufficiently by hand.

    2. Install a new gasket to the exhaust pipe assembly front.

  3. Install the exhaust center pipe assembly with the 3 exhaust pipe supports.




  4. Install the exhaust center pipe assembly to the exhaust pipe assembly front with the 2 bolts.

    Standard
    T = 43 N/m{ 439 kgf/cm }




  5. Install the exhaust center pipe assembly to the exhaust tail pipe assembly with the bolts and 2 compression springs.

    Standard
    T = 43 N/m{ 439 kgf/cm }

    ■ NOTICE ■
    After installation, check that there is no significant difference in the clearance between the flanges of the exhaust center pipe assembly and exhaust tail pipe assembly at the front, rear, left and right.



8. Install Front Floor Brace Center (Engine Type 2AZ-FE (FF))



  1. Install the front floor brace center with the 4 bolts.

    Standard
    T = 51 N/m{ 520 kgf/cm }



9. Install Exhaust Pipe Assembly CTR (Engine Type 2GR-FE)



  1. Compression Spring Inspection

    1. Using a vernier caliper, measure the free length of the compression spring.

      Limit
      38.5mm

      ■ NOTICE ■
      If it is less than the minimum, replace the spring with a new one.




  2. Gasket Installation

    1. Insert a new gasket into exhaust center pipe sub-assembly CTR NO.2 as far as it will go by hand.

      ■ NOTICE ■
      1. Do not install the gasket in the wrong direction.
      2. Do not reuse a gasket once it has been removed.
      3. Do not damage the gasket by dropping it, etc.
      4. Do not damage the gasket sliding surface.
      5. Never push the gasket in by installing the exhaust pipe without first pressing it in sufficiently by hand.

  3. Install exhaust center pipe sub-assembly CTR NO.2 with the 4 exhaust pipe supports.




  4. Install exhaust center pipe sub-assembly CTR NO.2 to the exhaust center pipe assembly with the 2 bolts and 2 compression springs.

    Standard
    T = 43 N/m{ 439 kgf/cm }




  5. Install exhaust center pipe sub-assembly CTR NO.2 to the exhaust tail pipe assembly with the 2 bolts and 2 compression springs.

    Standard
    T = 43 N/m{ 439 kgf/cm }

    ■ NOTICE ■
    After installation, check that there is no significant difference in the clearance between the flanges of exhaust center pipe sub-assembly CTR NO.2 and the exhaust tail pipe assembly at the front, rear, left and right.



10. Install Front Floor Brace Center (Engine Type 2GR-FE)



  1. Install the 4 bolts and the front floor brace center.

    Standard
    T = 51 N/m{ 520 kgf/cm }



11. Install Propeller Shaft with Center Bearing Assembly (Engine Type 2AZ-FE (4WD))

□ HINT □
The procedure from installing the propeller shaft with center bearing assembly isfor reference.



12. Install Parking Brake Pull Rod Sub-assembly NO.1



  1. Connect parking brake cable assembly No.3 to parking brake pull rod sub-assembly No.1 as shown in the illustration.

  2. Connect parking brake cable assembly No.2 to parking brake pull rod sub-assembly No.1 using the same procedure as for parking brake cable assembly No.3.



13. Connect Parking Brake Cable Assembly NO.1



  1. Connect parking brake cable assembly No.1 to parking brake pull rod sub-assembly No.1 as shown in the illustration.

    Standard
    T = 5.4 N/m{ 55 kgf/cm }



14. Adjust Parking Brake Pedal Travel

  1. Release the parking brake.

  2. Remove instrument panel airbag assembly LWR No.1 (see).




  3. Remove the lock nut and loosen wire adjusting nut No.1.

  4. Turn wire adjusting nut No.1 to adjust the parking brake pedal travel to the standard value.

    Standard
    7 to 10 notches [Pedal effort 300N{31kgf}]

  5. Using a wrench, hold wire adjusting nut No.1 and tighten the lock nut.

    Standard
    T = 5.4 N/m{ 55 kgf/cm }

  6. After operating the parking brake pedal 3 to 4 times, check that the pedal travel is within the standard range.

    Standard
    7 to 10 notches [Pedal effort 300N{31kgf}]

  7. Check that the parking brake does not drag.




  8. When the parking brake pedal is released, check that the clearance between the operating lever and the stopper of the rear disc brake cylinder is within the standard range.

    Standard
    0.5mm or less

  9. Install instrument panel airbag assembly LWR No.1 (see).
