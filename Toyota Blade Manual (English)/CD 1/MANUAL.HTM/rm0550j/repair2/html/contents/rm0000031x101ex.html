Circuit Description


The idle speed is controlled by the electronic throttle control system.

The electronic throttle control system consists of a throttle motor that drives the throttle valve, and a throttle position sensor that detects the throttle valve opening angle.

The engine control computer controls the throttle motor to adjust the throttle valve opening appropriately so that the idle speed reaches the target idle speed.

If the difference between the actual idle speed and the target idle speed is equal to or more than the judgment value and the idle speed feedback correction value has reached its upper limit, and this condition occurs 5 times or more during 1 trips, and the idle speed control learned value is equal to or more than the judgment value, the engine control computer determines that there is a malfunction in the idle speed control, illuminates the check engine warning light and stores a DTC.

Example:

If the actual idle speed falls 100 *1 rpm or more below the target idle speed, or rises 150 *1 rpm or more above it, 5 times during 1 driving cycles, the engine control computer illuminates the check engine warning light and stores a DTC. (2 trip detection logic)

□ HINT □
*1: The reference engine speed varies depending on the engine load (e.g. A/C ON/OFF, electrical load ON/OFF).

DTC Detection Condition
Diagnosis Condition
Vehicle stopped (idling) after being driven at 10 km/h or more
Abnormal Condition
  1. When both of the following conditions are met
    1. Value obtained by subtracting the target engine speed from the actual engine speed is -100 r/min or less or 150 r/min or more
    2. Idle speed feedback correction value is 1.3 L/s or less, or 6.0 L/s or more

10 minutes

Detected 1 times during 1 trips (no detection after judgment)

  1. Electronic throttle control system
  2. Intake system (air leakage)
  3. PCV valve, PCV hose and PCV hose connection condition
  4. Engine Control Computer


Function Description


Confirmation Driving
By performing confirmation driving, it is possible to check whether the DTC is reproduced.




SST
09991-70201  

  1. Connect SST (TaSCAN) to DLC3.
  2. Turn IG ON.
  3. Following the SST (TaSCAN) display screen, clear the DTCs. (see)
  4. Start the engine, turn all accessory switches OFF, and warm up the engine until the engine coolant temperature stabilizes. (Engine coolant temperature is 75 °C or higher) (A)
  5. With all accessory switches OFF, idle the engine for 1 minutes or more. (B)
  6. Following the SST (TaSCAN) screen display, check the DTC judgment result. (see)

    ■ WARNING ■
    When performing this driving test, be sure to obey speed limits and other traffic laws.

    □ HINT □
    If the DTC judgment result is "judging" or "cannot judge", drive the vehicle at 10km/h or more (C), then turn all accessory switches OFF and idle the engine for 20 seconds or more. (D)
    After repeating steps (C) to (D) 5 times or more, check the DTC judgment result.
