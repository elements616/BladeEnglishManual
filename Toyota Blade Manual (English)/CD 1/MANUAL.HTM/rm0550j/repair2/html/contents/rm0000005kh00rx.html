Meter & Gauge System DTC Check / Clear

Print



  1. Check DTCs Using TaSCAN
    SST
    09991-70200  

    1. Using SST (TaSCAN), select "Diagnosis" → "ALL Diag" or "Diagnosis" → "Body" → "Meter" → "DTC" by following the screen instructions, and check the diagnostic trouble codes.



    1. Clear DTC Memory Using TaSCAN
      SST
      09991-70200  

      1. Using SST (TaSCAN), select "Diagnosis" → "ALL Diag" → "Clear" or "Diagnosis" → "Body" → "Meter" → "DTC" → "Clear" by following the screen instructions, and clear the diagnostic trouble codes.
