DTC C1380/64 Stop Light Drive Relay Circuit Malfunction

Print

Preparation List


Function Description


During hill-start assist control, the skid control computer operates the BRAKE LP relay to illuminate the stop lights.

If a stop light switch open circuit code (C1249/49) is output, perform troubleshooting for the stop light switch circuit open.


DTC No.
DTC Detection Condition
DTC Output Related Items
C1380/64
  1. With the IG1 terminal voltage at 11to14V, a condition in which there is no input signal to the STP terminal when the stop light control relay drive output (STP0) is ON continues for 2 seconds or more
  2. With the IG1 terminal voltage at 11to14V, a condition in which the input signals of the STP and STP2 terminals differ when the stop light control relay drive output (STP0) is OFF continues for 5 seconds or more
  1. STOP Fuse
  2. BRAKE LP Relay
  3. Stop Light Switch Assembly
  4. Stop light switch wire harness open or short circuit
  5. Poor contact pressure, terminal deformation or corrosion of connector
  6. Actuator ground open circuit
  7. Actuator assembly
