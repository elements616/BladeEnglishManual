Steering Lock System Diagnosis System

Print



  1. About the Diagnosis Function

    1. When a malfunction occurs in the system, the steering lock ECU outputs the self-diagnosis malfunction as a diagnostic trouble code, which can be read using SST (TaSCAN).

    2. Since the steering lock ECU is not connected to CAN communication, it responds to SST (TaSCAN) via the certification ECU.

    3. The steering lock ECU outputs only current malfunctions as diagnostic trouble codes and does not store past DTCs.
