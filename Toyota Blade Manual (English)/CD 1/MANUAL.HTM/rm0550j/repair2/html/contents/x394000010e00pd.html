  1. Customer Problem Analysis Check Sheet





    1. How to Fill In

      □ HINT □
      1. In the ETC system, toll payment is made by wireless communication. Therefore, it is necessary to conduct a thorough customer problem analysis regarding the installation condition of the toll collection (ETC) computer assembly on the vehicle and the vehicle environment at that time.
      2. To find out the frequency of the problem, ask the customer how often they use ETC.
      3. Fill in each item in the entry fields by referring to the following.

        ETC On-board Unit Field 
        Item
        		Check Method (Reference)
        Part No.
        		ETC Diagnosis Check (Diagnosis Mode 1) - Model (On-board Unit Part Number) Notification Mode ()
        Model registration number
        		ETC Diagnosis Check (Diagnosis Mode 1) - Model Registration Number Notification Mode ()
        Serial No.
        		Shown on the label of the toll collection (ETC) computer assembly itself (see illustration)
        ETC On-board Unit Management Number
        1. ETC Registration Information - On-board Unit Management Number ()
        2. ETC Diagnosis Check (Diagnosis Mode 1) - On-board Unit Management Number Notification Mode ()
        Software Ver.
        		ETC Diagnosis Check (Diagnosis Mode 1) - Software Version Notification Mode ()

        DTC 1 Entry Field 
        Item
        		Check Method (Reference)
        Time, Error Code, Date
        		ETC Diagnosis Check (Diagnosis Mode 1) - Error Log Notification Mode ()

        DTC 2 (Communication Error Notification) Entry Field 
        Item
        		Check Method (Reference)
        Date, Time, Communication Result, Communication Location, (Vehicle Speed)
        		ETC Diagnosis Check (Diagnosis Mode 2) - Communication Log Notification Mode ()
