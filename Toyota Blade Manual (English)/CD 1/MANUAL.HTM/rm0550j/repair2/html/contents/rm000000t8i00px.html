DTC C1290/66 Steering Angle Sensor 0-point Malfunction

Print

Preparation List


Function Description


Each time the IG is turned ON, the skid control computer acquires the steering sensor 0 point by driving straight ahead at a vehicle speed of 35km/h or more for approximately 5 seconds, and also stores past 0 point positions.

If an alignment adjustment, steering wheel position adjustment, etc. is performed without disconnecting the battery terminal, or if yaw rate sensor 0 point acquisition is not performed after adjustment, a difference between the steering sensor 0 point acquired value while driving and the stored value is detected, and a steering angle sensor 0 point malfunction code is output as an adjustment malfunction.

The warning for the steering angle sensor 0 point malfunction code is canceled by turning the IG OFF.
