DTC U0327 Smart/Certification ECU Not Connected

Preparation List


Function Description


The instrument panel junction block assembly (main body ECU) stores code U0327 when it cannot receive data from the smart key computer assembly (certification ECU).

The instrument panel junction block assembly (main body ECU) stores code U1002 when it cannot receive data from any of the ECUs it has stored as connected to the MS bus. (The meter ECU is connected as a terminating resistor and does not send or receive data on the MS bus.)


DTC No.
DTC Detection Condition
DTC Output Related Items
U0327
Data cannot be received from the certification ECU while IG voltage is normal
  1. Smart key computer assembly (certification ECU) branch line open
  2. Poor connector contact or contact pressure
  3. Smart key computer assembly (certification ECU) power source malfunction
  4. Smart key computer assembly (certification ECU) internal malfunction
U1002
Data cannot be received from any of the ECUs on the MS bus side stored as connected in the main body ECU
  1. MS bus main line open or short
  2. Smart key computer assembly (certification ECU) branch line open or short
  3. Poor connector terminal contact or contact pressure
  4. CAN J/C3
  5. Smart Key Computer Assembly (Certification ECU)
  6. Main body ECU internal malfunction

Inspection Procedure


■ NOTICE ■
  1. When measuring the resistance of the CAN bus, turn the ignition switch off, check that warning functions such as the key reminder warning system are not operating, and leave the vehicle for at least 1 minutes without operating the key or switches or opening and closing the doors before starting the measurement. If it is necessary to open a door during inspection, open it beforehand.
  2. The following flowchart applies only when the code is output by the main body ECU (MS bus monitoring ECU). (When the CAN gateway ECU outputs U1002,)


□ HINT □
  1. When inspecting each connector, before disconnecting it, push the connector case in the connecting direction and check that the connector is not loose or disconnected.
  2. When disconnecting a connector, check that the connector terminals and connector case are free of damage, deformation, corrosion, etc.
