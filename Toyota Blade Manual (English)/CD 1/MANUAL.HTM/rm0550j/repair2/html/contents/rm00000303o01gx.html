DTC U0126 Steering Sensor Communication Malfunction

Print

Preparation List


Function Description


This DTC is output when a malfunction occurs in the CAN communication system connected to the navigation receiver assembly.

□ HINT □
When a CAN communication system malfunction DTC is output, other systems may also output CAN communication system malfunction DTCs.
