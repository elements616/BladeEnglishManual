    Step 2Customer Problem Analysis and Symptom Check

    1. Customer Problem Analysis and Symptom Check (see)

      1. Check on which screen the problem symptom occurs. (Occurs only on G-BOOK screen / occurs only on navigation screen / occurs only on TV screen / occurs on all screens / occurs elsewhere)

      2. G-BOOK provides a variety of services using communication. Therefore, it is important to determine whether the problem is caused by the communication system, including radio wave conditions, or by something else. Perform thorough customer problem analysis according to the questionnaire, and ask about the conditions of occurrence carefully to determine whether the problem may be temporary due to poor radio wave conditions.

        Screen Display Message and Problem Symptom
        		Cause
        The message "Please check the telephone" is displayed from the first connection
        		It is highly likely that the cellular phone being used is not G-BOOK compatible, so have the customer check it (compatible models can be checked at G-BOOK.com on the Internet)
        The message "Cannot display because the line is busy, etc. Please wait a while before operating" is temporarily displayed
        		This is due to radio wave conditions or base station congestion and is not a malfunction (explain to the customer and have them continue using it)
        The message "Could not acquire information because the line is busy, etc." is temporarily displayed
        		This is due to radio wave conditions or base station congestion and is not a malfunction (explain to the customer and have them continue using it)
        The message "Please wait" appears and it temporarily takes a long time until the screen is displayed
        		This is due to radio wave conditions or base station congestion and is not a malfunction (explain to the customer and have them continue using it)

    Step 3Basic Inspection

      SST
      09082-00030  

    1. Basic Inspection

      1. Using SST (Toyota electrical tester), inspect the battery voltage.

        Standard
        11 to 14 V (IG OFF)

      2. Inspect locations that can be checked visually, such as blown fuses, open or short circuits in the wire harness, and poor connector connections.
