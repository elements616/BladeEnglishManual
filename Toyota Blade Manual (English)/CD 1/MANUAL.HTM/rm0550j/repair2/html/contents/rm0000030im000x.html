Rear Bumper Reassembly

Print


1. Install Rear Bumper Side Retainer LH



  1. Engage the 2 claws.

  2. Install the rear bumper side retainer LH with the 2 screws.



2. Install Rear Bumper Side Retainer RH

□ HINT □
Install it in the same way as for the LH side.



3. Install Rear Bumper Retainer UPR LH



  1. Engage the 2 claws.

  2. Install the rear bumper retainer UPR LH with the screw.



4. Install Rear Bumper Retainer UPR RH

□ HINT □
Install it in the same way as for the LH side



5. Install License Plate Light Assembly



  1. Connect the connector.




  2. Engage the claws and install the license plate light assembly.



6. Install Rear Bumper Retainer LWR RH



  1. Engage the claw and install the rear bumper retainer lower RH.



7. Install Reflex Reflector Assembly RH



  1. Install the reflex reflector assembly RH with the screw.



8. Install Reflex Reflector Assembly LH

□ HINT □
Install it in the same way as for the RH side



9. Install Rear Bumper Guard



  1. Temporarily install the rear bumper guard with the 6 outside molding retainers.

  2. Install the rear bumper guard with the 3 clips.
