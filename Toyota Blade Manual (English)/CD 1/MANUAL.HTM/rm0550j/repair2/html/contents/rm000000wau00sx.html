Parking Brake Control Pedal Assembly Installation

Print

Preparation List



1. Install Parking Brake Control Pedal Assembly



  1. Install the parking brake control pedal assembly with the 2 bolts and nut.

    Standard
    T = 15 N/m{ 148 kgf/cm }




  2. Connect the parking brake switch assembly connector.

  3. Attach the wire harness clamp.




  4. Attach parking brake cable assembly No.1 to the clamp.

    ■ NOTICE ■
    Make sure that parking brake cable assembly No.1 is securely installed past the protrusion of the clamp.

  5. FF Drive:




    1. Securely place parking brake cable assembly No.1 on the guide bracket.




  6. Install the 2 bolts.

    Standard
    T = 15 N/m{ 148 kgf/cm }

  7. Attach parking brake cable assembly No.1 to the clamp.




  8. Temporarily install the lock nut.

    □ HINT □
    Fully tighten the lock nut after adjusting the parking brake pedal travel.



2. Install Cable Support Bracket Sub-assembly



  1. Install the cable support sub-assembly with the 2 bolts.

    ■ NOTICE ■
    Do not pinch the wire harness.

  2. Attach the wire harness clamp to the cable support sub-assembly.



3. Connect Parking Brake Cable Assembly NO.1



  1. Connect parking brake cable assembly No.1 to parking brake pull rod sub-assembly No.1 as shown in the illustration.

    Standard
    T = 5.4 N/m{ 55 kgf/cm }



4. Adjust Parking Brake Pedal Travel

  1. Release the parking brake.

  2. Remove instrument panel airbag assembly LWR No.1 (see).




  3. Remove the lock nut and loosen wire adjusting nut No.1.

  4. Turn wire adjusting nut No.1 to adjust the parking brake pedal travel to the standard value.

    Standard
    7 to 10 notches [Pedal effort 300N{31kgf}]

  5. Using a wrench, hold wire adjusting nut No.1 and tighten the lock nut.

    Standard
    T = 5.4 N/m{ 55 kgf/cm }

  6. After operating the parking brake pedal 3 to 4 times, check that the pedal travel is within the standard range.

    Standard
    7 to 10 notches [Pedal effort 300N{31kgf}]

  7. Check that the parking brake does not drag.




  8. When the parking brake pedal is released, check that the clearance between the operating lever and the stopper of the rear disc brake cylinder is within the standard range.

    Standard
    0.5mm or less

  9. Install instrument panel airbag assembly LWR No.1 (see).



5. Inspect Brake Warning Light

  1. Check that the brake warning light illuminates when the parking brake pedal is operated.

    Specified Condition
    The brake warning light must illuminate reliably at the 1 notch from the start of depression.



6. Install Instrument Panel Finish Panel Lower NO.2



  1. Push in the direction of the arrow shown in the illustration to engage the 2 clips and guide.




  2. Install instrument panel finish panel lower No.2 with the 2 screws <C>.



7. Install Instrument Panel Finish Panel Lower NO.1



  1. Push in the direction of the arrow shown in the illustration to engage the 2 clips and guide.




  2. Engage the 4 claws and 2 guides.




  3. Install instrument panel finish panel lower No.1 with the 2 screws <C>.



8. Install Instrument Panel Under Tray



  1. Engage the 4 claws and install the instrument panel under tray.



9. Install Box Bottom Mat


10. Install Console Box Insert FR NO.2



  1. Insert the guide.

  2. Engage the 3 claws and install console box insert FR No.2.



11. Install Console Box Insert



  1. Insert the guide.

  2. Engage the 3 claws and install the console box insert.



12. Install Instrument Cluster Finish Panel Assembly Center NO.1



  1. Engage the 6 clips and 4 claws.




  2. Install instrument cluster finish panel assembly center No.1 with the 2 screws <C>.



13. Install Position Indicator Housing Assembly

  1. Connect the connector.




  2. Engage the 9 claws and install the position indicator housing assembly.



14. Install Shift Lever Knob



  1. Turn the shift lever knob in the direction of the arrow shown in the illustration to install it.



15. Install Instrument Panel Finish Panel End RH



  1. Engage the 4 clips and install the instrument panel finish panel end RH.



16. Install Instrument Panel Finish Panel End LH



  1. Engage the 4 clips and install the instrument panel finish panel end LH.



17. Install Console Box Assembly Rear
