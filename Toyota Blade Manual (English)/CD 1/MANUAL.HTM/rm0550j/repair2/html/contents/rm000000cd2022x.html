EFI System (2GR-FE) Freeze Frame Data / Detailed Diagnostic Information

Print



  1. Freeze Data Check (Reading Using TaSCAN)

    1. Using the SST (TaSCAN), operate according to the screen display, and select a DTC with recorded freeze data (F displayed) from the [Diagnosis Function Menu] - [DTC Check] screen.

      SST
      09991-70200  

      ■ NOTICE ■
      1. Freeze frame data stores the engine condition when 3 DTCs are detected.
      2. Freeze frame data is classified as shown below, and freeze frame data for 1 DTCs is stored for each group.

        Group Classification
        		DTCs output for misfire detection (P0300/93, P0301/93, P0302/93, P0303/93, P0304/93, P0305/93, P0306/93), rich malfunction (P0172/26) and lean malfunction (P0171/25)
        DTCs that illuminate the check engine light
        DTCs that do not illuminate the check engine light
        To check whether the check engine light illuminates, refer to the Diagnostic Trouble Code Chart ().

      □ HINT □
      1. Time-series freeze data allows the engine condition (ECU data) before and after DTC detection to be checked.
      2. Using time-series freeze data is helpful for troubleshooting when the symptom cannot be reproduced (see).
