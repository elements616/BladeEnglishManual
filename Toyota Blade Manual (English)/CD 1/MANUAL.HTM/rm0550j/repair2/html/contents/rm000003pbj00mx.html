DTC P2109/B9 Throttle Flow Rate Malfunction

Print

Preparation List


Circuit Description


The engine control computer controls the throttle valve opening (ISC flow rate) during idling. If deposits adhere to the throttle valve, the ISC flow rate decreases, which may lead to engine stalling or unstable idling, so the ISC flow rate required for idling is ensured by ISC learning and feedback.

When the ISC learned amount approaches the control limit, the engine control computer outputs a DTC.


DTC No.
SAE/TCCS
P2109/B9
DTC Detection Condition
Diagnosis Condition
When all of the following conditions are met, 1 trip is established.
  1. The engine is started with the coolant temperature at 45°C or less, then warmed up and the ISC learning conditions are met, or 1 hours or more have elapsed with IG ON, the engine is warmed up and the ISC learning conditions are met
  2. There is a driving history of 30 km/h or more.
  3. Intake air flow meter sub-assembly is normal
  4. Atmospheric pressure is 85 kPa or more (altitude 1400 m or less)
Abnormal Condition
ISC learned amount is approximately 3 times normal and intake air volume during idling is normal (within 1.5 times normal)
Malfunction Duration
10 seconds or more continuously
Trip Count
5 trip
Detection Method
Detected 1 time(s) during 1 trip(s). (No detection after judgment.)
Sensors Used for Detection
  1. Throttle body assembly with motor (throttle position sensor)
  2. Intake Air Flow Meter Sub-assembly
Inspection Area
Throttle Body Assembly (with Motor)


Inspection Procedure


□ HINT □
  1. Using SST (TaSCAN), read the Freeze Frame Data. Freeze frame data records part of the engine operating condition when the malfunction occurred, and this information is useful when troubleshooting.
  2. Since no pending code is stored for this DTC, confirming the repair by whether the DTC is output takes a long time. When confirming the repair, it can be done in a short time by comparing the ISC flow learned value stored in the freeze frame data with the ISC flow learned value after repair.

Step 3Throttle Body Assembly (w/ Motor) (Cleaning)

    1. Push the throttle valve open by hand and wipe the carbon off the valve and bore using a cloth or equivalent soaked in engine conditioner (for EFI vehicles).
