Cooler Condenser Assembly (Engine Type 2GR-FE) Reassembly

Print

Preparation List



1. Cooler Dryer Installation



  1. Using needle-nose pliers, insert the cooler dryer into the modulator.




  2. Apply sufficient compressor oil (ND-OIL8) to the O-ring.




  3. Using a straight hexagon wrench 14mm, install the cap to the modulator.



2. Cooler Condenser Cushion NO.1 Installation



  1. Install the 4 cooler condenser cushions NO.1.
