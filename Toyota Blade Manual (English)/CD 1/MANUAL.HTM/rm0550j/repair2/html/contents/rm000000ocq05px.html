ETC System DTC Check/Clear

Print



  1. Read DTC (Read Using TaSCAN)

    1. Turn IG OFF.

    2. Connect SST (TaSCAN) to DLC3.

      SST
      09991-70201  

    3. Start the engine, select "Diagnosis" → "Vehicle Diagnosis/All DTCs" or "Body" → "System Name/Navigation System" → "DTC" on the SST (TaSCAN) screen to display the DTC check screen.

    4. Check the diagnostic trouble codes.

      ■ NOTICE ■
      Always check DTCs with the engine running.

      □ HINT □
      1. If a malfunction code is displayed, refer to the Diagnostic Trouble Code Chart ().
      2. The navigation receiver assembly outputs DTCs for the following systems. If a DTC not listed in the ETC System - Diagnostic Trouble Code Chart is output, refer to the other systems.
        System Name
        		Reference
        HDD Navigation System
        Back Guide Monitor System
      3. After repair, check the DTCs again and confirm that no malfunction code is output.



    1. Clear DTC Memory (Clear Using TaSCAN)

      1. Turn IG OFF.

      2. Connect SST (TaSCAN) to DLC3.

        SST
        09991-70201  

      3. Start the engine, select "Diagnosis" → "Vehicle Diagnosis/All DTCs" or "Body" → "System Name/Navigation System" → "DTC" on the SST (TaSCAN) screen to display the DTC check screen.

      4. Select "Clear" and clear the DTCs following the screen instructions.
