Defogger Relay Inspection

Print

Preparation List



1. Inspect Defogger Relay




  1. Disconnect connectors F, G and Q of the instrument panel junction block assembly.

  2. Using SST (Toyota electrical tester), measure the resistance between each pair of connector terminals.

    SST
    09082-00030  
    09083-00170  

    Resistance

    Tester Connection
    		Condition
    		Standard
    F2(DEF) - G1(ALTB)
    		IG OFF, rear defogger switch OFF
    		10k Ω or higher
    G1(ALTB) - Q12(DFSW)
    		IG ON
    		Below 1 Ω

  3. Connect each connector of the instrument panel junction block assembly.

  4. Using SST (Toyota electrical tester), measure the resistance between each pair of connector terminals.

    SST
    09082-00030  
    09083-00170  

    Resistance

    Tester Connection
    		Condition
    		Standard
    F2(DEF) - G1(ALTB)
    		IG ON, rear defogger switch ON
    		Below 1 Ω
