Function Description


If there are ECUs (sensors) not displayed on the "CAN Bus Connected ECU Check" screen of TaSCAN and ECUs (sensors) alternating between displayed and not displayed, a one-side open circuit has occurred in a CAN bus branch line.

□ HINT □
If there are ECUs (sensors) alternating between displayed and not displayed in the "CAN Bus Connected ECU Check", the incomplete signal output by the ECU with the one-side open branch line becomes noise and affects the signals of ECUs communicating normally.



Inspection Procedure

Step 1Check CAN Bus Connected ECUs
SST
09991-70200  

  1. Check which systems (ECUs, sensors) using CAN communication are equipped on the vehicle brought to the workshop. (see)

  1. Using the SST (TaSCAN), select and execute "CAN Bus Diagnosis" → "CAN Bus Connected ECU Check".

  1. Check the screen display for approximately 1 minutes and identify the ECU and sensor items that are not displayed at all and those alternating between displayed and not displayed.

  1. Perform the communication stop mode inspection for the ECUs and sensors that are not displayed on the screen at all. (List by symptom)
