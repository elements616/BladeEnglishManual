Front Brake Reassembly

Print

Preparation List



1. Temporarily Tighten Front Disc Brake Bleeder Plug


2. Install Front Disc Brake Bleeder Plug Cap


3. Install Piston Seal

  1. Apply rubber grease to the entire circumference of a new piston seal, and install it securely into the groove of the disc brake cylinder.



4. Install Front Disc Brake Piston



  1. Apply rubber grease to a new cylinder boot.

  2. Install the cylinder boot to the disc brake piston.

    ■ NOTICE ■
    Securely install the cylinder boot into the groove of the piston.

  3. Apply a thin coat of rubber grease to the outer circumference of the disc brake piston, and install it to the disc brake cylinder.

    ■ NOTICE ■
    Do not forcibly screw in the piston.



5. Install Cylinder Boot



  1. Install the cylinder boot to the disc brake cylinder.

    ■ NOTICE ■
    Securely install the cylinder boot into the groove of the disc brake cylinder.

  2. Using a flat-head screwdriver with its tip wrapped with protective tape, install a new set ring.

    ■ NOTICE ■
    Do not damage the cylinder boot.
