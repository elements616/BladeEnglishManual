CAN Communication System How to Proceed with Troubleshooting

Print



  1. Points to Note Regarding Troubleshooting

    1. CAN communication malfunction codes are also output due to internal malfunctions and power supply malfunctions of ECUs and sensors in systems that use CAN communication, so pay attention if internal malfunction or power supply malfunction codes for the system concerned are output or stored at the same time.

    2. If a CAN communication malfunction code is confirmed, or if there is no response to SST (TaSCAN) from an ECU that outputs via CAN communication, first check that the DLC3 branch wire and main bus main line circuits are normal.

    3. By inspecting the DLC3 terminals using SST (Toyota electrical tester), malfunctions in the DLC3 branch wire and CAN V bus main line circuits can be checked.

      ■ NOTICE ■
      1. When inspecting the DLC3 connector, do not insert the tester probes directly; connect SST (diagnosis check wire No.2 (09843-18040)) to inspect.
      2. Open circuits in the branch wires of each ECU (sensor) and the V bus No.2 and MS bus circuits cannot be inspected from DLC3.

    4. By checking "CAN Bus Connected ECU" using SST (TaSCAN), ECUs (sensors) with open branch wires connected to the CAN bus circuit can be identified. (When DLC3 branch wire and main bus main line circuits are normal)

      □ HINT □
      1. When checking CAN bus connected ECUs, ECUs (sensors) with open branch wires do not respond to (are not displayed on) SST (TaSCAN).
      2. When checking CAN bus connected ECUs, if all ECUs respond (are displayed) but a CAN communication malfunction DTC is output, check the communication malfunction DTCs.

    5. For past V bus malfunctions, identify the ECU (sensor) whose communication was lost from the combination of communication malfunction DTCs output.

    6. Malfunctions in the MS bus circuit are detected by the main body ECU, which outputs a DTC corresponding to the malfunctioning area.

    7. Malfunctions in the V bus No.2 circuit are detected by the CAN gateway ECU, which outputs a DTC corresponding to the malfunctioning area.

    8. If an open circuit malfunction is confirmed, before disconnecting and inspecting the related connectors, push the connector case in the connecting direction and check that the connector is not loose or disconnected.

    9. When disconnecting a connector, check that the connector terminals and connector case are free of damage, deformation, corrosion, etc.


    ■ NOTICE ■
    When measuring the resistance of the CAN bus, turn the IG OFF, confirm that warning functions such as the key reminder warning system are not operating, and leave the vehicle for 1 minutes or more without operating the key or opening/closing the doors before starting measurement. If it is necessary to open a door during inspection, open it beforehand.

        Step 3Check DTC (ALL DTCs)

        1. Using SST (TaSCAN), perform "DTC (ALL) Check".

          ■ NOTICE ■
          1. If the ECU or sensor indicated by a CAN communication malfunction code as having lost communication has stored codes such as power supply malfunction or internal malfunction, it is highly likely that the ECU or sensor was unable to transmit signals rather than that the communication line is malfunctioning, so first troubleshoot the DTCs for those component malfunctions.
          2. If a connector containing CAN communication lines is disconnected with the ignition ON or ACC ON, ECUs of related systems as well as the ECU of the system concerned store CAN communication malfunction codes.

        Step 9Check Communication Malfunction DTCs (Check Past DTCs)

          SST
          09991-70200  

        1. Perform "CAN Bus Diagnosis" → "Communication Malfunction DTC Check" on SST (TaSCAN). (see)

        2. Record all codes stored in each ECU.

          □ HINT □
          1. If communication malfunction DTCs are stored and all ECUs and sensors connected to CAN communication are displayed on the TaSCAN "CAN Bus Connected ECU Check" screen, a past malfunction that is not currently occurring is suspected.
          2. V bus branch wire malfunctions are detected by each related ECU, so identify the malfunctioning area from the combination of codes output.
          3. For MS bus malfunctions, the main body ECU detects loss of communication with connected ECUs and network malfunctions, and outputs codes.
          4. For V bus No.2 malfunctions, the CAN gateway ECU detects loss of communication with connected ECUs and outputs codes.
          5. If V bus connected ECUs and the main body ECU or CAN gateway ECU are outputting malfunction codes, inspect and repair the MS bus and V bus No.2 first.

        Step 11Problem Reproduction Test (Past Malfunction of V Bus Main Line)

          SST
          09991-70200  

        1. Using SST (TaSCAN), clear the DTCs.

        2. Perform a problem symptom simulation inspection on the wire harnesses and connectors including the V bus main line.

        3. Through the problem simulation inspection, check the area that outputs the malfunction DTC and identify the malfunctioning area.
