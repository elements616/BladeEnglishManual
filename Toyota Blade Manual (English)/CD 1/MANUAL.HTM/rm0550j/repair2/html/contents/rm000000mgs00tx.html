Engine Immobiliser System DTC Check/Clear

Print





  1. Pre-inspection Preparation

    1. Move the shift lever to the P position.

    2. Turn the A/C OFF.



    1. DTC Check

      1. Connect SST (TaSCAN) to DLC3.

        SST
        09991-70200  

      2. Check the DTCs of the EFI system. (see)

      3. Select [Diagnosis] → [Body] → [Certification] → [DTC] on the screen and check the DTCs.


      □ HINT □
      The output codes of the steering lock ECU (steering lock actuator) and ID code box (immobiliser code computer) are also output together. (The steering lock ECU and ID code box respond to SST (TaSCAN) via the certification ECU.)



      1. Clearing DTC Memory

        1. Connect SST (TaSCAN) to DLC3.

          SST
          09991-70200  

        2. Follow the screen display to display the [DTC Check] screen, select [Clear], and clear the DTCs.

          ■ NOTICE ■
          1. If the DTCs cannot be cleared, perform the procedure again from the ignition switch OFF state.
          2. If [Clear] is selected and executed on the ALL DTC display screen, the DTCs of all systems will be cleared.
