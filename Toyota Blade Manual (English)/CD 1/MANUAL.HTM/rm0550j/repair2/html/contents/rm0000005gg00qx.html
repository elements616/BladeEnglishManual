Smart Entry & Start System (Smart Entry) ECU Data Monitor / Active Test

Print


■ NOTICE ■
When using SST (TaSCAN) with the IG OFF, repeatedly turn any door courtesy light switch ON ←→ OFF until communication between TaSCAN and the vehicle starts. (ON←→OFF interval within 1.5 seconds)
