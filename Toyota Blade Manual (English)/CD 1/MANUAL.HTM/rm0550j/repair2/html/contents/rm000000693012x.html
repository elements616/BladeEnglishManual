Large-scale Body Multiplex Communication System [LIN] DTC Check / Clear

Print


■ NOTICE ■
  1. When using SST (TaSCAN) with the ignition switch OFF, repeatedly turn any door courtesy light switch ON/OFF (at intervals of 1.5 seconds or less) until communication between SST (TaSCAN) and the vehicle starts.



  1. DTC Check

    1. Check Certification ECU DTCs


      1. With the ignition switch OFF, connect SST (TaSCAN) to DLC3.

        SST
        09991-70200  

      2. Following the SST (TaSCAN) screen display, display the [Diagnosis] → [Body] → [Certification] → [DTC] screen and check the DTCs.

        □ HINT □
        DTCs are output even with the ignition switch OFF.

    2. Check Main Body ECU DTCs


      1. With the ignition switch OFF, connect SST (TaSCAN) to DLC3.

        SST
        09991-70200  

      2. Following the SST (TaSCAN) screen display, display the [Diagnosis] → [Body] → [Main Body] → [DTC] screen and check the DTCs.

        □ HINT □
        DTCs are output even with the ignition switch OFF.



    1. Clearing DTC Memory

      1. Clear Certification ECU DTCs


        1. With the ignition switch OFF, connect SST (TaSCAN) to DLC3.

          SST
          09991-70200  

        2. Following the SST (TaSCAN) screen display, display the [Diagnosis] → [Body] → [Certification] → [DTC] screen and clear the DTCs.

          ■ NOTICE ■
          1. If they cannot be cleared, start again from the ignition switch OFF condition.
          2. Do not clear DTCs using SST (TaSCAN) until the cause has been identified.

      2. Clear Main Body ECU DTCs


        1. With the ignition switch OFF, connect SST (TaSCAN) to DLC3.

          SST
          09991-70200  

        2. Following the SST (TaSCAN) screen display, display the [Diagnosis] → [Body] → [Main Body] → [DTC] screen and clear the DTCs.

          ■ NOTICE ■
          1. If they cannot be cleared, start again from the ignition switch OFF condition.
          2. Do not clear DTCs using SST (TaSCAN) until the cause has been identified.
