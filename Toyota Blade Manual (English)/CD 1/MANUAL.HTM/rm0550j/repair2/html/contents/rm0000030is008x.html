Front Bumper Assembly Reassembly

Print

Preparation List



1. Install Front Bumper Reinforcement Sub-assembly



  1. Install the front bumper reinforcement with the 8 bolts.

    Standard
    T = 50 N/m{ 510 kgf/cm }




  2. Engage the 8 clamps.



2. Install Front Bumper Energy Absorber



  1. Align the 3 fitting points and install the front bumper energy absorber to the front bumper reinforcement.



3. Install Front Bumper Side Retainer LH



  1. Engage the 2 claws.

  2. Install the front bumper side retainer LH with the bolt and screw.



4. Install Front Bumper Side Retainer RH

□ HINT □
Install it in the same way as for the LH side.



5. Install Front Bumper Hole Cover Assembly LH



  1. Engage the 8 claws and install the front bumper hole cover assembly LH.




  2. Install the screw.



6. Install Front Bumper Hole Cover Assembly RH

□ HINT □
Install it in the same way as for the LH side.



7. Install Radiator Grille LWR LH



  1. Engage the 6 claws and install the radiator grille LWR LH.



8. Install Radiator Grille LWR RH

□ HINT □
Install it in the same way as for the LH side.



9. Install Front Bumper Hole Cover LH



  1. Engage the 2 claws and install the front bumper hole cover LH.



10. Install Front Bumper Hole Cover RH

□ HINT □
Install it in the same way as for the LH side.



11. Install Radiator Grille Emblem Assembly (w/o Radar Cruise)



  1. Engage the 4 claws and 2 guides, and install the radiator grille emblem assembly.



12. Install Radiator Grille Emblem Assembly (w/ Radar Cruise)



  1. Engage the claws.

  2. Install the radiator grille emblem assembly with 2 new spring nuts.



13. Install Radiator Grille (Radiator Grille Bar Type)



  1. Engage the 6 claws and install the radiator grille.



14. Install Radiator Grille Sub-assembly (Radiator Grille Bar Type)



  1. Install the radiator grille sub-assembly with the 12 claws.

  2. Install the 3 screws.



15. Install Radiator Grille Sub-assembly (Radiator Grille Mesh Type)



  1. Engage the 6 claws and install the radiator grille sub-assembly.



16. Install Radiator Grille Molding UPR RH (Engine Type 2GR-FE)



  1. Install the radiator grille molding UPR RH with the 4 screws.



17. Install Hood to Front End Panel Seal

  1. Rub off the double-sided tape remaining on the radiator grille with a shop rag, etc.

    ■ NOTICE ■
    Installing the hood to front end panel seal with double-sided tape remaining may cause poor adhesion, so remove it thoroughly.

  2. Clean the adhesive surface with white gasoline.




  3. Peel off the release paper of a new hood to front end panel seal, install it with the 5 clips, then press it firmly against the radiator grille to install the hood to front end panel seal.



18. Install Fog Light Assembly LH



  1. Install the fog light assembly LH with the screw.



19. Install Fog Light Assembly RH

□ HINT □
Install it in the same way as for the LH side.



20. Install Front Spoiler Side Protector LH (w/ Front Spoiler)

  1. Rub off the double-sided tape remaining on the front spoiler cover LH with a cloth, etc.

    ■ NOTICE ■
    1. Installing the front spoiler side protector LH with double-sided tape remaining may cause poor adhesion, so continue until it is thoroughly removed.
    2. Removing it with a screwdriver, etc. will cause scratches and poor adhesion, so rub it off with a cloth, etc.

  2. Clean the installation surface using white gasoline.

  3. Apply primer to the front spoiler side protector LH installation surface of the front spoiler cover LH.

  4. Peel off the release paper of the double-sided tape without touching the adhesive surface.




  5. Install a new front spoiler side protector LH within the scribed lines (application reference range) on the front spoiler cover LH.

    Part
    		Specified Condition
    A
    		Application Range

    ■ NOTICE ■
    Press the front spoiler side protector LH firmly to apply it.



21. Install Front Spoiler Side Protector RH (w/ Front Spoiler)

□ HINT □
Install it in the same way as for the LH side.



22. Install Front Spoiler Cover LH (w/ Front Spoiler)



  1. Install the front spoiler cover with the 5 front spoiler retainers.



23. Install Front Spoiler Cover RH (w/ Front Spoiler)

□ HINT □
Install it in the same way as for the LH side.
