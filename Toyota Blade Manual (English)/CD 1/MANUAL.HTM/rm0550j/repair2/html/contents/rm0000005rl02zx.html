MS Bus DTC (Main Body ECU Output Code) List 
Symptom
Inspection Point
Reference Page
U0327

Sub-network Communication Malfunction (Main Body)

■ NOTICE ■
The reference pages for when the above codes are output apply only when they are output by the main body ECU (MS bus monitoring ECU). If an ECU other than the main body ECU outputs the above codes, it is necessary to identify the malfunctioning area from "How to Proceed with Troubleshooting".


□ HINT □
If a communication stop or bus malfunction occurs in an ECU connected to the MS bus, the main body ECU detects the malfunction and outputs a DTC.

Driving Support ECU Communication Malfunction

■ NOTICE ■
The reference pages for when the above codes are output apply only when they are output by the CAN gateway ECU (V bus No.2 monitoring ECU). If an ECU other than the CAN gateway ECU outputs the above codes, it is necessary to identify the malfunctioning area from "How to Proceed with Troubleshooting".


□ HINT □
  1. If a communication stop or bus malfunction occurs in an ECU connected to V bus No.2, the CAN gateway ECU detects the malfunction and outputs a DTC.
  2. 2WD models equipped with neither pre-crash safety nor radar cruise control have no V bus No.2 configuration and no CAN gateway ECU wiring.
