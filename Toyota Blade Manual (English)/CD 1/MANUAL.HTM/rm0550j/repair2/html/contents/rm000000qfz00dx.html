Side Airbag Sensor Assembly RH Installation

Print

Preparation List



1. Install Side Airbag Sensor Assembly RH

  1. Make sure that the ignition switch is OFF.

  2. Check that the battery negative terminal is disconnected.

    ■ WARNING ■
    1. If work is performed without disconnecting the battery negative terminal, the airbag may deploy even if an impact is applied only to the side airbag sensor assembly RH by itself, so always confirm that the battery negative terminal is disconnected before performing work.
    2. After disconnecting the battery negative terminal, do not start work for 90 seconds.

  3. Connect the connector to the side airbag sensor assembly RH.




  4. Insert the pin portion into the body hole and install the side airbag sensor assembly RH to the vehicle with the bolt.

    Standard
    T = 9.0 N/m{ 92 kgf/cm }

    ■ NOTICE ■
    1. Do not reuse any part that has been dropped or subjected to a strong impact during work.
    2. Securely set the pin portion in the body hole.
    3. As the pin portion (anti-rotation portion) is easily damaged, tighten the bolt while holding the side airbag sensor assembly RH by hand.

  5. Check that there is no looseness in the side airbag sensor assembly RH.



2. Install Center Pillar Garnish LWR RH



  1. Engage the 2 clips.

  2. Engage the 2 claws B.

  3. Spread the garnish left and right by hand, engage the 2 claws A and install the center pillar garnish LWR RH.



3. Install Rear Door Opening Trim Weatherstrip RH



  1. Align the paint mark (white) of the weatherstrip with the arrow part on the body side shown in the illustration, and install the rear door opening trim weatherstrip RH.

    ■ NOTICE ■
    After installation, check that the corners are not lifted.



4. Install Rear Door Scuff Plate RH



  1. Engage the 8 claws to install the rear door scuff plate RH.



5. Install Front Door Opening Trim Weatherstrip RH



  1. Align the paint mark (blue) of the weatherstrip with the arrow part on the body side shown in the illustration, and install the front door opening trim weatherstrip RH.

    ■ NOTICE ■
    After installation, check that the corners are not lifted.



6. Install Front Door Scuff Plate RH



  1. Engage the 10 claws and install the front door scuff plate RH.



7. Connect Battery Negative Terminal
Standard
T = 5.4 N/m{ 55 kgf/cm }
