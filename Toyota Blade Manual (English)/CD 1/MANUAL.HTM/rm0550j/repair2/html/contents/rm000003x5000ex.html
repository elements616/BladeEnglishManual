DTC B15BB USB-BOX Malfunction

Print

Preparation List


Function Description


This DTC is output when a malfunction occurs in the multimedia interface computer.


Diagnostic Trouble Code (DTC)
Diagnosis Description
Inspection Point
B15BB
  1. When a system microcomputer malfunction is detected
  2. When a media I/F microcomputer malfunction is detected
  3. When a CD-LSI malfunction is detected
  4. Internal power source malfunction
  1. A USB memory or "iPod"
  2. Wire Harness or Connector
  3. Stereo Jack Adapter Assembly NO.1
  4. Multimedia Interface ECU

Inspection Procedure

Step 1Replace USB Memory or "iPod"

  1. Disconnect the USB memory or "iPod" from stereo jack adapter assembly NO.1.

  1. Turn the ignition OFF → ACC ON.

    □ HINT □
    When connecting a different USB memory or "iPod", the ignition must be turned OFF for the vehicle to recognize the connected device.

  1. Connect a normal USB memory or "iPod" to stereo jack adapter assembly NO.1.

    □ HINT □
    1. If using a USB memory, check with a different USB memory.
    2. If using an "iPod", check with a different "iPod".
    3. For supported formats and versionsReference

    2. Disconnect the stereo jack adapter assembly NO.1 connector.

  1. Resistance Inspection

    1. Using SST (Toyota electrical tester), measure the resistance between each terminal of the vehicle wire harness connectors between the multimedia interface ECU and stereo jack adapter assembly NO.1.
