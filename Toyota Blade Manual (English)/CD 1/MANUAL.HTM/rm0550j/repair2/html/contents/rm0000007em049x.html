HDD Navigation System AVC-LAN Malfunction

Preparation List


Circuit Description


The HDD navigation system uses AVC-LAN for communication between devices. If a malfunction such as a short between communication lines, short to +B or short to GND occurs in the AVC-LAN circuit, communication is interrupted and the HDD navigation system does not operate normally. In this case, the system returns to normal when the malfunctioning area is disconnected from the AVC-LAN circuit, so the malfunctioning area can be identified.
