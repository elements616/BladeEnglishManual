Engine Mounting Insulator RH (2GR-FE) Installation

Print

Preparation List



1. Install Engine Mounting Insulator Sub-assembly RH



  1. Install the engine mounting insulator RH with the 3 bolts.

    Standard
    T = 95 N/m{ 969 kgf/cm }



2. Connect Engine Mounting Insulator Sub-assembly RH



  1. Install the engine mounting insulator RH to the engine mounting bracket RH with the 2 bolts and 2 nuts.

    Standard
    T = 95 N·m{ 969 kgf·cm } (Bolt)
    T = 95 N*m{ 969 kgf*cm } (Nut A)
    T = 52 N*m{ 530 kgf*cm } (Nut B)




  2. Install the cooler pipe bracket with the 2 bolts and nut.




  3. Connect the ground wire with the 2 bolts and 2 clamps.



3. Install Radiator Reserve Tank Assembly



  1. Install the radiator reserve tank assembly with the 2 bolts.

    Standard
    T = 5 N/m{ 51 kgf/cm }



4. Install Engine Under Cover Rear RH

  1. Install the engine under cover rear RH with the 5 clips.



5. Install Front Tire RH
Standard
T = 103 N/m{ 1050 kgf/cm }


6. Install Engine Mounting Stay NO.2 RH



  1. Install engine mounting stay No.2 RH with the bolt and 2 nuts.

    Standard
    T = 20 N/m{ 204 kgf/cm }



7. Install V-bank Cover Sub-assembly



  1. Engage the 3 clips to install the V-bank cover.

    ■ NOTICE ■
    1. Make sure the clips are securely engaged.
    2. Engaging them with excessive force or striking the top of the clips may cause damage.



8. Install Radiator Upper Air Deflector



  1. Install the radiator upper air deflector with the 9 clips.
