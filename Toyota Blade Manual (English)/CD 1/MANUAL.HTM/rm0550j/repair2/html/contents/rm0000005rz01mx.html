CAN Communication System System Description

Print



  1. Outline

    1. CAN (Controller Area Network) is a serial communication for real-time applications; it is an in-vehicle multiplex communication system with excellent data communication speed and error detection capability.

    2. CAN uses 2 lines, CAN-H and CAN-L, as a pair, and communicates using differential voltage.

    3. Vehicles are equipped with many ECUs (sensors), but they do not operate independently; they operate in coordination by sharing information with other ECUs (sensors) using CAN communication.

    4. The CAN communication main line contains 2 resistors necessary for communication transmission.



    1. Definition of Terms

      1. Main Line


        1. The harness between the 2 terminating circuits located on the bus (communication line) is defined as the main line. It is the trunk bus of the control system CAN.

      2. Branch Line


        1. A line branching from the main line, which is the trunk bus of the CAN bus, to an ECU or sensor is defined as a branch line.

      3. Terminating Circuit


        1. A circuit consisting of a resistor and a capacitor, provided to convert the communication current of the control system CAN to bus voltage, is called a terminating circuit. Terminating circuits must be provided at both ends of the bus main line, 1 at each end, for a total of 2.



      1. Circuit Description

        1. Except for some vehicle models, the system consists of 3 bus circuits: V bus, V bus No.2 and MS bus. (For the connection circuit,)

          □ HINT □
          E grade 2WD models not equipped with Intelligent Parking Assist (combined with HDD navigation) do not have V bus No.2.

        2. The V bus, V bus No.2 and MS bus each use a 120 Ω resistor in the terminating circuit, enabling high-speed communication of 500kbps on the V bus and V bus No.2, and 250kbps on the MS bus.
