Front Brake Installation

Print

Preparation List



1. Install Front Disc



  1. Align the matchmarks on the disc and axle hub, and install the disc.

    ■ NOTICE ■
    When replacing the disc, select the installation position where the disc runout is minimal.



2. Install Front Disc Brake Cylinder Mounting LH



  1. Install the disc brake cylinder mounting to the steering knuckle with the 2 bolts.

    Standard
    T = 107 N/m{ 1090 kgf/cm }



3. Install Front Disc Brake Bushing Dust Boot



  1. Apply rubber grease to the inside of the new dust boots.

  2. Install the dust boots to the disc brake cylinder mounting.



4. Install Front Disc Brake Cylinder Slide Bushing NO.1

  1. Apply rubber grease to the contact surfaces of the new front disc brake cylinder slide bushing No.1 and front disc brake cylinder slide pin No.2.

  2. Install front disc brake cylinder slide bushing No.1 to front disc brake cylinder slide pin No.2.



5. Install Front Disc Brake Cylinder Slide Pin



  1. Apply rubber grease to the sliding and fitting parts of the front disc brake cylinder slide pins.




  2. Install the front disc brake cylinder slide pins to the disc brake cylinder mounting.



6. Install Front Disc Brake Pad Support Plate No.1



  1. Install front disc brake pad support plate No.1 to the front disc brake cylinder mounting LH.

    ■ NOTICE ■
    Do not mistake the installation positions and directions of front disc brake pad support plate No.1 and front disc brake pad support plate No.2.



7. Install Front Disc Brake Pad Support Plate No.2

  1. Install front disc brake pad support plate No.2 to the front disc brake cylinder mounting LH.

    ■ NOTICE ■
    Do not mistake the installation positions and directions of front disc brake pad support plate No.1 and front disc brake pad support plate No.2.



8. Install Anti-squeal Shim Kit Front



  1. Apply disc brake grease to both sides of front disc brake anti-squeal shim No.1, and install it together with front disc brake anti-squeal shim No.2 to the brake pad.



9. Install Disc Brake Pad Kit Front



  1. Install the front disc brake pads to the front disc brake cylinder mounting LH.



10. Install Disc Brake Cylinder Assembly LH



  1. Hold the cylinder slide pin and cylinder slide pin No.2 with a wrench, and install the disc brake cylinder assembly to the front disc cylinder mounting LH with the 2 bolts.

    Standard
    T = 34 N/m{ 347 kgf/cm }



11. Connect Front Flexible Hose NO.1

  1. Install a new gasket to front brake flexible hose No.1.




  2. Connect front brake flexible hose No.1 to the disc brake cylinder assembly with the union bolt.

    Standard
    T = 29 N/m{ 296 kgf/cm }



12. Install Front Tire
Standard
T = 103 N/m{ 1050 kgf/cm }


13. Fill Brake Fluid



  1. Stand the brake fluid can upside down over the reservoir.

    ■ NOTICE ■
    1. Make sure that there is a sufficient amount of brake fluid in the can.
    2. When filling, bleed the air after confirming that the reservoir on top of the master cylinder assembly is sufficiently filled.



14. Bleed Brake Master Cylinder Assembly



  1. Using a union nut wrench (10mm), disconnect the 2 brake tubes from the master cylinder.




  2. Slowly depress the brake pedal and hold it.




  3. Block the tube holes with your fingers and release the brake pedal.

  4. Remove your fingers, slowly depress and hold the brake pedal, block the tube holes again and release the brake pedal; repeat this 3 or 4 times.




  5. Using a union nut wrench (10mm), connect the 2 brake tubes to the master cylinder assembly.

    Standard
    Specified torque
    T = 15 N/m{ 153 kgf/cm }
    When using union nut wrench + torque wrenchL155mm
    T = 13 N/m{ 133 kgf/cm }



15. Bleed Brake Line

  1. Connect a vinyl tube to the bleeder plug.

  2. Depress the brake pedal several times, and loosen the bleeder plug with the brake pedal depressed. (*1)

  3. When fluid stops coming out, tighten the bleeder plug and release the brake pedal. (*2)

  4. Repeat (*1) to (*2) until there is no air in the brake fluid.

  5. Bleed the air from the brake line of each wheel in the same way.

    Standard
    Front Bleeder Plug
    T = 8.3 N/m{ 85 kgf/cm }
    Rear Bleeder Plug
    T = 11 N/m{ 112 kgf/cm }



16. Bleed Air from ABS & Traction Actuator Assembly

■ NOTICE ■
  1. If appropriate brake pedal height and feel cannot be obtained after performing normal brake line bleeding, air may have entered; perform the following bleeding again.
  2. Bleeding without using the SST (TaSCAN) may lead to malfunctions or accidents, so be sure to use the SST (TaSCAN).

  1. Turn the IG OFF and depress the brake pedal 20 times or more.

  2. With the IG still OFF, connect the SST (TaSCAN) to DLC3.

    SST
    09991-70200  

  3. Turn IG ON.

    ■ NOTICE ■
    The engine will not start.

  4. Turn the SST (TaSCAN) power switch ON, select "Menu (Work Support)" → "ABS/VSC/ECB" → "Air Bleeding" and execute it.

  5. Bleed Actuator Intake System

    ■ NOTICE ■
    Bleed the actuator intake system at the 2 right side wheels (front and rear wheels).


    1. On the SST (TaSCAN) menu screen, select intake system bleeding and execute it.

    2. Loosen the bleeder plug of the right front wheel. (*1)

    3. Operate the SST (TaSCAN) to operate the actuator.

      □ HINT □
      1. To protect the actuator, it automatically stops after 4 seconds.
      2. Leave the brake pedal released.

    4. Check on the SST (TaSCAN) screen that operation has stopped.

    5. Temporarily tighten the bleeder plug. (*2)

    6. Repeat the procedure from (*1) to (*2) until the air is completely bled.

    7. Tighten the bleeder plug.

      Standard
      T = 8.3 N/m{ 85 kgf/cm }

    8. Perform the same procedure for the right rear wheel as for the right front wheel.

      Standard
      T = 11 N/m{ 112 kgf/cm }

  6. Bleed Actuator Pressure Reduction System

    ■ NOTICE ■
    Bleed the actuator pressure reduction system at each of the 4 wheels.


    1. Execute pressure reduction system bleeding on the SST (TaSCAN) menu screen.

    2. Loosen the bleeder plug of the right front wheel. (*3)

    3. Operate the actuator using the SST (TaSCAN), and at the same time fully depress the brake pedal and hold it.

      ■ NOTICE ■
      1. The brake pedal will feel heavy at this time, but keep depressing it until brake fluid comes out of the bleeder plug.
      2. Hold the brake pedal depressed and do not pump it.

      □ HINT □
      To protect the solenoids, actuator operation automatically stops after 4 seconds. Also, when operating it continuously, wait at least 20 seconds between operations.

    4. Tighten the bleeder plug and release the brake pedal. (*4)

    5. Repeat the procedure from (*3) to (*4) until the air is completely bled.

    6. Tighten the bleeder plug.

    7. Perform the same procedure for the other 3 wheels as for the right front wheel.

      Standard
      Front Bleeder Plug
      T = 8.3 N/m{ 85 kgf/cm }
      Rear Bleeder Plug
      T = 11 N/m{ 112 kgf/cm }

  7. Perform normal brake line bleeding again by pumping the brake pedal.

    ■ NOTICE ■
    Repeat bleeding for each of the 4 wheels until the air is completely bled.



17. Inspect for Brake Fluid Leaks


18. Inspect Brake Fluid Level

  1. Check the brake fluid level, and add fluid up to the MAX line of the reservoir if necessary.

    ■ NOTICE ■
    When adjusting the fluid level using a syringe etc., do not use one that has been used for mineral oil, water or deteriorated brake fluid. Doing so will cause deterioration of seal parts and fluid, resulting in fluid leaks and poor braking performance.
