Print

DTC P1551/A7 Battery Current Sensor Circuit (Low)

DTC P1552/A7 Battery Current Sensor Circuit (High)

Preparation List


Circuit Description


The battery current sensor assembly detects the amount of battery charge/discharge current, converts the signal into a voltage, and outputs it to the engine control computer. Based on this signal, the engine control computer commands the generating voltage of the alternator.
