Back Guide Monitor System Function Description

Print




  1. Communication System


    1. AVC-LAN


      1. The HDD navigation system uses AVC-LAN for communication between devices.

      2. The master device of the AVC-LAN is the navigation receiver assembly.

      3. The navigation receiver assembly contains a resistor necessary for communication transmission (between terminals TX+ and TX- 60 to 80 Ω).

      4. If an open or short occurs in the AVC-LAN circuit, communication is interrupted, and the HDD navigation system and back guide monitor system do not operate normally.



    1. Diagnosis Function

      1. Adjustment of the back guide monitor system is performed on the diagnosis screen of the navigation receiver assembly.

        When the work shown in the table below is performed, adjustment and checks on the diagnosis screen are necessary.

        Work Performed
        		Adjustment Item
        		Reference

        2. Replacement of television camera assembly

        		(see)
        1. Replacement of navigation receiver assembly
        2. When the estimated course has deviated for some reason
        1. Memorization of steering angle neutral point
        2. Memorization of left and right maximum steering angles
        3. Camera Optical Axis Adjustment
        		(see)
        1. When the battery terminal has been disconnected
        2. When the steering sensor has been replaced or removed/installed
        3. When the estimated course is not displayed in course display mode and there is no malfunction in the steering sensor

        		(see)

      2. The back guide monitor system has a diagnosis function. (Displayed on the navigation receiver assembly)

      3. Each component that makes up the AVC-LAN is assigned a 3-digit number (expressed in base 16) called a component code (physical address).

      4. Each function (unit) within an AVC-LAN component is assigned a 2-digit number (expressed in base 16) called a logical address.
