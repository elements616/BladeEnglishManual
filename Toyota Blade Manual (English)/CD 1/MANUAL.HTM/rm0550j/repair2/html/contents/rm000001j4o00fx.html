Indoor Electrical Key Oscillator (Installation Position Rear Floor) Installation

Print

Preparation List



1. Install Indoor Electrical Key Oscillator



  1. Install the indoor electrical key oscillator with the bolt.

  2. Connect the connector.



2. Install Rear Seat Assembly RH



  1. Set the rear seat assembly RH in the vehicle, and install the 2 rear side bolts in the order inner → outer.

    Standard
    T = 42 N/m{ 428 kgf/cm }




  2. Raise the seatback, and install the 2 front side bolts of the rear seat assembly RH in the order inner → outer.

    Standard
    T = 42 N/m{ 428 kgf/cm }



3. Install Rear Seat Cushion Hinge Cover NO.2



  1. Engage the 4 claws and install the rear seat cushion hinge cover NO.2.



4. Install Rear Seat Cushion Hinge Cover NO.1



  1. Engage the 4 claws and install the rear seat cushion hinge cover NO.1.



5. Install Rear Seat Headrest Assembly CTR


6. Install Rear Seat Headrest Assembly


7. Install Rear Door Scuff Plate RH



  1. Engage the 8 claws to install the rear door scuff plate RH.



8. Install Rear Seat Assembly LH



  1. Set the rear seat assembly LH in the vehicle, and install the 2 rear side bolts in the order inner → outer.

    Standard
    T = 42 N/m{ 428 kgf/cm }




  2. Raise the seatback, and install the 2 front side bolts of the rear seat assembly LH in the order inner → outer.

    Standard
    T = 42 N/m{ 428 kgf/cm }



9. Install Rear Seat Cushion Hinge Cover NO.2



  1. Engage the 4 claws to install the rear seat cushion hinge cover NO.2.



10. Install Rear Seat Cushion Hinge Cover NO.1



  1. Engage the 4 claws and install the rear seat cushion hinge cover NO.1.



11. Install Rear Seat Headrest Assembly


12. Install Rear Door Scuff Plate LH

□ HINT □
Install using the same procedure as for the RH side.
