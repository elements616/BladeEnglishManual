Electric Power Steering System Special Operation/Control History

Print



  1. Special Control History

    1. Turn IG OFF.

    2. Connect SST (TaSCAN) to DLC3.

      SST
      09991-70200  

    3. Turn the ignition ON, select "Diagnosis" → "Chassis" → "Electric Power Steering" → "Special Control History" on the SST (TaSCAN) display screen, and check the history.

      Special Control History 
      Item
      (TaSCAN Display)
      		Item Description
      Overheat Prevention Control History
      		Indicates whether there is overheat prevention control history
      Display: None/Yes
      PIG Power Supply Voltage Drop History
      		Indicates whether there is PIG power supply voltage drop history
      Display: None/Yes
      Engine Speed Signal Loss History
      		Indicates whether there is engine speed signal loss history
      Display: None/Yes
      Steering Angle Sensor Signal Loss History
      		Indicates whether there is steering angle sensor signal loss history
      Display: None/Yes
      Vehicle Speed Signal Invalid History
      		Indicates whether there is vehicle speed signal invalid history
      Display: None/Yes
