    Step 2Customer Problem Analysis and Symptom Check

    1. Check sheet (see)

      1. When a customer complains of a problem with the ETC system, perform a customer problem analysis using the ETC check sheet.

        □ HINT □
        1. In the ETC system, toll payment is made by wireless communication. For this reason, it is necessary to carefully ask about the installation condition of the ETC on-board unit in the vehicle and the vehicle environment at that time.
        2. To find out the frequency of the problem, ask the customer how often they use ETC.


    NEXT


    Step 3Check Toll Collection (ETC) Computer Assembly Startup

    1. Check Toll Collection (ETC) Computer Assembly Startup

      1. Turn ACC ON.

      2. Check that the green indicator and amber indicator illuminate for 5 seconds.

      3. Check that the startup check ends normally and the indicators go off.

        □ HINT □
        1. If there is a malfunction in the toll collection (ETC) computer assembly, the amber indicator blinks, the multi-display voice gives the notification "Bong. A malfunction has occurred in the ETC. ETC cannot be used", and the JEITA standard error code is displayed on the multi-display.
        2. If the toll collection (ETC) computer assembly has not yet been set up, the toll collection (ETC) computer assembly announces by voice "Beep beep. Not set up.".
        3. When not set up, voice notifications from the toll collection (ETC) computer assembly cannot be given if it has been muted by the volume adjustment on the toll collection (ETC) computer assembly itself. Therefore, set the volume of the toll collection (ETC) computer assembly itself to "Volume 1" or higher before checking.

    Step 5Check ETC Card Insertion (Card Authentication)

    1. ETC Card Insertion Check

      1. Insert the ETC card.

      2. A "beep" is announced by the multi-vision voice, the green indicator starts blinking, and card authentication begins.

      3. Check that "Bong, ETC card has been inserted" is announced by the multi-vision voice and the green indicator illuminates.

        □ HINT □
        1. If there is a problem with the ETC card, the orange indicator blinks, "Bong, card cannot be read, please check card" is announced by the multi-vision voice, and a JEITA unified error code is displayed on the multi-display.
        2. The warning sound of the toll collection (ETC) computer assembly continues until the card is removed.

      Step 12Work after Replacement

        □ HINT □
        1. When replacing the navigation receiver assembly on a vehicle not subscribed to the G-BOOK service, perform the vehicle linking setting. (see)
        2. When replacing the navigation receiver assembly on a vehicle subscribed to the G-BOOK service, perform the vehicle linking setting, then perform the G-BOOK use resumption operation and HELPNET service start operation.
        3. If the navigation receiver assembly is replaced while a purchased G-SOUND unlimited license exists, perform G-SOUND license recovery.
