ABS with EBD & TRC & VSC & BA System Freeze Frame Data / Detailed Diagnostic Information

Print



  1. About Freeze Frame Data Output

    1. The skid control computer (built into the actuator) stores the vehicle (sensor) conditions when the system operates or when a malfunction DTC is output, and these can be displayed using the SST (TaSCAN).

    2. Freeze Frame Data During System Operation


      1. Data is stored when the system operates and is updated each time the system operates.

      2. The number of times the IG has been turned OFF → ON since the system last operated is stored and displayed up to 31 times.

        □ HINT □
        1. The IG ON count is incremented only when the vehicle is driven at 7km/h or more after the IG is turned OFF → ON.
        2. If "Number of IG ON Times Since Freeze" exceeds 31, "31" is displayed.

      3. When freeze frame data from when a malfunction DTC occurred is stored, the freeze frame data from system operation is cleared.

    3. Freeze Frame Data When Malfunction DTC Occurs


      1. When a malfunction DTC is output, the freeze frame data from when the malfunction code occurred is stored.

      2. Once freeze frame data from when a malfunction DTC occurred is stored, the freeze frame data is not updated until the DTCs are cleared.

      3. In freeze frame data from when a malfunction DTC occurred, "Number of IG ON Times Since Freeze" is not stored.
