Timing Gear Case or Timing Chain Case Oil Seal (2GR-FE) Installation

Print

Preparation List



1. Install Timing Gear Case or Timing Chain Case Oil Seal



  1. Using SST, uniformly drive in the oil seal until it is flush with the end surface of the timing gear (chain) case.

    SST
    09223-22010  
    09506-35010  

    ■ NOTICE ■
    1. Do not tap in the oil seal at an angle.
    2. After installation, check that the oil seal is driven in to the end surface of the timing gear (chain) case.

    □ HINT □
    Drive in the oil seal to a depth of 0-1mm from the end surface of the timing chain cover.



2. Install Crankshaft Timing Gear Key



  1. Install the crankshaft timing gear key by aligning it with the key groove of the crankshaft pulley.



3. Install Crankshaft Pulley



  1. Using SST, hold the crankshaft pulley and tighten the crankshaft pulley bolt.

    SST
    09213-70011   (09213-70020)
    09330-00021  
    Standard
    T = 250 N/m{ 2550 kgf/cm }



4. Install Fan & Alternator V Belt

□ HINT □
When reusing the belt, inspect the entire circumference of the ribs and back for wear and cracks, and replace it if wear or cracks reach the core (1 or more places) or if the rib rubber is chipped (1 or more places).




  1. Install the belt onto each pulley as shown in the illustration.

    ■ NOTICE ■
    Place the back side of the belt on the tensioner and idler pulley.




  2. Put a tool on the pulley set bolt of the tensioner, turn the tensioner counterclockwise, remove the hexagon wrench, and install the belt.




  3. Check that the belt is correctly installed on each pulley.

  4. Start the engine and check that the belt rotates smoothly without abnormal noise.



5. Install Engine Under Cover Rear RH

  1. Install the engine under cover rear RH with the 5 clips.



6. Install Front Tire RH

  1. Install the front tire RH.

    Standard
    T = 103 N/m{ 1050 kgf/cm }



7. Install Radiator Upper Air Deflector



  1. Install the radiator upper air deflector with the 9 clips.



8. Install V-bank Cover Sub-assembly



  1. Engage the 3 clips to install the V-bank cover.

    ■ NOTICE ■
    1. Make sure the clips are securely engaged.
    2. Engaging them with excessive force or striking the top of the clips may cause damage.
