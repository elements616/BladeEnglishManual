    01-D5
    		Registered component lost
    1. The component indicated by the sub-code is disconnected from the system after ACC ON
    2. The component indicated by the sub-code has been disconnected from the system after ACC ON
    3. Communication with the component indicated by the sub-code cannot be established when ACC is ON
    		Inspect the power supply system and AVC-LAN communication system W/H of the component indicated by the sub-code

    01-D6
    		Master Absent
    1. The device that stored this code was disconnected from the system when ACC was ON
    2. The master component was disconnected when this code was stored
    		Inspect the power supply system and AVC-LAN communication system W/H of the radio receiver assembly
    		This code may be stored even when no malfunction is found, depending on the battery condition or the power source waveform at engine start
    01-D7
    		Connection Check Malfunction
    1. The component that stored this code has been disconnected from the system after the engine was started
    2. The master component was disconnected when this code was stored
    		Inspect the power supply system and AVC-LAN communication system W/H of the radio receiver assembly
    		This code is stored when the radio receiver assembly power turns OFF after ACC ON and 210 seconds elapse
    01-D8
    		No response to connection check
    1. The component indicated by the sub-code is disconnected from the system after ACC ON
    2. The component indicated by the sub-code has been disconnected from the system after ACC ON
    		Inspect the power supply system and AVC-LAN communication system W/H of the component indicated by the sub-code
    		This code is stored when the power of the component indicated by the sub-code turns OFF after ACC ON and 180 seconds elapse
    01-D9
    		Last mode error
    1. The component that was operating (outputting sound or images) before the ignition was turned OFF is disconnected from the system when ACC is ON
    2. The component that was operating (outputting sound or images) before the ignition was turned OFF has been disconnected from the system when ACC was ON
    		Inspect the power supply system and AVC-LAN communication system W/H of the component indicated by the sub-code
    		This code may be stored even when no malfunction is found, depending on the battery condition or the power source waveform at engine start
    01-DA
    		No response to ON/OFF command
    		The component indicated by the sub-code did not respond during sound/image mode switching (detected when the screen or sound does not switch with button operation, etc.)
    1. Inspect the power supply system and AVC-LAN communication system W/H of the component indicated by the sub-code
    2. If the malfunction recurs, replace the component indicated by the sub-code
    		-
    01-DB
    		Mode status error
    		2-fold sounding of the component indicated by the sub-code was detected
    		Inspect the power supply system and AVC-LAN communication system W/H of the component indicated by the sub-code
    		This code may be stored even when no malfunction is found, depending on the battery condition or the power source waveform at engine start
    01-DC
    		Transmission Failure
    		Transmission to the component indicated by the sub-code has failed (this code may not be directly related to a malfunction)
    1. If the component indicated by the sub-code is also stored in other components, inspect the power supply system and AVC-LAN communication system W/H of the component indicated by the sub-code
    2. If this code is not recorded in other components, clear the DTC and monitor for a while
    		This code may be stored if the engine is restarted 60 seconds after it was started
    01-DD
    		Master Reset (Momentary Interruption)
    		The master device was disconnected from the system after the engine was started
    1. Inspect the power supply system and AVC-LAN communication system W/H of the radio receiver assembly
    2. If the malfunction occurs frequently, replace the radio receiver assembly
    		This code may be stored if the engine is restarted after it was started
    01-DE
    		Slave reset (momentary interruption)
    		A slave component has been disconnected from the system after the engine was started
    		Inspect the power supply system and AVC-LAN communication system W/H of the component indicated by the sub-code
    		This code may be stored if the engine is restarted after it was started
    01-DF
    		Master Malfunction
    1. The component with a display became abnormal, and the master function switched to the audio component
    2. A malfunction occurred in communication between the sub-master (audio) device and the master device
    		Inspect the power supply system and AVC-LAN communication system W/H of the radio receiver assembly
    		This code is stored when the radio receiver assembly power turns OFF after ACC ON and 210 seconds elapse
    01-E0
    		Registration Complete Notification Malfunction
    		The "Registration Complete Notification" command cannot be received from the master device
    		This code is also detected by engineering diagnosis even when not directly related to a malfunction
    		This code may be stored even when no malfunction is found, depending on the battery condition or the power source waveform at engine start
    01-E1
    		Audio processing component ON error

    		Inspect the power supply system and AVC-LAN communication system W/H of the radio receiver assembly
    		This code may be stored even when no malfunction is found, depending on the battery condition or the power source waveform at engine start
