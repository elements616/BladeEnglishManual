Back Guide Monitor System Reverse Signal Circuit

Print

Preparation List


Circuit Description


The navigation receiver assembly receives the reverse signal from the neutral start switch assembly. When it receives the reverse signal, the navigation receiver assembly switches the screen display to the image from the television camera assembly.
