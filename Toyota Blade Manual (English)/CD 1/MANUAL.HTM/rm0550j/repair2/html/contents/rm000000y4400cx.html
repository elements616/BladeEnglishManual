    1.Precautions for Power Window System

    ■ NOTICE ■
    1. The power window system uses the Body Electronics Area Network. First, perform the "Communication Function Inspection" according to "How to Proceed with Troubleshooting", and confirm that there is no malfunction in the communication system before proceeding with troubleshooting.
    2. If there is a malfunction in the jam protection function, operating the power window system in AUTO could cause something to be caught, so AUTO operation is prohibited. For this reason, confirm that no DTCs are output before proceeding with troubleshooting.
    3. When the power window regulator motor assembly RH (driver side, rear RH) has been replaced with a new one, perform the power window system registration setting (see) must be performed.
    4. When the front door window regulator RH has been replaced, or the power window regulator motor assembly RH (driver side) has been removed from the front door window regulator RH, it is necessary to return the power window regulator motor assembly RH (driver side) to the uninitialized state (clear the current memory of the pulse sensor in the motor) and then reset the glass position (initialize the pulse sensor). If the reset is not performed, the jam protection function may operate at times other than its operating conditions.
    5. When the front door window regulator LH has been replaced, or the power window regulator motor assembly LH (front passenger side) has been removed from the front door window regulator LH, it is necessary to return the power window regulator motor assembly LH (front passenger side) to the uninitialized state (clear the current memory of the pulse sensor in the motor) and then reset the glass position (initialize the pulse sensor). If the reset is not performed, the jam protection function may operate at times other than its operating conditions.
    6. When the rear door window regulator RH has been replaced, or the power window regulator motor assembly RH (rear RH) has been removed from the rear door window regulator RH, it is necessary to return the power window regulator motor assembly RH (rear RH) to the uninitialized state (clear the current memory of the pulse sensor in the motor) and then reset the glass position (initialize the pulse sensor). If the reset is not performed, the jam protection function may operate at times other than its operating conditions.
    7. When the rear door window regulator LH has been replaced, or the power window regulator motor assembly LH (rear LH) has been removed from the rear door window regulator LH, it is necessary to return the power window regulator motor assembly RH (rear LH) to the uninitialized state (clear the current memory of the pulse sensor in the motor) and then reset the glass position (initialize the pulse sensor). If the reset is not performed, the jam protection function may operate at times other than its operating conditions.
    8. If AUTO UP operation is performed after replacing the glass, glass run, etc., the jam protection function may operate. In that case, repeat the AUTO UP hold → AUTO DOWN operation 5 times or more and the system will operate normally.
    9. Even if the power window system is normal, if the window movement speed changes suddenly under conditions such as the following, a window movement speed different from the normal learned operating value may be detected and the jam protection function may operate.
      1. When the window is opened or closed while driving on rough roads.
      2. When the window is opened or closed while the door is being opened or closed.
      3. When a sudden voltage fluctuation occurs.
    10. Do not disconnect the battery while the IG is ON. If the battery is disconnected while the IG is ON, DTC B2311 is output. (see)
