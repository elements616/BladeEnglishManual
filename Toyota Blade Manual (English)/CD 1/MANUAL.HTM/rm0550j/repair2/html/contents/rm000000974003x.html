Transmitter Battery (Smart Key) Replacement

Print

Preparation List



1. Remove Transmitter Battery



  1. Push in the release hook knob and pull out the emergency key.




  2. Using a screwdriver wrapped with protective tape, remove the transmitter housing cover.

    ■ NOTICE ■
    Do not pry the cover forcibly.




  3. Using a precision screwdriver wrapped with protective tape, insert the precision screwdriver into the groove shown in the illustration and remove the battery [lithium battery (CR1632)].

    ■ NOTICE ■
    1. Do not press the terminal with your fingers.
    2. Forcibly prying out the battery [lithium battery (CR1632)] will deform the terminal.



2. Install Transmitter Battery



  1. Install the battery [lithium battery (CR1632)].

    ■ NOTICE ■
    1. Install the battery with the positive side facing up.
    2. Do not deform the terminal.




  2. Install the transmitter housing cover.




  3. Insert the emergency key.

  4. Check that the LED on the unit comes on when any of the remote control switches is pressed.
