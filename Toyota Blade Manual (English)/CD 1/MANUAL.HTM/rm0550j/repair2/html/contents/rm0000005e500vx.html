Print



    □ HINT □
    If there is a malfunction in the pulse sensor in the power window regulator motor assembly RH (driver side, rear right) or power window regulator motor assembly LH (front passenger side, rear left), the fail-safe function operates.

    1. If there is a malfunction in the pulse sensor for jam protection operation, the window position or the learned value, the following power window operations are prohibited.

      □ HINT □
      If the pulse sensor is normal, holding manual operation (AUTO UP held) for 1 seconds or more cancels the fail-safe and enables AUTO operation.
