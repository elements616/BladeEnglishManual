EFI System (2AZ-FE) Fuel Pump Control Circuit

Print

Preparation List


Circuit Description


When the engine is cranked, the output signal from the STAR terminal (STAR signal) is input to the STA terminal. Also, the NE signal generated by the crankshaft position sensor is input to the ECU as the engine speed signal. When the STA signal and NE signal are input to the engine control computer, the internal Tr1 turns ON (FC terminal ON), current flows to the coil of the circuit opening relay (C/OPN relay), which turns on the relay switch and operates the fuel pump. While the NE signal is being output (engine running), the Tr1 inside the engine control computer is kept ON (circuit opening relay ON), so the fuel pump continues to operate.
