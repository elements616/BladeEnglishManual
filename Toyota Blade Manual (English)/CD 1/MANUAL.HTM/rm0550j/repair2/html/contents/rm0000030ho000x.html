Rear Seat Assembly RH Installation

Print

Preparation List



1. Install Rear Seat Outer Belt Assembly Center



  1. Install the rear seat outer belt assembly center, rear seat inner belt assembly and washer with the bolt.

    Standard
    T = 41 N/m{ 420 kgf/cm }

    ■ NOTICE ■
    1. Pay attention to the installation direction of the floor anchor.
    2. Be careful that the floor anchor does not ride up onto the locator.



2. Install Rear Seat Assembly RH



  1. Set the rear seat assembly RH in the vehicle, and install the 2 rear side bolts in the order inner → outer.

    Standard
    T = 42 N/m{ 428 kgf/cm }




  2. Raise the seatback, and install the 2 front side bolts of the rear seat assembly RH in the order inner → outer.

    Standard
    T = 42 N/m{ 428 kgf/cm }



3. Install Rear Seat Cushion Hinge Cover NO.2



  1. Engage the 4 claws and install the rear seat cushion hinge cover NO.2.



4. Install Rear Seat Cushion Hinge Cover NO.1



  1. Engage the 4 claws and install the rear seat cushion hinge cover NO.1.



5. Install Rear Seat Headrest Assembly CTR


6. Install Rear Seat Headrest Assembly
