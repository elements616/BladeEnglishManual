Lighting System Fail-safe Chart

Print



  1. Fail-safe Function

    1. Headlight Light Control Computer Assembly

      Status
      		Description
      Output open
      1. Operation stops after approximately 1 seconds.
      2. Operation remains stopped until power is reapplied (light control switch OFF → HEAD).
      Short between output terminals
      1. Operation stops within approximately 1 seconds.
      2. Operation remains stopped until power is reapplied (light control switch OFF → HEAD).
      Leak between output terminal and ground
      1. Operation stops after approximately 0.1 seconds.
      2. Operation remains stopped until power is reapplied (light control switch OFF → HEAD).
      Lamp voltage too low
      1. Operation stops after approximately 80 seconds.
      2. Operation remains stopped until power is reapplied (light control switch OFF → HEAD).
      Lamp voltage too high
      1. Operation stops within approximately 1 seconds.
      2. Operation remains stopped until power is reapplied (light control switch OFF → HEAD).
      Bulb blinking
      1. If blinking continues for approximately 60 seconds, operation stops.
      2. Operation remains stopped until power is reapplied (light control switch OFF → HEAD).
      Input overvoltage
      1. Operation stops when power source voltage is 20 ± 3V.
      2. Operation resumes when power source voltage returns to 16V or less.
      Input low voltage
      1. Operation stops when power source voltage is 6V or less.
      2. Operation resumes when power source voltage returns to 10V or more.

    2. Headlight Leveling Computer Assembly


      1. The headlight leveling computer assembly stops auto leveling control if it detects any of the following malfunctions. Also, if a malfunction is detected while the actuator is being driven, actuator drive is stopped.

        Item
        		Malfunction Detection Condition
        		Return Conditions
        		Warning Display
        Height Sensor Malfunction
        1. When vehicle height sensor power source malfunction (4.6V or less) is detected
        2. When vehicle height sensor signal malfunction (0.25V or less or 4.75V or more) is detected
        		When normal value is detected and IG turned ON again
        		Yes
        Vehicle Speed
        		When excessive vehicle speed is detected
        		When speed below a certain level is detected
        		None
        Power Supply Overvoltage
        		When IG power source voltage of 18.5V or more is detected
        		When 17.5V or less is detected
        		None
        Power Supply Low Voltage
        		When IG power source voltage of 9V or less is detected
        		When 9.3V or more is detected
        		None
        Reset While Driving
        		When the driving status judgment immediately after IG ON was driving
        		When judged as stopped
        		None
