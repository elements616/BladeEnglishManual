  1. Torque Sensor 0-point Calibration and Rotation Angle Sensor Output Calibration (Using TaSCAN)

    ■ NOTICE ■
    1. When the steering column assembly or power steering computer assembly has been replaced, or when there is a difference in steering effort between left and right, clear the sensor calibration values in the computer, then perform torque sensor 0 point calibration and rotation angle sensor output calibration.
    2. If C1516/16 (torque sensor 0 point calibration incomplete) is stored, torque sensor 0 point calibration cannot be performed, so clear the DTC beforehand.
    3. If C1526/18 (rotation angle sensor output calibration incomplete) is stored, rotation angle sensor output calibration cannot be performed, so clear the DTC beforehand.

    1. Pre-calibration Inspection


      1. Using SST (TaSCAN), check 'IG Power Supply Voltage' in the ECU Data Monitor. (see)

        SST
        09991-70200  

        Standard
        10V or more

        ■ NOTICE ■
        Calibration cannot be performed if the IG voltage is 9V or less. If it is not within the standard, replace or charge the battery and then perform calibration.

    2. Sensor Correction Value Clearing, Torque Sensor 0 Point Calibration and Rotation Angle Sensor Output Calibration


      1. Turn IG OFF.

      2. Set SST (TaSCAN) to DLC3.

        SST
        09991-70200  

      3. Turn IG ON.

      4. Select 'Utility' → 'Electric PS' → 'Rotation Angle Sensor Output Calibration' on the SST (TaSCAN) screen and, following the display, perform sensor calibration value initialization → torque sensor 0 point calibration → rotation angle sensor output calibration.

        ■ NOTICE ■
        1. Keep the steering and front tires in the straight-ahead position.
        2. Never touch the steering wheel during torque sensor 0 point calibration (3 seconds).
        3. Do not turn the steering wheel suddenly during rotation angle sensor output calibration.

        □ HINT □
        Rotation angle sensor output calibration calibrates the outputs of the motor rotation angle sensor and the torque sensor.



    1. Torque Sensor 0-point Calibration and Rotation Angle Sensor Output Calibration (DLC3 Short)

      ■ NOTICE ■
      1. When the steering column assembly or power steering computer assembly has been replaced, or when there is a difference in steering effort between left and right, clear the sensor calibration values in the computer, then perform torque sensor 0 point calibration and rotation angle sensor output calibration.
      2. If C1516/16 (torque sensor 0 point calibration incomplete) is stored, torque sensor 0 point calibration cannot be performed, so clear the DTC beforehand.
      3. If C1526/18 (rotation angle sensor output calibration incomplete) is stored, rotation angle sensor output calibration cannot be performed, so clear the DTC beforehand.




      1. Pre-calibration Inspection


        1. Turn the IG OFF and disconnect connector C of the power steering computer assembly.

        2. Turn IG ON.

        3. Using SST (Toyota electrical tester), check the voltage between terminal C6 (IG) of the power steering computer assembly wire harness side connector and body ground.

          SST
          09082-00030  09083-00170  

          Standard
          10V or more

          ■ NOTICE ■
          Calibration cannot be performed if the IG voltage is 9V or less. If it is not within the standard, replace or charge the battery and then perform calibration.

        4. Turn the IG OFF and connect connector C of the power steering computer assembly.




      2. Sensor Calibration Value Clearing


        1. Set the steering wheel and front tires in the straight-ahead position.

        2. Turn IG OFF.

        3. Using SST, with terminals 12 (TS) and 4 (CG) of the DLC3 connector shorted, turn the IG ON and short and open terminals 13 (TC) and 4 (CG) 20 times or more within 20 seconds.

          SST
          09843-18040  

          ■ NOTICE ■
          Connecting the connector to the wrong position will cause a malfunction, so never make a mistake.

        4. Check that the P/S warning light comes on and DTCs C1515/15 and C1525/17 are stored.

        5. Turn IG OFF.

          ■ NOTICE ■
          If the IG is left ON after clearing the sensor calibration values, torque sensor 0 point calibration and rotation angle sensor output calibration cannot be performed.




      3. Torque Sensor 0 Point Calibration

        ■ NOTICE ■
        If DTC C1515/15 (torque sensor 0 point calibration not performed) is not stored, torque sensor 0 point calibration cannot be performed, so be sure to clear the sensor calibration values before performing torque sensor 0 point calibration.


        1. Set the steering and front tires to the straight-ahead position.

        2. Turn IG OFF.

        3. Using SST, with terminals 12 (TS) and 4 (CG) of the DLC3 connector shorted, turn the IG ON, short terminals 13 (TC) and 4 (CG) to start torque sensor 0 point calibration, and wait 3 seconds or more.

          SST
          09843-18040  

          ■ NOTICE ■
          Never touch the steering wheel during torque sensor 0 point calibration (3 seconds).

          □ HINT □
          The P/S warning light remains on even after torque sensor 0 point calibration is complete.




      4. Rotation Angle Sensor Output Calibration

        ■ NOTICE ■
        If DTC C1525/17 (rotation angle sensor output calibration not performed) is not stored, rotation angle sensor output calibration cannot be performed, so be sure to clear the sensor calibration values and start again from torque sensor 0 point calibration.


        1. With terminals 12 (TS) and 4 (CG) and terminals 13 (TC) and 4 (CG) of the DLC3 connector shorted, open and then short terminals 13 (TC) and 4 (CG) once only. (Shifts to rotation angle sensor output calibration mode)

        2. Turn the steering wheel 45° or more to the left and right. Then turn the steering wheel 90° or more in either direction.

          ■ NOTICE ■
          Do not turn the steering wheel abruptly.

          □ HINT □
          When rotation angle sensor output calibration ends normally, the P/S warning light changes from on to blinking (4Hz).

        3. With terminals 12 (TS) and 4 (CG) and terminals 13 (TC) and 4 (CG) of the DLC3 connector open, turn the IG OFF to change from test mode to normal mode.
