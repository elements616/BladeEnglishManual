Seat Belt Warning System ECU Data Monitor / Active Test

Print



  1. Inspection Using TaSCAN

    1. Data Monitor


      1. Using SST (TaSCAN), follow the prompts on the screen to display the "ECU Data Monitor" screen and check the computer data.

        SST
        09991-70200  

        Specified Condition


        [System selection screen: Body → Meter → ECU Data Monitor] (combination meter) 
        Item Name (Symbol)
        		Item Description/Display Range
        		Standard Value
        		Remarks
        Front passenger buckle SW
        (PSBSW)
        		Occupant sensor status
        Display range: OFF - ON
        		ON: Seat occupied
        OFF: Seat not occupied
        		Front passenger buckle SW not fastened
        Front passenger buckle SW status
        Display range: ON - OFF
        		ON: Front passenger buckle SW not fastened
        OFF: Front passenger buckle SW fastened
        		Front passenger seat occupied

    2. Active Test


      1. Using SST (TaSCAN), follow the prompts on the screen to display the "Active Test" screen and perform the inspection.

        SST
        09991-70200  

        Specified Condition

        [System selection screen: Body → Meter → Active Test] (combination meter) 
        Item Name
        		Item Description
        		Reference Value
        TelltaleNo.2
        		Blink (1 Hz)/turn off front passenger seat belt indicator
        		Front passenger seat belt (*1)
        TelltaleNo.2
        		Blink (1 Hz)/turn off driver seat belt meter indicator
        		Driver seat belt (*2)

        □ HINT □
        1. *1: While the front passenger seat belt warning light is blinking at 1 Hz, the driver seat belt warning light is off.
        2. *2: While the driver seat belt warning light is blinking at 1 Hz, the front passenger seat belt warning light is off.
