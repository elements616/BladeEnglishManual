Back Door Adjustment

Print

Preparation List



1. Inspect Back Door Panel Sub-assembly


  1. Check that each clearance dimension is within the reference value.




    Reference Value

    A
    		5.1±1.5 mm
    		D
    		5.1±1.5 mm
    B
    		7.3±1.5 mm
    		E
    		4.6±1.5 mm
    C
    		1.0+1.0 mm
    1.0-0.5 mm
    		F
    		5.8±1.5mm



2. Remove Rear Floor Mat Rear



  1. Remove the rear floor mat rear.



3. Remove Deck Trim Service Hole Cover (Installation Position Rear Side)



  1. Remove the bolt and the trunk (luggage compartment) hold belt striker.

    □ HINT □
    Remove the LH side using the same procedure.



4. Remove Deck Trim Cover Rear



  1. Disengage the 10 claws and remove the deck trim cover rear.



5. Adjust Back Door Panel Sub-assembly



  1. To adjust the back door upper end vertically and the back door upper end laterally, loosen the bolts first.

    Standard
    T = 19.5 N/m{ 198 kgf/cm }

    ■ NOTICE ■
    When adjusting, use a service bolt to adjust the fit.




  2. When adjusting the back door rear end laterally and the back door lock striker assembly, use a torx socket wrench T40 to loosen the striker installation bolts until the striker can be moved. Using a brass bar, lightly tap the striker to adjust it.

    Standard
    T = 11.5 N/m{ 116 kgf/cm }



6. Install Deck Trim Cover Rear



  1. Engage the 10 claws to install the deck trim cover rear.

    ■ NOTICE ■
    After installation, check that the back door weatherstrip is not caught in the deck trim cover rear.



7. Install Deck Trim Service Hole Cover (Installation Position Rear Side)



  1. Install the trunk (luggage compartment) hold belt striker with the bolt.

    □ HINT □
    Install the LH side using the same procedure.



8. Install Rear Floor Mat Rear



  1. Install the rear floor mat rear.
