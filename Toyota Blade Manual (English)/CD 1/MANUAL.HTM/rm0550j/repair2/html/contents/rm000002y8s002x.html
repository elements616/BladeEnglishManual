Preparation List



1. Inspect Toll Collection Antenna Wire

  1. Toll Collection Antenna Wire Installation Condition Inspection

    1. Inspect the toll collection antenna wire cord for installation problems such as sharp bends or pinching.

      Specified Condition
      Installation normal




  2. Resistance Measurement

    1. Disconnect the connector connected to the navigation antenna assembly.

    2. Disconnect the connector shown in the illustration that is connected to the toll collection (ETC) computer assembly.

    3. Using SST (Toyota electrical tester), measure the resistance of the toll collection antenna wire between the navigation antenna assembly and toll collection (ETC) computer assembly.

      SST
      09082-00030  
      09083-00170  

      Resistance

      Tester Connection
