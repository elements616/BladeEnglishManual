EFI System (2AZ-FE) Freeze Frame Data / Detailed Diagnostic Information

Print



  1. Freeze Frame Data Check (Reading Using TaSCAN)

    1. Using the SST (TaSCAN), operate according to the screen display, and select a DTC with recorded freeze frame data (F displayed) from [Diagnosis Function Menu] - [DTC Check Screen].

      SST
      09991-70201  

      ■ NOTICE ■
      1. Freeze frame data stores the engine condition when 3 DTCs are detected.
      2. Freeze frame data is classified as shown below, and freeze frame data for 1 DTCs is stored for each group.

        Group Classification
        		DTCs output for misfire detection (P0300, P0301, P0302, P0303, P0304), rich malfunction (P0172) and lean malfunction (P0171)
        DTCs that illuminate the check engine light
        DTCs that do not illuminate the check engine light
        To check whether the check engine light illuminates, refer to the Diagnostic Trouble Code Chart ().

      □ HINT □
      1. Time-series freeze frame data allows the engine condition (ECU data) before and after DTC detection to be checked.
      2. Using time-series freeze frame data is helpful for troubleshooting when the symptom cannot be reproduced.
