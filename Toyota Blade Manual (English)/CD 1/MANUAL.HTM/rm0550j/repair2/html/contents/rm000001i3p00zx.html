DTC P0705/C2 T/M Control Switch Malfunction

Print

Preparation List


Function Description


The engine control computer detects the shift position using signals from the neutral start switch assembly. The engine can be started only when the shift lever is in the P or N position.


DTC No.
DTC Detection Condition
  1. Diagnosis Condition
  2. Abnormal Condition
  3. Malfunction Duration
  4. Others
Inspection Area
P0705/C2
  1. IG ON, battery voltage 10.5V or more
  2. (a). 2 or more of the P, R, N and D position signals are ON simultaneously
    (b). 2 or more of the NSW (STAR), R and D range signals are ON simultaneously
    (c). With the S position signal input, any of the NSW (STAR), P, R and N position signals is ON simultaneously
    (d). All of the NSW (STAR), P, R, N and D position signals are OFF
  3. 2 seconds or more [(a), (b) and (c)]
    60 seconds or more [(d)]
  4. 2 trip
  1. Neutral Start Switch Assembly
  2. Transmission Control Switch
  3. Wire Harness and Connector
  4. Engine Control Computer
