DTC U0100 EFI ECU Communication Stop

Print

Preparation List


Function Description


The combination meter assembly (meter ECU) receives signals from the engine control computer via CAN communication.


DTC No.
1. DTC Detection Condition
2. Malfunction Status
2. Malfunction Duration
Inspection Area
U0100
  1. Vehicle speed 5km/h or more, IG voltage 10.5V or more.
  2. Communication with engine control computer interrupted.
  3. 3 seconds or more. (If communication with both EFI and ABS/VSC ECUs is interrupted, the no-reception state continues for 60 seconds)
  1. CAN Communication System
  2. Engine Control Computer
