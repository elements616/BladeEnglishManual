Front Bumper Assembly Reassembly

Print


1. Install Front Bumper Reinforcement Sub-assembly



  1. Install the front bumper reinforcement with the 8 bolts.

    Standard
    T = 50 N/m{ 510 kgf/cm }




  2. Engage the 8 clamps.



2. Install Front Bumper Energy Absorber



  1. Align the fitting points and install the front bumper energy absorber to the front bumper reinforcement.



3. Install Front Bumper Side Retainer LH



  1. Engage the 2 claws.

  2. Install the front bumper side retainer LH with the 2 screws.



4. Install Front Bumper Side Retainer RH

□ HINT □
Install it in the same way as for the LH side.



5. Install Fog Light Assembly LH



  1. Install the fog light assembly LH with the screw.



6. Install Fog Light Assembly RH

□ HINT □
Install it in the same way as for the LH side.



7. Install Fog Light Cover LH



  1. Engage the 8 claws and install the fog light cover LH.



8. Install Fog Light Cover RH

□ HINT □
Install it in the same way as for the LH side.



9. Install Radiator Grille LWR LH



  1. Engage the 6 claws and install the radiator grille LWR LH.



10. Install Radiator Grille LWR RH

□ HINT □
Install it in the same way as for the LH side.



11. Install Front Bumper Hole Cover LH



  1. Engage the 2 claws and install the front bumper hole cover LH.



12. Install Front Bumper Hole Cover RH

□ HINT □
Install it in the same way as for the LH side.



13. Install Television Camera Wire (w/ Intelligent Parking Assist System)



  1. Engage the 2 clamps and install the parking assist wire.

    □ HINT □
    Install the RH side using the same procedure.



14. Install Ultrasonic Sensor Retainer NO.1 (w/ Intelligent Parking Assist System)



  1. As shown in the illustration, align the key of the front bumper assembly with the snap of ultrasonic sensor retainer NO.1, and insert ultrasonic sensor retainer NO.1 into the installation hole of the front bumper assembly.




  2. Engage the 2 claws and install ultrasonic sensor retainer NO.1 to the front bumper assembly.

    ■ NOTICE ■
    Install it securely, as the parking space detection function may not operate normally otherwise.



15. Install Ultrasonic Sensor NO.1 (w/ Intelligent Parking Assist System)



  1. Engage the 2 claws and install ultrasonic sensor NO.1.

    ■ NOTICE ■
    Install it securely, as the parking space detection function may not operate normally otherwise.




  2. Connect the connector.



16. Install Radiator Grille



  1. Engage the 4 claws and install the radiator grille.




  2. Engage the 4 clamps of the television camera wire. (w/ Intelligent Parking Assist System)



17. Install Hood to Front End Panel Seal

  1. Rub off the double-sided tape remaining on the radiator grille with a shop rag, etc.

    ■ NOTICE ■
    Installing the hood to front end panel seal with double-sided tape remaining may cause poor adhesion, so remove it thoroughly.

  2. Clean the adhesive surface with white gasoline.




  3. Peel off the release paper of a new hood to front end panel seal, install it with the 9 clips, then press it firmly against the radiator grille to install the hood to front end panel seal.
