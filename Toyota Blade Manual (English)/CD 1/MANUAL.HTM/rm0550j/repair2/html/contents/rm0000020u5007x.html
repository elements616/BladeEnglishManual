Shift Lock Control Unit Assembly Installation

Print

Preparation List



1. Install Shift Lock Control Unit Assembly

■ NOTICE ■
Check that the shift lever and neutral start switch are in the N position.




  1. Install the shift lock control unit with the 4 nuts.

    Standard
    T = 12 N/m{ 122 kgf/cm }




  2. Connect the 2 wire harness clamps and 2 connectors.



2. Install Transmission Control Cable Assembly


  1. Turn the nut of the transmission control cable 180° counterclockwise, and while holding the nut, push in the stopper until it clicks 2 time.





  2. Install the cable outer of the transmission control cable to the shift lever retainer, check that the spring is at position A shown in the illustration, and push in the stopper.



    □ HINT □
    If the stopper cannot be pushed in, turn the nut back slightly and push it in again.




  3. While pushing the claw of the lock piece, hold down the claw on the back side and push up the lock piece from the back side.




  4. Install the control cable end to the shift lock control unit.

    ■ NOTICE ■
    1. Check that the lock piece protrudes.
    1. Securely install the cable end all the way to the base of the pin.




  5. Push the lock piece into the adjuster case.

    ■ NOTICE ■
    If it is not pushed in securely, the cable cannot be locked and shift operation will not be reliable.



3. Install Instrument Panel Finish Panel Lower NO.2



  1. Push in the direction of the arrow shown in the illustration to engage the 2 clips and guide.




  2. Install instrument panel finish panel lower No.2 with the 2 screws <C>.



4. Install Instrument Panel Finish Panel Lower NO.1



  1. Push in the direction of the arrow shown in the illustration to engage the 2 clips and guide.




  2. Engage the 4 claws and 2 guides.




  3. Install instrument panel finish panel lower No.1 with the 2 screws <C>.



5. Install Instrument Panel Under Tray



  1. Engage the 4 claws and install the instrument panel under tray.



6. Install Box Bottom Mat


7. Install Console Box Insert FR NO.2



  1. Insert the guide.

  2. Engage the 3 claws and install the console box insert.



8. Install Console Box Insert



  1. Insert the guide.

  2. Engage the 3 claws to install console box insert front No.2.



9. Install Console Box Assembly Rear



  1. Engage the 4 claws.




  2. Install the console box assembly RR with the 4 bolts and 2 screws.



10. Install Console Box Carpet



  1. Install the console box carpet.



11. Install Instrument Panel Finish Panel LWR CTR



  1. Engage the 6 clips and 4 claws.




  2. Install the instrument panel finish panel LWR CTR with the 2 screws <C>.



12. Install Position Indicator Housing Assembly



  1. Connect the connector.




  2. Engage the 7 claws and install the position indicator housing assembly.

    ■ NOTICE ■
    Securely engage the claws.



13. Install Console Box Cover RR

  1. Connect the connectors.




  2. Engage the 4 clips to install the console box rear cover.



14. Install Shift Lever Knob



  1. Turn the shift lever knob in the direction of the arrow shown in the illustration to install it.



15. Install Instrument Panel Finish Panel End RH



  1. Engage the 4 clips and install the instrument panel finish panel end RH.



16. Install Instrument Panel Finish Panel End LH



  1. Engage the 4 clips and install the instrument panel finish panel end LH.



17. Connect Battery Negative Terminal
Standard
T = 5.4 N/m{ 55 kgf/cm }


18. Inspect Shift Lever Position

  1. Turn IG ON and depress the brake pedal.

  2. When shifting the shift lever to each position, check that the shift lever operates smoothly, moves into each position with a positive feel, and the position indicator shows the position correctly.

  3. Start the engine, and check that the vehicle moves forward when shifting from the N position to the D position, and moves backward when shifting to the R position.



19. Adjust Shift Lever Position

  1. Apply the parking brake and move the shift lever to the N position.

  2. Remove the instrument panel finish panel lower.
    (see)




  3. Disconnect the cable end from the shift lock control unit.




  4. Using a thin-bladed screwdriver, pull out the stopper of the transmission control cable, turn the nut approximately 180° counterclockwise, and while holding the nut, disconnect the transmission control cable from the shift lever retainer.

    ■ NOTICE ■
    1. Do not turn the nut too far, as the internal spring will come off the nut and the transmission control cable cannot be reused.
    2. Do not remove the stopper. If it has been removed, reinstall it in the same position.




  5. While pushing the claw of the lock piece, hold down the claw on the back side and push up the lock piece from the back side.



  6. Turn the nut of the transmission control cable 180° counterclockwise, and while holding the nut, push in the stopper until it clicks 2 time.





  7. Install the cable outer of the transmission control cable to the shift lever retainer, check that the spring is at position A as shown in the illustration, and push in the stopper.



    □ HINT □
    If the stopper cannot be pushed in, turn the nut back slightly and push it in again.




  8. Install the cable end to the shift control unit.

    ■ NOTICE ■
    1. Check that the lock piece protrudes.
    2. Securely install the cable end all the way to the base of the pin.




  9. Push the lock piece into the adjuster case to lock it.

    ■ NOTICE ■
    If it is not pushed in securely, the cable cannot be locked and shift operation will not be reliable.

  10. After adjustment, inspect the operation, and if there is a problem, adjust again.

  11. Install the instrument panel finish panel lower.
    (see)
