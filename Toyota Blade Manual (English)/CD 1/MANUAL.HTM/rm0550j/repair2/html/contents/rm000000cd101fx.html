EFI System (2AZ-FE) Inspection for Intermittent Problems

Print



  1. Inspection for Intermittent Problems (Can Only Be Performed Using TaSCAN)
    SST
    09991-70200  

    □ HINT □
    By changing the mode according to the following procedure, open circuit detection sensitivity is improved and intermittent malfunctions can be detected more reliably.

    1. Clearing DTCs

    2. Setting check mode

    3. Performing simulation test

    4. Visually inspect the connectors and each terminal, and check the connection condition

    5. Check that no excessive force is applied to the wire harness and connectors



    1. Connector and Wire Harness Momentary Interruption Check

      □ HINT □
      If the malfunctioning system is identified by the DTC output in the diagnosis (check mode) inspection, narrow down the malfunctioning area using the following method.

      1. After reading the DTCs in check mode, clear the DTC memory.

      2. Select check mode and start the engine.

      3. With the engine idling, wiggle the connectors and wire harness of the malfunctioning system output in the diagnosis (check mode) inspection.

      4. If the check engine warning light illuminates when the connector or wire harness is wiggled, there may be a poor connection in the connector or wire harness at that location.
