Door Control Receiver Installation

Print

Preparation List



1. Install Door Control Receiver



  1. Install the door control receiver with the bolt.

  2. Connect the connector.



2. Install Roof Side Garnish Assembly INN RH

  1. Install 4 new garnish clips to the roof side garnish assembly inner RH.




  2. Engage the clips and install the roof side garnish assembly inner RH.

    ■ NOTICE ■
    After installation, check that the back door weatherstrip is not caught in the roof side garnish assembly inner RH.



3. Install Deck Trim Side Panel Assembly RH



  1. Pass the rear seat outer belt assembly RH through the guide of the deck trim side panel assembly RH.

  2. Engage the 2 claws and 4 clips, and install the deck trim side panel assembly RH.

    ■ NOTICE ■
    After installation, check that the back door weatherstrip is not caught in the deck trim side panel assembly RH.



4. Install Deck Floor Box RH



  1. Insert the guide.

  2. Install the deck floor box RH with the 2 nuts.



5. Install Rear Floor Mat Rear



  1. Install the rear floor mat rear.



6. Install Package Tray Trim Panel Assembly



  1. Engage the package tray trim panel assembly with the 2 pins.

  2. Connect the 2 suspenders to the package tray trim garnish hooks, and install the package tray trim panel assembly.



7. Install Rear Door Opening Trim Weatherstrip RH



  1. Align the paint mark (white) of the weatherstrip with the arrow part on the body side shown in the illustration, and install the rear door opening trim weatherstrip RH.

    ■ NOTICE ■
    After installation, check that the corners are not lifted.



8. Install Rear Door Scuff Plate RH



  1. Engage the 8 claws to install the rear door scuff plate RH.



9. Install Rear Seat Assembly RH



  1. Set the rear seat assembly RH in the vehicle, and install the 2 rear side bolts in the order inner → outer.

    Standard
    T = 42 N/m{ 428 kgf/cm }




  2. Raise the seatback, and install the 2 front side bolts of the rear seat assembly RH in the order inner → outer.

    Standard
    T = 42 N/m{ 428 kgf/cm }



10. Install Rear Seat Cushion Hinge Cover NO.2



  1. Engage the 4 claws and install the rear seat cushion hinge cover NO.2.



11. Install Rear Seat Cushion Hinge Cover NO.1



  1. Engage the 4 claws and install the rear seat cushion hinge cover NO.1.



12. Remove Rear Seat Headrest Assembly CTR


13. Install Rear Seat Headrest Assembly
