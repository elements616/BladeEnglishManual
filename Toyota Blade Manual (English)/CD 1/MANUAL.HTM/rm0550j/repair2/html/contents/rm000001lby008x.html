CAN Gateway ECU Communication Stop Mode
"CAN Gateway" and ECUs connected to V bus No.2 are not displayed on the TaSCAN "CAN Bus Connected ECU Check" screen (malfunction in the CAN gateway ECU main bus side branch wire)
  1. Network gateway computer (CAN gateway ECU) branch wire open circuit or connector malfunction
  2. Network gateway computer (CAN gateway ECU) power supply circuit malfunction
  3. Network gateway computer (CAN gateway ECU) internal malfunction
