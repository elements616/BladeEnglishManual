CAN Communication System CAN Bus Main Line Open Circuit Inspection (DLC3 Branch Line / Main Line / Terminating Resistor)

Print

Preparation List


Function Description


If the resistance between 6 (CANH) and 14 (CANL) of DLC3 is 70 Ω or higher, an open circuit in the CAN bus main line and the DLC3 branch line is suspected.


Symptom
Suspected Area
Resistance between 6 (CANH) and 14 (CANL) of DLC3 is 70 Ω or higher
  1. CAN bus main line open circuit or connector
  2. DLC3 branch line open circuit or connector
  3. CAN J/C
  4. Engine Control Computer (EFI ECU)
  5. Combination Meter Assembly (Meter ECU)
