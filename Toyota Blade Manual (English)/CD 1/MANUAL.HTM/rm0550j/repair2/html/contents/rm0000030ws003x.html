Pre-crash Safety System Fail-safe List

Print



  1. Fail-safe Function

    1. If a malfunction occurs in part of the pre-crash safety system, the "PCS" indicator light comes on, "PCS SYSTEM CHECK" is displayed on the multi-information display in the combination meter assembly, and control of the pre-crash safety system is stopped according to the malfunction.

    2. If dirt adheres to the grille cover or millimeter wave radar sensor assembly, or if the millimeter wave radar sensor assembly determines that it cannot recognize obstacles in adverse conditions such as snowfall, the "PCS" indicator light blinks, "PCS CURRENTLY UNAVAILABLE" is displayed on the multi-information display in the combination meter assembly, and all control except brake-linked seat belt control is stopped. Also, when obstacles can be recognized again, the display goes off and normal control resumes.

    3. If the overheat protection function of the seat belt control computer operates, the seat belt control computer displays "PCS CURRENTLY UNAVAILABLE" on the multi-information display in the combination meter assembly and stops pre-crash seat belt control. Also, when the temperature drops and pre-crash seat belt control becomes possible, the display goes off and normal control resumes.
