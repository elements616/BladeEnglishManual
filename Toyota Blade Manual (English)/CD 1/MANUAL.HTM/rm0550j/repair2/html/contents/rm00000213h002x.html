Air Conditioner Radiator Assembly Reassembly

Print

Preparation List



1. Cooler Thermistor NO.1 Installation



  1. Install the cooler thermistor NO.1 at the position shown in the illustration.

    ■ NOTICE ■
    1. To ensure the holding force of the thermistor, insert it only 1 time.
    2. When reusing the evaporator, insert the thermistor at a position shifted one row next to the existing insertion mark (either the left or right side is acceptable). (Range of ①)
    3. After inserting the thermistor, do not apply excessive force to the lead wire.
    4. Insert straight until the end of resin case A contacts the end of evaporator B.



2. Cooler Evaporator NO.1 Installation

  1. Apply sufficient compressor oil (ND-OIL8) to the 2 new O-rings and the fitting surface of the cooler expansion valve.

  2. Install the 2 O-rings to the cooler evaporator NO.1.

    ■ NOTICE ■
    Do not allow dirt or foreign matter to adhere to the O-ring or O-ring sealing surface.




  3. Install the cooler thermistor NO.1 and cooler evaporator NO.1 together.

  4. Engage the connector clamp.




  5. Engage the 4 claws as shown in the illustration.




  6. Install the lower heater case with 4 screws.



3. Cooler Expansion Valve Installation

  1. Install the cooler expansion valve to the cooler evaporator No.1.




  2. Using a hexagon wrench, install the cooler expansion valve with 2 hexagon bolts.



4. Radiator Heater Unit Installation



  1. Install the radiator heater unit to the air conditioner unit assembly.

  2. Install the clamp with the screw.



5. Cooler Drain Hose Installation



  1. Install the cooler drain hose.



6. Air Conditioner Duct Installation



  1. Engage the 4 claws and install the air conditioner duct.



7. Air Conditioner Amplifier Assembly Installation



  1. Engage the claws.

  2. Install the air conditioner amplifier assembly with the screw.



8. Upper Console Mounting Bracket Installation



  1. Engage the claw and install the upper console mounting bracket.



9. Console Mounting Bracket LH Installation



  1. Install the console mounting bracket LH with the screw.



10. Air Conditioner Harness Assembly Installation



  1. Engage the 3 clamps and install the air conditioner harness assembly.



11. Air Mix Damper Servo Sub-assembly Installation



  1. Automatic air conditioning (driver side)

    1. Align the reference position and install the air mix damper servo with 3 screws.

    2. Connect the connector.

  2. Dual mode automatic air conditioning (driver side)




    1. Align the reference position and install the air mix damper servo with 3 screws.

    2. Connect the connector.

  3. Dual mode automatic air conditioning (front passenger side)




    1. Align the reference position and install the air mix damper servo with 3 screws.

    2. Connect the connector.



12. Mode Damper Servo Sub-assembly Installation



  1. Align the reference position and install the mode damper servo with 3 screws.

  2. Connect the connector.
