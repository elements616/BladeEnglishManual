Fuel Tank Assembly (2AZ-FE) Installation

Print

Preparation List



1. Install Fuel Emission Tube NO.1



  1. Align the axes of the pipe and connector, and insert until a "click" sound is heard.



2. Install Charcoal Canister Outlet Hose NO.1



  1. Connect the 2 clips and install the charcoal canister outlet hose No.1 to the fuel tank.



3. Install Fuel Tank to Filler Pipe Hose



  1. Install the fuel tank to filler pipe hose as shown in the illustration.



4. Install Fuel Tank Breather Hose



  1. Install the fuel tank breather hose as shown in the illustration.



5. Install Fuel Tank Assembly

  1. Clean and degrease the bolt holes.

  2. Set the fuel tank and 2 fuel tank bands on an engine lifter.




  3. While operating the engine lifter, slowly install the fuel tank to the vehicle.

    ■ NOTICE ■
    1. Be careful not to drop the fuel tank.
    2. Tilt the fuel tank while working so that it does not catch on the rear differential carrier assembly. (4WD)




  4. Secure the fuel tank with the 4 bolts and 2 fuel tank bands.

    Standard
    T = 39 N/m{ 398 kgf/cm }



6. Connect Parking Brake Cable Assembly (Drive Type 4WD)



  1. Connect the parking brake cable with the 2 bolts.

    Standard
    T = 6.0 N/m{ 61 kgf/cm }



7. Connect Fuel Tank Main Tube



  1. Align the axes of the pipe and connector, and insert until a "click" sound is heard.

    ■ NOTICE ■
    1. Before working, check that there are no scratches or foreign matter on the connecting parts of the pipe and connector.
    2. After connecting, pull on the connector and pipe to check that they are securely connected.



8. Connect Fuel Hose



  1. Align the axes of the pipe and connector, and insert until a "click" sound is heard.

    ■ NOTICE ■
    1. Before working, check that there are no scratches or foreign matter on the connecting parts of the pipe and connector.
    2. After connecting, pull on the connector and pipe to check that they are securely connected.
    3. After connecting, check on the top surface of the tank that the fuel hose is above the fuel tank main tube.



9. Connect Fuel Tank to Filler Pipe Hose



  1. Connect the fuel tank to filler pipe hose as shown in the illustration, and secure it with the clamp.



10. Connect Fuel Tank Breather Hose



  1. Connect the fuel tank breather hose as shown in the illustration, and secure it with the clamp.

  2. Connect the charcoal canister outlet hose No.1.



11. Install Fuel Tank Protector NO.1



  1. Install the fuel tank protector No.1 with the 3 clips.



12. Temporarily Tighten Propeller Shaft with Center Bearing Assembly (Drive Type 4WD)



  1. Align the matchmarks on the transfer assembly and propeller shaft assembly.

  2. Temporarily tighten the propeller with center bearing shaft assembly with 4 new nuts and 4 washers.




  3. Align the matchmarks on the differential carrier assembly and propeller shaft assembly.

  4. Temporarily tighten the propeller with center bearing shaft assembly with 4 new nuts and 4 washers.




  5. Temporarily tighten the center support bearing assembly with the 2 bolts, with the center support bearing washers in place.



13. Fully Tighten Propeller Shaft with Center Bearing Assembly (Drive Type 4WD)

  1. Fully tighten the 4 nuts installing the propeller shaft assembly to the transfer assembly.

    Standard
    T = 35 N/m{ 357 kgf/cm }

  2. Fully tighten the 4 nuts installing the propeller shaft assembly to the differential carrier assembly.

    Standard
    T = 35 N/m{ 357 kgf/cm }




  3. Check that the housing center line of the center support bearing assembly is at a right angle to the propeller shaft axis.

  4. Fully tighten the 2 installation bolts of the center support bearing assembly.

    Standard
    T = 37 N/m{ 377 kgf/cm }



14. Inspect and Adjust Joint Angle (Drive Type 4WD)

  1. Before measuring the angle, settle each part using the following procedure.

    1. Rotate the propeller shaft several times by hand.

    2. Place a jack under the differential and move it up and down.

      ■ NOTICE ■
      Perform the measurement in a condition as close to the vehicle being on the ground as possible, using a 4-post lift, pit or equivalent.

  2. Using SST, measure the installation angle of the intermediate shaft assembly (A in the illustration).

    SST
    09370-50010  

    		Angle
    A
    		-2°46’ ± 1°

  3. Using SST, measure the installation angle between the intermediate shaft assembly (A in the illustration) and propeller shaft assembly (B in the illustration).

    SST
    09370-50010  

    		Angle
    A-B
    		1°29’ ± 1°30’



  4. Using SST, measure the installation angle between the propeller shaft assembly (B in the illustration) and differential (C in the illustration).

    SST
    09370-50010  

    		Angle
    B-C
    		2°10’ ± 1°



  5. If the result is not as specified, replace the adjusting washers at the center support bearing with appropriate ones.

    ■ NOTICE ■
    1. Use washers of the same thickness on the left and right.
    2. Do not stack 2 washers.


    □ HINT □

    Adjusting Washer 
    Part No.
    		Thickness (mm)
    90201-10123
    		2.0
    90201-10081
    		4.5
    90201-10083
    		6.5



15. Install Front Floor Heat Insulator NO.2



  1. Install the front floor heat insulator No.2 with the 4 bolts.

    Standard
    T = 5.5 N/m{ 56 kgf/cm }



16. Install Exhaust Pipe Assembly Center



  1. Compression Spring Inspection

    1. Using a vernier caliper, measure the free length of the compression spring.

      Limit
      38.5mm

      ■ NOTICE ■
      If it is less than the minimum, replace the spring with a new one.




  2. Gasket Installation

    1. Insert a new gasket into the exhaust center pipe assembly as far as it will go by hand.

      ■ NOTICE ■
      1. Do not install the gasket in the wrong direction.
      2. Do not reuse a gasket once it has been removed.
      3. Do not damage the gasket by dropping it, etc.
      4. Do not damage the gasket sliding surface.
      5. Never push the gasket in by installing the exhaust pipe without first pressing it in sufficiently by hand.

    2. Install a new gasket to the exhaust pipe assembly front.

  3. Install the exhaust center pipe assembly with the 3 exhaust pipe supports.




  4. Install the exhaust center pipe assembly to the exhaust pipe assembly front with the 2 bolts.

    Standard
    T = 43 N/m{ 439 kgf/cm }




  5. Install the exhaust center pipe assembly to the exhaust tail pipe assembly with the bolts and 2 compression springs.

    Standard
    T = 43 N/m{ 439 kgf/cm }

    ■ NOTICE ■
    After installation, check that there is no significant difference in the clearance between the flanges of the exhaust center pipe assembly and exhaust tail pipe assembly at the front, rear, left and right.



17. Install Front Floor Brace Center (Drive Type FF)



  1. Install the front floor brace center with the 4 bolts.

    Standard
    T = 51 N/m{ 520 kgf/cm }



18. Install Fuel Sender Gauge Assembly



  1. Install the fuel sender gauge assembly with the 5 screws.

    ■ NOTICE ■
    Be careful not to bend the arm of the fuel sender gauge.



19. Install Rear Floor Service Hole Cover NO.2



  1. Connect the connector.

  2. Install the service hole cover using new butyl tape.



20. Install Fuel Suction Tube Assembly (with Pump & Gauge)


21. Install Fuel Tank Vent Tube Set Plate


22. Connect Fuel Emission Tube NO.1


23. Connect Fuel Hose


24. Connect Charcoal Canister Outlet Hose NO.1


25. Connect Fuel Tank Main Tube


26. Add Fuel


27. Connect Battery Negative Terminal
Standard
T = 5.4 N/m{ 55 kgf/cm }


28. Inspect for Exhaust Gas Leaks


  1. Check that there are no exhaust gas leaks from the locations shown in the illustration (exhaust pipe joints and each sensor installation area).





29. Inspect for Fuel Leaks

  1. Fuel Pump Operation Check

    1. Connect SST (TaSCAN) to DLC3.

      SST
      09991-70200  

    2. Operate according to the screen display, select 'Active Test' - 'Circuit Relay' - 'ON', and check the fuel pump operation.

  2. Fuel Leak Inspection

    1. Check that there are no fuel leaks in the fuel system while fuel pressure is applied.



30. Install Rear Floor Service Hole Cover


31. Install Rear Door Scuff Plate RH



  1. Engage the 8 claws to install the rear door scuff plate RH.



32. Install Rear Door Scuff Plate LH

□ HINT □
Install using the same procedure as for the RH side.



33. Install Rear Seat Outer Belt Assembly Center (RH Seat Position)



  1. Install the rear seat outer belt assembly center, rear seat inner belt assembly and washer with the bolt.

    Standard
    T = 41 N/m{ 420 kgf/cm }

    ■ NOTICE ■
    1. Pay attention to the installation direction of the floor anchor.
    2. Be careful that the floor anchor does not ride up onto the locator.



34. Install Rear Seat Assembly RH (Seat Position RH Side)



  1. Set the rear seat assembly RH in the vehicle, and install the 2 rear side bolts in the order inner → outer.

    Standard
    T = 42 N/m{ 428 kgf/cm }




  2. Raise the seatback, and install the 2 front side bolts of the rear seat assembly RH in the order inner → outer.

    Standard
    T = 42 N/m{ 428 kgf/cm }



35. Install Rear Seat Cushion Hinge Cover NO.2 (RH Seat Position)



  1. Engage the 4 claws and install the rear seat cushion hinge cover NO.2.



36. Install Rear Seat Cushion Hinge Cover NO.1 (RH Seat Position)



  1. Engage the 4 claws and install the rear seat cushion hinge cover NO.1.



37. Remove Rear Seat Headrest Assembly Center (RH Seat Position)


38. Install Rear Seat Headrest Assembly (RH Seat Position)


39. Install Rear Seat Assembly LH (Seat Position LH Side)



  1. Set the rear seat assembly LH in the vehicle, and install the 2 rear side bolts in the order inner → outer.

    Standard
    T = 42 N/m{ 428 kgf/cm }




  2. Raise the seatback, and install the 2 front side bolts of the rear seat assembly LH in the order inner → outer.

    Standard
    T = 42 N/m{ 428 kgf/cm }



40. Install Rear Seat Cushion Hinge Cover NO.2 (LH Seat Position)



  1. Engage the 4 claws to install the rear seat cushion hinge cover NO.2.



41. Install Rear Seat Cushion Hinge Cover NO.1 (LH Seat Position)



  1. Engage the 4 claws and install the rear seat cushion hinge cover NO.1.
