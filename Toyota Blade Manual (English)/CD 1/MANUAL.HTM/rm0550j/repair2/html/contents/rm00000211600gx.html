DTC P1605 Unstable Idle

Print

Preparation List


Circuit Description


The DTC is output when the idle speed drops or becomes unstable from a state in which the engine load is small and the engine is idling stably. The freeze frame data, which stores the conditions when the DTC was output, can be checked using TaSCAN. Serviceability is improved by making it possible to check the engine operating condition at the time of unstable idling using the freeze frame data. Also, since unstable idling caused by running out of fuel is also detected, it is necessary to check whether the vehicle has run out of fuel before starting work.
