Shift Lock Control Unit Assembly (U660E) Reassembly

Print


1. Install Position Indicator Light Bulb

  1. Install the bulb cap to the position indicator light bulb.

  2. Install the position indicator light bulb to the indicator light wire.



2. Install Indicator Light Wire



  1. Install the bulb socket and the 5 clamps to the position indicator housing.



3. Install Position Indicator Slide Cover



  1. Install position indicator slide cover No.2 to the position indicator slide cover.




  2. Install the position indicator slide cover together with position indicator slide cover No.2 to the shift lock control unit.



4. Install Position Indicator Housing UPR



  1. Install the position indicator housing UPR to the shift lock control unit.

    ■ NOTICE ■
    Securely engage the claws.
