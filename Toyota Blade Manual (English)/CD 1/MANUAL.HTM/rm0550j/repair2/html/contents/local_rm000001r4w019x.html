CAN Communication System How to Proceed with Troubleshooting



  1. Points to Note Regarding Troubleshooting

  1. Vehicle brought to workshop

  2. Customer Problem Analysis and Symptom Check

  3. Check DTC (ALL DTCs)

  4. Check Installation Status of CAN Communication Systems (ECUs, Sensors)

  5. DLC3 Branch Line and CAN V Bus Main Line Open Circuit and Line-to-line Short Circuit Inspection (CANH - CANL)

  6. CAN V Bus +B Short Circuit Inspection (BAT - CANH, CANL)

  7. CAN V Bus GND Short Circuit Inspection (CG - CANH, CANL)

  8. Check ECUs Connected to CAN Bus (Check Connection Status Using TaSCAN)

  9. Check Communication Malfunction DTCs (Check Past DTCs)

  10. Check DTC Combination Table (Past Malfunction of No.1 Bus Branch Line Open)

  11. Problem Reproduction Test (Past Malfunction of No.1 Bus Main Line)

  12. Adjust, Repair or Replace

  13. Confirmation Test
