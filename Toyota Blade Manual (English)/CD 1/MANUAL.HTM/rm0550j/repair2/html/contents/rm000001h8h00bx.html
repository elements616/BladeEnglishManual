DTC P0705/C2 T/M Selection Switch Malfunction

Print

Preparation List


Circuit Description


The transmission control computer detects the shift position using signals from the neutral start switch assembly. The engine can be started only when the shift lever is in the P or N position.


DTC No.
SAE/TCCS
DTC Detection Condition
1. Diagnosis condition 2. Malfunction status 3. Malfunction time 4. Other
Inspection Area
P0705/C2*
  1. IG ON, battery voltage 10.5 V or more
  2. 2 or more of the NSW, R and D signals are ON simultaneously
  3. 2 seconds or more
  4. 2 trip
  1. Neutral Start Switch Assembly
  2. Wire Harness and Connector
  3. Transmission Control Computer
P0705/C2*
  1. IG ON, battery voltage 10.5 V or more
  2. All of the NSW, R and D signals are OFF
  3. 60 seconds or more
  4. 2 trip
  1. Neutral Start Switch Assembly
  2. Wire Harness and Connector
  3. Transmission Control Computer

□ HINT □
*: C2 (lamp code) indicates that the tens digit of the conventional 2-digit code blinks 12 times and the ones digit blinks 2 times.
