Engine Mounting Insulator Rear (2GR-FE) Installation

Print

Preparation List



1. Install Engine Mounting Insulator Rear



  1. Install the engine mounting insulator rear to the front suspension crossmember with the 2 bolts and 2 nuts.

    Standard
    T = 95 N/m{ 969 kgf/cm }



2. Connect Engine Mounting Insulator RR



  1. Connect the engine mounting insulator rear to the engine mounting bracket rear with the bolt.

    Standard
    T = 95 N/m{ 969 kgf/cm }



3. Connect Transmission Control Cable Assembly



  1. Install the transmission control cable support to the engine mounting insulator RR with the bolt.

    Standard
    T = 12 N/m{ 122 kgf/cm }



4. Install Engine Under Cover NO.2

  1. Install engine under cover NO.2 with the 5 clips.
