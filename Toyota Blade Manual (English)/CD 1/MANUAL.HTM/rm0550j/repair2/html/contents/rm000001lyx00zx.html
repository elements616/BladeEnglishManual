    1. A/T Learned Value Initialization

      ■ NOTICE ■
      Perform A/T learned value initialization 1 minutes or more after connecting the battery terminal.

      □ HINT □
      Learned values are not initialized (cleared) by simply disconnecting the battery negative terminal.

      1. Stop the vehicle on a level road surface.

      2. Check that the shift position is in the P range, connect SST (TaSCAN) to DLC3, and turn the ignition ON and the SST power ON.

        SST
        09991-70200  

        ■ NOTICE ■
        The engine will not start.

      3. Perform A/T Learned Value Initialization


        1. Following the SST (TaSCAN) screen display, select and execute main menu [Work Support] → work support category [Transmission] → [A/T/CVT Learned Value Initialization] to initialize the A/T learned values.

          □ HINT □
          Initialization takes approximately 1 minutes to complete.



      1. A/T Unit Compensation (Manual A/T Code Registration)

        □ HINT □
        When replacing the transaxle assembly (including both ECU-integrated and transaxle-only replacement), perform A/T unit compensation (manual A/T code registration) after replacing the axle.




        1. Record the A/T code (5 digits × 12 blocks) printed on the TM label of the supply part.

        2. Complete the transaxle assembly replacement work.

        3. With the IG OFF, connect SST (TaSCAN) to the DLC3 connector.

          SST
          09991-70200  

        4. With the shift lever in the P range, press the IG switch 2 times without depressing the brake pedal to turn the ignition ON.

          ■ NOTICE ■
          1. The engine will not start.
          2. Do not operate the shift lever or IG switch until the compensation work is completed.

        5. Turn the SST (TaSCAN) power ON and select "Diagnosis" → "Diagnosis Item / Work Support" → "Support Category / Transmission" → "A/T Unit Compensation (Manual A/T Code Registration)".




        6. While checking the screen display, press "Next" to proceed to the input screen (step 4/6).

        7. Operate the buttons on the screen to input the A/T code on the TM label in the same positions as on the label, and press "Complete" after input.




        8. Check that the entered A/T code is the same as that on the TM label, and press "Start".

        9. Confirm work completion on the screen.



        1. A/T Unit Compensation (A/T Code Read/Save) and A/T Unit Compensation (Automatic A/T Code Registration)

          □ HINT □
          1. When replacing only the transmission control computer, perform A/T unit compensation (A/T code read/save) before replacement, and perform A/T unit compensation (automatic A/T code registration) after replacing the computer.
          2. If the A/T code cannot be read due to a malfunction of the transmission control computer, perform A/T unit compensation (A/T code initialization) and then perform driving learning.
          3. Do not perform manual input from the A/T code label affixed to the vehicle transaxle.

          1. With the IG OFF, connect SST (TaSCAN) to the DLC3 connector.

            SST
            09991-70200  

          2. With the shift lever in the P range, press the IG switch 2 times without depressing the brake pedal to turn the ignition ON.

            ■ NOTICE ■
            1. The engine will not start.
            2. Do not operate the shift lever or IG switch until the work is completed.

          3. Turn the SST (TaSCAN) power ON and select "Diagnosis" → "Diagnosis Item / Work Support" → "Support Category / Transmission" → "A/T Unit Compensation (Read/Save A/T Code)".

          4. Press "Start" to read the A/T code stored in the transmission control computer.




          5. After reading of the A/T code (5 digits × 12 blocks) is completed, press "Save" to store the A/T code in SST (TaSCAN).

            □ HINT □
            If the A/T code cannot be read, perform driving learning after A/T unit compensation (A/T code initialization).




          6. Record the <Save Date/Time> and press "Complete".

          7. Turn the IG OFF and replace the transmission control computer.

          8. After completing the replacement work, set SST (TaSCAN) in the same way as for reading.

          9. From the SST (TaSCAN) screen, select "Diagnosis" → "Diagnosis Item / Work Support" → "Support Category / Transmission" → "A/T Unit Compensation (Automatic A/T Code Registration)".




          10. Press "NEXT", check the save date and time of the A/T code saved in SST (TaSCAN), and press "Start".

          11. Confirm work completion on the screen.

            1. Driving Learning

              ■ WARNING ■
              Exercise sufficient caution when performing the driving work.

              1. With the IG OFF, connect SST (TaSCAN) to the DLC3 connector.

                SST
                09991-70200  

              2. Depress the brake pedal, turn the ignition ON (START) and start the engine.

              3. Turn the SST (TaSCAN) power ON, select Diagnosis" → "System Diagnosis / Chassis" → "System Name / ECT" → "Diagnosis Function / ECU Data", then select and execute the monitor item "Accelerator Opening".

              4. With the vehicle stopped, check the pedal depression amount that gives an accelerator opening of 15%.

              5. From a vehicle speed of 0km/h, depress the accelerator pedal at an accelerator opening of 15% or less and accelerate to the highest possible vehicle speed while keeping the accelerator constant.

              6. If there is shift shock, repeat until the shift shock disappears.

              7. With the vehicle stopped, check the pedal depression amount that gives an accelerator opening of 25 to 35%.

              8. From a vehicle speed of 0km/h, depress the accelerator to an opening of 25 to 35% and accelerate to the highest possible vehicle speed while keeping the accelerator constant.

              9. If there is shift shock, repeat until the shift shock disappears.



              1. CVT Learned Value Initialization, G Sensor 0-point Learning and CVT Hydraulic Pressure Learning

                ■ NOTICE ■
                1. When the learned values are initialized, both the G sensor 0 point learned value and the CVT hydraulic pressure learned value are cleared.
                2. After initializing the CVT learned values, always perform G sensor 0 point learning first, then perform CVT hydraulic pressure learning.

                1. TaSCAN - CVT Learned Value Initialization


                  1. Turn the IG OFF, move the shift lever to the P position and apply the parking brake.

                  2. Turn the IG ON (engine stopped).

                    ■ NOTICE ■
                    The engine will not start.

                  3. Using SST (TaSCAN), following the screen display, select [Utility] from the TOP menu and select [Transmission] in the utility category.

                    SST
                    09991-70200  

                  4. Select [AT/CVT Learned Value Initialization] on the screen to initialize the CVT learned values.

                2. TaSCAN - G Sensor 0 Point Learning

                  ■ NOTICE ■
                  1. Be sure to place the vehicle on a level surface and perform 0 point learning.
                  2. Do not subject the vehicle to vibration while 0 point learning is in progress.
                  3. Do not start the engine, to avoid idling vibration.


                  1. Turn the IG ON (engine stopped) and wait for 2 seconds or more.

                  2. Using SST (TaSCAN), following the screen display, select [Utility] from the TOP menu and select [Transmission] in the utility category.

                    SST
                    09991-70200  

                  3. Select [G Sensor 0 Point Learning Start] on the screen to perform G sensor 0 point learning. (*1)

                    □ HINT □
                    1. When [Complete] is displayed on the screen, G sensor 0 point learning is complete.
                    2. If [Error] is displayed on the screen and the check engine warning light comes on, there may be a malfunction in the G sensor circuit.
                    3. If the vehicle is subjected to vibration during 0 point learning, 0 point learning may be canceled. (If [Error] is displayed on the screen and the check engine warning light does not illuminate) In that case, perform the work in (*1) again.

                3. TaSCAN - CVT Hydraulic Pressure Learning


                  1. Turn the IG OFF and wait for 30 seconds or more.

                  2. Turn the IG ON (engine stopped) and wait for 2 seconds or more.

                    ■ NOTICE ■
                    The engine will not start.

                  3. Using SST (TaSCAN), follow the screen instructions to select [Work Support] on the TOP menu, then select [Transmission] in the work support category.

                    SST
                    09991-70200  

                  4. Start the engine and wait for 5 seconds or more.

                  5. Select [CVT Hydraulic Pressure Learning Start] on the screen to perform CVT hydraulic pressure learning.

                    □ HINT □
                    1. During CVT hydraulic pressure learning, the engine is in an idle-up state.
                    2. CVT hydraulic pressure learning is complete when [Complete] is displayed on the screen.
                    3. The CVT hydraulic pressure learned values are not initialized just by disconnecting the battery terminal.

                  1. Yaw Rate Sensor & G Sensor 0-point Acquisition

                    ■ NOTICE ■
                    Always perform 0 point acquisition on a level surface (gradient within 1%), and do not rock the vehicle or open and close the doors during the procedure. Also, to avoid idling vibration, do not start the engine.

                    1. Clear Yaw Rate Sensor & G Sensor 0 Point Memory


                      1. Turn the ignition switch off and connect SST (TaSCAN) to DLC3.

                        SST
                        09991-70200  

                      2. Check that the shift lever is in the P position and the parking brake is applied, then turn the ignition ON.

                        ■ NOTICE ■
                        If 0 point clearing is performed with the shift position other than P, it may not finish normally.

                      3. Following the SST (TaSCAN) screen display, select and execute [Work Support] → [Support Category / ABS/VSC/Electronically Controlled Brake System] → [Backup Memory Clear].

                      4. After completion, turn the ignition OFF within 15 seconds.

                        ■ NOTICE ■
                        After 0 point clearing, if the ignition is left ON for 15 seconds or more with the shift lever in P, only the yaw rate sensor 0 point is stored and the VSC warning goes off. If the vehicle is driven in this condition, G sensor 0 point uncalibrated is stored and a VSC system malfunction is displayed.

                    2. Acquiring Yaw Rate & G Sensor 0 Point


                      1. With the shift lever in the P position, turn the ignition switch ON and check that the initial check of the indicators finishes.

                      2. Following the SST (TaSCAN) screen display, select and execute [Diagnosis] → [System Name / ABS/VSC] → [Mode Change] to change to test mode.

                      3. After changing to test mode, keep the vehicle stationary for approximately 2 seconds, and check that the "VSC Check" display on the multi-information display in the meter disappears and "VSC TEST MODE" is displayed.

                        ■ NOTICE ■
                        1. If test mode is entered with the shift lever in any position other than P, the yaw rate sensor and G sensor 0 point uncalibrated malfunction code is stored.
                        2. If the 0 point uncalibrated malfunction code is stored, perform the procedure again from 0 point memory clearing.

                        □ HINT □
                        After 0 point calibration is completed, the display in the meter changes to the test mode display.

                      4. Following the SST (TaSCAN) screen display, select and execute [Diagnosis] → [System Name / ABS/VSC] → [Mode Change] to switch to normal mode.



                    1. Torque Sensor 0 Point Calibration and Rotation Angle Sensor Output Calibration

                      ■ NOTICE ■
                      1. If the steering column assembly or power steering computer assembly has been replaced, or if steering effort differs between left and right, clear the computer correction values and then perform torque sensor 0 point calibration and rotation angle sensor output calibration.
                      2. If C1516/16 (torque sensor 0 point calibration incomplete) is stored, torque sensor 0 point calibration cannot be performed, so clear the DTC beforehand.
                      3. If C1526/18 (rotation angle sensor output calibration incomplete) is stored, rotation angle sensor output calibration cannot be performed, so clear the DTC beforehand.

                      1. Pre-calibration Inspection


                        1. Using SST (TaSCAN), check "IG Power Supply Voltage" in the ECU data monitor.

                          SST
                          09991-70200  

                          Standard
                          10V or more

                          ■ NOTICE ■
                          If the IG voltage is 9V or less, the rotation angle sensor output and torque sensor 0 point cannot be calibrated, so if the value is out of the standard range, replace or charge the battery before performing the calibration.

                      2. Sensor Correction Value Clearing, Torque Sensor 0 Point Calibration and Rotation Angle Sensor Output Calibration


                        1. Turn IG OFF.

                        2. Connect SST (TaSCAN) to DLC3.

                          SST
                          09991-70200  

                        3. Turn IG ON.

                        4. Select "Work Support" → "Electric PS" → "Rotation Angle Sensor Output Calibration" on the SST (TaSCAN) screen display, and following the display, perform sensor correction value initialization → torque sensor 0 point calibration → rotation angle sensor output calibration.

                          ■ NOTICE ■
                          1. Keep the steering and front tires in the straight-ahead position.
                          2. Never touch the steering wheel during torque sensor 0 point calibration (3 seconds).
                          3. Do not turn the steering wheel suddenly during rotation angle sensor output calibration.

                          □ HINT □
                          Rotation angle sensor output calibration calibrates the outputs of the motor rotation angle sensor and the torque sensor.

                              When the television camera controller is replaced, or when the vehicle height has changed due to removal/installation or replacement of the height control sensor assembly (rear), suspension replacement, tire replacement, etc., the height control sensor vehicle height difference setting / G sensor 0 point writing must be performed before camera optical axis adjustment.


                              1. Stop the vehicle with the steering wheel straight.



                              2. Place the adjustment target bars in the positions shown in the illustration.



                                □ HINT □
                                1. Adjust the tire pressure to the specified pressure beforehand.
                                2. Adjustment target bars A and B are made by applying tape of the size shown in the illustration to the floor; check the color on the vehicle display and choose a conspicuous color.
                                3. Before stopping the vehicle, always move the vehicle slightly forward and backward, and check that not only the steering wheel but also the tires are in the straight-ahead position.




                            2. Start Diagnosis

                              ■ NOTICE ■
                              The registration setting must be performed with the engine running. Therefore, apply the parking brake, depress the brake pedal, move the shift lever to P, and take sufficient care that the vehicle does not move off.

                              □ HINT □
                              For the diagnosis startup procedure, seeReference




                            3. Select "Inspection Menu" on the service inspection screen to display the diagnosis inspection menu screen.




                            4. Select "Camera Inspection" on the diagnosis inspection menu screen to display the signal connection check screen.

                            5. Select "NEXT" on the signal connection check screen to display the camera optical axis adjustment (rotation adjustment mode) screen.




                            6. Camera Optical Axis Adjustment (Rotation Adjustment Mode)

                              ■ NOTICE ■
                              When the television camera controller is replaced, or when the vehicle height has changed due to removal/installation or replacement of the height control sensor assembly (rear), suspension replacement, tire replacement, etc., the height control sensor vehicle height difference setting and G sensor 0-point writing must be performed before performing the camera optical axis adjustment.


                              1. Touch switch A or B to rotate C so that it is parallel to adjustment target bar A.

                              2. Select "Next" to display the camera optical axis adjustment (left/right/up/down position adjustment mode) screen.




                            7. Camera Optical Axis Adjustment (Left/Right/Up/Down Position Adjustment Mode)




                              1. Press the left/right/up/down arrow switches to move A left, right, up or down, and align A with C (corner) of adjustment target bar B.



                                ■ NOTICE ■
                                If A and adjustment target bar B do not align completely, align only C (corner).

                              2. Select "Next" to display the BUMPER screen.




                            8. Camera Optical Axis Adjustment (Bumper Reference Line Display Position Adjustment Mode)


                              1. Press the left/right/up/down switches and switch A or B to move the bumper reference line left, right, up, down and rotate it so that the bumper reference line overlaps or touches the bumper edge line.

                              2. Select "Next" to display the confirmation screen.




                            9. Confirmation Screen


                              1. Check that A (indicating 1 m from the bumper edge) and adjustment target bar A almost overlap, and that the bumper reference line almost overlaps the bumper edge line. Also, check that the expected course lines are straight (overlapping the vehicle width extension lines) when the steering is in the straight-ahead position.

                              2. When "NEXT" is selected, the screen changes to the steering angle adjustment screen and the camera optical axis adjustment value is stored.

                                □ HINT □
                                1. The memory is not updated unless "Next" is selected.
                                2. When "NEXT" is selected, a confirmation beep is output from the driver side speaker and the camera optical axis adjustment value is stored.




                            10. Steering Angle Adjustment

                              □ HINT □
                              1. When the television camera controller is replaced, perform the steering angle adjustment after checking the camera optical axis adjustment.
                              2. If the only adjustment required after vehicle servicing is camera optical axis adjustment, steering angle adjustment is not necessary, so select "Complete".


                              1. Check that the steering wheel is in the position in which the vehicle travels straight ahead (as a guide, nearly straight within ± 5 degrees), and select "Store Steering Angle Neutral Point".

                              2. After storing the steering angle neutral point, turn the steering wheel fully to the left, then fully to the right, and select "Store Maximum Steering Angle"; the screen changes to the diagnosis inspection menu screen and the steering angle adjustment value is stored.

                                □ HINT □
                                1. The steering wheel may be turned to the right first.
                                2. When "Store Maximum Steering Angle" is pressed, a confirmation beep is output from the driver side speaker and the steering angle adjustment value is stored.
                                3. The stored value is not updated unless "Store Maximum Steering Angle" is selected.
                                4. Selecting "Back" switches to the camera optical axis adjustment confirmation screen without storing the setting values.

                              3. When "Complete" is selected, a confirmation beep is output from the driver side speaker and the screen changes to the diagnosis inspection menu screen.

                                □ HINT □
                                If steering angle adjustment has not been performed, touching "Complete" is not accepted until the steering angle neutral point and maximum steering angle have been stored.

                                ■ NOTICE ■
                                After initializing the headlight leveling computer assembly, perform headlight aim adjustment.

                                1. Check Vehicle Condition (*1)


                                  1. Put the vehicle in the following condition.

                                    1. Reduce the remaining fuel to approximately 10 liters or less.
                                    2. Unload any removable luggage from the vehicle. (Spare tire and on-board tools remain loaded)
                                    3. No occupants.
                                    4. Headlights off.
                                    5. Vehicle stopped with no change in vehicle height. (Vehicle stable on a level surface)

                                    □ HINT □
                                    If the above is not performed, initialization cannot be performed normally.

                                2. Check Warning Display


                                  1. 3 seconds after turning the ignition OFF → ON, check the warning display of the headlight leveling warning light in the combination meter.

                                    Specified Condition

                                    Work Description
                                    		Warning Display
                                    Initialization malfunction or headlight leveling computer assembly replaced (new)
                                    		Blinks
                                    Height control sensor replacement/removal, suspension replacement, etc.
                                    		Goes off

                                    □ HINT □
                                    If not within the standard, inspect the headlight leveling computer assembly, wire harness and connectors.




                                3. Initialization Operation


                                  1. Using SST, connect terminals 8 (LVL) ←→ 4 (CG) of connector DLC3.

                                    SST
                                    09843-18040  

                                  2. Within 20 seconds after connecting the initialization terminals, operate the light control switch OFF → HEAD 3 times or more. (*2)

                                    ■ NOTICE ■
                                    Operate the switch at 1 second intervals.

                                  3. Check the warning display.

                                    Specified Condition

                                    Work Description
                                    		Warning Display
                                    Replace Headlight Leveling Computer Assembly (New)
                                    		Blinks 2Hz 2 times → blinks 2Hz 3 times, then goes off (initialization completed normally)
                                    Height control sensor replacement/removal, suspension replacement, etc.
                                    		No blinking → blinks 2Hz 3 times, then goes off (initialization completed normally)

                                    □ HINT □
                                    If the operation (*2) does not finish normally even after repeating it 20 times or more, start again from step (*1).

                                    1. Power Window Reset (Pulse Sensor Initialization)

                                      ■ NOTICE ■
                                      1. When a power window regulator motor assembly (any seat) is replaced with a new one, DTC B2313 is output. After resetting the power window (initializing the pulse sensor), clear the DTC.
                                      2. If the door window regulator of any seat has been replaced, or the power window regulator motor assembly (any seat) has been removed from the door window regulator, the power window regulator motor assembly (applicable seat) must be returned to the uninitialized state (current memory of the pulse sensor in the motor cleared) and then the glass position must be reset (pulse sensor initialized). If the reset is not performed, the jam protection function may operate at times other than its operating conditions.
                                      3. If AUTO UP is operated for a seat after replacing its glass, glass run, etc., the jam protection function may operate. In that case, holding AUTO UP until the door glass of the applicable seat is in the fully closed position will make that seat operate normally.
                                      4. If the reset cannot be completed normally, there may be a LIN communication malfunction, so inspect the body multiplex communication system [LIN] (see).

                                      1. Connect the battery and turn the ignition ON; at this time, the indicators of the power window regulator switch assembly, rear power window regulator switch assembly and power window regulator master switch assembly for the location where the power window regulator motor assembly was replaced or removed/installed blink, and the system enters the reset standby state.

                                        □ HINT □
                                        1. If the indicator does not blink and the jam protection function operates outside its operating conditions, perform the following work to return the power window regulator motor assembly (applicable seat) to the uninitialized state (current memory of the pulse sensor in the motor cleared), then proceed.
                                        2. While the power window of the applicable seat is operating, disconnect the connector of the power window regulator motor assembly (applicable seat) or disconnect the battery negative terminal.

                                      2. After the glass is fully closed, operate the applicable seat switch on the power window regulator master switch assembly or the applicable seat power window switch for 1 seconds or more (hold AUTO UP); the power window (applicable seat) position is reset, the indicators of the power window regulator master switch assembly and the power window switch (applicable seat) change from blinking to illuminated, and the reset is complete.

                                        □ HINT □
                                        If the switch indicator does not change from blinking to illuminated even after performing the above operation, lower the glass 50 mm or more and perform the above operation again.

                                        1. Millimeter Wave Radar Sensor Adjustment

                                          ■ NOTICE ■

                                          1. Perform the measurement on a level floor.
                                          2. Check that there are no metal objects in the surrounding area or on the floor surface. (The area approximately 10m ahead and approximately 14m wide is a prohibited area for objects. It is preferable that there are no large metal objects around it either.)

                                          1. Pre-adjustment Work


                                            1. Unload all luggage from the vehicle.

                                            2. Leave only the standard tools and spare tire in the trunk.

                                            3. Adjust the tire pressure to the specified value.

                                            4. Reduce the remaining fuel to less than 15L.



                                          2. Vertical Adjustment


                                            1. Remove dust and oil from the level shelf of the millimeter wave radar sensor assembly.




                                            2. Place the dedicated level in the center of the level shelf of the millimeter wave radar sensor assembly.




                                            3. Turn the vertical adjustment bolt A of the millimeter wave radar sensor assembly to adjust so that the bubble is on the red line of the level.

                                              Specified Condition
                                              Upward 0.2°

                                              □ HINT □
                                              Adjustment range within red frame of level ±0.2°

                                              Vertical Adjustment
                                              1. Upward: turn bolt A to the minus side
                                              2. Downward: turn bolt A to the plus side
                                              		1 turn of the screwdriver moves it approximately 0.12°




                                          3. Reflector (SST) Height Adjustment


                                            1. Set the reflector (SST) at a height of 70cm from the ground.

                                              SST
                                              09870-60000   (09870-60010, 09870-60040)



                                          4. Reflector (SST) Installation


                                            1. Hang a pointed weight from the center (emblem center) of the front and rear bumpers of the vehicle, and accurately mark the center positions on the floor surface.

                                            2. Make a mark 5m ahead of the vehicle on the line connecting the 2 front and rear points.

                                              □ HINT □

                                              Fix one end of a string to the rear mark, and from 5m ahead of the vehicle, move the other end of the string left and right to align it with the front mark and establish a straight line.



                                            3. Install the reflector (SST) at a position offset 12mm to the left of the vehicle from the marked position.



                                              ■ NOTICE ■
                                              Perform as accurately as possible.



                                          5. Beam Axis Adjustment


                                            1. Connect SST (TaSCAN) to the vehicle.

                                              SST
                                              09991-70200  

                                            2. Turn IG ON.

                                            3. Turn the cruise control main switch ON.




                                            4. On the screen, select "Work Support" → "Radar Cruise" → "Millimeter Wave Radar Beam Axis Adjustment" in that order.

                                            5. Follow the screen instructions and press the "Start" button.

                                              ■ NOTICE ■
                                              Check that the beam axis distance is approximately 5m.



                                          6. Horizontal Adjustment





                                            1. Read the current angle deviation.

                                              Specified Condition
                                              0° for both left and right




                                            2. Based on the beam axis deviation measurement result, use a screwdriver to turn the horizontal adjustment bolt B of the millimeter wave radar sensor assembly to adjust it.

                                              Horizontal Adjustment
                                              1. Rightward: turn bolt B to the plus side
                                              2. Leftward: turn bolt B to the minus side
                                              		1 turn of the screwdriver moves it approximately 0.05°

                                              ■ NOTICE ■
                                              If it is difficult to reach 0°, an object other than the reflector (SST) may be being targeted, so check again for any highly reflective objects in the surrounding area.




                                            3. To reset the driving learned values, cover the right half of the sensor with aluminum foil etc. (a metal object that blocks radio waves). (For approximately 10 seconds)

                                              ■ NOTICE ■
                                              At this time, leave the reflector (SST) installed, and make sure there is nothing between the right half of the sensor and the reflector.

                                              □ HINT □
                                              When reset, the buzzer sounds for 10 seconds and the screen displays "Beam Axis Deviation 6.3°" and "Beam Axis Distance 6.3m".




                                            4. Press the "Complete" button to end the beam axis adjustment mode.

                                            5. Disconnect SST (TaSCAN) from the vehicle.



                                          7. Recheck Vertical Adjustment





                                            1. Place the dedicated level in the center of the level shelf of the millimeter wave radar sensor assembly.




                                            2. Using a screwdriver, turn the vertical adjustment bolt A of the millimeter wave radar sensor assembly to readjust so that the bubble is on the red line of the level.

                                              Specified Condition
                                              Upward 0.2°

                                              □ HINT □
                                              Adjustment range within red frame of level ±0.2°

                                              Vertical Adjustment
                                              1. Upward: turn bolt A to the minus side
                                              2. Downward: turn bolt A to the plus side
