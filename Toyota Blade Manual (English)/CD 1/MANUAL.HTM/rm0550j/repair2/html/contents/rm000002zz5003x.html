Fusible Link Block Assembly (Engine Type 2GR-FE) On-vehicle Inspection

Print


1. Inspect Fusible Link Block Assembly



  1. Using a work light, check whether any fuses in the fusible link block are blown.

    ■ NOTICE ■
    If even 1 fuse in the fusible link block is blown or broken, replace the fusible link block assembly with a new one.
