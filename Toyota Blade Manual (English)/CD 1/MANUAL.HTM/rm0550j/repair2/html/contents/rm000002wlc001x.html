4WD Computer Assembly (4WD) Installation

Print

Preparation List



1. Install 4WD Computer Assembly



  1. Install the 4WD computer assembly with the bolt.

    Standard
    T = 8.0 N/m{ 82 kgf/cm }

  2. Connect the connector.



2. Install Instrument Panel Airbag Assembly LWR NO.1



  1. Connect the connector to the instrument lower airbag No.1.

    ■ NOTICE ■
    Securely lock the connector.




  2. Install the instrument lower airbag No.1 with the 6 claws and 2 guides.




  3. Install the instrument lower airbag No.1 with the 4 bolts.

    Standard
    T = 10 N/m{ 102 kgf/cm }



3. Install Steering Column Cover

■ NOTICE ■
If the installation procedure is incorrect, gaps may form in the column cover.




  1. Engage the 2 claws and pins, and install the steering column cover (upper side).




  2. Engage the 2 claws and install the steering column cover (lower side).




  3. Engage the 4 claws.




  4. Engage the claws.

    ■ NOTICE ■
    Push the bottom surface of the steering column cover (lower side) to securely engage the claws.



4. Install Steering Wheel Assembly



  1. Align the matchmarks and install the steering wheel assembly to the steering column assembly.

  2. Install the nut.

    Standard
    T = 50 N/m{ 510 kgf/cm }

  3. Connect each connector to the spiral cable.



5. Install Horn Button Assembly



  1. Connect the horn connector to the horn button assembly.

  2. Connect the airbag connector to the horn button assembly and lock it securely.

    ■ NOTICE ■
    Securely lock the airbag connector.




  3. Using a torx socket wrench (T30), install the horn button assembly to the steering wheel assembly with the 2 torx bolts.

    Standard
    T = 8.8 N/m{ 90 kgf/cm }



6. Install Steering Wheel Cover Lower NO.3



  1. Engage the claws and install the steering wheel cover lower No.3.



7. Install Steering Wheel Cover Lower NO.2



  1. Engage the claws and install the steering wheel cover lower No.2.



8. Install Instrument Panel Under Cover Sub-assembly NO.1



  1. Engage the 2 screws and claws, and install instrument panel under cover NO.1.



9. Fuse Box Opening Cover Installation

  1. Connect each connector.




  2. Engage the 4 clips and 4 claws, and install the fuse box opening cover.



10. Connect Battery Negative Terminal
Standard
T = 5.4 N/m{ 55 kgf/cm }


11. Inspect Airbag Warning Light



  1. Check that the warning light comes on when the IG is turned ON.

  2. Check that the warning light goes off approximately 6 seconds after the IG is turned ON.

    □ HINT □
    1. If the warning light remains on even after approximately 6 seconds have elapsed after the IG is turned ON, there is a malfunction in the airbag/pretensioner system.
    2. If the light comes on occasionally even after approximately 6 seconds have elapsed after the IG is turned ON, a short to +B, short to ground or open circuit in the airbag warning light circuit may be the cause.
    3. If the light comes on even with the IG OFF or ACC ON, a malfunction in the power supply system or combination meter assembly may be the cause.
