1. Height Control Sensor Vehicle Height Difference Setting and G Sensor 0-point Writing



  1. Preparation Before Adjustment

    ■ NOTICE ■
    1. Perform the height control sensor vehicle height difference setting and G sensor 0-point writing on a level surface.
    2. When the television camera controller is replaced, or when the vehicle height has changed due to removal/installation or replacement of the height control sensor assembly (rear), suspension replacement, tire replacement, etc., the height control sensor vehicle height difference setting and G sensor 0-point writing must be performed before performing the camera optical axis adjustment.


    1. At the measurement position shown in the illustration, measure height A from the floor to the lower edge of the wheel arch.

    2. Calculate the difference between the measured value and the standard height below.

      Standard
      703 mm

      □ HINT □
      If the measured value is 703mm, the difference from the standard height is 713 - 703 = + 10 mm.




  2. Start Diagnosis

    ■ NOTICE ■
    The registration setting must be performed with the engine running. Therefore, apply the parking brake, depress the brake pedal, move the shift lever to P, and take sufficient care that the vehicle does not move off.

    □ HINT □
    For the diagnosis startup procedure, seeReference




  3. Select "Inspection Menu" on the service inspection screen to display the diagnosis inspection menu screen.




  4. Select "Camera Inspection" on the diagnosis inspection menu screen to display the signal connection check screen.

  5. On the signal connection check screen, select "HT INIT" to display the HEIGHT SET screen.




  6. Height Control Sensor Vehicle Height Difference Setting / G Sensor 0-point Writing

    ■ NOTICE ■
    1. Perform the height control sensor vehicle height difference setting and G sensor 0-point writing on a level surface.
    2. When the television camera controller is replaced, or when the vehicle height has changed due to removal/installation or replacement of the height control sensor assembly (rear), suspension replacement, tire replacement, etc., the height control sensor vehicle height difference setting and G sensor 0-point writing must be performed before performing the camera optical axis adjustment.


    1. Press "UP" or "DOWN" to set the difference from the standard height.

      □ HINT □
      1. A value displayed in green indicates a positive value, and a value displayed in red indicates a negative value.
      2. If "10 MM" is displayed in green, it indicates + 10 mm.

    2. Selecting "Complete" switches to the signal connection screen and stores the height control sensor vehicle height difference setting value and the G sensor 0-point.

      □ HINT □
      1. The memory is not updated unless Complete" is selected.
      2. Selecting "Back" switches to the camera signal connection screen without storing the height control sensor vehicle height difference setting value and the G sensor 0-point.
      3. Press the "Complete" switch with the vehicle in the same condition as when the vehicle height difference was measured.
      4. If the vehicle height difference was measured with 1 person in the driver seat, press the "Complete" switch with 1 person in the driver seat.
      5. Check that the "HT INIT" display on the signal connection check screen is "OK" (displayed in blue).

  7. Diagnosis Cancellation

    □ HINT □
    For the diagnosis cancellation procedure, seeReference



2. Camera Optical Axis Adjustment

  1. Preparation Before Adjustment

    ■ NOTICE ■
    When the television camera controller is replaced, or when the vehicle height has changed due to removal/installation or replacement of the height control sensor assembly (rear), suspension replacement, tire replacement, etc., the height control sensor vehicle height difference setting and G sensor 0-point writing must be performed before performing the camera optical axis adjustment.


    1. Stop the vehicle with the steering wheel straight.



    2. Place the adjustment target bars in the positions shown in the illustration.



      □ HINT □
      1. Adjust the tire pressure to the specified pressure beforehand.
      2. Adjustment target bars A and B are made by applying tape of the size shown in the illustration to the floor; check the color on the vehicle display and choose a conspicuous color.
      3. Before stopping the vehicle, always move the vehicle slightly forward and backward, and check that not only the steering wheel but also the tires are in the straight-ahead position.




  2. Start Diagnosis

    ■ NOTICE ■
    The registration setting must be performed with the engine running. Therefore, apply the parking brake, depress the brake pedal, move the shift lever to P, and take sufficient care that the vehicle does not move off.

    □ HINT □
    For the diagnosis startup procedure, seeReference




  3. Select "Inspection Menu" on the service inspection screen to display the diagnosis inspection menu screen.




  4. Select "Camera Inspection" on the diagnosis inspection menu screen to display the signal connection check screen.

  5. Select "NEXT" on the signal connection check screen to display the camera optical axis adjustment (rotation adjustment mode) screen.




  6. Camera Optical Axis Adjustment (Rotation Adjustment Mode)

    ■ NOTICE ■
    When the television camera controller is replaced, or when the vehicle height has changed due to removal/installation or replacement of the height control sensor assembly (rear), suspension replacement, tire replacement, etc., the height control sensor vehicle height difference setting and G sensor 0-point writing must be performed before performing the camera optical axis adjustment.


    1. Press switch A or B to rotate C so that it is parallel to adjustment target bar A.

    2. Select "Next" to display the camera optical axis adjustment (left/right/up/down position adjustment mode) screen.




  7. Camera Optical Axis Adjustment (Left/Right/Up/Down Position Adjustment Mode)



    1. Press the left/right/up/down switches to move A left, right, up and down, and align A with C (corner) of adjustment target bar B.



      ■ NOTICE ■
      If A and adjustment target bar B do not align completely, align only C (corner).

    2. Select "Next" to display the BUMPER screen.




  8. Camera Optical Axis Adjustment (Bumper Reference Line Display Position Adjustment Mode)

    1. Press the left/right/up/down switches and switch A or B to move the bumper reference line left, right, up, down and rotate it so that the bumper reference line overlaps or touches the bumper edge line.

    2. Select "Next" to display the confirmation screen.




  9. Confirmation Screen

    1. Check that A (indicating 1 m from the bumper edge) and adjustment target bar A almost overlap, and that the bumper reference line almost overlaps the bumper edge line. Also, check that the expected course lines are straight (overlapping the vehicle width extension lines) when the steering is in the straight-ahead position.

    2. When "NEXT" is selected, the screen changes to the steering angle adjustment screen and the camera optical axis adjustment value is stored.

      □ HINT □
      1. The memory is not updated unless "Next" is selected.
      2. When "Next" is selected, a confirmation beep is output from the driver side speaker and the camera optical axis adjustment value is stored.




  10. Steering Angle Adjustment

    □ HINT □
    1. When the television camera controller is replaced, perform the steering angle adjustment after checking the camera optical axis adjustment.
    2. If the only adjustment required after vehicle servicing is the camera optical axis adjustment, the steering angle adjustment is not necessary, so select "Complete".


    1. Check that the steering wheel is in the position in which the vehicle travels straight ahead (as a guide, nearly straight within ± 5 degrees), and select "Store Steering Angle Neutral Point".

    2. After storing the steering angle neutral point, turn the steering wheel fully to the left, then fully to the right, and select "Store Maximum Steering Angle"; the screen changes to the diagnosis inspection menu screen and the steering angle adjustment value is stored.

      □ HINT □
      1. The steering wheel may be turned to the right first.
      2. When "Store Maximum Steering Angle" is pressed, a confirmation beep is output from the driver side speaker and the steering angle adjustment value is stored.
      3. The stored value is not updated unless "Store Maximum Steering Angle" is selected.
      4. Selecting "Back" switches to the camera optical axis adjustment confirmation screen without storing the setting values.

    3. When "Complete" is selected, a confirmation beep is output from the driver side speaker and the screen changes to the diagnosis inspection menu screen.

      □ HINT □
      If steering angle adjustment has not been performed, touching "Complete" is not accepted until the steering angle neutral point and maximum steering angle have been stored.

  11. Diagnosis Cancellation

    □ HINT □
    For the diagnosis cancellation procedure, seeReference

  12. Steering Angle Adjustment Check

    □ HINT □
    When the television camera controller is replaced, check the steering angle adjustment on the intelligent parking assist screen after canceling diagnosis mode.


    1. On the intelligent parking assist screen, check that the expected course lines move in conjunction with the steering wheel until it is turned fully to the left and right.

      □ HINT □
      If the expected course lines stop moving before the steering wheel is turned fully to the left and right, the steering angle adjustment value has not been stored correctly and readjustment is necessary.

  4. Select "Next" on the signal connection check screen to display the camera optical axis adjustment (rotation adjustment mode) screen.




  5. Camera Optical Axis Adjustment (Rotation Adjustment Mode)

    □ HINT □
    If the only adjustment required after vehicle servicing is bumper reference line display position adjustment, camera optical axis adjustment (rotation adjustment mode) is not necessary, so select "NEXT".

  6. Camera Optical Axis Adjustment (Left/Right/Up/Down Position Adjustment Mode)

    □ HINT □

      □ HINT □
      1. The memory is not updated unless "Next" is selected.

  9. Steering Angle Adjustment

    □ HINT □

      □ HINT □

    □ HINT □

  3. Select "Camera Inspection" on the diagnosis inspection menu screen to display the signal connection check screen.

  4. Select "Next" on the signal connection check screen to display the camera optical axis adjustment (rotation adjustment mode) screen.




  5. Camera Optical Axis Adjustment (Rotation Adjustment Mode)

    □ HINT □
    If the only adjustment required after vehicle servicing is steering angle adjustment, camera optical axis adjustment (rotation adjustment mode) is not necessary, so select "NEXT".


    1. Select "Next" to display the camera optical axis adjustment (left/right/up/down position adjustment mode) screen.




  6. Camera Optical Axis Adjustment (Left/Right/Up/Down Position Adjustment Mode)

    □ HINT □
    If the only adjustment after vehicle service is the steering angle adjustment, it is not necessary to perform the camera optical axis adjustment (left/right/up/down position adjustment mode), so select "NEXT".


    1. Select "Next" to display the BUMPER screen.




  7. Bumper Reference Line Display Position Adjustment

    □ HINT □
    If the only adjustment required after vehicle servicing is steering angle adjustment, bumper reference line display position adjustment is not necessary, so select "NEXT".


    1. Select "Next" to display the confirmation screen.




  8. Confirmation Screen

    □ HINT □
    If the only adjustment required after vehicle servicing is steering angle adjustment, the check is not necessary, so select "NEXT".


    1. Selecting "NEXT" changes the display to the steering angle adjustment screen.

      □ HINT □
      When "NEXT" is selected, a confirmation beep is output from the driver side speaker.




  9. Steering Angle Adjustment

    1. Check that the steering wheel is in the position in which the vehicle travels straight ahead (as a guide, nearly straight within ± 5 degrees), and select "Store Steering Angle Neutral Point".

    2. After storing the steering angle neutral point, turn the steering wheel fully to the left, then fully to the right, and select "Store Maximum Steering Angle"; the screen changes to the diagnosis inspection menu screen and the steering angle adjustment value is stored.

      □ HINT □
      1. The steering wheel may be turned to the right first.
      2. When "Store Maximum Steering Angle" is pressed, a confirmation beep is output from the driver side speaker and the steering angle adjustment value is stored.
      3. The stored value is not updated unless "Store Maximum Steering Angle" is selected.
      4. Selecting "Back" switches to the camera optical axis adjustment confirmation screen without storing the setting values.

  10. Diagnosis Cancellation

    □ HINT □
    For the diagnosis cancellation procedure, seeReference

  11. Steering Angle Adjustment Check

    1. On the intelligent parking assist screen, check that the expected course lines move in conjunction with the steering wheel until it is turned fully to the left and right.

      □ HINT □
      If the expected course lines stop moving before the steering wheel is turned fully to the left and right, the steering angle adjustment value has not been stored correctly and readjustment is necessary.
