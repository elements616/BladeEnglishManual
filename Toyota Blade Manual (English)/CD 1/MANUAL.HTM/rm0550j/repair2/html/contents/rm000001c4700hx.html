Hands-free System System Description

Print



  1. Hands-free System

    1. Hands-free System


      1. On this model, the hands-free function built into the navigation receiver assembly can be used by using a Bluetooth compatible cellular phone.



    1. Communication Device



      1. With Bluetooth Telephone Connected


        1. A Bluetooth cellular phone is used for hands-free calls.

          □ HINT □
          1. When replacing the navigation receiver assembly on a vehicle not subscribed to the G-BOOK service, perform the vehicle linking setting. (see)
          2. When replacing the navigation receiver assembly on a vehicle subscribed to the G-BOOK service, perform the vehicle linking setting, then perform the G-BOOK use resumption operation and HELPNET service start operation. (see)
          3. If the navigation receiver assembly is replaced while a purchased G-SOUND unlimited license exists, perform G-SOUND license recovery. (see)



      1. About Cellular Phone for Calls

        1. Use a model whose operation has been verified for hands-free calls.
