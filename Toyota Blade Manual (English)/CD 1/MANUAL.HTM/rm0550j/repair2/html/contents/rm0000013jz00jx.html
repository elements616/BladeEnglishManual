Preparation List


Function Description


The engine control computer performs learning control of the belt clamping pressure based on the belt clamping pressure signal detected by the oil pressure sensor.


DTC No.
DTC Detection Conditions
1. Diagnosis conditions 2. Malfunction status 3. Malfunction duration 4. Other
Inspection Area
P0840/C8
  1. 2 seconds have elapsed after starting the engine
  2. Oil pressure sensor circuit shorted then opened, or opened then shorted, within 0.5 seconds
  3. Detected continuously for 0.5 seconds or more
  4. 1 trip

Step 5TaSCAN (A/T / CVT Learned Value Initialization, G Sensor 0-point Learning and CVT Hydraulic Pressure Learning)

■ NOTICE ■
  1. Initializing the learned values clears both the G sensor 0-point learning values and the CVT hydraulic pressure learning values, so when replacing the parts in the table below, perform AT/CVT learned value initialization and be sure to perform both G sensor 0-point learning and CVT hydraulic pressure learning.
    Replacement Parts
    1. Continuously Variable Transaxle
    2. Engine Control Computer
    3. Skid control computer
    4. Oil Pressure Sensor
    5. Yaw Rate Sensor
  2. After performing AT/CVT learned value initialization, be sure to perform G sensor 0-point learning first, and then CVT hydraulic pressure learning.
  3. Be sure to place the vehicle on a level surface and perform 0 point learning.
  4. Do not subject the vehicle to vibration while 0 point learning is in progress.
