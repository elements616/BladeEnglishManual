DTC B2799 Immobiliser: Separate ECU Communication Malfunction

Print

Preparation List


Circuit Description


The engine ECU (engine control computer) outputs this code when there is a communication line malfunction with the ID code box (immobiliser code computer) or when the communication ID is different.


DTC No.
DTC Detection Condition
Inspection Area
B2799
  1. Communication malfunction or communication line malfunction between the engine ECU (engine control computer) and ID code box (immobiliser code computer)
  2. When the communication ID is different during communication with the ID code box (immobiliser code computer)
  1. ID code box (immobiliser code computer)
  2. Engine ECU (Engine Control Computer)
  3. Wire Harness and Connector
