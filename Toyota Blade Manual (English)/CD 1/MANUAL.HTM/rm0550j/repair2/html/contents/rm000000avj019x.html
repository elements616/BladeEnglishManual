Electronically Controlled Automatic Transaxle [ECT] (U660E) Function Description

Print



  1. Diagnosis Function

    1. When a malfunction occurs in the ECT system, the check engine warning light comes on.

      ■ NOTICE ■
      If the malfunction item returns to normal, the light does not come on.

    2. Diagnosis results when a malfunction occurs are stored in the transmission control computer.

      ■ NOTICE ■
      Since the computer memory data will be erased, do not remove the EFI fuse, ETCS fuse or battery terminal until the inspection is finished.



    1. Fail-safe Function

      1. If an open or short occurs in any of the solenoid valve circuits, the transmission control computer turns the other normal solenoid valves ON or OFF. Also, if all the solenoid valves malfunction, only the mechanical hydraulic circuit operates, resulting in manual shifting. (In the case of an open or short, the transmission control computer stops current flow to the malfunctioning solenoid valve)



      1. Sequential Shiftmatic Function

        1. Only when the shift position is in the S position can the shift range be changed using (+) and (-) of the sequential gate.

          □ HINT □
          Moving the shift position to the S position disconnects the shift lever from the transmission control link.
