Preparation List


Circuit Description


  1. The engine control computer outputs the cruise control SW signal, vehicle speed signal, etc. to the distance control computer assembly.
  2. The distance control computer assembly outputs the acceleration signal, deceleration request signal, etc. to the engine control computer. Using these signals, the engine control computer performs cruise control.


DTC No.
Diagnosis Description
  1. Diagnosis Condition
  2. Abnormal Condition
Inspection Area
P1616/62
  1. Control vehicle speed (40 - 100 km/h), cruise control main switch ON (vehicle-to-vehicle distance control mode)
  2. Communication data from the engine control computer to the distance control computer assembly is abnormal
  1. Engine Control Computer
  2. Distance Control Computer Assembly
  3. CAN Communication System
