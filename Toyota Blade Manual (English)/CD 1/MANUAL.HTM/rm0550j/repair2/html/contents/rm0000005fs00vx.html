Steering Lock System Function Description

Print



  1. Steering Lock System, Unlock Operation Conditions

    1. Unlock operation is performed when the following conditions are met.


      1. Key verification completed

      2. Engine switch ON



    1. Steering Lock System, Lock Operation Conditions

      1. Lock operation is performed when the following conditions are met.


        1. IG OFF、ACC OFF

        2. Shift position in P

        3. Door closed → open



      1. Engine Switch Indicator Display Function

        1. If there is a system malfunction when the engine switch is turned ON/OFF or the electrical key is removed, the malfunction is indicated by the engine switch indicator light blinking.

          Indicator Display
          		Display Content
          		Display Condition
          		Display Time
          Green at 1-second cycle
          		Steering Lock Not Released
          		Unlock completion is not input even though unlock operation was performed
          		15 seconds
          Amber blinking at 2-second cycle
          		Smart start system malfunction
          		Malfunction occurred in the motor drive circuit in the steering lock actuator
          		15 seconds after power OFF



        1. About the Steering Lock ECU

          1. The steering lock ECU is not connected to the CAN communication system. It communicates with the body multiplex communication system via LIN communication with the certification ECU.

            ■ NOTICE ■
            If the certification ECU is replaced, the engine may not start unless the driver side door is opened and closed. (This makes the certification ECU store the current steering lock position)

          2. The steering lock ECU is built into the steering lock actuator on the steering column.
