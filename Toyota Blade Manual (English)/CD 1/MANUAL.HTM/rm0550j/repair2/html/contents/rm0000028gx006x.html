DTC C1696 G Sensor 0 Point Writing Not Performed

Preparation List


Function Description


This DTC is output when the television camera controller self-diagnosis determines that vehicle height sensor 0 point writing and G sensor 0 point writing have not been performed (height control sensor vehicle height difference setting and G sensor 0 point writing not performed).


DTC No.
Diagnosis Description
Inspection Area
C1695
Height Sensor 0-point Not Written
  1. Height Control Sensor Vehicle Height Difference Setting / G Sensor 0-point Writing
  2. Television Camera Controller
C1696
G Sensor 0-point Not Written
  1. Height Control Sensor Vehicle Height Difference Setting / G Sensor 0-point Writing
  2. Television Camera Controller
