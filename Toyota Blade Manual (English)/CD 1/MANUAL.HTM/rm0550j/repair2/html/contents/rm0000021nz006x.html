DTC C1628 Height Sensor Circuit

Print

Preparation List


Function Description


This DTC is output when the television camera controller self-diagnosis judges that the vehicle height sensor signal input from the height control sensor assembly (rear) is abnormal.


DTC No.
Diagnosis Description
Inspection Area
C1628
  1. Height Sensor Signal Malfunction
  2. Height Sensor Signal Stuck
  1. Wire harness and connector between television camera controller and height control sensor assembly (rear)
  2. Television Camera Controller
  3. Height Control Sensor Assembly (Rear)
