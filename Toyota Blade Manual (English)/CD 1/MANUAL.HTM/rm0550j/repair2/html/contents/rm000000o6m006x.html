Intelligent Parking Assist System Intelligent Parking Assist Screen is Black, Wrong Color or Distorted

Preparation List


Circuit Description


The video signal from the television camera assembly is input to the navigation receiver assembly via the television camera controller.


Wiring Diagram

  3. If registration/setting becomes necessary while proceeding with the inspection, perform the registration/setting work before proceeding to the next inspection step.
