Starter Assembly (2AZ-FE) Installation

Print

Preparation List



1. Install Starter Assembly



  1. Install the starter assembly with the 2 bolts.

    Standard
    T = 37 N/m{ 380 kgf/cm }




  2. Connect terminal B with the nut.

    Standard
    T = 9.8 N/m{ 100 kgf/cm }

  3. Install the terminal cap cover.

  4. Connect the connector to the starter assembly.



2. Install Battery Carrier NO.2



  1. Install battery carrier No.2 with the 2 bolts.

    Standard
    T = 19 N/m{ 194 kgf/cm }



3. Install Battery Carrier



  1. Install the battery carrier with the 4 bolts.

    Standard
    T = 19 N/m{ 194 kgf/cm }

  2. Install the wire harness with the 2 clamps.

  3. Install the battery tray.



4. Install Battery



  1. Install the battery to the vehicle.

  2. Install the insulator.

  3. Install the battery clamp with the bolt and nut. (*1)

    Standard
    T = 17 N·m{ 173 kgf·cm } (Bolt)

  4. Connect the battery positive terminal with the nut.

    Standard
    T = 5.4 N/m{ 55 kgf/cm }




  5. Connect the current sensor connector.



5. Install Radiator Upper Air Deflector

  1. Install the radiator upper air deflector with the 8 clips.



6. Connect Battery Negative Terminal
Standard
T = 5.4 N/m{ 55 kgf/cm }
