1. Basic Inspection (Check JEITA Standard Error Code)

  1. Check Toll Collection (ETC) Computer Assembly Startup

    1. Turn ACC ON.

    2. Check that the green indicator and amber indicator illuminate for 5 seconds.

    3. Check that the startup check ends normally and the indicators go off.

      □ HINT □
      If there is a malfunction in the toll collection (ETC) computer assembly, the amber indicator blinks, the multi-display voice gives the notification "Bong. A malfunction has occurred in the ETC. ETC cannot be used", and the JEITA standard error code is displayed on the multi-display. (see)

  2. ETC Card Insertion Check

    ■ NOTICE ■
    The multi-display does not give guidance until 20 seconds or more have elapsed after the ignition switch is turned to ACC.


    1. Insert the ETC card.

    2. The multi-display voice gives the notification "Beep", the green indicator of the toll collection (ETC) computer assembly starts blinking, and card authentication starts.

    3. Check that the multi-display voice gives the notification "Bong. The ETC card has been inserted" (*) and the green indicator of the toll collection (ETC) computer assembly illuminates.

      □ HINT □
      1. If there is a problem with the ETC card, the amber indicator of the toll collection (ETC) computer assembly blinks and a warning sound is emitted. The warning sound continues until the card is removed. Also, the multi-display voice gives the notification "Bong. Cannot read card. Please check the card", and the JEITA standard error code is displayed on the multi-display. (see)
      2. *: Depending on the expiration date of the inserted card, the multi-display voice gives the notification "Bong. The ETC card expires at the end of this month. Please check the card" or "Bong. The ETC card has expired".



2. ETC Registration Information

□ HINT □
The following information of the toll collection (ETC) computer assembly can be checked by displaying it on the navigation receiver assembly display.
  1. On-board unit management number
  2. On-board unit registration number
  3. Setup card issue date
  4. Setup card information expiration date
  5. Unified Error Code

  1. ETC Registration Information Screen Display

    1. Press the "Info G" switch to display the information screen.

    2. Press "ETC" on the information screen.

    3. Press "Display Registration Information" on the ETC menu screen.




  2. Check Screen Display Content

    □ HINT □
    The screen is an example display and may differ from the actual screen.


    1. Check the on-board unit management number.

      On-board Unit Management Number Display Content 
      Digits
      		Meaning
      XXXXX (5 digits)
      		SAM (encryption IC) manufacturer code
      XXXXXXXX (8 digits)
      		SAM production lot No.
      XXXXXX (6 digits)
      		SAM serial No.

      □ HINT □
      1. The on-board unit management number is displayed as "XXXXX - XXXXXXXX - XXXXXX" (X is a number from 0 to 9).
      2. Record this display content on the customer problem analysis sheet.

    2. Check the on-board unit registration number.

      On-board Unit Registration Number Display Content 
      Digits
      		Meaning
      XXX (3 digits)
      		On-board unit model
      XXXXXXXX (8 digits)
      		Serial No.

      □ HINT □
      The on-board unit registration number is displayed as "XXX - XXXXXXXX" (X is a number from 0 to 9).

    3. Check the setup card issue date.

      □ HINT □
      If the on-board unit has not been set up, " Year Month Day" is displayed.

    4. Check the setup card information expiration date.

      □ HINT □
      If the on-board unit has not been set up and the expiration date (*) of the setup card information has not been set, " Year Month Day" is displayed. (*: Not the expiration date of the ETC card)

    5. Check the standard error code.

      □ HINT □
      1. The most recently occurring JEITA standard error code is displayed.
      2. The toll collection (ETC) computer assembly stores the 1 most recently occurring JEITA standard error code, and this error code is displayed. Therefore, even if an error code is displayed, it does not necessarily indicate the current system condition.



3. Check Latest Stored JEITA Standard Error Code

  1. Check by Toll Collection (ETC) Computer Assembly Voice Guidance

    1. Remove the ETC card and turn the ignition switch to ACC.

    2. When the "History" switch is pressed for 2 seconds or more, the latest JEITA standard error code is announced.

      □ HINT □
      1. The most recently occurring JEITA standard error code is announced.
      2. The toll collection (ETC) computer assembly stores the 1 most recently occurring JEITA standard error code, and this error code is displayed. Therefore, even if an error code is displayed, it does not necessarily indicate the current system condition.



4. Clear Stored JEITA Standard Error Code

  1. Clearing Method

    1. Start ETC diagnosis mode 1. (see)

    2. Press the "History" switch and "VOL UP" switch simultaneously for 2 seconds or more to clear the JEITA standard error code.
