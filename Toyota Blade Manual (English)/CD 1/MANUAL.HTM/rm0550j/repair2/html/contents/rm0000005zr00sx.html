ABS with EBD & TRC & VSC & BA System Precaution

Print



    1. Precautions for Troubleshooting

    1. If the malfunction is caused by poor terminal contact or improper part installation, reconnecting the connector or removing and installing the relevant part may return the system to normal, either permanently or temporarily.

    2. To clearly identify the malfunctioning area, before disconnecting any connectors or removing and installing parts, check the operating conditions at the time of the malfunction, such as by checking DTC output and freeze frame data output, and keep a record. Also, if an open circuit malfunction code subject to the momentary interruption monitor is output, perform the momentary interruption monitor before disconnecting the connector. (see)

    3. The system may be affected by a malfunction in a system other than the brake control system, so also check for malfunction DTCs of other systems.



      2. Precautions for Handling and Operation

      1. Unless otherwise specified as an inspection method, always remove and install the actuator, sensors, etc. with the IG OFF.

      2. After removing and installing the actuator, sensors, etc., install all parts and then perform the test mode inspection and DTC output check to confirm that the system is normal.

      3. Do not remove or install VSC-related parts unless necessary, as removal and installation may result in incomplete adjustment.

      4. When performing VSC-related work, follow the instructions in the text and reliably perform pre-work preparation, confirmation of work completion, etc.



        3. Fail-safe Function

        1. If a malfunction occurs in part of the ABS, TRC, VSC or brake assist system, the respective warning lights come on or a warning is displayed on the multi-information display, and at the same time ABS, TRC, VSC, brake assist and hill-start assist control operation is prohibited.

          □ HINT □
          EBD control is performed as far as possible even when ABS control is prohibited; if control is not possible, the brake warning light comes on.



          4. Precautions for DTCs

          1. For some DTCs, the warning is not cleared just by repairing the malfunctioning part.

          2. To clear the warning (light on), it is necessary to clear the DTCs or perform the operation below.

            ■ NOTICE ■
            1. While the warning is output (light on), the system does not operate due to the fail-safe function, so drive and brake carefully.
            2. DTCs for malfunctions currently present are stored again.




            5. Precautions When Using a Drum Tester

            1. When using a drum tester, always switch to "Maintenance Mode" to prohibit TRC and VSC control. (see)

              ■ WARNING ■
              1. If a drum tester is used in normal mode, the vehicle may jump off the tester due to TRC and VSC operation.
              2. Even in maintenance mode, secure the vehicle with lock chains for safe operation.



              6.CAN Precautions for Communication

              1. CAN communication is used for data communication of the skid control computer (built into the actuator), steering sensor, yaw rate sensor (with built-in G sensor) and engine control computer; if there is a problem with the CAN communication lines, a communication line malfunction code is output.

              2. If a CAN communication malfunction code is output, repair the communication line malfunction, and then troubleshoot the VSC system with data communication in a normal condition.

              3. Each CAN communication line has a specified length and route, and cannot be temporarily fixed or repaired with bypass wiring, etc.
