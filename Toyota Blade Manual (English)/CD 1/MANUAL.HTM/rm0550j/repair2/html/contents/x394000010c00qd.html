  1. ETC System Diagnosis Function (Self-diagnosis)

    □ HINT □
    1. The ETC system has a diagnosis function that performs self-diagnosis.
    2. The ETC system diagnosis function has the following 3 types.



    1. JEITA Standard Error Codes





      1. To facilitate handling and processing when the toll collection (ETC) computer assembly malfunctions, for ETC users and expressway claim counters (toll gates, etc.), JEITA (Japan Electronics and Information Technology Industries Association) has established JEITA unified error codes that immediately indicate the malfunction. The toll collection (ETC) computer assembly supports this JEITA unified error code display.

        □ HINT □
        When a JEITA standard error code occurs, it is notified by an interrupt display on the multi-display.




      2. The toll collection (ETC) computer assembly stores the latest 1 detected JEITA unified error codes in non-volatile memory. These can be announced by voice, or called up and displayed from the HDD navigation system display menu. (see)




    2. Diagnosis Mode 1 (Error Log)


      1. Up to 20 previously input DTCs are stored as an error log, and these can be announced by voice from the toll collection (ETC) computer assembly. (see)




    3. Diagnosis Mode 2 (Communication Log)


      1. Up to 25 results of communication with the roadside antenna when an ETC vehicle passes through an ETC gate are stored as a communication log, and these can be announced by voice from the toll collection (ETC) computer assembly. (see)



    1. Communication System


      1. AVC-LAN




        1. The ETC system communicates with the navigation receiver assembly via AVC-LAN, allowing the usage history list to be displayed and ETC settings to be changed on the display screen.

        2. The master device of the AVC-LAN is the navigation receiver assembly.

        3. The navigation receiver assembly contains a resistor necessary for communication transmission (60 to 80 Ω between terminals TX+ - TX-).

        4. Each ETC system display on the HDD navigation system display is drawn by the navigation receiver assembly according to commands from the toll collection (ETC) computer assembly.

        5. If an open or short occurs in the AVC-LAN circuit, communication is interrupted and the system does not operate normally. (The toll collection (ETC) computer assembly can operate on its own)




      1. HDD Navigation System Diagnosis Function (AVC-LAN)

        1. The HDD navigation system has a diagnosis function that can check the connection of and diagnose devices connected via AVC-LAN. (Displayed on the HDD navigation system display)

        2. Each device constituting the AVC-LAN is assigned a 3-digit number (in base 16) called a device code (physical address).

        3. Each function (unit) within each device constituting the AVC-LAN is assigned a 2-digit number (in base 16) called a logical address.
