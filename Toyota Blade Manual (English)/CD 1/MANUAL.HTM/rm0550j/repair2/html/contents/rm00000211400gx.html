DTC P1603 Engine Stall Detected

Print

Preparation List


Circuit Description


  1. The DTC is output when the engine stops after the engine has started. Since the conditions when the DTC was output are stored, the freeze frame data can be checked using SST (TaSCAN). Serviceability is improved by making it possible to check the engine operating condition at the time of the engine stall using the freeze frame data. Also, since an engine stall caused by running out of fuel is also detected, it is necessary to check whether the vehicle has run out of fuel before starting work. (An engine stall may be detected due to cranking while the engine is running, even if the engine does not stop)
