  1. Intelligent Parking Assist Diagnosis System

    1. The intelligent parking assist diagnosis system allows registration, setting, adjustment and checking of the intelligent parking assist system to be performed on the multi-display screen of the navigation receiver assembly.

      ■ NOTICE ■
      Depending on the parts replaced or the work performed during vehicle inspection and maintenance, registration and setting operations for other systems as well as the intelligent parking assist system may be necessary. (see)

      □ HINT □
      Registration, setting, adjustment and checking of the intelligent parking assist system are performed from the Diagnosis System - Signal Connection Check screen.




    1. Diagnosis Screen Transitions




      1. Service Inspection (AVC-LAN Connection Check and AVC-LAN DTC Check)

        1. Start Diagnosis

          □ HINT □
          1. For the diagnosis startup procedure, seeReference




        2. Service Inspection

          □ HINT □
          1. For details of the service inspection procedure, seeReference
          2. Inspect the connection condition of each ECU and the DTC output.

        3. Diagnosis Cancellation

          □ HINT □
          1. For the diagnosis cancellation procedure, seeReference



        1. Signal Connection Check

          1. Start Diagnosis




          2. Select "Inspection Menu" on the service inspection screen to display the diagnosis inspection menu screen.

          3. Select "Camera Inspection" on the diagnosis inspection menu screen to display the signal connection check screen.




          4. Signal Connection Check


            1. On the signal connection check screen, the input condition of the CAN signal and height control sensor signal input to the television camera controller, and the status of the height control sensor vehicle height difference setting can be checked.

              □ HINT □
              1. For each signal, if the signal has been input even 1 time, "Input OK" is displayed.
              2. If a signal has not been input, "Checking" is displayed and the button is shown in red.
              3. If all signals are "Input OK" (displayed in blue), touch "Next" to proceed to the next screen.
              4. If there is a signal showing "Checking" (displayed in red), it is not possible to proceed to the next screen unless "Checking" is touched (changes from red to orange) and then "Next" is touched.
              5. If even one button is displayed in red, it is not possible to proceed to the next screen.

          5. CAN Inspection


            1. Check that the "CAN" display is "OK" (displayed in blue), and press the display.

            2. Check that the display changes from "OK" (displayed in blue) → "Checking" (displayed in red), and returns to "OK" (displayed in blue).

              □ HINT □
              If the "CAN" inspection result is abnormal, check the DTCs and take action according to the output code. (see)

          6. HT SENS Inspection


            1. Check that the "HT SENS" display is "OK" (displayed in blue), and press the display.

            2. Check that the display changes from "OK" (displayed in blue) → "Checking" (displayed in red), and returns to "OK" (displayed in blue).

              □ HINT □
              If the "HT SENS" inspection result is abnormal, check the DTCs and take action according to the output code. (see)

          7. HT INIT Check


            1. Check that the "HT INIT" display is "OK" (displayed in blue).

              □ HINT □
              1. If the height control sensor vehicle height difference setting and G sensor 0-point writing have not been performed, the "HT INIT" display shows "Checking" (displayed in red).
              2. If the "HT INIT" display shows "Checking" (displayed in red), perform the height control sensor vehicle height difference setting and G sensor 0-point writing.
              3. The height control sensor vehicle height difference setting and G sensor 0-point writing must be performed before performing camera optical axis adjustment.

          8. Drive Type Determination Signal


            1. Check that "2WD" (displayed in blue) or "4WD" (displayed in blue) is displayed at *1, and check that it matches the drive type of the vehicle.

              □ HINT □
              1. "2WD" display indicates FF vehicle setting
              2. "4WD" display indicates 4WD vehicle setting
              3. If "WD CHK" (displayed in red) is displayed, check the DTCs and take action according to the output code. (see)

          9. Diagnosis Cancellation



          1. Height Control Sensor Vehicle Height Difference Setting / G Sensor 0-point Writing



            1. Preparation Before Adjustment

              ■ NOTICE ■
              1. Perform the height control sensor vehicle height difference setting and G sensor 0-point writing on a level surface.
              2. The height control sensor vehicle height difference setting and G sensor 0-point writing must be performed before performing camera optical axis adjustment.


              1. At the measurement position shown in the illustration, measure height A from the floor to the lower edge of the wheel arch.

              2. Calculate the difference between the measured value and the standard height below.

                Standard
                703mm

                □ HINT □
                If the measured value is 713 mm, 713 - 703 = + 10 mm is the difference from the standard height.

            2. Start Diagnosis

              ■ NOTICE ■
              The adjustment must be performed with the engine running. Therefore, apply the parking brake, depress the brake pedal, move the shift lever to P, and take sufficient care that the vehicle does not move off.

            3. Select "Inspection Menu" on the service inspection screen to display the diagnosis inspection menu screen.

            4. Select "Camera Inspection" on the diagnosis inspection menu screen to display the signal connection check screen.

            5. On the signal connection check screen, select "HT INIT" to display the HEIGHT SET screen.




            6. Height Control Sensor Vehicle Height Difference Setting / G Sensor 0-point Writing

              ■ NOTICE ■
              1. Perform the height control sensor vehicle height difference setting and G sensor 0-point writing on a level surface.
              2. The height control sensor vehicle height difference setting and G sensor 0-point writing must be performed before performing camera optical axis adjustment.


              1. Press "UP" or "DOWN" to set the difference from the standard height.

                □ HINT □
                1. A value displayed in green indicates a positive value, and a value displayed in red indicates a negative value.
                2. If "10 MM" is displayed in green, it indicates + 10 mm.

              2. Selecting "Complete" switches to the signal connection screen and stores the height control sensor vehicle height difference setting value and the G sensor 0-point.

                □ HINT □
                1. The memory is not updated unless "Complete" is selected.
                2. Selecting "Back" switches to the camera signal connection screen without storing the height control sensor vehicle height difference setting value and the G sensor 0-point.
                3. Press the "Complete" switch with the vehicle in the same condition as when the vehicle height difference was measured.
                4. If the vehicle height difference was measured with 1 person in the driver seat, press the "Complete" switch with 1 person in the driver seat.
                5. Check that the "HT INIT" display on the signal connection check screen is "OK" (displayed in blue).

            7. Diagnosis Cancellation



            1. Camera Optical Axis Adjustment / Check


              1. Preparation Before Adjustment

                □ HINT □
                1. Before performing camera optical axis adjustment, the height control sensor vehicle height setting and G sensor 0-point writing must be performed on the HEIGHT SET screen.
                2. Install adjustment target bars A and B only when performing camera optical axis adjustment.
                3. If the only adjustment required after vehicle servicing is the bumper reference line display position adjustment, the preparation before adjustment is not necessary.




                1. Stop the vehicle with the steering wheel straight.

                2. Place the adjustment target bars in the positions shown in the illustration.

                  □ HINT □
                  1. Adjust the tire pressure to the specified pressure beforehand.
                  2. Adjustment target bars A and B are made by applying tape of the size shown in the illustration to the floor; check the color on the vehicle display and choose a conspicuous color.
                  3. Before stopping the vehicle, always move the vehicle slightly forward and backward, and check that not only the steering wheel but also the tires are in the straight-ahead position.

              2. Start Diagnosis

                ■ NOTICE ■
                The adjustment must be performed with the engine running. Therefore, apply the parking brake, depress the brake pedal, move the shift lever to P, and take sufficient care that the vehicle does not move off.

              3. Select "Inspection Menu" on the service inspection screen to display the diagnosis inspection menu screen.

              4. Select "Camera Inspection" on the diagnosis inspection menu screen to display the signal connection check screen.

              5. Select "Next" on the signal connection check screen to display the camera optical axis adjustment (rotation adjustment mode) screen.




              6. Camera Optical Axis Adjustment (Rotation Adjustment Mode)

                ■ NOTICE ■
                Before performing camera optical axis adjustment, the height control sensor vehicle height difference setting and G sensor 0-point writing must be performed on the HEIGHT SET screen.


                1. Press switch A or B to rotate C so that it is parallel to adjustment target bar A.

                2. Select "Next" to display the camera optical axis adjustment (left/right/up/down position adjustment mode) screen.




              7. Camera Optical Axis Adjustment (Left/Right/Up/Down Position Adjustment Mode)




                1. Press the left/right/up/down switches to move A left, right, up and down, and align A with C (corner) of adjustment target bar B.



                  ■ NOTICE ■
                  If A and adjustment target bar B do not align completely, align only C (corner).

                2. Select "Next" to display the BUMPER screen.




              8. Bumper Reference Line Display Position Adjustment


                1. Press the left/right/up/down switches and switch A or B to move the bumper reference line left, right, up, down and rotate it so that the bumper reference line overlaps or touches the bumper edge line.

                2. Select "Next" to display the confirmation screen.



              9. Confirmation Screen





                1. If rotation adjustment, left/right/up/down position adjustment and bumper reference line display position adjustment have been performed, check that A (indicating 1.00m beyond the bumper edge) and adjustment target bar A almost overlap, and that the bumper reference line almost overlaps the bumper edge line. Also, check that the expected course lines are straight (overlapping the vehicle width extension lines) when the steering is in the straight-ahead position.

                2. Selecting "Next" switches to the steering angle adjustment screen and stores the camera optical axis adjustment value.

                  □ HINT □
                  1. The memory is not updated unless "Next" is selected.
                  2. When "Next" is selected, a confirmation beep is output from the driver side speaker and the camera optical axis adjustment value is stored.




              10. Steering Angle Adjustment


                1. Check that the steering wheel is in the position for driving the vehicle straight ahead (approximately straight, ± 5 degrees or less as a guide), and press "Steering Angle Neutral Point Memory".

                2. After memorizing the steering angle neutral point, turn the steering wheel to the left until it stops, then to the right until it stops, and press "Maximum Steering Angle Memory". The LH/RH maximum steering angles are stored at the moment the button is pressed. (Right may be done first)

                3. Selecting "Complete" switches to the diagnosis inspection menu screen and stores the steering angle adjustment value.

                  □ HINT □
                  1. When "Complete" is selected, a confirmation beep is output from the driver side speaker and the steering angle adjustment value is stored.
                  2. If steering angle adjustment has not been performed, touching "Complete" is not accepted until the steering angle neutral point and maximum steering angle have been stored.
                  3. The memory is not updated unless "Complete" is selected.
                  4. Selecting "Back" switches to the camera optical axis adjustment confirmation screen without storing the setting values.

              11. Diagnosis Cancellation

              12. Steering Angle Adjustment Check

                □ HINT □
                If steering angle adjustment has been performed, perform the steering angle adjustment check on the intelligent parking assist screen after diagnosis cancellation.


                1. On the intelligent parking assist screen, check that the expected course lines move in conjunction with the steering wheel until it is turned fully to the left and right.

                  □ HINT □
                  If the expected course lines stop moving before the steering wheel is turned fully to the left and right, the steering angle adjustment value has not been stored correctly and readjustment is necessary.



              1. Parallel Parking Mode Parking Position Left/Right Adjustment

                1. Start Diagnosis

                  ■ NOTICE ■
                  The adjustment must be performed with the engine running. Therefore, apply the parking brake, depress the brake pedal, move the shift lever to P, and take sufficient care that the vehicle does not move off.

                2. Select "Inspection Menu" on the service inspection screen to display the diagnosis inspection menu screen.

                3. Select "Camera Inspection" on the diagnosis inspection menu screen to display the signal connection check screen.

                4. Select "PARALLEL OFFSET" on the signal connection check screen to display the PARALLEL PARKING screen.




                5. Parking Position Adjustment for Parallel Parking

                  □ HINT □
                  On the PARALLEL PARKING screen, if the actual parking position deviates to the right or left of the set target parking position in parallel parking assist mode, that position can be offset.




                  1. Press "UP" or "DOWN" to adjust the parallel parking position lateral offset value.



                    □ HINT □
                    1. A value displayed in green indicates a + value, and a value displayed in red indicates a - value.
                    2. Offset + direction is toward the road shoulder, - direction is toward the road surface
                    3. If "10 CM" is displayed in red, it indicates - 10 cm toward the road surface.
                    4. Settable range: + 20 cm ←→ - 40 cm (setting value in 1 cm increments)

                  2. Selecting "Complete" switches to the signal connection screen and stores the setting value.

                    1. The memory is not updated unless "Complete" is selected.
                    2. Selecting "Back" switches to the signal connection screen without storing the setting value.
