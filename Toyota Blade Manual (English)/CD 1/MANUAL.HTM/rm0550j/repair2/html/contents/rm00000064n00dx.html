DTC U0235/71 Radar Sensor Communication Malfunction

Print

Preparation List


Circuit Description


The distance control computer assembly sends vehicle speed, steering angle and steering direction information to the millimeter wave radar sensor assembly. The radar sensor sends information such as the presence of a preceding vehicle, vehicle-to-vehicle distance and relative speed to the distance control computer assembly. The distance control computer assembly sends this information to the engine control computer to perform cruise control.

  2. Communication data from the millimeter wave radar sensor assembly to the distance control computer assembly is abnormal

  2. Wire harness and connector (millimeter wave radar sensor assembly - distance control computer assembly)
  3. Distance Control Computer Assembly
