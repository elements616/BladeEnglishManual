Power Outlet Socket Assembly Installation

Print


1. Install Power Outlet Socket Cover



  1. Align the guide of a new power outlet socket cover with the cutout of box panel No.2.

  2. Engage the 2 claws and install the power outlet socket cover.



2. Install Power Point Socket Assembly



  1. Align the guide of the power point socket assembly with the cutout of the power outlet socket cover.

  2. Engage the 2 claws and install the power point socket assembly.



3. Install Box Panel NO.2

  1. Connect the connectors.




  2. Engage the 2 claws and 4 clips to install box panel No.2.
