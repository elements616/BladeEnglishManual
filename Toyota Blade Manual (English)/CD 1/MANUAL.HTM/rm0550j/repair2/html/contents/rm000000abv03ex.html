How to Troubleshoot ECU Controlled Systems Description of Basic Diagnosis Procedure

Print


□ HINT □
Perform troubleshooting in accordance with the diagnostic procedure below. Only the basic procedure is shown here. For details, the most effective method for each circuit is described in the section for each system. Before starting troubleshooting of the relevant circuit, check the troubleshooting procedure first.




Step 1Malfunctioning Vehicle Brought to Workshop


    NEXT


    Step 2 Customer Problem Analysis and Malfunction Analysis

    1. Confirm with the customer the conditions and circumstances when the problem occurred, and fill out the customer problem analysis check sheet.


    NEXT


    Step 3Confirm Problem Symptom and Check DTCs (Including Freeze Frame Data)

    1. Using SST (Toyota electrical tester), inspect the battery voltage.

      2. SST
      09082-00030  

      Standard
      11 to14V (Engine Stopped)

    2. Inspect areas that can be checked visually, such as blown fuses, open or short circuits in the wire harness and poor connector connections.

    3. Confirm the problem location, symptom and conditions, and check the DTCs according to the relevant chart.

      DTC present
      To each Diagnostic Trouble Code Chart

      No DTC
      Go to List by Symptom


    NEXT


    Step 4Understand Vehicle Condition

    1. Some systems lose their memory when the battery negative terminal is disconnected, and some systems return to the initial state when parts are replaced, so record the vehicle's settings before repair.

      □ HINT □
      1. Settings after battery terminal removal / installation ()
      2. Settings after part removal / installation ()
      3. Customization ()


    NEXT


    Step 5Circuit Inspection or Parts Inspection

    1. Using the Diagnostic Trouble Code Chart or the Problem Symptoms Table, determine which system circuit or part should be inspected.


    NEXT


    Step 6Repair Malfunctioning Area

    1. Following the instructions in step 5, repair the malfunctioning system or part.


    NEXT


    Step 7Confirmation Test

    1. After repairs are completed, check that the problem has been eliminated. (If the problem recurs, perform a confirmation test under the same environment and conditions as when the problem first occurred.)

    2. If the problem was one for which a DTC was stored, perform the diagnosis judgment result check.


    NEXT


    Step 8Restore Vehicle

    1. Restore each setting to the vehicle condition confirmed in step 4.

      □ HINT □
      If there are any items whose settings cannot be restored, be sure to explain to the customer.
