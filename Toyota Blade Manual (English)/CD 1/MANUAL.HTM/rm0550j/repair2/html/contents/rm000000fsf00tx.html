CVT System [Super CVT-i] (K112/K112F) Function Description

Print



  1. Diagnosis Function

    1. When a malfunction occurs in the CVT system, the check engine warning light is illuminated.

      ■ NOTICE ■
      When the malfunctioning item returns to normal, the check engine warning light goes off.

    2. The diagnosis result when a malfunction occurs is stored in the engine control computer.

      ■ NOTICE ■
      The data stored in the computer will be cleared, so do not remove the EFI fuse (20A), ETC-S fuse (10A) or battery terminal until the inspection is finished.



    1. Fail-safe Function

      1. If one of the solenoid valve circuits has an open or short circuit, the engine control computer turns the other solenoid valves ON or OFF. Also, if all the solenoid valves malfunction, only the mechanical hydraulic circuit operates.

        □ HINT □
        In the case of an open or short circuit, the engine control computer stops energizing the malfunctioning solenoid valve.



      1. Sequential Shiftmatic Function

        1. Only when the shift position is in the M position, each gear (1 ←→ 2 ←→ 3 ←→ 4 ←→ 5 ←→ 6 ←→ 7) can be selected by shifting to (+) or (-) in the sequential gate.

          □ HINT □
          1. When the sequential shiftmatic system is operating, the sport sequential shiftmatic indicator light (M) in the combination meter is illuminated, and the gear selected by the shift lever is illuminated on the shift position indicator.
          2. While the system is operating, the system is canceled by moving the shift lever to a position other than M.
          3. When the sequential shiftmatic system is operating, it automatically switches to gear 1 when the vehicle stops.
          4. The transmission automatically upshifts 1 gear so that the engine speed does not become too high.
          5. The transmission automatically downshifts 1 gear so that the engine speed does not become too low.

        2. If a system malfunction occurs while the shift lever is in the M position, the sport sequential shiftmatic indicator light (M) and shift position indicator go off, and D position control is used.

          □ HINT □
          When the malfunction returns to normal, the indicators and control are restored.
