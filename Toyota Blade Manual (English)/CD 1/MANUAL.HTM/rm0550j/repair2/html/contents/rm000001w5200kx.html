DTC B2789 No Response from ID Code Box

Print

Preparation List


Circuit Description


The smart key computer assembly (certification ECU) outputs this code when information from the immobiliser code computer (ID code box) cannot be received for 10 seconds. Past DTCs are also stored.

■ NOTICE ■
When replacing the smart key computer assembly (certification ECU) or immobiliser code computer (ID code box), check the registration procedure in the reference section before proceeding.
