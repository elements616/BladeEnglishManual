Smart Entry & Start System (Start System) DTC Check / Clear

Print


■ NOTICE ■
When using the TaSCAN with the IG OFF, repeatedly turn any door courtesy light switch ON and OFF (at intervals of 1.5 seconds or less) until communication between the TaSCAN and the vehicle starts.



  1. DTC Check (Reading Using TaSCAN)

    1. With the IG OFF, connect SST (TaSCAN) to DLC3.

      SST
      09991-70200  

    2. Following the SST (TaSCAN) screen display, display the "System Diagnosis Menu/Main Body" screen and select "DTC".

    3. Check the diagnostic trouble codes.

      □ HINT □
      DTCs are output even with the ignition switch OFF.



    1. Clearing DTC Memory (Clearing Using TaSCAN)

      1. With the IG OFF, connect SST (TaSCAN) to DLC3.

        SST
        09991-70200  

      2. Following the SST (TaSCAN) screen display, display the "System Diagnosis Menu/Main Body" screen and select "DTC".

      3. Select "Clear" on the screen to clear the data.

      4. Check the DTCs again, and confirm that the malfunction codes have been cleared and the normal code is displayed.

        ■ NOTICE ■
        If a malfunction code is output, repair again according to the code.
