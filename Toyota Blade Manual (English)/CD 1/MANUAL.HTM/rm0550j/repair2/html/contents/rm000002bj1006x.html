Function Description


Hydraulic pressure switches No.1, No.2 and No.3 are built into the transmission wire together with the fluid temperature sensor, and detect the fluid pressure in the valve body.

When a hydraulic pressure malfunction is input due to a solenoid malfunction, the transmission control computer performs fail-safe control. If the fail-safe function is operating normally, the hydraulic pressure switch is normal.
