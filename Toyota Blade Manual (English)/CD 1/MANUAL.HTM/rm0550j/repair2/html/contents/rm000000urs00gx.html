Electric Power Steering System Precautions

Print



    1. Precautions for Handling and Servicing

    1. Handling Electronic Parts


      1. Do not subject electronic parts such as computers to impacts. If it has been subjected to a severe impact (such as being struck or dropped on the floor), replace it with a new part.

      2. Do not expose electronic parts to high temperature or humidity.

      3. Do not touch the connector terminals, as deformation and static electricity may cause malfunctions.

    2. Handling the Power Steering Computer Assembly


      1. When replacing the power steering computer assembly, always install a new one.

        ■ NOTICE ■
        Do not use a power steering computer assembly from another vehicle (display vehicle, etc.).

      2. When the power steering computer assembly has been replaced with a new one, perform torque sensor 0 point calibration and rotation angle sensor output calibration. (see)

    3. Handling the Steering Column Assembly


      1. Do not subject the steering column assembly (especially the motor and torque sensor) to impacts. If it has been subjected to a severe impact (such as being struck or dropped on the floor), replace it with a new part.

      2. When carrying the steering column assembly, do not pull on the wire harness.

      3. When the steering column assembly has been replaced, clear the sensor calibration values, and then perform torque sensor 0 point calibration and rotation angle sensor output calibration. (see)



      2.CAN Precautions for Communication

      1. CAN communication is used for sending and receiving information from each ECU, sending warnings to the meter and communicating with the TC and TS terminals of DLC3. If there is a problem in the CAN communication lines, a communication line malfunction code is output.

      2. If a CAN communication malfunction code is output, repair the communication line malfunction, and then troubleshoot the electric power steering system with data communication operating normally.
