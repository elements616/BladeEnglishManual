  1. This DTC is displayed on the service inspection screen.

  1. AVN

    □ HINT □
    1. Logical address 01: Communication control
    2. Logical Address 34: Front Seat Monitor
    3. Logical Address 40:TV Tuner
    4. Logical Address 57: Telephone Drawing
    5. Logical Address 58: Navigation
    6. Logical Address 60: Radio Unit
    7. Logical Address 62:CD-P
    8. Logical Address 64:MD-P

    01-D5
    		Registered component lost
    1. The component indicated by the sub-code is disconnected from the system when ACC is ON
    2. The component indicated by the sub-code has been disconnected from the system when ACC was ON
    3. Communication with the component indicated by the sub-code cannot be established when the engine is started
    		Inspect the power supply system and AVC-LAN communication system W/H of the component indicated by the sub-code
    		This code may be stored even when no malfunction is found, depending on the battery condition or the power source waveform at engine start
    01-D6
    		Master Absent
    1. The component that stored this code has been disconnected from the system when ACC was ON
    2. The master device was disconnected when this code was stored
    		Inspect the power supply system and AVC-LAN communication system W/H of the navigation receiver assembly
    		This code may be stored even if no malfunction is found, depending on the battery condition or the power supply waveform when the engine is started.
    01-D7
    		Connection Check Malfunction
    1. The component that stored this code has been disconnected from the system after the engine was started
    2. The master device was disconnected when this code was stored
    		Inspect the power supply system and AVC-LAN communication system W/H of the navigation receiver assembly
    		This code is stored when the navigation receiver assembly power turns OFF after the engine is started and 210 seconds elapse.
    01-D8
    		No response to connection check
    1. The component indicated by the sub-code is disconnected from the system after the engine is started
    2. The component indicated by the sub-code has been disconnected from the system after the engine was started
    		Inspect the power supply system and AVC-LAN communication system W/H of the component indicated by the sub-code
    		This code is stored when the power of the component indicated by the sub-code turns OFF after the engine is started and 180 seconds elapse
    01-D9
    		Last mode error
    1. The component that was operating (outputting sound or images) before the engine was stopped is disconnected from the system when ACC is ON
    2. The component that was operating (outputting sound or images) before the engine was stopped has been disconnected from the system when ACC was ON
    		Inspect the power supply system and AVC-LAN communication system W/H of the component indicated by the sub-code
    		This code may be stored even when no malfunction is found, depending on the battery condition or the power source waveform at engine start
    01-DA
    		No response to ON/OFF command
    		The component indicated by the sub-code did not respond during sound/image mode switching (detected when the screen or sound does not switch with button operation, etc.)
    1. Inspect the power supply system and AVC-LAN communication system W/H of the component indicated by the sub-code
    2. If the malfunction recurs, replace the component indicated by the sub-code
    		-
    01-DB
    		Mode status error
    		2-fold sounding detected
    		Inspect the power supply system and AVC-LAN communication system W/H of the component indicated by the sub-code
    		This code may be stored even when no malfunction is found, depending on the battery condition or the power source waveform at engine start
    01-DC
    		Transmission Failure
    		Transmission to the component indicated by the sub-code has failed (this code may not be directly related to a malfunction)
    1. If the component indicated by the sub-code is also stored in other components, inspect the power supply system and AVC-LAN communication system W/H of the component indicated by the sub-code
    2. If this code is not recorded in other components, clear the DTC and monitor for a while
    		This code may be stored if the engine is started again 60 seconds after the engine was started
    01-DD
    		Master Reset (Momentary Interruption)
    		The master device was disconnected from the system after the engine was started
    1. Inspect the power supply system and AVC-LAN communication system W/H of the navigation receiver assembly
    2. If the malfunction occurs frequently, replace the navigation receiver assembly
    		This code may be stored if the engine is restarted after it was started.
    01-DE
    		Slave reset (momentary interruption)
    		A slave component has been disconnected from the system after the engine was started
    		Inspect the power supply system and AVC-LAN communication system W/H of the component indicated by the sub-code
    		This code may be stored if the engine is started again after the engine was started
    01-E0
    		Registration Complete Notification Malfunction
    		The "Registration Complete Notification" command cannot be received from the master device
    		This code is an engineering diagnosis and is detected even when not directly related to a malfunction
    		This code may be stored even when no malfunction is found, depending on the battery condition or the power source waveform at engine start
    01-E1
    		Audio processing component ON error
    		The amplifier component detected that the amplifier output stopped even though the source component was operating
    		Inspect the power supply system and AVC-LAN communication system W/H of the navigation receiver assembly
    		This code may be stored even when no malfunction is found, depending on the battery condition or the power source waveform at engine start
