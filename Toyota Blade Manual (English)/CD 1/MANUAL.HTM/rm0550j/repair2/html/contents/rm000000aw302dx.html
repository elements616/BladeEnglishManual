  1. TaSCAN ECU Data Monitor

    ■ NOTICE ■
    For subtle symptoms such as hesitation and rough idle, it is necessary to use a method of collecting data from a vehicle of the same model under the same conditions for comparison, and make an overall judgment from all items of the computer data.

    1. TaSCAN Active Test

      1. Using SST (TaSCAN), display the [Active Test] screen according to the screen display, and perform the Active Test.

        SST
        09991-70201   

        [Selection menu screen: Powertrain → ECT → Active Test] 
        Item Name
        		Test Details
        		Restrictions
        TC Terminal ON
        *1
        		Used when changing to fluid temperature detection mode
        		-
        ECT Shift Position
        		Can be set to any shift position
        		Test possible after warm-up at vehicle speed of 50 km/h or less
        Shift Linear SOL1
        		Solenoid SL1 MIN current ←→ MAX current possible
        		Possible in P or N position, with engine stopped and at vehicle speed of 0 km/h
        Shift Linear SOL2
        		Solenoid SL2 MIN current ←→ MAX current possible
        		Possible in P or N position, with engine stopped and at vehicle speed of 0 km/h
        Shift Linear SOL3
        		Solenoid SL3 MIN current ←→ MAX current possible
        		Possible in P or N position, with engine stopped and at vehicle speed of 0 km/h
        Shift Linear SOL4
        		Solenoid SL4 MIN current ←→ MAX current possible
        		Possible in P or N position, with engine stopped and at vehicle speed of 0 km/h
        Lock-up SOL
        		Lock-up ON ←→ OFF possible
        		Possible at vehicle speed of 60 km/h or more
        Lock-up Control SOL (SL)
        		Transmission 3-way solenoid (SL) MIN current ←→ MAX current possible
        		Possible in P or N position, with engine stopped and at vehicle speed of 0 km/h
        Slip Control SOL
        		Solenoid SLU MIN current ←→ MAX current possible
        		Possible in P or N position, with engine stopped and at vehicle speed of 0 km/h
        Line Pressure SOL
        		Solenoid SLT MIN current ←→ MAX current possible
        (MAX current → duty ratio 100% (line pressure at idle))
        (MIN current → duty ratio 0% (line pressure at stall))
        		Possible in P or N position, with throttle fully closed and at vehicle speed of 0 km/h

        ■ NOTICE ■
        *1... Warning diagnosis is not displayed all at once

        □ HINT □
        Perform the Active Test of the line pressure SOL using an oil pressure gauge.
