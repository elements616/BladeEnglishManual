Fusible Link Block Assembly (Engine Type 2AZ-FE) Installation

Print

Preparation List



1. Install Fusible Link Block Assembly



  1. Connect the 3 wire harnesses to the fusible link block assembly with the 3 bolts (M5).

  2. Connect the 2 connectors to the fusible link block assembly.




  3. Connect the 2 wire harnesses to the fusible link block assembly with the 2 bolts (M6).

    Standard
    T = 5.4 N/m{ 55 kgf/cm }




  4. Engage the claw and install the fuse holder to the fusible link block assembly.

  5. Install the bolt (M6).

    Standard
    T = 5.4 N/m{ 55 kgf/cm }




  6. Engage the 4 claws and install the fuse holder and fusible link block assembly.




  7. Engage the 10 claws and assemble the upper side and lower side of the fuse block cover.

    ■ NOTICE ■
    Assemble securely so that the wire harness is not pinched.



2. Install Engine Room Relay Block



  1. Engage the guide and claw of the relay block.

  2. Install the 3 bolts.

    Standard
    T = 8.4 N/m{ 86 kgf/cm }

  3. Clamp the harness.



3. Install Front Fender Liner LH



  1. Install the front fender liner LH with the pin hold clip and 4 clips.



4. Install Engine Control Computer



  1. Install the engine control computer bracket with the 4 screws.




  2. Connect the clamp and install the engine control computer with the 2 bolts.

    Standard
    T = 8.0 N/m{ 82 kgf/cm }




  3. Connect the 2 engine control computer connectors to the engine control computer.

    ■ NOTICE ■
    1. When installing the connector, be careful not to allow foreign matter such as mud or water to adhere to the connector connection.
    2. Securely lock the lever.



5. Install Air Cleaner Case



  1. Install the air cleaner case with the 3 bolts and clamp.

    Standard
    T = 7.0 N/m{ 71 kgf/cm }

  2. Install the air cleaner filter element.



6. Install Air Cleaner Cap w/ Air Cleaner Hose

  1. Install the hinge portion first, then install the air cleaner cap with the 3 clamps.




  2. Install air cleaner hose No.1 to the throttle body assembly and release the lock of air cleaner hose clamp No.1.

    ■ NOTICE ■
    1. Align the triangular projection of air cleaner hose No.1 with the throttle body bolt on the right front side of the vehicle.
    2. Align the position of air cleaner hose clamp No.1 using the triangular projection of air cleaner hose No.1 as a reference.




  3. Connect the clamp and intake air flow meter connector.




  4. Connect the fuel vapor feed hose and fuel vapor feed hose No.2 to vacuum switching valve assembly No.1.

  5. Connect the clamp and vacuum switching valve connector.

  6. Connect the ventilation hose.



7. Install Engine Cover Sub-assembly NO.1



  1. Install the engine cover assembly No.1 with the 2 nuts.

    Standard
    T = 9.0 N/m{ 92 kgf/cm }



8. Connect Wire Harness



  1. Connect the wire harness with the 2 nuts, 2 connectors and 2 clamps.

    Standard
    T = 8.4 N/m{ 86 kgf/cm }



9. Install Relay Block Cover UPR NO.1


10. Connect Battery Negative Terminal
Standard
T = 5.4 N/m{ 55 kgf/cm }
