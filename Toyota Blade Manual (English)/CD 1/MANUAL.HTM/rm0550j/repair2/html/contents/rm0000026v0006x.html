Outer Rear View Mirror Assembly RH Installation

Print

Preparation List



1. Install Outer Mirror Cover RH



  1. Fit the outer mirror cover RH over the outer rear view mirror assembly from the direction of claws A and B.

    ■ NOTICE ■
    Check that the outer circumference of the outer mirror cover RH is securely fitted into the outer rear view mirror assembly RH.

  2. Engage the 7 claws and install the outer mirror cover RH.

    ■ NOTICE ■
    Make sure the claws are securely engaged.



2. Install Outer Mirror RH (w/o Cold Area Specification)



  1. Insert the 2 guides.




  2. Engage the 2 claws and install the outer mirror RH.



3. Install Outer Mirror RH (w/ Cold Area Specification)



  1. Connect the connectors.




  2. Insert the 2 guides.




  3. Engage the 2 claws and install the outer mirror RH.



4. Install Outer Rear View Mirror Assembly w/ Cover



  1. Install the outer rear view mirror assembly w/ cover with the 3 bolts.

    Standard
    T = 5.5 N/m{ 56 kgf/cm }

  2. Connect the connector.



5. Install Outer Mirror Install Hole Cover RH



  1. Insert the guide.

  2. Engage the 3 claws and install the outer mirror install hole cover RH.



6. Install Front Door Service Hole Cover RH

  1. Apply butyl tape to the door panel side.

  2. Pass the front door lock remote control cable RH, rear door inside locking cable RH and each connector through a new front door service hole cover RH.




  3. Align a new front door service hole cover RH with the reference position on the front door panel and attach it.

    ■ NOTICE ■
    Attach the front door service hole cover RH so that there are no wrinkles or lifting, and press it down firmly.

  4. Connect the connector.



7. Install Power Window Regulator Master Switch Assembly w/ Front Armrest Base Panel UPR RH



  1. Engage the 7 claws to install the power window regulator master switch assembly w/ front armrest base panel UPR RH to the front door trim board RH.



8. Install Front Door Inside Handle Sub-assembly RH



  1. Install the front door lock remote control cable RH and front door inside locking cable RH to the front door inside handle RH.




  2. Engage the 2 claws to install the front door inside handle RH to the front door trim board RH.



9. Install Front Door Trim Board Sub-assembly RH



  1. Engage the 4 claws to install the front door trim board RH to the front door glass weatherstrip inner RH.

  2. Engage the 9 clips to install the front door trim board RH to the front door panel.




  3. Install the 3 screws.



10. Install Door Assist Grip Cover RH



  1. Engage the 4 claws to install the door assist grip cover RH to the front door trim board RH.



11. Install Front Door Inside Handle Bezel RH



  1. Engage the 3 claws to install the front door inside handle bezel RH to the front door trim board RH.
