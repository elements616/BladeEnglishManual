DTC P1589/C1 Acceleration Sensor Learned Value Malfunction

Print

Preparation List


Function Description


When G sensor 0 point learning is required, such as when the engine control computer is replaced, the engine control computer outputs a DTC if G sensor 0 point learning has not been performed or if G sensor 0 point learning ended with an error.

DTC No.
DTC Detection Conditions
1. Diagnosis conditions 2. Malfunction status 3. Malfunction duration 4. Other
Inspection Area
P1589/C1
  1. Vehicle speed 2km/h or more
  2. G sensor 0 point not learned
  3. When conditions are met
  4. 1 trip
  1. G sensor 0 point learning performed

  2. Yaw Rate Sensor


Inspection Procedure

Step 1TaSCAN (G Sensor 0-point Learning)

■ NOTICE ■
  1. If CVT hydraulic pressure learning is performed before G sensor 0 point learning, P1589/C1 is output; in that case, perform (*1), (*2) and (*3), (*4) to return to normal.
  2. Be sure to place the vehicle on a level surface and perform 0 point learning.
  3. Do not subject the vehicle to vibration while 0 point learning is in progress.

SST
09991-70200  

  1. Turn the IG OFF, move the shift lever to the P position and apply the parking brake. (*1)

  1. Turn the IG ON (engine stopped). (*2)

  1. Using SST (TaSCAN), following the screen display, select [Utility] from the main menu and select [Transmission] in the utility category.

  1. Select [A/T/CVT Learned Value Initialization] on the screen to initialize the learned values.

    ■ NOTICE ■
    The engine will not start.

  1. Using SST (TaSCAN), following the screen display, select [Utility] from the TOP menu and select [Transmission] in the utility category. (*3)

  1. Select [G Sensor 0 Point Learning Start] on the screen to perform G sensor 0 point learning. (*4)

    □ HINT □
    1. When [Complete] is displayed on the screen, G sensor 0 point learning is complete.
    2. If [Error] is displayed on the screen and the check engine warning light illuminates, there may be a malfunction in the yaw rate sensor system.
    3. If the vehicle is subjected to vibration during 0 point learning, 0 point learning may be canceled. (If [Error] is displayed on the screen and the check engine warning light does not illuminate) In that case, perform the work in (*4) again.

Step 2TaSCAN (CVT Hydraulic Pressure Learning)

■ NOTICE ■
Do not initialize the learned values.

SST
09991-70200  

  1. Turn the IG OFF and wait for 30 seconds or more.

  1. Move the shift lever to P.

  1. Turn the IG ON (engine stopped) and wait for 2 seconds or more.

    ■ NOTICE ■
    The engine will not start.

  1. Using SST (TaSCAN), following the screen display, select [Utility] from the TOP menu and select [Transmission] in the utility category.

  1. Start the engine and wait for 5 seconds or more.

  1. Select [CVT Hydraulic Pressure Learning Start] on the screen to perform CVT hydraulic pressure learning.

    □ HINT □
    1. During CVT hydraulic pressure learning, the engine is in an idle-up state.
    2. When [Complete] is displayed on the screen, hydraulic pressure learning is complete.
    3. The CVT hydraulic pressure learned values are not initialized just by disconnecting the battery.

Step 6TaSCAN (A/T / CVT Learned Value Initialization, G Sensor 0-point Learning and CVT Hydraulic Pressure Learning)

■ NOTICE ■
  1. Initializing the learned values clears both the G sensor 0-point learning values and the CVT hydraulic pressure learning values, so when replacing the parts in the table below, perform AT/CVT learned value initialization and be sure to perform both G sensor 0-point learning and CVT hydraulic pressure learning.
    Replacement Parts
    1. Continuously Variable Transaxle
    2. Engine Control Computer
    3. Skid control computer
    4. Oil Pressure Sensor
    5. Yaw Rate Sensor
  2. After performing AT/CVT learned value initialization, be sure to perform G sensor 0-point learning first, and then CVT hydraulic pressure learning.
  3. Be sure to place the vehicle on a level surface and perform 0 point learning.
  4. Do not subject the vehicle to vibration while 0 point learning is in progress.
  5. When replacing the skid control computer or the yaw rate sensor on vehicles with the Intelligent Parking Assist system, be sure to also perform G sensor 0 point writing for the Intelligent Parking Assist system.

□ HINT □
For the Intelligent Parking Assist system G sensor 0 point writing procedure, refer to for reference.
