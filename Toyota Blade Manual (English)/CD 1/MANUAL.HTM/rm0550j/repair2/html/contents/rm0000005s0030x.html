  1. CAN Bus Diagnosis (Communication Malfunction DTC Check)

    □ HINT □
    TaSCAN can display only the malfunction DTCs related to CAN communication, by ECU.

    1. Select "Diagnosis" on the TOP menu of the SST (TaSCAN).

      SST
      09991-70201  




    2. Select "CAN Bus Diagnosis" on the diagnosis menu screen.




    3. Select "Communication Malfunction DTC Check" on the CAN bus diagnosis screen.




    4. The screen appears and the malfunction DTCs related to CAN communication are displayed by ECU.




    1. CAN Bus Diagnosis (CAN Bus Connected ECU Check)

      □ HINT □
      TaSCAN can display the ECUs and sensors that are correctly connected to CAN communication.

      1. Select "CAN Bus Connected ECU Check" on the CAN bus diagnosis screen of the SST (TaSCAN).

        SST
        09991-70201  




      2. The screen appears and the ECUs and sensors currently connected correctly are displayed.

        □ HINT □
        1. If an ECU or sensor that should be connected is not displayed, communication in that system has stopped.
        2. If no ECUs or sensors are connected to the CAN bus, "No ECUs are currently connected to the CAN bus. " is displayed.

      3. Check the screen display for approximately 1 minutes and check that there are no items alternating between displayed and not displayed.

        □ HINT □
        1. If there is a one-side open circuit in any branch line other than DLC3, the output of the other, unbroken communication line becomes noise and may interfere with the responses (display) of other ECUs and sensors.
        2. If there are ECUs or sensors alternating between displayed and not displayed, inspect the branch lines of those ECUs or sensors and of the ECUs or sensors with no response at all (not displayed) for a one-side open circuit, and repair the abnormal branch line.

          1. DTC Combination Table (V Bus Branch Line Open, Past Communication Stop Malfunction)


            1. For past malfunctions of ECUs connected to the V bus (displayed normally in the CAN bus connected ECU check but a DTC is output), refer to the combination table to determine the branch line in which the malfunction occurred.

              □ HINT □
              1. ECUs with a branch line open circuit or communication stop cannot respond to the DTC output request from the SST (TaSCAN).
              2. A current branch line open circuit or communication stop can be confirmed by performing the "CAN Bus Connected ECU Check" using the SST (TaSCAN): the ECUs and sensors connected to the open branch line do not respond (are not displayed on the screen).
              3. If the CAN gateway ECU is outputting a malfunction code, inspect and repair the V bus No.2 malfunction first.



              □ HINT □
              1. ×: May be output when there is a one-side open circuit in a branch line
              2. *1: DTCs cannot be output while communication is stopped
              3. *2:CAN: Applies when the gateway ECU DTCs are normal (V bus No.2 normal)
