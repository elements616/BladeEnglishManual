Function Description


The skid control computer (built into the actuator) receives the yaw rate sensor signals via CAN communication.

The yaw rate sensor has a built-in G sensor.

If there is a malfunction in the communication line with the yaw rate sensor, DTCs "U0123/62 (yaw rate sensor communication malfunction)" and "U0124/95 (G sensor communication malfunction)" are output.

If a CAN communication line malfunction code is output, perform troubleshooting for the CAN communication line malfunction first.
