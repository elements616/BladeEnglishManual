DTC C1241/41 Low or High Voltage Malfunction

Print

Preparation List


Function Description


If there is a malfunction in the power source circuit, the skid control computer (built into the actuator) outputs a DTC and prohibits operation as a fail-safe.

This code is stored if the voltage to terminal IG1 goes outside the range of the DTC detection condition due to a malfunction in the power source or charging circuit, such as the battery or alternator circuit.

When the voltage to terminal IG1 returns to normal, the DTC is cleared.


DTC No.
DTC Detection Condition
DTC Output Related Items
C1241/41
  1. At a vehicle speed of 3km/h or more, IG1 terminal voltage remains below 9.5V for 10 seconds or more
  2. While the solenoid relay remains ON, IG1 terminal voltage drops below 9.5V and the relay contact remains OFF for 0.2 seconds or more
  3. With IG1 terminal voltage below 9.5V, the vehicle speed sensor power source voltage remains low for 60 seconds or more
  4. While the motor relay is ON and the fail-safe motor relay is ON, IG1 terminal voltage remains below 9.5V with the actuator pump drive motor OFF for 0.2 seconds or more
  5. IG1 terminal voltage remains higher than 17.4V for 0.8 seconds or more
  1. Alternator (regulator)
  2. Open in wire harness
  3. Poor connector contact pressure, terminal deformation or corrosion
  4. Power source circuit in skid control computer
