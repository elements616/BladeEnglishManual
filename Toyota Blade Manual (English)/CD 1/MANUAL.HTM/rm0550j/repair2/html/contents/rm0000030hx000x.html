Rear Seat Assembly LH Reassembly

Print

Preparation List



1. Install Separate Type Rear Seat Cushion Cover LH



  1. Using hog ring pliers, install the separate type rear seat cushion cover LH with 6 new hog rings.




  2. Install the separate type rear cushion cover w/ pad with the 13 J hooks.



2. Install Rear Seatback Lock Assembly LH



  1. Install the rear seatback lock assembly LH with the 4 bolts.

    Standard
    T = 18 N/m{ 184 kgf/cm }



3. Install Separate Type Rear Seatback Cover LH



  1. Using hog ring pliers, install the separate type rear seatback cover LH with 10 new hog rings.



4. Install Rear Seat Headrest Support

  1. Temporarily install the separate type rear seatback cover w/ pad to the rear seatback frame sub-assembly LH.




  2. Engage the 4 claws and install the 2 rear seat headrest supports.



5. Install Rear Seatback Board Carpet Assembly LH

  1. Temporarily install the rear seatback board carpet assembly LH to the rear seatback frame sub-assembly LH.




  2. Install the rear seatback board carpet assembly LH with the 3 J hooks.




  3. Install the 2 clips.




  4. Install the 2 clips.



6. Install Rear Seatback Cover



  1. Engage the 4 claws and install the rear seatback cover.



7. Install Rear Seatback Lock Cover LH



  1. Install the rear seatback lock cover LH with the 2 screws.



8. Install Rear Seat Lock Base



  1. Engage the 3 claws and install the rear seat lock base.



9. Install Rear Seat Lock Control Lever NO.1



  1. Slide rear seatback lock control lever NO.1 as shown in the illustration to install it.



10. Install Rear Seatback Lock Control Lever w/ Base



  1. Engage the 3 claws and temporarily install the rear seatback lock control lever w/ base.

  2. Install the rear seatback lock control lever w/ base with the 2 screws.



11. Install Rear Seatback Assembly LH



  1. Using a Torx socket wrench T45, install the rear seatback assembly LH with the 2 Torx bolts.

    Standard
    T = 18 N/m{ 184 kgf/cm }
