  1. ECU Data Monitor (TaSCAN)

    ■ NOTICE ■
    1. Data monitor values vary greatly due to slight measurement differences, differences in measurement environment, changes in the vehicle over time, etc., so it is difficult to give clear standard values (judgment values). Therefore, a malfunction may exist even if values are within the reference range.
    2. For subtle symptoms such as hesitation or rough idle, it is necessary to make an overall judgment from all data monitor items by collecting and comparing data from a vehicle of the same model under the same conditions.

    1. Using SST (TaSCAN), follow the prompts on the screen to display the "ECU Data Monitor" screen and check the computer data.
