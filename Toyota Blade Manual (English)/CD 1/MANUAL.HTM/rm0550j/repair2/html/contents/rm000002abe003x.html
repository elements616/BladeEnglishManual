Fuel Injector Assembly (2AZ-FE) Installation

Print

Preparation List



1. Install Fuel Injector Assembly

  1. Install a new insulator to the injector.




  2. Apply gasoline to a new O-ring and install it to the injector.

  3. Apply gasoline to the injector installation hole of the fuel delivery pipe.




  4. While turning the fuel injector left and right, install it to the fuel delivery pipe.

    ■ NOTICE ■
    Install the O-ring so that it is not twisted.
    After installing it to the delivery pipe, check that the injector rotates smoothly.



2. Install Fuel Delivery Pipe w/ Injector



  1. Set the 2 spacers on the cylinder head.

  2. Install the fuel delivery pipe w/ injector to the cylinder head.

    ■ NOTICE ■
    Do not drop the fuel injectors when installing the fuel delivery pipe.




  3. Temporarily tighten the 2 bolts.




  4. Turn the fuel injectors left and right by hand to check that they are installed without excessive force.

    □ HINT □
    If a fuel injector does not rotate smoothly, replace the O-ring with a new one and reinstall it.

  5. Position the fuel injector connectors toward the rear of the vehicle.

  6. Tighten the 2 bolts.

    Standard
    T = 20 N/m{ 204 kgf/cm }




  7. Install the 3 wire harness clamps. (*2)

  8. Connect the 4 fuel injector connectors.

  9. Connect the oil control valve connector (*1).




  10. Connect the throttle body connector.



3. Connect Oxygen Sensor (Drive Type FF)



  1. Connect the oxygen sensor connector and clamp.



4. Connect Ventilation Hose NO.2



  1. Connect the ventilation hose No.2 with the clamp.



5. Connect Fuel Tube Sub-assembly

  1. Align the axes of the fuel pressure pulsation damper pipe and the fuel tube connector, and push in the fuel tube securely until it clicks (see ).




  2. Install EFI fuel pipe clamp No.2.



6. Install Air Cleaner Cap w/ Air Cleaner Hose

  1. Install the hinge portion first, then install the air cleaner cap with the 3 clamps.




  2. Install air cleaner hose No.1 to the throttle body assembly and release the lock of air cleaner hose clamp No.1.

    ■ NOTICE ■
    1. Align the triangular projection of air cleaner hose No.1 with the throttle body bolt on the right front side of the vehicle.
    2. Align the position of air cleaner hose clamp No.1 using the triangular projection of air cleaner hose No.1 as a reference.




  3. Connect the clamp and intake air flow meter connector.




  4. Connect the fuel vapor feed hose and fuel vapor feed hose No.2 to vacuum switching valve assembly No.1.

  5. Connect the clamp and vacuum switching valve connector.

  6. Connect the ventilation hose.



7. Connect Battery Negative Terminal
Standard
T = 5.4 N/m{ 55 kgf/cm }


8. Inspect for Fuel Leaks

  1. Fuel Pump Operation Check

    1. Connect SST (TaSCAN) to DLC3.

      SST
      09991-70200  

    2. Operate according to the screen display, select 'Active Test' - 'Circuit Relay' - 'ON', and check the fuel pump operation.

  2. Fuel Leak Inspection

    1. Check that there are no fuel leaks in the fuel system while fuel pressure is applied.



9. Install Engine Cover Sub-assembly NO.1



  1. Install the engine cover assembly No.1 with the 2 nuts.

    Standard
    T = 9.0 N/m{ 92 kgf/cm }



10. Install Cowl Top Panel Outer



  1. Install the cowl top panel outer with the 8 bolts.

    Standard
    T = 8.8 N/m{ 90 kgf/cm }




  2. Bend the heater air duct splash shield seal No.2 and water guard plate RH as shown in the illustration, and engage each clamp.




  3. Engage the windshield deicer wire harness connector and 3 clamps, and attach them to the cowl top panel outer. (w/ Cold Area Specification)



11. Install Cowl Body Mounting Reinforcement RH



  1. Install the cowl body mounting reinforcement RH to the cowl top panel outer with the 3 bolts.

    Standard
    T = 8.8 N/m{ 90 kgf/cm }



12. Install Windshield Wiper Motor & Link Assembly



  1. Install the windshield wiper motor & link assembly with the 2 bolts.

    Standard
    T = 5.5 N/m{ 56 kgf/cm }

  2. Connect the connector.



13. Install Cowl Top Ventilator Louver RH



  1. Engage the 5 claws and install the cowl top ventilator louver RH as shown in the illustration.



14. Install Front Side Panel Protector NO.1 RH



  1. Engage the pin and install the front side panel protector NO.1 RH.



15. Install Cowl Top Ventilator Louver LH



  1. Engage the 11 claws and install the cowl top ventilator louver LH as shown in the illustration.



16. Install Front Side Panel Protector NO.1 LH



  1. Engage the pin and install the front side panel protector NO.1 LH.



17. Install Hood to Cowl Top Seal



  1. Engage the 7 clips and install the hood to cowl top seal.



18. Install Front Wiper Arm & Blade Assembly LH



  1. Stop the windshield wiper motor assembly at the automatic stop position.

  2. Using a round file or equivalent, clean the wiper arm serrations. (When reassembling)

  3. Using a wire brush, clean the wiper pivot serrations.




  4. Install the front wiper arm & blade assembly LH with the front wiper arm nut so that it is in the position shown in the illustration.

    Standard
    T = 26 N/m{ 265 kgf/cm }

    □ HINT □
    While holding the arm hinge by hand, tighten the front wiper arm nut.



19. Install Front Wiper Arm & Blade Assembly RH



  1. Using a round file or equivalent, clean the wiper arm serrations. (When reassembling)

  2. Using a wire brush, clean the wiper pivot serrations.




  3. Install the front wiper arm & blade assembly RH with the front wiper arm nut so that it is in the position shown in the illustration.

    Standard
    T = 26 N/m{ 265 kgf/cm }

    □ HINT □
    While holding the arm hinge by hand, tighten the front wiper arm nut.

  4. Operate the front wipers while spraying water or washer fluid on the glass, and check the wiping condition of the blades and that they do not interfere with the body.



20. Install Front Wiper Arm Head Cap



  1. Install the 2 front wiper arm head caps.
