1. Install Tie Rod End Sub-assembly LH



  1. Install the lock nut and tie rod end LH up to the matchmarks, and temporarily tighten the lock nut.

    □ HINT □
    Perform final tightening after the toe-in adjustment.



2. Install Tie Rod End Sub-assembly RH

□ HINT □
Use the same procedure for the RH side as for the LH side.
