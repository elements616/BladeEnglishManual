Steering Gear Assembly Disassembly

Print

Preparation List



1. Secure Steering Link Assembly



  1. Using SST wrapped with protective tape, secure the power steering link assembly in a vise.

    SST
    09612-00012  

    □ HINT □
    Remove and install SST as necessary.



2. Remove Tie Rod End Sub-assembly LH



  1. Place matchmarks on the tie rod end sub-assembly LH and rack end.

  2. Remove the tie rod end sub-assembly LH and lock nut.



3. Remove Tie Rod End Sub-assembly RH

□ HINT □
Use the same procedure for the RH side as for the LH side.



4. Remove Steering Rack Boot Clip (LH Side Installation Position)

  1. Using pliers, remove the steering rack boot clip.



5. Remove Steering Rack Boot Clip (RH Side Installation Position)

□ HINT □
Use the same procedure for the RH side as for the LH side.



6. Remove Steering Rack Boot Clamp NO.2



  1. Using a screwdriver, unstake steering rack boot clamp No.2.

    ■ NOTICE ■
    Do not damage steering rack boot No.2.



7. Remove Steering Rack Boot Clamp NO.1

□ HINT □
Use the same procedure for the RH side as for the LH side.



8. Remove Steering Rack Boot NO.2


9. Remove Steering Rack Boot NO.1
