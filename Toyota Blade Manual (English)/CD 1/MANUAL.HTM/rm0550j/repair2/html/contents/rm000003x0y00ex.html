DTC C1582/26 Assist Map Identification Malfunction

Print

Preparation List


Function Description


If an incorrect power steering computer assembly or engine control computer is installed, the data will not match the vehicle specifications, and DTC C1582/26 will be output.


Diagnostic Trouble Code (DTC)
Detection Item
Trouble Area
C1582/26
When data that does not match the vehicle specifications is received via CAN communication
  1. Assist map not written
  2. CAN Communication System
  3. Power Steering Computer Assembly
  4. Skid control computer (brake ECU)
  5. Engine control computer
