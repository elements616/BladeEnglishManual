Circuit Description


  1. The knock control sensor is installed on the cylinder block and detects engine knocking. The knock control sensor contains a sensor that generates voltage when the cylinder block vibrates and deforms due to knocking. When knocking occurs, the engine control computer retards the ignition timing to suppress the knocking.
