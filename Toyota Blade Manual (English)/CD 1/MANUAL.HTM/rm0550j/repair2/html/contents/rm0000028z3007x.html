Cruise Control Main Switch Installation

Print

Preparation List



1. Install Cruise Control Main Switch



  1. Insert the cruise control main switch in the direction of the arrow shown in the illustration.




  2. Install the cruise control main switch with the 2 screws.

  3. Connect the connector.



2. Install Horn Button Assembly



  1. Connect the horn connector to the horn button assembly.

  2. Connect the airbag connector to the horn button assembly and lock it securely.

    ■ NOTICE ■
    Securely lock the airbag connector.



  3. Using a torx socket wrench (T30), install the horn button assembly to the steering wheel assembly with the 2 torx bolts.

    Standard
    T = 8.8 N/m{ 90 kgf/cm }





3. Install Steering Wheel Cover Lower NO.3



  1. Engage the claws and install steering wheel cover lower NO.3.



4. Install Steering Wheel Cover Lower NO.2



  1. Engage the claws and install steering wheel cover lower NO.2.
