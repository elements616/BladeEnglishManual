Preparation List


Function Description


The transmission revolution sensor (NT) inputs the input shaft speed signal, and the transmission revolution sensor (NC) inputs the output shaft speed signal, to the transmission control computer. (The NT and NC sensors are integrated)

The engine control computer and transmission control computer perform engine torque control and shift timing control based on the transmission revolution sensor (NT) and (NC) signals. Lock-up control is also performed based on the input shaft speed signal and engine speed signal.
