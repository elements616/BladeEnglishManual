Circuit Description


CAN (Controller Area Network) is a serial data communication system for real-time applications. It is a multiplex communication system for vehicles, with a high communication speed (500kbps) and a malfunction detection function. By combining the CANH bus line and the CANL bus line, CAN performs communication based on differential voltage.
