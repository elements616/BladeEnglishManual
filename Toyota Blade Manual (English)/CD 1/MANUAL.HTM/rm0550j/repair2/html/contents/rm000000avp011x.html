DTC P2716/77 Pressure Control Solenoid Circuit

Print

Preparation List


Function Description


Based on signals from the accelerator position sensor and transmission revolution sensor, the transmission control computer controls the line pressure control solenoid assembly to the specified duty ratio. As a result, the line pressure is adjusted according to the throttle opening angle and engine output.
