  1. JEITA Standard Error Codes

    □ HINT □
    When a JEITA standard error code occurs, it is notified by an interrupt display on the multi-display.


    JEITA Standard Error Codes 
    Diagnostic Trouble Code (DTC)
    		Diagnosis Item
    		Possible Cause
    		Countermeasure
    01
    		ETC Card Insertion Error
    1. ETC card not inserted during communication
    2. ETC card improperly inserted
    		Check the insertion of the ETC card and insert it again
    Communication other than ETC, such as with a parking lot system, was performed without an ETC card inserted
    		Ask the customer whether a parking lot system etc. using ETC was used
    02
    		Data Processing Error
    1. Error reading from or writing to ETC card
    2. Poor contact between ETC card and ETC on-board unit
    3. Momentary interruption while accessing ETC card
    4. Card removed during writing
    5. An IC card other than an ETC card is inserted
    1. If an ETC card was inserted, insert it again; if the same error code is output, inspect the ETC on-board unit
    2. If the vehicle is directed (displayed) to stop at the toll gate, stop the vehicle and follow the attendant's instructions
    03
    		ETC Card Error
    1. ETC card is faulty
    2. A card other than an IC card is inserted and does not communicate
    3. ETC card inserted incorrectly (upside down, wrong insertion direction)
    		Check that the ETC card is correct and the insertion direction etc., and insert it again; if the same error code is output, contact the ETC card issuer
    04
    		On-board unit malfunction
    		The ETC on-board unit is judged to be faulty based on the self-diagnosis result
    		Start the engine again; if the same error code is output, inspect the ETC on-board unit
    05
    		ETC card information abnormal
    1. ETC card authentication error
    2. An IC card other than an ETC card is inserted
    3. ETC card removed during authentication
    4. ETC card inserted into ETC on-board unit that has not been set up
    		Check that the ETC card is correct and the insertion direction etc., and insert it again; if the same error code is output, inspect the ETC on-board unit
    Setup card was reinserted
    		Check whether the on-board unit has been set up
    A setup card with a different on-board unit management number was inserted
    		Check that the on-board unit management number is correct using the 3 items: setup card, setup application form and ETC on-board unit part number label
    06
    		On-board unit information abnormal
    		Authentication error with roadside antenna
    		An error occurred in data processing between the on-board unit and the toll gate, so follow the toll gate attendant's instructions
    07
    		Communication Error
    		Communication with roadside antenna ended prematurely
    1. An error occurred in data processing between the on-board unit and the toll gate, so follow the toll gate attendant's instructions
    2. Ask the customer whether a parking lot system etc. using ETC was used


    1. ETC System Error Codes (Diagnosis Mode 1)

      □ HINT □
      This DTC is announced by voice from the toll collection (ETC) computer assembly.


      ETC System Error Codes (Diagnosis Mode 1) 
      Diagnostic Trouble Code (DTC)
      		Diagnosis Item
      		Possible Cause
      		Action if Recurring
      11
      		Self-diagnosis error
      		Internal malfunction of the toll collection (ETC) computer assembly, such as the security IC or memory
      		If it recurs, replace and set up the toll collection (ETC) computer assembly
      (fatal error)
      12
      		Self-diagnosis error
      		Internal malfunction of the toll collection (ETC) computer assembly, such as the security IC or memory
      		If it recurs, replace and set up the toll collection (ETC) computer assembly
      (fatal error)
      41
      		ETC card write error
      		Writing data to the ETC card has failed
      1. Check the ETC card for abnormalities
      2. In other cases, contact the card company; if it recurs, replace and set up the toll collection (ETC) computer assembly
      42
      		DSRC authentication error
      		A security-related malfunction has occurred during road-to-vehicle communication
      		Investigate the toll gate where it occurred; if it recurs, replace and set up the toll collection (ETC) computer assembly
      43
      		Road-to-vehicle communication error
      		An error (other than an authentication error) has occurred during road-to-vehicle communication
      		Investigate the toll gate where it occurred
      44
      		Communication with no card inserted
      		Road-to-vehicle communication has occurred with no card inserted
      		Explain to the customer
      45
      		Passage not permitted error
      		"Passage not permitted" has been notified from the roadside antenna with a card inserted
      1. Investigate the toll gate where it occurred
      2. Explain to the customer (check whether the ETC card has expired)
      46
      		Passage not permitted error
      		"Passage not permitted" has been notified from the roadside antenna because ETC card authentication was not completed
      1. Investigate the toll gate where it occurred
      2. Explain to the customer (check whether the card was inserted just before the ETC gate)
      47
      		Passage not permitted error
      		"Passage not permitted" has been notified from the roadside antenna because a card read error occurred
      1. Investigate the toll gate where it occurred
      2. Explain to the customer
      48
      		Communication incomplete error
      		Communication with the roadside antenna was lost (timeout)
      1. Investigate the toll gate where it occurred
      2. Check that there are no objects blocking radio waves around the instrument panel
      49
      		Communication incomplete error
      		Communication with the roadside antenna was cut off midway (release received)
      		Investigate the toll gate where it occurred
      51
      		Charge information malfunction
      		Charge amount abnormal at toll gate settlement
      		Investigate the toll gate where it occurred
      52
      		Charge information malfunction
      		Charge unit abnormal at toll gate settlement
      		Investigate the toll gate where it occurred
      61
      		RF module malfunction
      1. The frequency could not be locked by the frequency switching function at some time
      2. Toll collection (ETC) computer assembly malfunction
      		If it recurs, replace and set up the toll collection (ETC) computer assembly
      62
      		Antenna malfunction (history)
      		The ETC antenna has been disconnected or the ETC antenna cable has had an open circuit
      1. Check the navigation antenna assembly connection
      2. Inspect the toll collection (ETC) computer assembly as a single unit
      3. After clearing the DTC, check the symptom again; if the same code is detected again, replace the toll collection (ETC) computer assembly
      71
      		Card read error
      		Reading data from the ETC card has failed
      1. If none of several ETC cards are authenticated, replace and set up the toll collection (ETC) computer assembly
      2. If some ETC cards are not authenticated, contact the card company
      72
      		Card authentication error
      		Authentication with the ETC card has failed
      1. If none of several ETC cards are authenticated, replace and set up the toll collection (ETC) computer assembly
      2. If some ETC cards are not authenticated, contact the card company
      73
      		Card error
      		No response from the ETC card
      1. If none of several ETC cards are authenticated, replace and set up the toll collection (ETC) computer assembly
      2. If some ETC cards are not authenticated, contact the card company
      74
      		Card removal error
      		The ETC card has been removed while it was being read
      		Explain to the customer
      75
      		Card removal error
      		The ETC card has been removed while data was being written to it
      		Explain to the customer
      76
      		Wrong card insertion error
      1. The ETC card has been inserted incorrectly (upside down, wrong insertion direction)
      2. A card other than an IC card has been inserted
      3. A faulty ETC card has been inserted
      4. Toll collection (ETC) computer assembly malfunction
      		Explain to the customer
      77
      		Wrong card insertion error
      		An IC card other than an ETC card has been inserted
      		Explain to the customer
      81
      		AVC-LAN communication malfunction
      		AVC-LAN periodic communication malfunction
      1. Inspect the power supply system and AVC-LAN communication system W/H of the navigation receiver assembly
      2. Inspect the power supply system and AVC-LAN communication system W/H of the toll collection (ETC) computer assembly
      91
      		SAM error (card cause)
      		There was no response from SAM
      1. If none of several ETC cards are authenticated, replace and set up the toll collection (ETC) computer assembly
      2. If some ETC cards are not authenticated, contact the card company
      92
      		SAM error (card cause)
      		Response from SAM is abnormal
      1. If none of several ETC cards are authenticated, replace and set up the toll collection (ETC) computer assembly
      2. If some ETC cards are not authenticated, contact the card company
      93
      		Setup processing error
      		An ETC card was inserted into an ETC on-board unit that has not been set up
      		Setup
      94
      		Setup processing error
      		A setup card that has already been used for setup was inserted
      		Check the setup card
      95
      		Setup processing error
      		A setup card with a different on-board unit management number was inserted
      1. Check the setup card
      2. Check the setup application form
