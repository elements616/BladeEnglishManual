1. Basic Inspection (Check JEITA Standard Error Code)

  1. Check Toll Collection (ETC) Computer Assembly Startup

    1. Turn ACC ON.

    2. Check that the green indicator and amber indicator illuminate for 5 seconds.

    3. Check that the startup check ends normally and the indicators go off.

      □ HINT □
      If there is a malfunction in the toll collection (ETC) computer assembly, the amber indicator blinks, and the following notification is given depending on the specification.
      Specifications
      		Notification Content When Malfunctioning
      Vehicles w/o HDD navigation system
      		The toll collection (ETC) computer assembly gives the voice notification "Beep. A malfunction has occurred. ETC cannot be used. Error 04". (see)
      Vehicles w/ HDD navigation system
      		The multi-vision voice gives the notification "Bong. A malfunction has occurred in the ETC. ETC cannot be used", and the JEITA standard error code is displayed on the multi-display. (see)

  2. ETC Card Insertion Check (Vehicles w/o HDD Navigation System)

    1. Insert the ETC card.

    2. The toll collection (ETC) computer assembly gives the voice notification "Beep", the green indicator starts blinking, and card authentication starts.

    3. Check that the toll collection (ETC) computer assembly gives the voice notification "Bong. The ETC card has been inserted" and the green indicator illuminates.

      □ HINT □
      1. If there is a problem with the ETC card, the amber indicator blinks and the toll collection (ETC) computer assembly gives the voice notification "Beep beep. Cannot read card. Error ** (JEITA standard error code)". (see)
      2. The warning sound of the toll collection (ETC) computer assembly continues until the card is removed.

  3. ETC Card Insertion Check (Vehicles w/ HDD Navigation System)

    ■ NOTICE ■
    The multi-vision does not give guidance until 20 seconds or more have elapsed after the ignition switch is turned to ACC.


    1. Insert the ETC card.

    2. The multi-vision voice gives the notification "Beep", the green indicator on the ETC unit starts blinking, and card authentication starts.

    3. Check that the multi-vision voice gives the notification "Bong. The ETC card has been inserted" and the green indicator on the ETC unit illuminates.

      □ HINT □
      1. If there is a problem with the ETC card, the amber indicator on the ETC unit blinks, the multi-vision voice gives the notification "Bong. Cannot read card. Please check the card", and the JEITA standard error code is displayed on the multi-display. (see)
      2. The warning sound of the toll collection (ETC) computer assembly continues until the card is removed.



2. ETC Registration Information (Vehicles w/ HDD Navigation System)

□ HINT □
The following information of the toll collection (ETC) computer assembly can be checked on the ETC registration information screen of the HDD navigation display.
  1. On-board unit management number
  2. On-board unit registration number
  3. Setup card issue date
  4. Setup card information expiration date
  5. Unified Error Code

  1. ETC Registration Information Screen Display

    □ HINT □
    The screen is an example display and may differ from the actual screen.


    1. Press the "Info G" button to display the information screen.




    2. Press "ETC" on the information screen.




    3. Press "Display Registration Information" on the ETC menu screen.




  2. Check Screen Display Content

    1. Check the on-board unit management number.

      On-board Unit Management Number Display Content 
      Digits
      		Meaning
      XXXXX (5 digits)
      		SAM (encryption IC) manufacturer code
      XXXXXXXX (8 digits)
      		SAM production lot No.
      XXXXXX (6 digits)
      		SAM serial No.

      □ HINT □
      1. The on-board unit management number is displayed as "XXXXX-XXXXXXXX-XXXXXX" (X is a number from 0 to 9).
      2. Record this display content on the customer problem analysis sheet.

    2. Check the on-board unit registration number.

      On-board Unit Registration Number Display Content 
      Digits
      		Meaning
      XXX (3 digits)
      		On-board unit model
      XXXXXXXX (8 digits)
      		Serial No.

      □ HINT □
      The on-board unit registration number is displayed as "XXX-XXXXXXXX" (X is a number from 0 to 9).

    3. Check the setup card issue date.

      □ HINT □
      If the on-board unit has not been set up, " Year Month Day" is displayed.

    4. Check the setup card information expiration date.

      □ HINT □
      If the on-board unit has not been set up and the expiration date (*) of the setup card information has not been set, " Year Month Day" is displayed. (*: Not the expiration date of the ETC card)

    5. Check the standard error code.

      □ HINT □
      1. The latest JEITA standard error code is displayed.
      2. If there are error codes, the last 1 error that occurred is displayed. Note that the last recorded error code may be displayed even when the system is normal, so it does not necessarily indicate the current condition.



3. Check Latest Stored JEITA Standard Error Code

  1. Check by Unit Voice Guidance

    1. Remove the ETC card and turn the ignition switch to ACC.

    2. When the "History" switch is pressed for 2 seconds or more, the latest JEITA standard error code is announced.

      □ HINT □
      1. The latest JEITA standard error code is announced.
      2. If there are error codes, the last 1 error that occurred is announced. Note that the last recorded error code may be announced even when the system is normal, so it does not necessarily indicate the current condition.



4. Clear Latest Stored JEITA Standard Error Code

□ HINT □
There are 2 methods for clearing the latest recorded JEITA standard error code.

  1. Clearing method 1

    1. Start ETC diagnosis mode 1 or mode 2. (see)

    2. Press the "History" switch and "VOL UP" switch simultaneously for 2 seconds or more to clear the latest standard error code.

  2. Clearing method 2 (vehicles w/ HDD navigation system)

    1. Start the HDD navigation system diagnosis mode. (see)




    2. On the service inspection screen, select "Check" for "ETC" to display the individual diagnosis ETC screen.




    3. On the individual diagnosis ETC screen, select "Clear Diagnosis" (press and hold for 3 seconds or more) to clear the diagnosis.
