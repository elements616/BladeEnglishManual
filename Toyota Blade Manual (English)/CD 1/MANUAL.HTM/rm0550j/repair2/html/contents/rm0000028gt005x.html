DTC C1631 FLS Sensor Frozen

Print

Preparation List


Function Description


This DTC is output when the television camera controller self-diagnosis determines, while ultrasonic sensor NO.1 is being driven (when the shift lever is in a position other than "P" or "R" and the vehicle is not stopped), that ultrasonic sensor NO.1 (FLS sensor) is frozen or has dirt such as ice, snow or mud adhering to it.


DTC No.
Diagnosis Description
Inspection Area
C1631
IPA Ultrasonic Sensor Frozen (Left)
  1. Ultrasonic Sensor NO.1 (FLS Sensor)
  2. Television Camera Controller
