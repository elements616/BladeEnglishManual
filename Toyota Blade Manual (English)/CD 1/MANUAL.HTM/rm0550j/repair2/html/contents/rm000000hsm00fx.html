DTC P0503/23 Cruise Vehicle Speed Sensor Circuit

Print

Preparation List


Circuit Description


The ABS & traction actuator assembly outputs the vehicle speed signal to the engine control computer via the combination meter assembly.


DTC No.
Diagnosis Description

  2. Abnormal Condition

  2. Sudden change in vehicle speed signal input
