Timing Gear Case or Timing Chain Case Oil Seal (2AZ-FE) Installation

Print

Preparation List



1. Install Timing Gear Case or Timing Chain Case Oil Seal

  1. Apply a small amount of MP grease No.2 to the lip of a new oil seal.

    ■ NOTICE ■
    Keep foreign matter such as chips and sand off the lip.




  2. Using SST, tap in the oil seal evenly until it is flush with the end surface of the gear cover.

    SST
    09223-22010  

    ■ NOTICE ■
    1. Do not tap in the oil seal at an angle.
    2. Wipe off any grease on the crankshaft.



2. Install Crankshaft Pulley



  1. Using SST, hold the crankshaft pulley and tighten the bolt

    SST
    09213-54015   (91651-60855)
    09330-00021  
    Standard
    T = 170 N/m{ 1730 kgf/cm }



3. Install Front Suspension Member Reinforcement RH



  1. Install the front suspension member reinforcement RH with the 4 bolts.

    Standard
    T = 96 N/m{ 979 kgf/cm }



4. Install Fan & Alternator V Belt

□ HINT □
When reusing the belt, inspect the entire circumference of the ribs and back for wear and cracks, and replace it if wear or cracks reach the core (1 or more places) or if the rib rubber is chipped (1 or more places).




  1. Using SST, slowly turn the V-belt tensioner clockwise and install the V-belt.

    SST
    09961-01270  

    ■ NOTICE ■
    1. Check that the SST and tools are securely set.
    2. When compressing the V-belt tensioner, slowly apply force perpendicular to the tool, taking 3 seconds or more.




  2. Check that the belt is fitted on each pulley.




  3. Check that the belt is correctly set on each pulley.

  4. Start the engine and check that the belt rotates smoothly with no abnormal noise.



5. Install Engine Under Cover Rear RH

  1. Install the engine under cover rear RH with the 5 clips.



6. Install Radiator Upper Air Deflector

  1. Install the radiator upper air deflector with the 8 clips.



7. Install Front Tire RH
Standard
T = 103 N/m{ 1050 kgf/cm }


8. Inspect for Engine Oil Leaks
