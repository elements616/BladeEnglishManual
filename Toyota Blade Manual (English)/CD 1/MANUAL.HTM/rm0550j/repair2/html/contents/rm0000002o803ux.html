  1. Back Guide Monitor Diagnosis System

    1. The back guide monitor diagnosis system allows checking the condition of each signal input to the navigation receiver assembly, and registration, setting, adjustment and checking of the back guide monitor system to be performed on the multi-display screen of the navigation receiver assembly.

      ■ NOTICE ■
      Depending on the parts replaced or the work performed during vehicle inspection and maintenance, registration and setting operations for other systems as well as the back guide monitor system may be necessary. (see)

      □ HINT □
      Registration, setting, adjustment and checking of the back guide monitor system are performed from the Diagnosis System - Function Inspection/Adjustment screen.

        1. Vehicle Speed Signal Inspection

          1. Start Diagnosis


            1. Select "Function Inspection/Adjustment" on the service inspection screen to display the function inspection/adjustment screen.




          2. Vehicle Speed Signal Input Check

            □ HINT □
            Check the condition of the vehicle speed signal (part A) input to the navigation receiver assembly.


            1. Check that "Vehicle Speed Input OK" is displayed in part A of the steering angle adjustment screen.

              □ HINT □
              1. The vehicle speed signal is displayed in blue if it has been input even once in the past.
              2. If "Checking Vehicle Speed" (displayed in red) is shown, check the DTCs of the HDD navigation system and take action according to the output code. (see)
              3. If "Vehicle Speed Input OK" is displayed in part A, the vehicle speed signal is being input normally, so proceed to each adjustment procedure.
              4. If the vehicle speed signal has not been input, part A displays "Checking Vehicle Speed" with a red background.
              5. If "Checking Vehicle Speed" (displayed in red) is displayed in part A, the screen does not switch even if "Maximum Steering Angle Memory" or "Next" is selected.
              6. If "Checking Vehicle Speed" (displayed in red) is displayed in part A, the screen switches when "Checking Vehicle Speed" is touched (changes from red to orange) and then "Maximum Steering Angle Memory" or "Next" is selected.

          3. Diagnosis Cancellation



          1. Vehicle Signal Inspection (Navigation Receiver Assembly Input Signals)

            1. Start Diagnosis


              1. Select "Function Inspection/Adjustment" on the service inspection screen to display the function inspection/adjustment screen.

              2. Select "Vehicle Signal Inspection" on the function inspection/adjustment screen to display the vehicle signal inspection screen.




            2. Vehicle Signal Check


              1. On the vehicle signal inspection screen, the input condition of each signal input to the navigation receiver assembly through the vehicle wire harness can be inspected and checked. (see)

                □ HINT □
                1. Inspect and check display areas A (vehicle speed signal) and B (reverse signal).

                  Display Area
                  		Item
                  		Inspection Details
                  		Signal Input Source
                  A
                  		Vehicle Speed Signal
                  		Displays vehicle speed signal input condition
                  		Combination Meter Assembly
                  B
                  		Reverse Signal
                  		Displays reverse signal input condition
                  		Neutral Start Switch Assembly
                2. The vehicle signals are updated every 1 seconds.

            3. Vehicle Speed Signal Inspection


              1. Drive the vehicle and check that the displayed vehicle speed and the vehicle speed displayed on the combination meter assembly almost match.

                ■ NOTICE ■
                As this inspection involves moving the vehicle, secure a wide area where the safety of the surroundings can be ensured before performing the inspection.

                □ HINT □
                If the displayed vehicle speed differs from the vehicle speed displayed on the combination meter assembly, check the DTCs of the HDD navigation system and take action according to the output code. (see)

            4. Reverse Signal Inspection


              1. Check that the display changes from "OFF" → "ON" when the shift lever is moved from P to R.

                ■ NOTICE ■
                As this inspection involves operating the shift lever, apply the parking brake, depress the brake pedal and take sufficient care that the vehicle does not move when performing the inspection.

                □ HINT □
                If the display does not change, perform inspection according to the instructions in Troubleshooting Flowchart [Reverse Signal Circuit]. (see)

            5. Diagnosis Cancellation



            1. Registration Settings during Vehicle Servicing

              ■ NOTICE ■
              Depending on the parts replaced or the work performed during inspection, registration and setting operations for other systems as well as the back guide monitor system may be necessary. (see)



              1. Steering Angle Adjustment

                □ HINT □
                If the vehicle width extension lines and expected course lines are misaligned when the steering wheel is straight, or the expected course lines stop moving before the steering wheel is turned fully to the left and right, perform steering angle adjustment.

                1. Stop the vehicle with the steering wheel in the straight-ahead position.

                2. Start Diagnosis

                  ■ NOTICE ■
                  The adjustment must be performed with the engine running. Therefore, apply the parking brake, depress the brake pedal, move the shift lever to P, and take sufficient care that the vehicle does not move off.


                  1. Select "Function Inspection/Adjustment" on the service inspection screen to display the function inspection/adjustment screen.

                  2. Select "Camera Optical Axis Adjustment" on the function inspection/adjustment screen to display the steering angle adjustment screen.




                3. Steering Angle Adjustment

                  □ HINT □
                  1. If "Checking Vehicle Speed" (displayed in red) is displayed in part A, check the DTCs of the HDD navigation system and take action according to the output code. (see)
                  2. If "Vehicle Speed Input OK" is displayed in part A, the vehicle speed signal is being input normally, so perform steering angle adjustment.
                  3. If the vehicle speed signal has not been input, part A displays "Checking Vehicle Speed" with a red background.
                  4. If "Checking Vehicle Speed" (displayed in red) is displayed in part A, the screen does not switch even if "Maximum Steering Angle Memory" or "Next" is selected.
                  5. If "Checking Vehicle Speed" (displayed in red) is displayed in part A, touch "Checking Vehicle Speed" (changes from red to orange) and then perform steering angle adjustment.


                  1. Check that the steering wheel is in the position for driving the vehicle straight ahead (approximately straight, ±5 degrees or less as a guide), and select "Steering Angle Neutral Point Memory".

                  2. After memorizing the steering angle neutral point, turn the steering wheel to the left until it stops, then to the right until it stops, and press "Maximum Steering Angle Memory". (Right may be done first)

                  3. At the moment it is pressed, a confirmation beep is output, the steering angle adjustment values (steering angle neutral point and maximum steering angle) are stored, and the screen switches to the camera optical axis adjustment screen.

                    □ HINT □
                    1. The adjustment values are not stored until the beep finishes sounding.
                    2. If all input signals are being input normally, the screen automatically switches to the camera optical axis adjustment screen after the maximum steering angle is memorized.
                    3. If steering angle adjustment has not been performed or "Checking Vehicle Speed" (displayed in red) is displayed in part A, selecting "Next" is not accepted.
                    4. Even if no DTC is detected, selecting "Maximum Steering Angle Memory" may not be accepted due to a steering sensor malfunction.
                    5. If selecting "Maximum Steering Angle Memory" is not accepted, replace the steering sensor. (see)




                4. Camera Optical Axis Adjustment

                  □ HINT □
                  1. If the back door is open, "Back door is open. Close the back door before use." is displayed and camera optical axis adjustment cannot be performed.
                  2. If "Back door is open. Close the back door before use." is displayed even though the back door is closed, perform inspection according to Troubleshooting Flowchart ["Back door is open. Close the back door before use." is Displayed Even when Back Door is Closed]. (see)
                  3. When performing only steering angle adjustment, camera optical axis adjustment is not necessary, so select "Next".
                  4. Do not touch the screen except for "Next".




                5. Confirmation Screen

                  □ HINT □
                  1. When performing only steering angle adjustment, camera optical axis adjustment is not performed, so select "Complete".
                  2. When "Complete" is selected, a confirmation beep sounds and the screen changes to the function inspection/adjustment screen.
                  3. The adjustment values are not stored until the beep finishes sounding.

                6. Diagnosis Cancellation

                7. Steering Angle Adjustment Check

                  □ HINT □
                  If the steering angle adjustment was performed, check the steering angle adjustment on the back guide monitor screen after canceling diagnosis.


                  1. On the back guide monitor screen, check that the estimated course line moves in conjunction with the steering wheel until the steering wheel is turned fully to the left or right.

                    □ HINT □
                    If the estimated course line stops moving before the steering wheel is turned fully to the left or right, the steering angle adjustment value has not been stored correctly, and adjustment must be performed again.
