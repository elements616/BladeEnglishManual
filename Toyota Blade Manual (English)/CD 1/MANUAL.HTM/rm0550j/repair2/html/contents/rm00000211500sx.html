DTC P1604 Poor Starting

Print

Preparation List


Circuit Description


The DTC is output when the engine does not start or takes a long time to start even though the STA signal is input. The freeze frame data, which stores the conditions when the DTC was output, can be checked using TaSCAN. Serviceability is improved by making it possible to check the engine operating condition at the time of poor starting using the freeze frame data. Also, since poor starting caused by running out of fuel is also detected, it is necessary to check whether the vehicle has run out of fuel before starting work.


DTC No.
SAE
DTC Detection Conditions
1. Diagnosis conditions 2. Malfunction status 3. Malfunction duration 4. Other
P1604
  1. STA signal ON
  2. Engine speed less than 500r/min
  3. 7 seconds or more (at engine coolant temperature of 20°C)
  4. 1 trip
