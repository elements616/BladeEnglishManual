Heater & Air Conditioner System DTC Check / Clear

Print



  1. DTC Check (Reading Using TaSCAN)

    1. With the IG OFF, connect SST (TaSCAN) to DLC3.

      SST
      09991-70200  

    2. Turn IG ON.

    3. Following the TaSCAN screen instructions, display the [Diagnosis Menu] → [Body] → [A/C] screen and select [DTC/Freeze Data].

    4. Check the diagnostic trouble codes.



    1. Clearing DTC Memory (Clearing Using TaSCAN)

      1. With the IG OFF, connect SST (TaSCAN) to DLC3.

        SST
        09991-70200  

      2. Turn IG ON.

      3. Following the TaSCAN screen instructions, display the [Diagnosis Menu] → [Body] → [A/C] screen and select [DTC/Freeze Data].

      4. Select [Clear] on the screen to clear the data.
