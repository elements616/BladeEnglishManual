Television Camera Controller Installation

Print

Preparation List



1. Install Television Camera Controller



  1. Install the television camera controller with the 2 bolts.

  2. Connect the connectors.



2. Install Front Seat Assembly RH (Power Seat Type)

  1. Place the front seat assembly RH in the vehicle, and align the adjuster pins with the holes on the vehicle side.

  2. Connect the connectors.

  3. Connect the battery negative terminal.

    Standard
    T = 5.4 N/m{ 55 kgf/cm }

  4. Operate the power seat switch knob (for slide & vertical) to move the front seat assembly RH to the rearmost position.

    ■ NOTICE ■
    Check that it is locked.




  5. Temporarily install the front side of the front seat assembly RH with the 2 bolts.

  6. Operate the power seat switch knob (for slide & vertical) to move the front seat assembly RH to the frontmost position.

    ■ NOTICE ■
    Check that it is locked.




  7. Temporarily install the rear side of the front seat assembly RH with the 2 bolts.

  8. Tighten the 2 rear side bolts of the front seat assembly RH in the order of inner → outer.

    Standard
    T = 37 N/m{ 377 kgf/cm }

  9. Operate the power seat switch knob (for slide & vertical) to move the front seat assembly RH to the rearmost position.

    ■ NOTICE ■
    Check that it is locked.

  10. Tighten the 2 front side bolts of the front seat assembly RH.

    Standard
    T = 37 N/m{ 377 kgf/cm }

  11. Operate the power seat switch knob (for slide & vertical) to move the front seat assembly RH to the frontmost position.

    ■ NOTICE ■
    Check that it is locked.



3. Install Seat Track Bracket Cover Inner RH (Power Seat Type)



  1. Engage the 2 claws to install the seat track bracket cover inner RH.



4. Install Seat Track Cover Outer RH (Power Seat Type)



  1. Engage the 2 claws to install the seat track bracket cover outer RH.



5. Install Seat Track Bracket Cover Inner Front RH (Power Seat Type)

  1. Operate the power seat switch knob (for slide & vertical) to move the front seat assembly RH to the rearmost position.

    ■ NOTICE ■
    Check that it is locked.




  2. Engage the 3 claws to install the seat track bracket cover inner front RH.



6. Install Seat Track Bracket Cover Outer Front RH (Power Seat Type)



  1. Engage the 3 claws to install the seat track bracket cover outer front RH.



7. Install Front Seat Assembly RH (Manual Seat Type)

  1. Place the front seat assembly RH in the vehicle, and align the adjuster pins with the holes on the vehicle side.

  2. Operate the seat track handle to move the front seat assembly RH to the rearmost position.




  3. Temporarily install the front side of the front seat assembly RH with the 2 bolts.

  4. Operate the seat track handle to move the front seat assembly RH to the frontmost position.




  5. Temporarily install the rear side of the front seat assembly RH with the 2 bolts.

  6. Tighten the 2 rear side bolts of the front seat assembly RH in the order of inner → outer.

    Standard
    T = 37 N/m{ 377 kgf/cm }

  7. Operate the seat track handle to move the front seat assembly RH to the rearmost position.

  8. Tighten the 2 front side bolts of the front seat assembly RH.

    Standard
    T = 37 N/m{ 377 kgf/cm }

  9. Connect the connectors.



8. Slide Adjuster Lock Synchronization Inspection (Manual Seat Type)

  1. Check that the left and right adjusters lock at the same time when the seat is slid.

  2. If the slide is not synchronized, loosen the seat set bolts and adjust.



9. Install Seat Track Bracket Cover Inner RH (Manual Seat Type)

  1. Operate the seat track handle to move the front seat assembly RH to the frontmost position.




  2. Insert the guide

  3. Engage the claws to install the seat track bracket cover inner RH.



10. Install Seat Track Cover Outer RH (Manual Seat Type)



  1. Engage the 2 claws to install the seat track cover outer RH.



11. Install Seat Track Bracket Cover Inner Front RH (Manual Seat Type)

  1. Operate the seat track handle to move the front seat assembly RH to the rearmost position.




  2. Engage the 3 claws to install the seat track bracket cover inner front RH.



12. Install Seat Track Bracket Cover Outer Front RH (Manual Seat Type)



  1. Engage the 3 claws to install the seat track bracket cover outer front RH.
