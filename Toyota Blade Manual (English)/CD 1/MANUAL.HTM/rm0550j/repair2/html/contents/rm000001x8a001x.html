Headlight Assembly LH Reassembly

Print


1. Install Headlight Unit LH


2. Install Headlight Gasket (Discharge Headlight Type)

  1. Install a new headlight gasket.



3. Install Headlight Light Control Computer Assembly LH (Discharge Headlight Type)

  1. Connect the connector and pass the socket of the headlight light control computer assembly LH through the headlight assembly LH.

    ■ NOTICE ■
    Be careful not to damage the reflector and headlight housing.




  2. Install the headlight light control computer assembly LH with the 4 screws.



4. Install Clearance Light Socket


5. Install Clearance Light Bulb

  1. Install the clearance light bulb to the clearance light socket.




  2. Turn in the direction indicated by the arrow in the illustration and install the clearance light bulb together with the clearance light socket.



6. Install Front Turn Signal Light Socket


7. Install Front Turn Signal Light Bulb

  1. Install the front turn signal light bulb to the front turn signal light socket.




  2. Turn in the direction indicated by the arrow in the illustration and install the front turn signal light bulb together with the front turn signal light socket.



8. Install Headlight NO.2 Bulb



  1. Turn the headlight bulb NO.2 in the direction indicated by the arrow in the illustration and install it.



9. Install Headlight NO.1 Bulb (Halogen Headlight Type)



  1. Turn the headlight bulb NO.1 in the direction indicated by the arrow in the illustration and install it.



10. Install Discharge Headlight Bulb (Discharge Headlight Type)



  1. In the order shown in the illustration, lock the set spring and install the discharge headlight bulb.




  2. Turn in the direction indicated by the arrow in the illustration and connect the socket of the headlight light control computer assembly LH.



11. Install Headlight Cover (Discharge Headlight Type)



  1. Turn the headlight cover in the direction indicated by the arrow in the illustration and install it.
