DTC B2325 Door System LIN Bus Malfunction

Print

Preparation List


Circuit Description


The instrument panel junction block assembly (main body ECU) detects door bus errors; it performs 1 error detections in 2.6 seconds, and outputs this code when an error is detected 3 times in a row (7.8 seconds).


DTC No.
DTC Detection Condition
Inspection Area

    (LIN communication line malfunction)

Inspection Procedure


□ HINT □
  1. When using the TaSCAN with the IG OFF, repeatedly turn any door courtesy light switch ON and OFF (at intervals of 1.5 seconds or less) until communication between the TaSCAN and the vehicle starts.
  2. When the main body ECU is replaced with a new one and the battery negative terminal is reconnected, it enters the IG ON state. Also, when the battery is removed and reinstalled, it returns to the state it was in when the battery was removed.
