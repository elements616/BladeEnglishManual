DTC U1002 Sub-network Communication Malfunction (CAN Gateway)

Print

Preparation List


Function Description


The CAN gateway ECU outputs the code when it cannot receive data from any of the V bus No.2 connected ECUs whose connection is stored in memory.


DTC No.
DTC Detection Condition
DTC Output Related Items
U1002
Data cannot be received from any of the ECUs whose connection is stored in the CAN gateway ECU memory
  1. CAN V bus No.2 main line open or short circuit
  2. V bus No.2 branch wire open or short circuit
  3. Poor connector terminal contact or contact pressure
  4. CAN J/C internal short or open circuit
  5. Network gateway computer (CAN gateway ECU) internal malfunction

Inspection Procedure


■ NOTICE ■
  1. When measuring the resistance of the CAN bus, turn the IG OFF, confirm that warning functions such as the key reminder warning system are not operating, and leave the vehicle for 1 minutes or more without operating the key or switches or opening/closing the doors before starting measurement. If it is necessary to open a door during inspection, open it beforehand.
  2. The following flowchart applies only when output by the CAN gateway ECU (V bus No.2 monitoring ECU). (If the main body ECU outputs U1002,)


□ HINT □
  1. When inspecting each connector, before disconnecting it, push the connector case in the connecting direction and check that the connector is not loose or disconnected.
  2. When disconnecting a connector, check that the connector terminals and connector case are free of damage, deformation, corrosion, etc.
