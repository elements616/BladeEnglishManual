Front Suspension Crossmember Sub-assembly Installation

Print

Preparation List



1. Install Steering Link Assembly



  1. Install the steering link assembly to the front suspension crossmember with the 2 nuts and 2 bolts.

    ■ NOTICE ■
    Hold the nut and turn the bolt.

    Standard
    T = 138 N/m{ 1410 kgf/cm }



2. Install Stabilizer Bar FR


  1. Install the front stabilizer bar to the front suspension crossmember with the identification paint on the right side of the vehicle.





3. Install Front Suspension Member Brace FR LH



  1. Install the front suspension member brace FR LH with the 4 bolts.

    Standard
    T = 87 N/m{ 887 kgf/cm }

    ■ NOTICE ■
    1. Tighten the bolts in the following order: A: temporarily tighten → B: fully tighten → C: fully tighten → D: fully tighten → A: fully tighten.
    2. After installing the front suspension member brace FR LH, check that the protrusion of front stabilizer bar bushing No. 1 is sticking out.



4. Install Front Suspension Member Brace FR RH

□ HINT □
Use the same procedure for the RH side as for the LH side.



5. Temporarily Tighten Front Suspension Arm Sub-assembly Lower NO.1 LH



  1. Temporarily tighten front suspension lower arm NO.1 LH to the front suspension crossmember with the 2 bolts and nut.

    ■ NOTICE ■
    Turn bolt A while holding nut B in place.



6. Temporarily Tighten Front Suspension Arm Sub-assembly Lower NO.1 RH

□ HINT □
Use the same procedure for the RH side as for the LH side.



7. Install Front Suspension Crossmember Sub-assembly



  1. Support the front suspension crossmember with a high mission jack or equivalent.

  2. While alternately inserting SST into the reference holes on the RH and LH sides of the front suspension crossmember, tighten the A2 bolts on the RH and LH sides, and lower the mission jack.

    SST
    09670-00020  
    Standard
    T = 145 N/m{ 1479 kgf/cm }



  3. Tighten the B2 bolts and C2 nuts to the specified torque in several steps.

    Standard
    T = 95 N/m{ 969 kgf/cm }





8. Install Front Suspension Member Brace Rear LH



  1. Install the front suspension member brace rear LH with the 3 bolts.

    Standard
    Bolt A
    T = 145 N/m{ 1479 kgf/cm }
    Bolt B
    T = 93 N/m{ 948 kgf/cm }



9. Install Front Suspension Member Brace Rear RH

□ HINT □
Use the same procedure for the RH side as for the LH side.



10. Install Front Suspension Member Reinforcement LH



  1. Install the front suspension member reinforcement LH with the 4 bolts.

    Standard
    T = 96 N/m{ 979 kgf/cm }

    ■ NOTICE ■
    Tighten the bolts in the following order: A: temporarily tighten → B: temporarily tighten → C: fully tighten → B: fully tighten → D: fully tighten → A: fully tighten.



11. Install Front Suspension Member Reinforcement RH

  1. Use the same procedure for the RH side as for the LH side.



12. Install Engine Front Mounting Bracket Reinforcement Lower



  1. Install the engine front mounting bracket reinforcement lower with the 2 bolts.

    Standard
    T = 96 N/m{ 979 kgf/cm }



13. Connect Front Suspension Arm Sub-assembly Lower NO.1 LH



  1. Push down front suspension lower arm No.1 LH to install the front lower ball joint LH, and tighten the bolt and 2 nuts.

    Standard
    T = 89 N/m{ 908 kgf/cm }



14. Connect Front Suspension Arm Sub-assembly Lower NO.1 RH

□ HINT □
Use the same procedure for the RH side as for the LH side.



15. Connect Front Stabilizer Link Assembly LH



  1. Connect the front stabilizer link assembly LH to the front stabilizer bar with the nut.

    Standard
    T = 74 N/m{ 755 kgf/cm }

    □ HINT □
    Hold the stud bolt using a socket hexagon wrench 6 so that it does not turn freely.



16. Connect Front Stabilizer Link Assembly RH

□ HINT □
Use the same procedure for the RH side as for the LH side.



17. Connect Tie Rod End Sub-assembly LH



  1. Connect the tie rod end LH to the steering knuckle and install it with the castle nut.

    Standard
    T = 49 N/m{ 500 kgf/cm }

    ■ NOTICE ■
    When aligning the cotter pin hole after tightening the castle nut, tighten the nut further within 60°.

  2. Install the cotter pin.



18. Connect Tie Rod End Sub-assembly RH

□ HINT □
Use the same procedure for the RH side as for the LH side.



19. Install Engine Under Cover Rear LH

  1. Install the engine under cover rear LH with the 5 clips.



20. Install Engine Under Cover Rear RH

□ HINT □
Use the same procedure for the RH side as for the LH side.



21. Install Engine Under Cover NO.2

  1. Install engine under cover NO.2 with the 5 clips.



22. Install Engine Under Cover NO.1

  1. Install engine under cover NO.1 with the 6 bolts and 7 clips.



23. Check Front Tires Straight-ahead Position


24. Connect Steering Column Hole Cover Sub-assembly NO.1



  1. Insert clip A, hook clip B onto the top surface of the panel, and connect the steering column hole cover to the floor panel.



25. Connect Steering Intermediate Shaft Assembly NO.2



  1. Align the matchmarks and connect steering intermediate shaft assembly No.2 to the steering intermediate shaft.




  2. Install the bolt.

    Standard
    T = 35 N/m{ 360 kgf/cm }



26. Install Column Hole Cover Silencer Sheet



  1. Install the column hole cover silencer sheet with the 2 clips.

  2. Put the floor carpet back in place.



27. Install Front Tire


28. Stabilize Suspension


29. Fully Tighten Front Suspension Arm Sub-assembly Lower NO.1 LH



  1. Using SST, fully tighten the bolts.

    SST
    09961-01270  
    Standard
    Torque
    T = 233 N/m{ 2376 kgf/cm }
    When using SST + torque wrenchL600mm
    T = 175 N/m{ 1784 kgf/cm }

  2. Fully tighten bolt A.

    Standard
    T = 233 N/m{ 2376 kgf/cm }

    ■ NOTICE ■
    1. Tighten bolt A while holding the nut in place.
    2. Using a 4-post lift, place the vehicle with the tires on the ground.
