DTC P0504/51 STP Light SW System

Print

Preparation List


Circuit Description


  1. The stop light switch detects the brake pedal operating condition and outputs it to the engine control computer. The stop light switch is installed on the brake pedal bracket, and is connected to the engine control computer via the wire harness.

□ HINT □
Using SST (TaSCAN), read the freeze frame data. The freeze frame data records part of the engine operating condition when the malfunction occurred, and this information is useful when troubleshooting.
