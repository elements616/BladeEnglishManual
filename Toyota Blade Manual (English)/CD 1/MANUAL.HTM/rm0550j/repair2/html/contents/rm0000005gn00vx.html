Steering Lock System ECU Data Monitor / Active Test

Print



  1. ECU Data Monitor

    1. Using SST (TaSCAN), the input, communication and operating status of the steering lock ECU can be read.

      SST
      09991-70200  


      1. Connect SST (TaSCAN) to DLC3 and turn the IG ON.

      2. On the SST (TaSCAN) screen, select [Diagnosis] → [System Diagnosis/Body] → [System Name/Certification ECU (Steering Lock)] → [ECU Data], and select the item to be checked.

        ■ NOTICE ■
        1. Since the steering lock ECU responds to SST (TaSCAN) via the CAN communication function of the certification ECU, monitoring may not be performed normally if there is a malfunction in CAN communication or the certification ECU.
        2. When checking diagnostic trouble codes or data monitor related to the smart entry & start system from the IG OFF state, the main body may not respond unless any door is opened to cancel its sleep state.
