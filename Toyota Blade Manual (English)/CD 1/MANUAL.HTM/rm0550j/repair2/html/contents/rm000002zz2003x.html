Fusible Link Block Assembly (Engine Type 2GR-FE) Installation

Print

Preparation List



1. Install Fusible Link Block Assembly



  1. Connect the 3 wire harnesses to the fusible link block assembly with the 3 bolts (M5).

  2. Connect the 2 connectors to the fusible link block assembly.




  3. Connect the 2 wire harnesses to the fusible link block assembly with the 2 bolts (M6).

    Standard
    T = 5.4 N/m{ 55 kgf/cm }




  4. Engage the claw and install the fuse holder to the fusible link block assembly.

  5. Install the bolt (M6).

    Standard
    T = 5.4 N/m{ 55 kgf/cm }




  6. Engage the 4 claws and install the fuse holder and fusible link block assembly.




  7. Engage the 10 claws and assemble the upper side and lower side of the fuse block cover.

    ■ NOTICE ■
    Assemble securely so that the wire harness is not pinched.



2. Install Engine Room Relay Block



  1. Engage the guide and claw of the relay block.

  2. Install the 3 bolts.

    Standard
    T = 8.4 N/m{ 86 kgf/cm }

  3. Clamp the harness.



3. Install Front Fender Liner LH



  1. Install the front fender liner LH with the pin hold clip and 4 clips.



4. Connect Wire Harness



  1. Connect the wire harness with the 2 nuts, 4 connectors and 2 clamps.

    Standard
    T = 8.4 N/m{ 86 kgf/cm }



5. Install Relay Block Cover UPR NO.1


6. Install Engine Control Computer



  1. Install the engine control computer bracket with the 4 screws.




  2. Connect the clamp and install the engine control computer with the 2 bolts.

    Standard
    T = 8.0 N/m{ 82 kgf/cm }




  3. Connect the 2 engine control computer connectors to the engine control computer.

    ■ NOTICE ■
    1. When connecting the connectors, be careful not to allow foreign matter such as mud or water to adhere to the connecting parts.

    1. Securely lock the lever.



7. Install Air Cleaner Case



  1. Install the air cleaner case with the 3 bolts.

    Standard
    T = 7.0 N/m{ 71 kgf/cm }

  2. Connect the clamp.



8. Install Air Cleaner Cap w/ Air Cleaner Hose



  1. Install the hinge portion first, and then install the air cleaner cap w/ air cleaner hose with the 3 clamps.

  2. Install the clamp hose band. (*1)

  3. Connect ventilation hose No.2. (*2)

  4. Connect the air flow meter connector. (*3)



9. Install Battery

  1. Install the battery to the vehicle

  2. Install the insulator.




  3. Connect the current sensor connector.




  4. Install the battery clamp with the bolt and nut.

    Standard
    T = 17 N·m{ 173 kgf·cm } (Bolt)
    T = 5.0 N·m{ 51 kgf·cm } (Nut)

  5. Connect the battery positive terminal with the nut.

    Standard
    T = 13 N·m{ 130 kgf·cm } (Nut)



10. Connect Battery Negative Terminal
Standard
T = 5.4 N/m{ 55 kgf/cm }


11. Install Radiator Upper Air Deflector



  1. Install the radiator upper air deflector with the 9 clips.



12. Install V-bank Cover Sub-assembly



  1. Engage the 3 clips to install the V-bank cover.

    ■ NOTICE ■
    1. Make sure the clips are securely engaged.
    2. Engaging them with excessive force or striking the top of the clips may cause damage.
