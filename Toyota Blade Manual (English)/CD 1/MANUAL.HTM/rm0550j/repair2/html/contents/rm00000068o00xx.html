  1. Large-scale Body Multiplex Communication System (LIN) Function Description

    1. The LIN communication line is used to control the computers connected to the power window system, Smart Entry & Start System and engine immobiliser system. If communication on the line becomes impossible for any reason, a function that outputs DTCs for that circuit from each ECU and a fail-safe function that ensures minimum performance and system protection for each ECU operate.
