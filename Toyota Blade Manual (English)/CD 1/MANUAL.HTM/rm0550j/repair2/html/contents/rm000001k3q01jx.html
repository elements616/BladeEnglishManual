Electric Power Steering System Special Operation/Control History

Print



  1. Special Control History

    1. Turn IG OFF.

    2. Connect SST (TaSCAN) to DLC3.

      SST
      09991-70201  

    3. Turn the ignition ON, select "Diagnosis" → "Chassis" → "Electric Power Steering" → "Special Control History" on the SST (TaSCAN) display screen, and check the history.

      Special Control History 
      Item
      (TaSCAN Display)
      		Item Description
      Overheat Prevention Control History
      [REC1]
      		Indicates whether there is overheat prevention control history
      Display: None/Yes
      PIG Power Supply Voltage Drop History
      [REC3]
      		Indicates whether there is PIG power supply voltage drop history
      Display: None/Yes
      Engine Speed Signal Loss History
      [REC4]
      		Indicates whether there is engine speed signal loss history
      Display: None/Yes
      Steering Angle Sensor Signal Loss History
      [REC5]
      		Indicates whether there is steering angle sensor signal loss history
      Display: None/Yes
      Vehicle Speed Signal Invalid History
      [REC6]
      		Indicates whether there is vehicle speed signal invalid history
      Display: None/Yes
      Battery Voltage Drop History
      [BLH]
      		Indicates the number of battery voltage drop history events
      Display range: 0 to 65535 times

      □ HINT □
      1. If the steering wheel is turned repeatedly while the vehicle is stopped or driven at low speed, or if the steering wheel is held fully turned for a long time, the power assist may be reduced to prevent the motor and computer from overheating. In this case, the system returns to normal if the steering wheel is not operated for approximately 10 minutes with the engine idling.
      2. If the battery is insufficiently charged or the voltage drops temporarily, the power assist may be reduced or the P/S warning light may come on. In this case, the system returns to normal when the battery voltage recovers.
      3. If "Battery Voltage Drop History" displays a value other than "0", inspect the charging system. (see[2AZ-FE models],see [2GR-FE models])
