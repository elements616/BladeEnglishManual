Steering Column Assembly Inspection

Print

Preparation List



1. Inspect Preload

  1. Secure the steering column assembly in a vise with aluminum plates.

    ■ NOTICE ■
    Do not overtighten the vise.




  2. Using SST and a torque wrench, measure the preload of the steering column assembly.

    SST
    09616-00011  
    Standard
    T = 0.8 to 1.2 N/m{ 8.2 to 12.2 kgf/cm }

    □ HINT □
    If the result is not as specified, replace the steering column assembly.
