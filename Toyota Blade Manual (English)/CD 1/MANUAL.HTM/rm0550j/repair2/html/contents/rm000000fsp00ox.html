CVT System [Super CVT-i] (K112/K112F) Inspection for Intermittent Problems

Print



  1. Wire Harness and Connector Momentary Interruption Check

    □ HINT □
    If the malfunctioning system is identified by the DTC output in the DTC (check mode) inspection, narrow down the malfunctioning area using the following method.

    1. Using SST (TaSCAN), following the screen display, display the [Diagnosis Menu/TCCS] screen.

      SST
      09991-70200  

    2. Select [Mode Change] and switch to check mode.

    3. After reading the DTCs in check mode, clear the DTC memory.

    4. Select check mode and start the engine.

    5. With the engine idling, wiggle the wire harnesses and connectors of the malfunctioning system output in the DTC (check mode) inspection.

    6. If the check engine warning light illuminates, there may be a poor contact in the wire harness or connector at that location.

    7. After the inspection, be sure to select [Mode Change] and switch to normal mode.
