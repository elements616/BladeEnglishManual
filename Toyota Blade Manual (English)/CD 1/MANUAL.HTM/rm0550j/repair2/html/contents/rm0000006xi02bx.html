Step 3Service Inspection (DTC Check)



  1. Service Inspection

    1. Read the inspection result.

      Inspection Result
      		Meaning
      OK
      		No DTCs input (excluding communication diagnosis of each device via AVC-LAN)
      Replace
      		A DTC indicating that replacement is required has been input
      Check
      		A DTC indicating that diagnosis is required has been input
      Old Ver
      		Some DTC has been input in a device with old diagnosis specifications
      Not Connected
      		The device has been registered in the system at least once in the past, but there is no response when diagnosis is started
      No Response
      		There is a response when diagnosis is started, but no diagnosis information is returned
      Connected to AVC-LAN, but neither the device name nor the inspection result is displayed
      		There is no history of registration in the system, and there is no response when diagnosis is started

Step 5Individual Diagnosis



  1. Individual Diagnosis

    1. When the inspection result is "Replace", "Check" or "Old Ver", select this display to switch to the individual diagnosis screen.




    2. Check and record the contents of the output diagnostic trouble codes.

      Individual Diagnosis Screen Display Contents 
      Display
      		Meaning
      Device Name
      		Name of target device
      Category
      		Target logical address number
      Diagnostic Trouble Code (DTC)
      		Diagnostic Trouble Code (DTC)
      Current Status
      		Displays DTCs input during system inspection (up to 6 items)
      History
      		Displays diagnosis memory collection results and normal diagnosis notification contents (up to 6 items)
      Clear Diagnosis
      		Clears the diagnosis information of the target device and clears the display (press and hold for 3 seconds)
      Service Inspection
      		Returns to the "Service Inspection" screen

Step 8Clear DTC

    		Meaning
    Clear Diagnosis
