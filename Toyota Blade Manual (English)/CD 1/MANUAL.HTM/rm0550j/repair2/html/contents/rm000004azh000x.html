Multimedia Interface ECU Installation

Print


1. Install Multimedia Interface Computer


2. Install Multimedia Interface Bracket NO.1



  1. Install multimedia interface bracket No.1 with the 2 screws.



3. Install Multimedia Interface Computer Assembly w/ Bracket

  1. Connect the connectors.




  2. Insert the 2 guides and install the multimedia interface computer assembly w/ bracket with the 2 bolts.



4. Air Conditioner Control Assembly Installation



  1. Connect the connector.

  2. Engage the 4 clips and install the air conditioner control assembly.



5. Install Navigation Receiver Assembly w/ Bracket

  1. Connect the connectors.




  2. Engage the 4 clips and temporarily install the navigation receiver assembly w/ bracket.




  3. Install the navigation receiver assembly w/ bracket with the 4 bolts.



6. Install Instrument Cluster Finish Panel Assembly Center NO.1



  1. Engage the 6 clips and 4 claws.




  2. Install instrument cluster finish panel assembly center No.1 with the 2 screws <C>.



7. Install Position Indicator Housing Assembly

  1. Connect the connector.




  2. Engage the 9 claws and install the position indicator housing assembly.



8. Install Box Panel NO.2

  1. Connect the connectors.




  2. Engage the 2 claws and 4 clips to install box panel No.2.



9. Install Shift Lever Knob



  1. Turn the shift lever knob in the direction of the arrow shown in the illustration to install it.



10. Install Instrument Panel Register Assembly CTR



  1. Connect the connector.




  2. Engage the 2 clips, 5 claws and 3 guides, and install the instrument panel register assembly CTR.



11. Install Instrument Panel Finish Panel End RH



  1. Engage the 4 clips and install the instrument panel finish panel end RH.



12. Install Instrument Panel Finish Panel End LH



  1. Engage the 4 clips and install the instrument panel finish panel end LH.
