Steering Pad Switch Assembly (4-spoke Steering Wheel) Installation

Print

Preparation List



1. Install Steering Pad Switch Assembly



  1. Steering pad switch RH side

    1. Engage the 2 pins.

    2. Install the steering pad switch RH side with the screw.

    3. Route the harness of the steering pad switch RH side under the clamp.




  2. Steering pad switch LH side

    1. Engage the 2 pins.

    2. Install the steering pad switch LH side with the screw.

    3. Route the harness of the steering pad switch LH side under the clamp.

  3. Connect the connector to the spiral cable.



2. Install Horn Button Assembly



  1. Connect the horn connector to the horn button assembly.

  2. Connect the airbag connector to the horn button assembly and lock it securely.

    ■ NOTICE ■
    Securely lock the airbag connector.




  3. Using a torx socket wrench (T30), install the horn button assembly to the steering wheel assembly with the 2 torx bolts.

    Standard
    T = 8.8 N/m{ 90 kgf/cm }



3. Install Steering Wheel Cover Lower NO.3



  1. Engage the claws and install the steering wheel cover lower No.3.



4. Install Steering Wheel Cover Lower NO.2



  1. Engage the claws and install the steering wheel cover lower No.2.



5. Connect Battery Negative Terminal
Standard
T = 5.4 N/m{ 55 kgf/cm }
