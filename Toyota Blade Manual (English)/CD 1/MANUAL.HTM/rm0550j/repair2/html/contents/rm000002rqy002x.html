Airbag Computer Assembly Installation

Print

Preparation List



1. Install Airbag Computer Assembly

  1. Make sure that the ignition switch is OFF.

  2. Check that the battery negative terminal is disconnected.

    ■ WARNING ■
    1. If work is performed without disconnecting the negative battery terminal, the airbag may deploy even if only the airbag computer assembly itself receives an impact, so be sure to check that the cable is disconnected from the negative battery terminal before performing the work.
    2. After disconnecting the battery negative terminal, do not start work for 90 seconds.




  3. Install the airbag computer assembly with the 3 bolts.

    Standard
    T = 18 N/m{ 184 kgf/cm }

    ■ NOTICE ■
    1. Do not reuse any part that has been dropped or subjected to a strong impact during work.
    2. When turning the IG ON for the first time after replacing the airbag computer assembly, make sure there is no one in the vehicle.
    3. Check that there is no looseness in the airbag computer assembly.

  4. Connect the connector to the airbag computer assembly.

    ■ NOTICE ■
    Check that the drip-proof sheet is not turned up or pinched.



2. Install Instrument Panel Finish Panel Lower NO.2



  1. Push in the direction of the arrow shown in the illustration to engage the 2 clips and guide.




  2. Install instrument panel finish panel lower No.2 with the 2 screws <C>.



3. Install Instrument Panel Finish Panel Lower NO.1



  1. Push in the direction of the arrow shown in the illustration to engage the 2 clips and guide.




  2. Engage the 4 claws and 2 guides.




  3. Install instrument panel finish panel lower No.1 with the 2 screws <C>.



4. Install Console Box Insert FR NO.2



  1. Insert the guide.

  2. Engage the 3 claws to install console box insert front No.2.



5. Install Console Box Insert



  1. Insert the guide.

  2. Engage the 3 claws and install the console box insert.



6. Install Instrument Panel Finish Panel LWR CTR



  1. Engage the 6 clips and 4 claws.




  2. Install the instrument panel finish panel LWR CTR with the 2 screws <C>.



7. Install Position Indicator Housing Assembly

  1. Connect the connector.




  2. Engage the 7 claws and install the position indicator housing assembly.



8. Install Instrument Panel Finish Panel End RH



  1. Engage the 4 clips and install the instrument panel finish panel end RH.



9. Install Instrument Panel Finish Panel End LH



  1. Engage the 4 clips and install the instrument panel finish panel end LH.



10. Install Instrument Panel Under Tray



  1. Engage the 4 claws and install the instrument panel under tray.



11. Install Box Bottom Mat


12. Install Console Box Assembly Rear



  1. Engage the 4 claws.




  2. Install the console box assembly RR with the 4 bolts and 2 screws.



13. Install Console Box Carpet



  1. Install the console box carpet.



14. Install Console Box Cover RR

  1. Connect the connectors.




  2. Engage the 4 clips to install the console box rear cover.



15. Install Shift Lever Knob



  1. Turn the shift lever knob in the direction of the arrow shown in the illustration to install it.
