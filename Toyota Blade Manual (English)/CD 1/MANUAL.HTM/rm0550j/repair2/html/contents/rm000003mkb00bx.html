Parking Brake Control Pedal Assembly Reassembly

Print

Preparation List



1. Install Parking Pedal Pad

  1. Install the parking pedal pad to the parking brake pedal.



2. Install Parking Brake Cable Assembly NO.1



  1. Install parking brake cable assembly No.1 to the parking brake control pedal assembly.

  2. Install the clip to parking brake cable assembly No.1.




  3. Bend the claw of the parking brake control pedal assembly.




  4. Temporarily install wire adjusting nut No.1 to parking brake cable assembly No.1.



3. Install Parking Brake Switch Assembly



  1. Install the parking brake switch assembly to the parking brake control pedal assembly with the screw.

    Standard
    T = 3.2 N/m{ 33 kgf/cm }
