Circuit Description


The front collision sensor circuit (front airbag sensor RH circuit and front airbag sensor LH circuit) consists of the airbag computer assembly, front airbag sensor RH and front airbag sensor LH.

The front airbag sensor RH and front airbag sensor LH detect impacts and send signals to the airbag computer assembly for airbag deployment judgment.

When a malfunction is detected in the front collision sensor circuit (front airbag sensor RH circuit and front airbag sensor LH circuit), DTC B161A is recorded in the airbag computer assembly.
