Power Window System DTC Check/Clear

Print



  1. Check DTC/(Read Using TaSCAN)

    1. With the IG OFF, connect SST (TaSCAN) to DLC3.

      SST
      09991-70200  

    2. Following the SST (TaSCAN) screen display, display the [Diagnosis] → [Body] → [Power Window SW] [D Seat Motor] [P Seat Motor] [RR Seat Motor] [RL Seat Motor] screen, and select [DTC/Freeze Data].

    3. Check the diagnostic trouble codes.

      □ HINT □
      DTCs are output even with the ignition switch OFF.



    1. Clear DTC Memory (Clear Using TaSCAN)

      1. With the IG OFF, connect SST (TaSCAN) to DLC3.

        SST
        09991-70200  

      2. Following the SST (TaSCAN) screen display, display the [Diagnosis] → [Body] → [Power Window SW] [D Seat Motor] [P Seat Motor] [RR Seat Motor] [RL Seat Motor] screen, and select [DTC/Freeze Data].

      3. Select [Clear] on the screen display to clear the data.

      4. Check the DTCs again, and confirm that the malfunction codes have been cleared and the normal code is displayed.

        ■ NOTICE ■
        If a malfunction code is output, repair again according to the code.
