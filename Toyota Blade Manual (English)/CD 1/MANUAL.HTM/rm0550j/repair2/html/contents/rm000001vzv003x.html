Rear Seat Outer Belt Assembly Center Installation

Print

Preparation List



1. Install Rear Seat Outer Belt Assembly Center



  1. Install the rear seat outer belt assembly center with the nut.

    Standard
    T = 41 N/m{ 420 kgf/cm }



2. Install Separate Type Rear Seatback Cover RH



  1. Using hog ring pliers, install the front side of the separate type rear seatback cover RH with 10 new hog rings.




  2. Using hog ring pliers, install the back side of the separate type rear seatback cover RH with 8 new hog rings.



3. Install Rear Seat Headrest Support

  1. Temporarily install the separate type rear seatback cover w/ pad to the rear seatback frame sub-assembly RH.




  2. Engage the 4 claws and install the 2 rear seat headrest supports.



4. Install Rear Seatback Board Carpet Assembly RH

  1. Temporarily install the rear seatback board carpet assembly RH to the rear seatback frame sub-assembly RH.




  2. Install the rear seatback board carpet assembly RH with each J hook.




  3. Install the 2 clips.




  4. Install the 2 clips.



5. Install Rear Seatback Cover



  1. Engage the 4 claws and install the rear seatback cover.



6. Install Rear Seatback Lock Cover RH



  1. Install the rear seatback lock cover RH with the 2 screws.



7. Install Rear Seat Shoulder Belt Hole Cover



  1. Engage the 4 claws and install the rear seat shoulder belt hole cover.



8. Install Rear Seat Lock Control Lever w/ Base



  1. Engage the 2 claws and temporarily install the rear seatback lock control lever w/ base.

  2. Install the rear seatback lock control lever w/ base with the 3 screws.



9. Install Rear Seat Armrest Assembly CTR



  1. Install the bushing to the rear seatback assembly RH.




  2. Insert the rear seat armrest assembly CTR onto the pin.

  3. Install the rear seat armrest assembly CTR with the bolt and bushing.

    Standard
    T = 8.0 N/m{ 82 kgf/cm }



10. Install Center Armrest Hinge Cover



  1. Engage the claws and install the center armrest hinge cover by sliding it as shown in the illustration.



11. Install Rear Seatback Assembly RH



  1. Using a Torx socket wrench T45, install the rear seatback assembly RH with the 2 Torx bolts and 2 bushings.

    Standard
    T = 18 N/m{ 184 kgf/cm }



12. Install Rear Seat Outer Belt Assembly Center



  1. Install the rear seat outer belt assembly center, rear seat inner belt assembly and washer with the bolt.

    Standard
    T = 41 N/m{ 420 kgf/cm }

    ■ NOTICE ■
    1. Pay attention to the installation direction of the floor anchor.
    2. Be careful that the floor anchor does not ride up onto the locator.



13. Install Rear Seat Assembly RH



  1. Set the rear seat assembly RH in the vehicle, and install the 2 rear side bolts in the order inner → outer.

    Standard
    T = 42 N/m{ 428 kgf/cm }




  2. Raise the seatback, and install the 2 front side bolts of the rear seat assembly RH in the order inner → outer.

    Standard
    T = 42 N/m{ 428 kgf/cm }



14. Install Rear Seat Cushion Hinge Cover NO.2



  1. Engage the 4 claws and install the rear seat cushion hinge cover NO.2.



15. Install Rear Seat Cushion Hinge Cover NO.1



  1. Engage the 4 claws and install the rear seat cushion hinge cover NO.1.



16. Install Rear Seat Headrest Assembly CTR


17. Install Rear Seat Headrest Assembly
