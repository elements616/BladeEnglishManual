  1. JEITA Standard Error Codes

    □ HINT □
    When a JEITA standard error code occurs, it is notified by an interrupt display on the multi-display.


    JEITA Standard Error Codes 
    Diagnostic Trouble Code (DTC)
    		Diagnosis Item
    		Possible Cause
    		Countermeasure
    01
    		ETC Card Insertion Error
    1. ETC card not inserted during communication
    2. ETC card improperly inserted
    		Check the insertion of the ETC card and insert it again
    Communication other than ETC, such as with a parking lot system, was performed without an ETC card inserted
    		Ask the customer whether a parking lot system etc. using ETC was used
    02
    		Data Processing Error
    1. ETC card read/write error
    2. Poor contact between ETC card and ETC on-board unit
    3. Momentary interruption while accessing ETC card
    4. Card removed during writing
    5. An IC card other than an ETC card is inserted
    1. If an ETC card was inserted, insert it again; if the same error code is output, inspect the ETC on-board unit
    2. If the vehicle is directed (displayed) to stop at the toll gate, stop the vehicle and follow the attendant's instructions
    03
    		ETC Card Error
    1. ETC card is faulty
    2. A card other than an IC card is inserted and does not communicate
    3. ETC card inserted incorrectly (upside down, wrong insertion direction)
    		Check that the ETC card is correct and the insertion direction etc., and insert it again; if the same error code is output, contact the ETC card issuer
    04
    		On-board unit malfunction
    		The ETC on-board unit is judged to be faulty based on the self-diagnosis result
    		Start the engine again; if the same error code is output, inspect the ETC on-board unit
    05
    		ETC card information abnormal
    1. Authentication error with ETC card
    2. An IC card other than an ETC card is inserted
    3. ETC card removed during authentication
    4. ETC card inserted into ETC on-board unit that has not been set up
    		Check that the ETC card is correct and the insertion direction etc., and insert it again; if the same error code is output, inspect the ETC on-board unit
    Setup card was reinserted
    		Check whether the on-board unit has been set up
    A setup card with a different on-board unit management number was inserted
    		Check that the on-board unit management number is correct using the 3 items: setup card, setup application form and ETC on-board unit part number label
    06
    		On-board unit information abnormal
    		Authentication error with roadside antenna
    		An error occurred in data processing between the on-board unit and the toll gate, so follow the toll gate attendant's instructions
    07
    		Communication Error
    		Communication with roadside antenna ended prematurely
    		An error occurred in data processing between the on-board unit and the toll gate, so follow the toll gate attendant's instructions

      1. HDD Navigation System Diagnostic Trouble Code

        □ HINT □
        This DTC is displayed on the service inspection screen of the HDD navigation system.

        1. ETC

          □ HINT □
          1. Logical address 01: Communication control
          2. Logical address 87:ETC unit


          Service inspection screen display name: ETC, part name: toll collection (ETC) computer assembly, physical address: 530 
          Diagnostic Trouble Code (DTC)
          		Diagnosis Item
          		Diagnosis Description
          		Action
          		Remarks
          01-D1
          		Transmission malfunction
          1. The device that stored this code was disconnected from the system when ACC was ON
          2. The master device was disconnected when this code was stored
          1. Inspect the power supply system and AVC-LAN communication system W/H of the navigation receiver assembly
          2. Inspect the power supply system and AVC-LAN communication system W/H of the toll collection (ETC) computer assembly
          		This code may be stored even when no malfunction is found, depending on the battery condition or the power source waveform at engine start
          01-D6
          		Master Absent
          1. The master device was disconnected when this code was stored
          1. Inspect the power supply system and AVC-LAN communication system W/H of the navigation receiver assembly
          2. Inspect the power supply system and AVC-LAN communication system W/H of the toll collection (ETC) computer assembly
          		This code may be stored even when no malfunction is found, depending on the battery condition or the power source waveform at engine start
          01-D7
          		Connection Check Malfunction
          1. The component that stored this code has been disconnected from the system after the engine was started
          2. The master device was disconnected when this code was stored
          1. Inspect the power supply system and AVC-LAN communication system W/H of the navigation receiver assembly
          2. Inspect the power supply system and AVC-LAN communication system W/H of the toll collection (ETC) computer assembly
          		This code is stored when the navigation receiver assembly power turns OFF after the engine is started and 210 seconds elapse
          01-DC
          		Transmission Failure
          		Transmission to the component indicated by the sub-code has failed (this code may not be directly related to a malfunction)
          1. If the component indicated by the sub-code is also stored in other components, inspect the power supply system and AVC-LAN communication system W/H of the component indicated by the sub-code
          2. If this code is not recorded in other components, clear the DTC and monitor for a while
          		This code may be stored if the engine is started again 60 seconds after the engine was started
          01-DD
          		Master Reset (Momentary Interruption)
          		The master device was disconnected from the system after the engine was started
          1. Inspect the power supply system and AVC-LAN communication system W/H of the navigation receiver assembly
          2. If the malfunction occurs frequently, replace the navigation receiver assembly
          		This code may be stored if the engine is started again after the engine was started
          01-DF
          		Master Malfunction
          1. The component with a display became abnormal, and the master function switched to the audio component
          2. A malfunction occurred in communication between the sub-master (audio) device and the master
          1. Inspect the power supply system and AVC-LAN communication system W/H of the navigation receiver assembly
          2. Inspect the AVC-LAN communication system W/H between the navigation receiver assembly and the radio receiver assembly
          		This code is stored when the navigation receiver assembly power turns OFF after the engine is started and 210 seconds elapse
          01-E0
          		Registration Complete Notification Malfunction
          		The "registration complete notification" command from the master cannot be received
          		This code is an engineering diagnosis and is detected even when not directly related to a malfunction
          		This code may be stored even when no malfunction is found, depending on the battery condition or the power source waveform at engine start
          01-E3
          		Registration Request Transmission
          1. The master device was slow to start up at some time
          		This code is an engineering diagnosis and is detected even when not directly related to a malfunction
          		This code may be stored even when no malfunction is found, depending on the battery condition or the power source waveform at engine start
          01-E4

          		Multiple frame transmission terminated midway
          		This code is an engineering diagnosis and is detected even when not directly related to a malfunction
