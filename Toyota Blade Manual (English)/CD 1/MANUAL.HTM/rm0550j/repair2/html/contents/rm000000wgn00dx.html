Circuit Description


CAN (Controller Area Network) is a multiplex communication system for vehicles. It is a serial data communication system for real-time applications, and has excellent communication speed and malfunction detection functions. By combining the CANH bus line and the CANL bus line, CAN performs communication based on differential voltage.

□ HINT □
  1. Malfunctions on the CAN bus (communication lines) can be inspected from the DLC3 connector. (Except for an open circuit in the DLC3 branch line)
  2. Using TaSCAN, DTCs related to CAN communication can be checked.
  3. DLC3 is connected to the CAN communication lines, but CAN communication cannot detect malfunctions on the DLC3 branch line.
