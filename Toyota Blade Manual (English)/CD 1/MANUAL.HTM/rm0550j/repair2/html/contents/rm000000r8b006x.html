Circuit Description


  1. When the instrument panel junction block assembly (main body ECU) receives a door lock/unlock request signal, it drives the door lock motor of each seat to lock/unlock all doors.

■ NOTICE ■
  1. The power door lock system uses large-scale body multiplex communication. First, follow "How to Proceed with Troubleshooting" to perform the "communication function inspection" and confirm that there is no malfunction in the communication system before proceeding with troubleshooting.
