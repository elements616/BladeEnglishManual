Preparation List



1. Install Engine Mounting Insulator Front



  1. Install the engine mounting insulator FR with the 2 bolts.

    Standard
    T = 95 N/m{ 969 kgf/cm }




  2. Install the engine mounting insulator FR to the engine mounting bracket FR with the bolt and nut.

    Standard
    T = 145 N/m{ 1480 kgf/cm }



2. Install Engine Under Cover NO.1

  1. Install the engine under cover No.1 with the 6 bolts and 7 clips.
