ABS & Traction Actuator Assembly Installation

Print

Preparation List



1. Install ABS & Traction Actuator Assembly



  1. Install the brake actuator assembly to the brake actuator bracket assembly with the 4 bolts.

    Standard
    T = 5.4 N/m{ 55 kgf/cm }

    ■ NOTICE ■
    1. A new actuator is filled with brake fluid, so do not remove the hole plugs until the brake tubes are connected.
    2. Tighten the bolts in the order shown in the illustration.



2. Install Brake Actuator Assembly w/ Bracket



  1. Install the ABS & traction actuator assembly w/ bracket with the 3 nuts.

    Standard
    T = 19 N/m{ 194 kgf/cm }

    ■ NOTICE ■
    Tighten the nuts in the order shown in the illustration.

  2. Connect the brake tube w/ tube clamp and fuel tube w/ fuel tube clamp No.3 to the bracket.




  3. Using a union nut wrench 10mm, connect the 6 brake tubes to the ABS & traction actuator assembly.

    Standard
    Torque
    T = 15 N/m{ 153 kgf/cm }
    When using union nut wrench + torque wrenchL155mm
    T = 13 N/m{ 133 kgf/cm }




  4. Connect the vehicle wire harness to the brake actuator assembly, and push in the lock lever to lock it.

    ■ NOTICE ■
    1. Before connecting the vehicle wire harness, check that there is no water, oil or foreign matter on the connector surfaces (including the inside).
    2. After connecting the vehicle wire harness, check that the lock lever is securely engaged.



3. Install Wire Harness



  1. Connect the ground wire with the bolt.

    Standard
    T = 8.4 N/m{ 85 kgf/cm }




  2. Connect the ground wire with the bolt and clamp.

    Standard
    T = 8.4 N/m{ 85 kgf/cm }




  3. Connect the wire harness to the engine room junction block with the 2 nuts and 2 clamps.

    Standard
    T = 8.4 N/m{ 85 kgf/cm }

  4. Connect the connectors to the engine room junction block.




  5. Connect the engine control computer connector to the engine control computer with the clamp and lock lever.

    ■ NOTICE ■
    1. When installing the connector, be careful not to allow foreign matter such as mud or water to adhere to the connector connection.
    2. Securely lock the lever.



4. Install Air Cleaner Case



  1. Install the air cleaner case with the 3 bolts and clamp.

    Standard
    T = 7.0 N/m{ 71 kgf/cm }

  2. Install the air cleaner filter element.



5. Install Air Cleaner Cap w/ Air Cleaner Hose

  1. Install the hinge portion first, then install the air cleaner cap with the 3 clamps.




  2. Install air cleaner hose No.1 to the throttle body assembly and release the lock of air cleaner hose clamp No.1.

    ■ NOTICE ■
    1. Align the triangular projection of air cleaner hose No.1 with the throttle body bolt on the right front side of the vehicle.
    2. Align the position of air cleaner hose clamp No.1 using the triangular projection of air cleaner hose No.1 as a reference.




  3. Connect the clamp and intake air flow meter connector.




  4. Connect the fuel vapor feed hose and fuel vapor feed hose No.2 to vacuum switching valve assembly No.1.

  5. Connect the clamp and vacuum switching valve connector.

  6. Connect the ventilation hose.



6. Install Cowl Top Panel Outer



  1. Install the cowl top panel outer with the 8 bolts.

    Standard
    T = 8.8 N/m{ 90 kgf/cm }




  2. Bend the heater air duct splash shield seal No.2 and water guard plate RH as shown in the illustration, and engage each clamp.




  3. Engage the windshield deicer wire harness connector and 3 clamps, and attach them to the cowl top panel outer. (w/ Cold Area Specification)



7. Install Cowl Body Mounting Reinforcement RH



  1. Install the cowl body mounting reinforcement RH to the cowl top panel outer with the 3 bolts.

    Standard
    T = 8.8 N/m{ 90 kgf/cm }



8. Install Windshield Wiper Motor Assembly



  1. Install the windshield wiper motor assembly to the front wiper link assembly with the 3 bolts.

    Standard
    T = 5.4 N/m{ 55 kgf/cm }

  2. Connect the connector.

  3. Align the matchmarks and install the crank arm assembly of the windshield wiper link assembly to the windshield wiper motor assembly.




  4. Install the nut.

    Standard
    T = 17 N/m{ 175 kgf/cm }




  5. Apply Denso No. 50 grease to the crank arm pivot of the windshield wiper motor assembly.




  6. Connect the rod of the windshield wiper link assembly to the crank pivot of the windshield wiper motor assembly.



9. Install Windshield Wiper Motor & Link Assembly



  1. Install the windshield wiper motor & link assembly with the 2 bolts.

    Standard
    T = 5.5 N/m{ 56 kgf/cm }

  2. Connect the connector.



10. Install Cowl Top Ventilator Louver RH



  1. Engage the 5 claws and install the cowl top ventilator louver RH as shown in the illustration.



11. Install Front Side Panel Protector NO.1 RH



  1. Engage the pin and install the front side panel protector NO.1 RH.



12. Install Cowl Top Ventilator Louver LH



  1. Engage the 11 claws and install the cowl top ventilator louver LH as shown in the illustration.



13. Install Front Side Panel Protector NO.1 LH



  1. Engage the pin and install the front side panel protector NO.1 LH.



14. Install Hood to Cowl Top Seal



  1. Engage the 7 clips and install the hood to cowl top seal.



15. Connect Battery Negative Terminal
Standard
T = 5.4 N/m{ 55 kgf/cm }


16. Install Front Wiper Arm & Blade Assembly LH



  1. Stop the windshield wiper motor assembly at the automatic stop position.

  2. Using a round file or equivalent, clean the wiper arm serrations. (When reassembling)

  3. Using a wire brush, clean the wiper pivot serrations.




  4. Install the front wiper arm & blade assembly LH with the front wiper arm nut so that it is in the position shown in the illustration.

    Standard
    T = 26 N/m{ 265 kgf/cm }

    □ HINT □
    While holding the arm hinge by hand, tighten the front wiper arm nut.



17. Install Front Wiper Arm & Blade Assembly RH



  1. Using a round file or equivalent, clean the wiper arm serrations. (When reassembling)

  2. Using a wire brush, clean the wiper pivot serrations.




  3. Install the front wiper arm & blade assembly RH with the front wiper arm nut so that it is in the position shown in the illustration.

    Standard
    T = 26 N/m{ 265 kgf/cm }

    □ HINT □
    While holding the arm hinge by hand, tighten the front wiper arm nut.

  4. Operate the front wipers while spraying water or washer fluid on the glass, and check the wiping condition of the blades and that they do not interfere with the body.



18. Install Front Wiper Arm Head Cap



  1. Install the 2 front wiper arm head caps.



19. Install Engine Cover Sub-assembly NO.1



  1. Install the engine cover assembly No.1 with the 2 nuts.

    Standard
    T = 9.0 N/m{ 92 kgf/cm }



20. Fill Brake Fluid



  1. Stand the brake fluid can upside down over the reservoir.

    ■ NOTICE ■
    1. Make sure that there is a sufficient amount of brake fluid in the can.
    2. When filling, bleed the air after confirming that the reservoir on top of the master cylinder assembly is sufficiently filled.



21. Bleed Brake Master Cylinder Assembly



  1. Using a union nut wrench (10mm), disconnect the 2 brake tubes from the master cylinder.




  2. Slowly depress the brake pedal and hold it.




  3. Block the tube holes with your fingers and release the brake pedal.

  4. Remove your fingers, slowly depress and hold the brake pedal, block the tube holes again and release the brake pedal; repeat this 3 or 4 times.




  5. Using a union nut wrench (10mm), connect the 2 brake tubes to the master cylinder assembly.

    Standard
    Specified torque
    T = 15 N/m{ 153 kgf/cm }
    When using union nut wrench + torque wrenchL155mm
    T = 13 N/m{ 133 kgf/cm }



22. Bleed Brake Line

  1. Connect a vinyl tube to the bleeder plug.

  2. Depress the brake pedal several times, and loosen the bleeder plug with the brake pedal depressed. (*1)

  3. When fluid stops coming out, tighten the bleeder plug and release the brake pedal. (*2)

  4. Repeat (*1) to (*2) until there is no air in the brake fluid.

  5. Bleed the air from the brake line of each wheel in the same way.

    Standard
    Front Bleeder Plug
    T = 8.3 N/m{ 85 kgf/cm }
    Rear Bleeder Plug
    T = 11 N/m{ 112 kgf/cm }



23. Bleed Air from ABS & Traction Actuator Assembly

■ NOTICE ■
  1. If appropriate brake pedal height and feel cannot be obtained after performing normal brake line bleeding, air may have entered; perform the following bleeding again.
  2. Bleeding without using the SST (TaSCAN) may lead to malfunctions or accidents, so be sure to use the SST (TaSCAN).

  1. Turn the IG OFF and depress the brake pedal 20 times or more.

  2. With the IG still OFF, connect the SST (TaSCAN) to DLC3.

    SST
    09991-70200  

  3. Turn IG ON.

    ■ NOTICE ■
    The engine will not start.

  4. Turn the SST (TaSCAN) power switch ON, select "Menu (Work Support)" → "ABS/VSC/ECB" → "Air Bleeding" and execute it.

  5. Bleed Actuator Intake System

    ■ NOTICE ■
    Bleed the actuator intake system at the 2 right side wheels (front and rear wheels).


    1. On the SST (TaSCAN) menu screen, select intake system bleeding and execute it.

    2. Loosen the bleeder plug of the right front wheel. (*1)

    3. Operate the SST (TaSCAN) to operate the actuator.

      □ HINT □
      1. To protect the actuator, it automatically stops after 4 seconds.
      2. Leave the brake pedal released.

    4. Check on the SST (TaSCAN) screen that operation has stopped.

    5. Temporarily tighten the bleeder plug. (*2)

    6. Repeat the procedure from (*1) to (*2) until the air is completely bled.

    7. Tighten the bleeder plug.

      Standard
      T = 8.3 N/m{ 85 kgf/cm }

    8. Perform the same procedure for the right rear wheel as for the right front wheel.

      Standard
      T = 11 N/m{ 112 kgf/cm }

  6. Bleed Actuator Pressure Reduction System

    ■ NOTICE ■
    Bleed the actuator pressure reduction system at each of the 4 wheels.


    1. Execute pressure reduction system bleeding on the SST (TaSCAN) menu screen.

    2. Loosen the bleeder plug of the right front wheel. (*3)

    3. Operate the actuator using the SST (TaSCAN), and at the same time fully depress the brake pedal and hold it.

      ■ NOTICE ■
      1. The brake pedal will feel heavy at this time, but keep depressing it until brake fluid comes out of the bleeder plug.
      2. Hold the brake pedal depressed and do not pump it.

      □ HINT □
      To protect the solenoids, actuator operation automatically stops after 4 seconds. Also, when operating it continuously, wait at least 20 seconds between operations.

    4. Tighten the bleeder plug and release the brake pedal. (*4)

    5. Repeat the procedure from (*3) to (*4) until the air is completely bled.

    6. Tighten the bleeder plug.

    7. Perform the same procedure for the other 3 wheels as for the right front wheel.

      Standard
      Front Bleeder Plug
      T = 8.3 N/m{ 85 kgf/cm }
      Rear Bleeder Plug
      T = 11 N/m{ 112 kgf/cm }

  7. Perform normal brake line bleeding again by pumping the brake pedal.

    ■ NOTICE ■
    Repeat bleeding for each of the 4 wheels until the air is completely bled.



24. Inspect Brake Fluid Level

  1. Check the brake fluid level, and add fluid up to the MAX line of the reservoir if necessary.

    ■ NOTICE ■
    When adjusting the fluid level using a syringe etc., do not use one that has been used for mineral oil, water or deteriorated brake fluid. Doing so will cause deterioration of seal parts and fluid, resulting in fluid leaks and poor braking performance.
