Circuit Description


When the power window regulator master switch assembly (all seats) is operated, the power window regulator motor assemblies (all seats) are driven. The power window regulator motor assemblies (all seats) have a motor function, regulator function and ECU function.

B2313 is output when it is determined that the power window regulator motor assembly RH (driver side, rear right) or power window regulator motor assembly LH (front passenger side, rear left) has not been set.

■ NOTICE ■
  1. Identify the power window regulator motor assembly (ECU) at the location that output this DTC (B2313) before inspecting.
  2. The power window system uses the Body Electronics Area Network. First, follow "How to Proceed with Troubleshooting" to perform the "communication function inspection" and confirm that there is no malfunction in the communication system before proceeding with troubleshooting.
  3. If AUTO UP is operated after replacing the glass, glass run, etc., the jam protection function may operate. In that case, repeating AUTO UP hold ←→ AUTO DOWN operation 5 times or more returns it to normal operation.
