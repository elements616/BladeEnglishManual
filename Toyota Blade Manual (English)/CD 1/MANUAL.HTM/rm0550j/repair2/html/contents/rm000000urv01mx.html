Electric Power Steering System ECU Data Monitor/Active Test

Print



  1. ECU Data Monitor

    1. Turn IG OFF.

    2. Connect SST (TaSCAN) to DLC3.

      SST
      09991-70201  

    3. Turn the IG ON, select "Diagnosis" → "Chassis" → "Electric Power Steering" → "ECU Data Monitor" on the display screen of SST (TaSCAN), and check the ECU data monitor.
