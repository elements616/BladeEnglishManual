  1. AVC-LAN Diagnostic Trouble Code Chart

    □ HINT □
    1. This DTC is displayed on the service inspection screen of the HDD navigation system (navigation receiver assembly).
    2. The display consists of logical address (2-digit, 16-base) - DTC (2-digit, 16-base).

    1. CAMERA-C

      □ HINT □
      1. Logical address 01: Communication control
      2. Logical address 5C: Camera unit


      Service inspection screen display name: CAMERA-C, Part name: Television camera controller, Physical address: 1AC 
      Diagnostic Trouble Code (DTC)
      		Diagnosis Item
      		Diagnosis Description
      		Action
      		Remarks
      01-D6
      		Master Absent
      1. The device that stored this code was disconnected from the system when ACC was ON
      2. The master device was disconnected when this code was stored
      1. Inspect the navigation receiver assembly power source system and AVC-LAN communication system W/H
      2. Inspect the television camera controller power source system and AVC-LAN communication system W/H
      		This code may be stored even when no malfunction is found, depending on the battery condition or the power source waveform at engine start
      01-D7
      		Connection Check Malfunction
      1. The device that stored this code was disconnected from the system after the engine was started
      2. The master device was disconnected when this code was stored
      1. Inspect the navigation receiver assembly power source system and AVC-LAN communication system W/H
      2. Inspect the television camera controller power source system and AVC-LAN communication system W/H
      		This code is stored when the navigation receiver assembly power turns OFF after ACC ON and 210 seconds elapse
      01-DC
      		Transmission Failure
      		Transmission to the device indicated by the sub-code failed (this code may not be directly related to a malfunction)
      		If the device indicated by the sub-code is also stored in other devices, inspect the power source system and AVC-LAN communication system W/H of the device indicated by the sub-code
      		This code may be stored if the engine is started again 60 seconds after the engine was started
      01-DD
      		Master Reset (Momentary Interruption)
      		The master device was disconnected from the system after the engine was started
      1. Inspect the navigation receiver assembly power source system and AVC-LAN communication system W/H
      2. If the malfunction occurs frequently, replace the navigation receiver assembly
      		This code may be stored if the engine is started again after the engine was started
      01-DF
      		Master Malfunction
      1. The device with the display entered an abnormal condition, and the master function was switched to the audio device
      2. A malfunction occurred in communication between the sub-master (audio) device and the master device
      		Inspect the navigation receiver assembly power source system and AVC-LAN communication system W/H
      		This code is stored when the navigation receiver assembly power turns OFF after ACC ON and 210 seconds elapse
      01-E0
      		Registration Complete Notification Malfunction
      		The "Registration Complete Notification" command cannot be received from the master device
      		This code is an engineering diagnosis and is detected even when not directly related to a malfunction
      		This code may be stored even when no malfunction is found, depending on the battery condition or the power source waveform at engine start
      01-E2
      		ON/OFF Instruction Parameter Malfunction
      		There was a malfunction in the command from the master device controlling ON/OFF
      		Replace the navigation receiver assembly
      		-
      01-E3
      		Registration Request Transmission
      1. A "Registration Request" command was output from the device indicated by the sub-code
      2. A "Registration Request" command was output from the sub-master device upon receiving a "Connection Check Instruction" command
      		This code is an engineering diagnosis and is detected even when not directly related to a malfunction
      		This code may be stored even when no malfunction is found, depending on the battery condition or the power source waveform at engine start
