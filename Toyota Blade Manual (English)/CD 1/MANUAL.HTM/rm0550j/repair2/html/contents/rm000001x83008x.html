Rear Combination Light Assembly LH Reassembly

Print


1. Install Tail Light (Rear Combination Light) Lens & Body LH


2. Install Rear Combination Light Socket & Wire Sub-assembly LH



  1. Connect the connector.

  2. Engage the claw and clamp, and install the rear combination light socket & wire sub-assembly LH.



3. Install Rear Turn Signal Light Bulb

  1. Install the rear turn signal light bulb to the rear combination light socket & wire sub-assembly LH.




  2. Turn in the direction indicated by the arrow in the illustration and install the rear turn signal light bulb together with the rear combination light socket & wire sub-assembly LH.



4. Install Back-up Light Bulb

  1. Install the back-up light bulb to the rear combination light socket & wire sub-assembly LH.




  2. Turn in the direction indicated by the arrow in the illustration and install the back-up light bulb together with the rear combination light socket & wire sub-assembly LH.



5. Install Rear Combination Light Body Packing LH



  1. Install a new rear combination light body packing LH.
