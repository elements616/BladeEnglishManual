Front Lower Ball Joint Assembly LH Installation

Print

Preparation List



1. Install Front Lower Ball Joint Assembly LH

  1. Using aluminum plates, secure the front axle assembly LH in a vise.

    ■ NOTICE ■
    Do not overtighten the vise.




  2. Install the front lower ball joint assembly LH to the front axle assembly with the nut.

    Standard
    T = 133 N/m{ 1360 kgf/cm }

  3. Install a new cotter pin.

    ■ NOTICE ■
    Align the cotter pin hole by further tightening the nut within 60°.



2. Install Front Axle Assembly LH



  1. Install the front axle assembly LH to the shock absorber, insert the 2 bolts from the rear of the vehicle, and tighten the 2 nuts.

    Standard
    T = 240 N/m{ 2450 kgf/cm }

  2. Push the front axle assembly LH toward the outside of the vehicle, engage the splines of the front drive shaft assembly LH, and insert it into the front axle assembly LH.

    ■ NOTICE ■
    1. Do not push the front axle assembly LH toward the outside of the vehicle more than necessary.
    2. Do not damage the drive shaft outboard joint boot.
    3. Do not damage the speed sensor rotor.
    4. Check that there is no foreign matter on the speed sensor rotor or insertion part.



3. Install Front Suspension Arm Sub-assembly Lower NO.1 LH



  1. Push down the front suspension lower arm No.1 LH, install the front lower ball joint LH, and tighten it with the 1 bolts and 2 nuts.

    Standard
    T = 89 N/m{ 908 kgf/cm }



4. Install Tie Rod End LH



  1. Connect the tie rod end LH to the steering knuckle and install it with the castle nut.

    Standard
    T = 49 N/m{ 500 kgf/cm }

    ■ NOTICE ■
    After tightening the castle nut, align the cotter pin hole by further tightening the nut within 60°.

  2. Install a new cotter pin.



5. Temporarily Tighten Front Axle Shaft Nut LH

  1. Temporarily tighten a new front axle hub nut LH.



6. Inspect Front Axle Hub & Bearing Assembly Axial Play



  1. Using a dial indicator, check the bearing axial play near the inner circumference (flange) of the axle hub.

    Limit
    0.05mm

    ■ NOTICE ■
    If it exceeds the maximum, replace the bearing with a new one.



7. Inspect Front Axle Hub & Bearing Assembly Runout



  1. Using a dial indicator, check the axle hub runout near the outer circumference of the axle hub.

    Limit
    0.05mm

    ■ NOTICE ■
    If it exceeds the maximum, replace the hub & bearing with a new one.



8. Install Front Disc



  1. Align the matchmarks on the disc and axle hub, and install the disc.

    ■ NOTICE ■
    When replacing the disc, select the installation position where the disc runout is minimal.



9. Install Front Disc Brake Caliper Assembly LH



  1. Install the front disc brake caliper assembly LH to the steering knuckle with the 2 bolts.

    Standard
    T = 107 N/m{ 1090 kgf/cm }



10. Install Speed Sensor Front LH


  1. Install the speed sensor to the steering knuckle with bolt C.

    Standard
    Bolt C
    T = 8.5 N/m{ 87 kgf/cm }

    ■ NOTICE ■
    1. Check that there is no foreign matter on the speed sensor tip and installation part.
    2. When installing the speed sensor, do not insert it while rotated relative to the tightening position.
    3. Do not tighten the bolt with the sensor tilted.




  2. Install the clip to the steering knuckle.

  3. Using bolt A, install sensor clamp No.1 together with the brake flexible hose to the shock absorber.

    Standard
    Bolt A
    T = 29 N/m{ 296 kgf/cm }

    ■ NOTICE ■
    1. Install the speed sensor front LH wire harness without twisting it.
    2. Assemble so that the clamp of the speed sensor front LH is on the near side.

  4. Install sensor clamp No.2 to the body with bolt B.

    Standard
    Bolt B
    T = 8.5 N/m{ 87 kgf/cm }

    ■ NOTICE ■
    Install the speed sensor front LH wire harness without twisting it.

  5. Connect the connector.

  6. Install the speed sensor clip to the body.



11. Fully Tighten Front Axle Shaft Nut LH

  1. Using a socket wrench (30mm), fully tighten the front axle hub nut LH.

    Standard
    T = 216 N/m{ 2200 kgf/cm }




  2. Using a chisel and hammer, stake the front axle hub nut LH.



12. Install Front Tire
Standard
T = 103 N/m{ 1050 kgf/cm }
