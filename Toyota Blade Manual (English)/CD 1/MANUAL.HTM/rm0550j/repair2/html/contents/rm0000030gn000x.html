1. Inspect Accelerator Position Sensor Function

  1. Connect SST (TaSCAN) to DLC3.

  2. Turn IG ON.

  3. Following the screen display, select [ECU Data Monitor] → [Accelerator Sensor No. 1 Voltage (VPA1) and Accelerator Sensor No. 2 Voltage (VPA2)], and check the values when the accelerator pedal is operated.
