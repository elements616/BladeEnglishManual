Function Description


Each solenoid adjusts the pressure applied to each wheel cylinder to control the vehicle.

While a malfunction DTC is output, the solenoid relay is forcibly turned OFF by the fail-safe function, so the solenoids are not turned ON.

The solenoid relay and solenoids are built into the actuator.
