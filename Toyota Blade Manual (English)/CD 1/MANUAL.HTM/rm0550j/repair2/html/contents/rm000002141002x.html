Air Conditioner Control Panel Assembly Installation

Print

Preparation List



1. Air Conditioner Control Assembly Installation



  1. Connect the connector.

  2. Engage the 4 clips and install the air conditioner control assembly.



2. Navigation Receiver Assembly w/ Bracket Installation (w/ HDD Navigation System)

  1. Connect the connectors.




  2. Engage the 4 clips and temporarily install the navigation receiver assembly w/ bracket.




  3. Install the navigation receiver assembly w/ bracket with the 4 bolts.



3. Radio Receiver Assembly w/ Bracket Installation (w/o HDD Navigation System)

  1. Connect the connectors.




  2. Engage the 4 clips and temporarily install the radio receiver assembly w/ bracket.




  3. Install the radio receiver assembly w/ bracket with 4 bolts.



4. Radio Tuner Opening Cover w/ Bracket Installation (w/o Radio Receiver)



  1. Install the radio tuner opening cover w/ bracket with 4 bolts <G>.



5. Instrument Cluster Finish Panel Sub-assembly Center Installation (w/o Radio Receiver)



  1. Engage the 4 clips and install the instrument cluster finish panel center.



6. Install Instrument Panel Finish Panel LWR CTR



  1. Engage the 6 clips and 4 claws.




  2. Install the instrument panel finish panel LWR CTR with the 2 screws <C>.



7. Install Position Indicator Housing Assembly

  1. Connect the connector.




  2. Engage the 7 claws and install the position indicator housing assembly.



8. Install Console Box Cover RR


9. Install Shift Lever Knob



  1. Turn the shift lever knob in the direction of the arrow shown in the illustration to install it.



10. Install Instrument Panel Register Assembly CTR



  1. Connect the connector.




  2. Engage the 2 clips, 5 claws and 3 guides, and install the instrument panel register assembly CTR.



11. Install Instrument Panel Finish Panel End RH



  1. Engage the 4 clips and install the instrument panel finish panel end RH.



12. Install Instrument Panel Finish Panel End LH



  1. Engage the 4 clips and install the instrument panel finish panel end LH.



13. Connect Battery Negative Terminal
Standard
T = 5.4 N/m{ 55 kgf/cm }
