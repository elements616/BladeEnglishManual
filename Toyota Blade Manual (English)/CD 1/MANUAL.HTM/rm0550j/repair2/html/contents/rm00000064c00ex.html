Radar Cruise Control System DTC Check / Clear

Print



  1. DTC Check (Reading Using TaSCAN)

    1. With the IG OFF, connect SST (TaSCAN) to DLC3.

      SST
      09991-70200  

    2. Turn IG ON.

    3. Following the SST (TaSCAN) screen display, display the "System Diagnosis Menu/TCCS" screen and select "DTC Freeze Data".

    4. Check the diagnostic trouble codes.

      □ HINT □
      If freeze frame data is recorded, "F" is displayed at the left end and the color of that row changes.



    1. Freeze Frame Data Check (Reading Using TaSCAN)

      1. With the ignition switch OFF, connect SST (TaSCAN) to DLC3.

        SST
        09991-70200  

      2. Turn IG ON.

      3. Operate according to the SST (TaSCAN) screen display and, from the "DTC Check" screen, select a DTC for which freeze frame data is recorded ("F" displayed).

        □ HINT □
        1. The engine condition (ECU data) at the time of DTC detection and before and after detection (before: 1.5 seconds, after: 0.5 seconds) can be checked at 0.5-second intervals.
        2. Check that the malfunction symptoms from the customer problem analysis are consistent with the Diagnostic Trouble Code Chart.
        3. After repair, perform a confirmation test referring to the driving conditions confirmed above.



      1. DTC Check (Reading Using Indicator Light)

        1. Turn IG OFF.




        2. Using SST, connect terminals 13 (TC) and 4 (CG) of the DLC3.

          SST
          09843-18040  

          ■ NOTICE ■
          Never connect the wrong terminals as this will cause a malfunction.

        3. Turn IG ON.

          □ HINT □
          The "CRUISE" indicator in the combination meter assembly blinks. DTCs are indicated by the number of blinks and the blinking cycle.



        4. Read the DTC (number of blinks of the "CRUISE" indicator light).



          □ HINT □
          1. A 2-digit DTC is output from the indicator light.
          2. When the system is normal, the light repeatedly comes on for 0.25 seconds and goes off for 0.25 seconds.
          3. When there is 1 DTC, the same code is output repeatedly at 4.0-second intervals. When multiple codes are output, the different codes are output at 2.5-second intervals, and after one cycle they are output again after a 4.0-second interval.
          4. When 2 or more codes are output, they are displayed in order from the lowest code number.

        5. Turn IG OFF.

        6. Disconnect terminals 13 (TC) and 4 (CG) of the DLC3.



        1. Clearing DTC Memory (Clearing Using TaSCAN)

          1. With the ignition switch OFF, connect SST (TaSCAN) to DLC3.

            SST
            09991-70200  

          2. Turn IG ON.

          3. Following the SST (TaSCAN) screen display, display the "System Diagnosis Menu/TCCS" screen and select "DTC Freeze Data".

          4. Select "Clear" on the screen to clear the data.

            □ HINT □
            DTCs and freeze frame data are cleared at the same time.



          1. Clearing DTC Memory (Clearing by Removing Fuse)

            1. Turn IG OFF.

            2. Remove the EFI fuse and ETCS fuse and wait for 60 seconds or more.

            3. Check the DTCs again and make sure that the malfunction codes have been cleared.

              ■ NOTICE ■
              If a malfunction code is output, repair again according to the code.
