DTC C1699 2WD/4WD Undetermined

Print

Preparation List


Function Description


This DTC is output when the television camera controller's self-diagnosis determines that the drive type cannot be identified, or that the drive type signal cannot be received from the engine control computer connected via CAN communication.


DTC No.
Diagnosis Description
Inspection Area
C1699
Drive Type Undetermined
  1. Check Drive Type Determination Signal
  2. Television Camera Controller
  3. Engine Control Computer
