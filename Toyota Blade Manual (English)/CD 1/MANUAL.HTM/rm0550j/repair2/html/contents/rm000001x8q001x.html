Height Control Sensor Sub-assembly Rear Removal

Print


1. Remove Height Control Sensor Sub-assembly Rear (Drive Type FF)



  1. Disconnect the connector and disengage the clamp.




  2. Remove the 2 bolts and remove the height control sensor assembly (rear).



2. Remove Height Control Sensor Sub-assembly Rear (Drive Type 4WD)



  1. Disconnect the connector and disengage the clamp.




  2. Remove the 3 bolts and remove the height control sensor assembly (rear).
