DTC C1210/36 Yaw Rate Sensor 0-point Not Calibrated

Print

DTC C1336/39 G Sensor 0 Point Not Calibrated


Function Description


If the skid control computer is replaced, the yaw rate & G sensor 0 point acquisition procedure is necessary.

If the yaw rate sensor is replaced, it is necessary to clear the yaw rate & G sensor 0 point stored values in the skid control sensor and then perform the acquisition procedure again.

This code is output if the yaw rate & G sensor 0 point acquisition is incomplete.
