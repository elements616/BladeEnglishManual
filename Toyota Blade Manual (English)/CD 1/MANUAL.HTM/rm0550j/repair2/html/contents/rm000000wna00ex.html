Parking Brake Adjustment

Print

Preparation List


■ NOTICE ■
Before adjusting the parking brake, complete bleeding of the brake fluid.



1. Inspect Parking Brake Lever Travel

  1. Pull the parking brake lever all the way once with force.

  2. Release the parking brake lever.

  3. Slowly pull the parking brake lever and count the number of clicks.

    Standard
    5-8 notches [Operating force 200N{20kgf}]



2. Remove Console Box Cover RR



  1. Using a thin flat-tip screwdriver wrapped with protective tape, disengage the 2 clips.




  2. Place your hand at the position shown in the illustration and disengage the 2 clips.

  3. Disconnect the connectors and remove the console box rear cover.



3. Remove Console Box Carpet



  1. Remove the console box carpet.



4. Remove Console Box Assembly RR



  1. Remove the 4 bolts and 2 screws.




  2. Disengage the 4 claws and remove the console box assembly RR.



5. Adjust Parking Brake Lever Travel

  1. Fully release the parking brake lever.

  2. Loosen the lock nut and adjusting nut at the parking brake lever, and fully loosen the parking brake cable.

  3. With the engine OFF, depress the brake pedal firmly 3-5 times.




  4. Turn the adjusting nut to adjust the lever travel to the standard value.

    Standard
    5-8 notches [Operating force 200N{20kgf}]

  5. Using a wrench, hold the adjusting nut and tighten the lock nut.

    Standard
    T = 6.0 N/m{ 61 kgf/cm }

  6. Operate the parking brake lever 3-4 times, then check the lever travel.

  7. Check that the parking brake does not drag.




  8. When the parking brake lever is released, check that the clearance between the operating lever and the stopper of the rear disc brake cylinder is within the standard range.

    Standard
    0-0.5mm

  9. Check that the brake warning light comes on when the parking brake lever is operated.

    Specified Condition
    The light must come on reliably at the 1 notch from the start of pulling.



6. Install Console Box Assembly Rear



  1. Engage the 4 claws.




  2. Install the console box assembly RR with the 4 bolts and 2 screws.



7. Install Console Box Carpet



  1. Install the console box carpet.



8. Install Console Box Cover RR

  1. Connect the connectors.




  2. Engage the 4 clips to install the console box rear cover.
