Engine Oil Pressure Switch Assembly (2GR-FE) Installation

Print

Preparation List



1. Install Engine Oil Pressure Switch Assembly

  1. Degrease the threads of the engine oil pressure switch assembly.




  2. Apply adhesive 1324 to the threads.




  3. Using a deep socket wrench 24mm, install the engine oil pressure switch assembly.

    Standard
    T = 15 N/m{ 153 kgf/cm }

    ■ NOTICE ■
    After installation, leave it without starting the engine for 1 hours.

  4. Connect the engine oil pressure switch assembly connector.



2. Install Engine Under Cover NO.1

  1. Install engine under cover NO.1 with the 6 bolts and 7 clips.
