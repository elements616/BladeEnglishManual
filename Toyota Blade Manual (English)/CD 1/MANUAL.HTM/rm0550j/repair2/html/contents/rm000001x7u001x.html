Side Turn Signal Light Assembly LH Installation

Print


1. Install Side Turn Signal Light Assembly LH



  1. Install the side turn signal light assembly LH with the 3 screws.

  2. Connect the connector.



2. Install Outer Mirror Cover LH



  1. Fit the outer mirror cover RH over the outer rear view mirror assembly from the direction of claws A and B.

    ■ NOTICE ■
    Check that the outer circumference of the outer mirror cover RH is securely fitted into the outer rear view mirror assembly RH.

  2. Engage the 7 claws and install the outer mirror cover RH.

    ■ NOTICE ■
    Make sure the claws are securely engaged.



3. Install Outer Mirror LH (w/o Cold Area Specification)



  1. Insert the 2 guides.




  2. Engage the 2 claws and install the outer mirror RH.



4. Install Outer Mirror LH (w/ Cold Area Specification)



  1. Connect the connectors.




  2. Insert the 2 guides.




  3. Engage the 2 claws and install the outer mirror RH.
