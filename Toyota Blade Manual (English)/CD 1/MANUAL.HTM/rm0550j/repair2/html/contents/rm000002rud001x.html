Smart Entry & Start System (Smart Entry) Smart Entry System Exterior Warning and Answer-back Buzzer Do Not Sound

Print

Circuit Description


The Smart Entry & Start System (smart entry) uses the wireless door lock buzzer for various exterior warnings. When the conditions for a warning are met, the smart key computer assembly (certification ECU) drives the wireless door lock buzzer to sound it.

■ NOTICE ■
  1. The Smart Entry & Start System (smart entry) has functions that use multiplex communication. First, follow "How to Proceed with Troubleshooting" and confirm that there is no malfunction in the communication system before proceeding with troubleshooting.
  2. When using TaSCAN with the ignition switch OFF, repeatedly turn any door courtesy light switch ON←→OFF until communication between TaSCAN and the vehicle starts. (ON←→OFF interval within 1.5 seconds)
  3. When the electrical key transmitter or smart key computer assembly (certification ECU) has been replaced, refer to the registration procedure in the immobiliser reference section.
  4. Check that there are no other electrical key transmitters in the vehicle interior.
