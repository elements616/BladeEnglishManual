Electric Power Steering System Freeze Frame Data

Print



  1. Freeze Frame Data

    □ HINT □
    1. When a malfunction DTC is output, the freeze frame data at the time the malfunction code was set is stored.
    2. Once the freeze frame data at the time a malfunction DTC was set has been stored, the data is not updated or erased until the stored data is cleared (DTCs cleared).

    1. Turn IG OFF.

    2. Connect SST (TaSCAN) to DLC3.

      SST
      09991-70200  

    3. Display the malfunction codes on the DTC code check screen. (see)

    4. Select a code displaying "F" (freeze data present) and check the freeze frame data.
