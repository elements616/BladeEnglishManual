    Step 2Customer Problem Analysis and Symptom Check

    1. Check sheet (see)

      1. When a customer complains of a problem with the ETC system, perform a customer problem analysis using the ETC check sheet.

        □ HINT □
        1. In the ETC system, toll payment is made by wireless communication. For this reason, it is necessary to carefully ask about the installation condition of the ETC on-board unit in the vehicle and the vehicle environment at that time.
        2. To find out the frequency of the problem, ask the customer how often they use ETC.


    NEXT


    Step 3Check Toll Collection (ETC) Computer Assembly Startup

    1. Check Toll Collection (ETC) Computer Assembly Startup

      1. Turn ACC ON.

      2. Check that the green indicator and amber indicator illuminate for 5 seconds.

      3. Check that the startup check ends normally and the indicators go off.

        □ HINT □
        1. If there is a malfunction in the toll collection (ETC) computer assembly, the orange indicator blinks, the multi-display voice announces "Bong. A malfunction has occurred. ETC cannot be used.", and a JEITA standard error code is displayed on the multi-display.
        2. If the toll collection (ETC) computer assembly has not yet been set up, the toll collection (ETC) computer assembly announces by voice "Beep beep. Not set up.". If the volume of the toll collection (ETC) computer assembly is set to mute, no announcement is made, so set the volume to "Volume 1" or higher and check.

    Step 5Check ETC Card Insertion (Card Authentication)

    1. ETC Card Insertion Check

      1. Insert the ETC card.

      2. The multi-display voice gives the notification "Beep", the green indicator of the toll collection (ETC) computer assembly starts blinking, and card authentication starts.

      3. Check that the multi-display voice gives the notification "Bong. The ETC card has been inserted" (*) and the green indicator of the toll collection (ETC) computer assembly illuminates.

        □ HINT □
        1. If there is a problem with the ETC card, the amber indicator of the toll collection (ETC) computer assembly blinks and a warning sound is emitted. The warning sound continues until the card is removed. Also, the multi-display voice announces "Bong. Card cannot be read. Please check the card.", and a JEITA standard error code is displayed on the multi-display.
        2. *: Depending on the expiration date of the inserted card, the multi-display voice gives the notification "Bong. The ETC card expires at the end of this month. Please check the card" or "Bong. The ETC card has expired".
