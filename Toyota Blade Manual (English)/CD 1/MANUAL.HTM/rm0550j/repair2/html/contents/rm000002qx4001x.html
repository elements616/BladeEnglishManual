Smart Entry & Start System (Smart Entry) Smart Unlock Does Not Operate from Front Passenger Side Door Only (Lock Operates)

Print

Preparation List


Function Description


If only the door unlock function by smart operation from the front passenger side door does not operate, the lock function is normal, so the request code is being transmitted normally from the front passenger side door. The touch sensor circuit (certification ECU -> front passenger side door outside handle [touch sensor] -> front passenger side door outside transmitter) is suspected as the malfunctioning area.

■ NOTICE ■
  1. The Smart Entry & Start System (smart entry) has functions that use multiplex communication. First, follow "How to Proceed with Troubleshooting" and confirm that there is no malfunction in the communication system before proceeding with troubleshooting.
  2. When using TaSCAN with the ignition switch OFF, repeatedly turn any door courtesy light switch ON←→OFF until communication between TaSCAN and the vehicle starts. (ON←→OFF interval within 1.5 seconds)
  3. When the electrical key transmitter (electronic key) or smart key computer assembly (certification ECU) is replaced, refer to the immobiliser registration procedure in the reference section.
  4. Check that there are no other electrical key transmitters in the vehicle interior.
