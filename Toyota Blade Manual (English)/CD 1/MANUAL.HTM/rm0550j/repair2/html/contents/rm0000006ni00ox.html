1. Install Parking Brake Cable Assembly NO.1



  1. Install parking brake cable assembly No.1 to the parking brake control pedal assembly.

  2. Install the clip to parking brake cable assembly No.1.




  3. Bend the claw of the parking brake control pedal assembly.




  4. Temporarily install wire adjusting nut No.1 to parking brake cable assembly No.1.
