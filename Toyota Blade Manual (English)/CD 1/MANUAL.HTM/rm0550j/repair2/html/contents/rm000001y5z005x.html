Engine Mounting Insulator LH (2GR-FE) Installation

Print

Preparation List



1. Install Engine Mounting Insulator LH



  1. Install the engine mounting insulator LH with the 4 bolts.

    Standard
    T = 95 N/m{ 969 kgf/cm }



2. Connect Engine Mounting Bracket LH



  1. Install the engine mounting insulator LH to the engine mounting bracket LH with the bolt and nut.

    Standard
    T = 56 N/m{ 571 kgf/cm }

    ■ NOTICE ■
    Hold the bolt side and tighten the nut side.



3. Install Air Cleaner Case



  1. Install the air cleaner case with the 3 bolts.

    Standard
    T = 7.0 N/m{ 71 kgf/cm }

  2. Connect the clamp.



4. Install Air Cleaner Filter Element Sub-assembly

  1. Install the air cleaner filter element.



5. Install Air Cleaner Cap w/ Air Cleaner Hose



  1. Install the hinge portion first, and then install the air cleaner cap w/ air cleaner hose with the 3 clamps.

  2. Install the clamp hose band. (*1)

  3. Connect ventilation hose No.2. (*2)

  4. Connect the air flow meter connector. (*3)



6. Install Battery Carrier NO.2



  1. Install battery carrier NO.2 with the 2 bolts.

    Standard
    T = 19 N/m{ 194 kgf/cm }



7. Install Battery Carrier



  1. Install the battery carrier with the 4 bolts.

    Standard
    T = 19 N/m{ 194 kgf/cm }

  2. Attach the 2 clamps to the battery carrier.

  3. Install the battery tray.



8. Install Battery

  1. Install the battery to the vehicle

  2. Install the insulator.




  3. Connect the current sensor connector.




  4. Install the battery clamp with the bolt and nut.

    Standard
    T = 17 N·m{ 173 kgf·cm } (Bolt)
    T = 5.0 N·m{ 51 kgf·cm } (Nut)

  5. Connect the battery positive terminal with the nut.

    Standard
    T = 13 N·m{ 130 kgf·cm } (Nut)



9. Check Front Wheels Straight-ahead Position


10. Connect Battery Negative Terminal
Standard
T = 5.4 N/m{ 40 kgf/cm }


11. Install V-bank Cover Sub-assembly



  1. Engage the 3 clips to install the V-bank cover.

    ■ NOTICE ■
    1. Make sure the clips are securely engaged.
    2. Engaging them with excessive force or striking the top of the clips may cause damage.



12. Install Radiator Upper Air Deflector



  1. Install the radiator upper air deflector with the 9 clips.
