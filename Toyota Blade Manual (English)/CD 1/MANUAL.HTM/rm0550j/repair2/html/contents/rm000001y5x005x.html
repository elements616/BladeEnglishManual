Engine Mounting Insulator Front (2GR-FE) Installation

Print

Preparation List



1. Install Engine Mounting Insulator Front



  1. Install the engine mounting insulator front to the front crossmember with the 3 bolts.

    Standard
    T = 95 N/m{ 969 kgf/cm }



2. Install Front Crossmember Sub-assembly



  1. Install the front crossmember with the 4 bolts.

    Standard
    T = 96 N/m{ 979 kgf/cm }



3. Connect Engine Mounting Insulator FR



  1. Connect the engine mounting insulator front to the engine mounting bracket front with the bolt and nut.

    Standard
    T = 145 N/m{ 1479 kgf/cm }



4. Install Front Suspension Member Reinforcement LH



  1. Install the front suspension member reinforcement LH with the 4 bolts.

    Standard
    T = 96 N/m{ 979 kgf/cm }



5. Install Front Suspension Member Reinforcement RH



  1. Install the front suspension member reinforcement RH with the 4 bolts.

    Standard
    T = 96 N/m{ 979 kgf/cm }



6. Install Engine Under Cover

  1. Install the engine under cover with the 4 bolts and 4 screws.



7. Install Engine Under Cover NO.1

  1. Install engine under cover NO.1 with the 6 bolts and 7 clips.



8. Install Battery Carrier NO.2



  1. Install battery carrier NO.2 with the 2 bolts.

    Standard
    T = 19 N/m{ 194 kgf/cm }



9. Install Battery Carrier



  1. Install the battery carrier with the 4 bolts.

    Standard
    T = 19 N/m{ 194 kgf/cm }

  2. Attach the 2 clamps to the battery carrier.

  3. Install the battery tray.



10. Install Battery

  1. Install the battery to the vehicle

  2. Install the insulator.




  3. Connect the current sensor connector.




  4. Install the battery clamp with the bolt and nut.

    Standard
    T = 17 N·m{ 173 kgf·cm } (Bolt)
    T = 5.0 N·m{ 51 kgf·cm } (Nut)

  5. Connect the battery positive terminal with the nut.

    Standard
    T = 13 N·m{ 130 kgf·cm } (Nut)



11. Check Front Wheels Straight-ahead Position


12. Connect Battery Negative Terminal
Standard
T = 5.4 N/m{ 40 kgf/cm }


13. Install V-bank Cover Sub-assembly



  1. Engage the 3 clips to install the V-bank cover.

    ■ NOTICE ■
    1. Make sure the clips are securely engaged.
    2. Engaging them with excessive force or striking the top of the clips may cause damage.



14. Install Radiator Upper Air Deflector



  1. Install the radiator upper air deflector with the 9 clips.
