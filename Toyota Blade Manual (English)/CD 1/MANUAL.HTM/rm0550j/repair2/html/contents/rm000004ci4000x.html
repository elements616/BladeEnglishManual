Front Spoiler Cover LH Installation

Print

Preparation List



1. Install Front Spoiler Side Protector LH

  1. Rub off the double-sided tape remaining on the front spoiler cover LH with a cloth, etc.

    ■ NOTICE ■
    1. Installing the front spoiler side protector LH with double-sided tape remaining may cause poor adhesion, so continue until it is thoroughly removed.
    2. Removing it with a screwdriver, etc. will cause scratches and poor adhesion, so rub it off with a cloth, etc.

  2. Clean the installation surface using white gasoline.

  3. Apply primer to the front spoiler side protector LH installation surface of the front spoiler cover LH.

  4. Peel off the release paper of the double-sided tape without touching the adhesive surface.




  5. Install a new front spoiler side protector LH within the scribed lines (application reference range) on the front spoiler cover LH.

    Part
    		Specified Condition
    A
    		Application Range

    ■ NOTICE ■
    Press the front spoiler side protector LH firmly to apply it.



2. Install Front Spoiler Cover LH



  1. Install the front spoiler cover with the 5 front spoiler retainers.
