Millimeter Wave Radar Sensor Assembly Installation

Print

Preparation List



1. Install Millimeter Wave Radar Sensor Bracket NO.1



  1. Temporarily install the millimeter wave radar sensor bracket with the 4 bolts.

  2. Fully tighten the bolts in the order A, B, C, D.

    Standard
    T = 9.0 N/m{ 92 kgf/cm }



2. Install Millimeter Wave Radar Sensor Assembly



  1. Temporarily install the millimeter wave radar sensor assembly with the 3 bolts.

  2. Fully tighten the bolts in the order A, B, C.

    Standard
    T = 11 N/m{ 112 kgf/cm }

  3. Connect the connector.

    ■ NOTICE ■
    Do not use a sensor that has been dropped or subjected to a strong impact during work.



3. Install Engine Under Cover

  1. Install the engine under cover with the 4 bolts and 4 screws.



4. Install Front Bumper Assembly

  1. Connect the connectors.




  2. Engage the 8 claws (4 each on LH/RH).




  3. Install the front bumper assembly with the 5 clips, 2 bolts and 6 screws.




  4. Install the pin hold clip.

    □ HINT □
    Install the RH side using the same procedure.



5. Install Radiator Grille Protector



  1. Install the 2 radiator grille protectors.



6. Install Radiator Upper Air Deflector

  1. Install the radiator upper air deflector with the 8 clips.



7. Millimeter Wave Radar Sensor Assembly Adjustment

■ NOTICE ■

  1. Perform the measurement on a level floor.
  2. Check that there are no metal objects in the surrounding area or on the floor surface. (The area approximately 10m ahead and approximately 14m wide is a prohibited area for objects. It is preferable that there are no large metal objects around it either.)

  1. Pre-adjustment Work

    1. Unload all luggage from the vehicle.

    2. Leave only the standard tools and spare tire in the trunk.

    3. Adjust the tire pressure to the specified value.

    4. Reduce the remaining fuel to less than 15L.

  2. Vertical Adjustment

    1. Remove dust and oil from the level shelf of the millimeter wave radar sensor assembly.




    2. Place the dedicated level in the center of the level shelf of the millimeter wave radar sensor assembly.




    3. Using a screwdriver, turn vertical adjusting bolt A of the millimeter wave radar sensor assembly to adjust so that the bubble is on the red line of the level.

      Specified Condition
      Upward 0.2°

      □ HINT □
      Adjustment range within red frame of level ±0.2°

      Vertical Adjustment
      1. Upward: Turn bolt A to the minus side
      2. Downward: Turn bolt A to the plus side
      		1 turn of the screwdriver moves it approximately 0.12°




  3. SST (Reflector) Height Adjustment

    1. Set SST (reflector) at a height of 70cm from the ground.

      SST
      09870-60000   (09870-60010, 09870-60040)

  4. SST (Reflector) Setting

    1. Hang a pointed weight from the center (emblem center) of the front and rear bumpers of the vehicle, and accurately mark the center positions on the floor surface.




    2. Make a mark 5m ahead of the vehicle on the line connecting the 2 front and rear points.

      □ HINT □
      Fix one end of a string to the rear mark, and from 5m ahead of the vehicle, move the other end of the string left and right to align it with the front mark and establish a straight line.



    3. Set SST (reflector) at a position shifted 12mm to the right of the vehicle from the marking position.

      ■ NOTICE ■
      Perform as accurately as possible.




  5. Beam Axis Adjustment

    1. Connect SST (TaSCAN) to the vehicle.

      SST
      09991-70200  

    2. Turn IG ON.

    3. Turn the cruise control main switch ON.




    4. On the screen, select "Work Support" → "Radar Cruise" → "Millimeter Wave Radar Beam Axis Adjustment" in that order.

    5. Follow the screen instructions and press the "Start" button.

      ■ NOTICE ■
      Check that the beam axis distance is approximately 5m.

  6. Horizontal Adjustment




    1. Read the current angle deviation.

      Specified Condition
      0° for both left and right




    2. Based on the beam axis deviation measurement result, use a screwdriver to turn horizontal adjusting bolt B of the millimeter wave radar sensor assembly to adjust it.

      Horizontal Adjustment
      1. Upward: Turn bolt B to the plus side
      2. Downward: Turn bolt B to the minus side
      		1 turn of the screwdriver moves it approximately 0.05°

      ■ NOTICE ■
      If it is difficult to reach 0°, the sensor may be targeting an object other than SST (reflector), so check again that there are no highly reflective objects in the surrounding area.




    3. To reset the driving learned value, cover the left half of the sensor with aluminum foil, etc. (a metal object that blocks radio waves). (For approximately 10 seconds)

      ■ NOTICE ■
      At this time, leave SST (reflector) installed, and make sure there are no objects between the right half of the sensor and the reflector.

      □ HINT □
      When reset, the buzzer sounds for 10 seconds and the screen displays "Beam Axis Deviation 6.3°" and "Beam Axis Distance 6.3m".




    4. Press the "Complete" button to end the beam axis adjustment mode.

    5. Disconnect SST (TaSCAN) from the vehicle.

  7. Recheck Vertical Adjustment




    1. Place the dedicated level in the center of the level shelf of the millimeter wave radar sensor assembly.




    2. Using a screwdriver, turn vertical adjusting bolt A of the millimeter wave radar sensor assembly to readjust so that the bubble is on the red line of the level.

      Specified Condition
      Upward 0.2°

      □ HINT □
      Adjustment range within red frame of level ±0.2°

      Vertical Adjustment
      1. Upward: Turn bolt A to the minus side
      2. Downward: Turn bolt A to the plus side
      		1 turn of the screwdriver moves it approximately 0.12°



8. Road Test

  1. Road Test

    ■ NOTICE ■
    1. Always perform a road test after adjusting the millimeter wave radar sensor assembly.
    2. Drive with sufficient care.


    1. On a straight road with 1 or more lanes in each direction where safety can be confirmed and visibility is good, drive at a vehicle speed of 30km/h or more near the center of the lane, parallel to the lane.

      ■ NOTICE ■
      Since the pre-crash safety may operate under the following conditions, avoid such conditions when performing the road test.
      1. When there are roadside objects at the entrance to a curve.
      2. When passing oncoming vehicles on a curve.
      3. When passing through a narrow steel bridge.
      4. When there are metal objects on the road surface.
      5. When there is an oncoming vehicle while turning right.
      6. When rapidly approaching a vehicle ahead.
      7. When passing through an ETC gate.

    2. On a straight road, when passing an oncoming vehicle with no danger of collision, check that the master warning does not illuminate, the buzzer does not sound, and "BRAKE!" is not displayed on the combination meter display.

    3. If it is displayed, adjust the millimeter wave radar sensor assembly again.

      □ HINT □
      1. Check the installation condition of the millimeter wave radar sensor assembly.
      2. Check that the pre-crash brake switch is not pushed in.
