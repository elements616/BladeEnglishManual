Rear Combination Light Assembly LH Installation

Print


1. Install Rear Combination Light Assembly LH

  1. Engage the 2 clips and guide, and install the rear combination light assembly LH.

  2. Install the 2 nuts.

    Standard
    T = 4.9 N/m{ 50 kgf/cm }

  3. Connect the connector and engage the clamp.



2. Install Rear Combination Light Cover LH

  1. Insert the 2 guides.

  2. Engage the 4 claws and install the rear combination light cover LH.
