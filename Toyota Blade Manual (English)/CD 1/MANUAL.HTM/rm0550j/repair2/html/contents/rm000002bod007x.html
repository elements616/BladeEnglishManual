DTC P0776/63 SL2 Solenoid Circuit (Functional Malfunction)

Print

Preparation List


Function Description


The transmission control computer detects the gear position from the signals of the transmission revolution sensor (NT) and (NC).

When the detected gear position differs from the commanded gear position, the transmission control computer detects a mechanical problem in the related solenoid valve, valve body or automatic transmission.
