Shift Lock Control Unit Assembly (U660E) Reassembly

Print


1. Install Indicator Light Wire



  1. Install the bulb socket and indicator light wire to the position indicator light guide.




  2. Install the position indicator light guide together with the indicator light wire to the position indicator housing assembly with the 3 screws.




  3. Install the indicator light wire to the position indicator housing assembly with the clamp.



2. Install Shift Lock Control Computer



  1. Engage the 3 claws to install the shift lock control computer to the shift lock control unit assembly.




  2. Connect the connector to the shift lock control computer.



3. Install Position Indicator Housing LWR



  1. Insert the guide of the position indicator housing LWR into the shift lock control unit assembly, and engage the 2 claws to install the position indicator housing LWR to the shift lock control unit assembly.

    ■ NOTICE ■
    Securely engage the claws.



4. Install Position Indicator Slide Cover NO.2



  1. Install position indicator slide cover No.2 to the position indicator slide cover.



5. Install Position Indicator Slide Cover



  1. Install the position indicator slide cover together with position indicator slide cover No.2 as a unit to the shift lock control unit assembly.



6. Install Position Indicator Housing UPR



  1. Engage the 4 claws to install the position indicator housing UPR to the shift lock control unit assembly.

    ■ NOTICE ■
    Securely engage the claws.
