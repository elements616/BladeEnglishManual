Windshield Wiper Switch Assembly Installation

Print

Preparation List



1. Install Windshield Wiper Switch Assembly



  1. Engage the claws and install the windshield wiper switch assembly.

  2. Connect the connector.



2. Install Steering Column Cover

■ NOTICE ■
If the installation procedure is incorrect, gaps may form in the column cover.




  1. Engage the 2 claws and pins, and install the steering column cover (upper side).




  2. Engage the 2 claws and install the steering column cover (lower side).




  3. Engage the 4 claws.




  4. Engage the claws.

    ■ NOTICE ■
    Push the bottom surface of the steering column cover (lower side) to securely engage the claws.



3. Check Front Wheels Straight-ahead Position


4. Center Spiral Cable

  1. Check that the IG is OFF.

  2. Check that the battery negative terminal is disconnected.

    ■ NOTICE ■
    After disconnecting the battery negative terminal, do not start work for 90 seconds.




  3. Slowly turn the spiral cable counterclockwise until it locks.

    ■ NOTICE ■
    1. To prevent breaking the spiral cable, turn it gently without applying force.
    1. Do not turn the spiral cable 2.5 or more turns left or right from the matchmark, as it may break.

    □ HINT □
    The spiral cable rotates approximately 5 turns maximum.




  4. From the locked position, turn the spiral cable back 2.5 turns clockwise and align the matchmarks shown in the illustration.



5. Install Steering Wheel Assembly



  1. Align the matchmarks and install the steering wheel assembly to the steering column assembly.

  2. Install the nut.

    Standard
    T = 50 N/m{ 510 kgf/cm }

  3. Connect each connector to the spiral cable.



6. Install Horn Button Assembly



  1. Connect the horn connector to the horn button assembly.

  2. Connect the airbag connector to the horn button assembly and lock it securely.

    ■ NOTICE ■
    Securely lock the airbag connector.




  3. Using a torx socket wrench (T30), install the horn button assembly to the steering wheel assembly with the 2 torx bolts.

    Standard
    T = 8.8 N/m{ 90 kgf/cm }



7. Install Steering Wheel Cover Lower NO.3



  1. Engage the claws and install the steering wheel cover lower No.3.



8. Install Steering Wheel Cover Lower NO.2



  1. Engage the claws and install the steering wheel cover lower No.2.



9. Check Steering Wheel Assembly Center Position


10. Connect Battery Negative Terminal
Standard
T = 5.4 N/m{ 55 kgf/cm }
