Engine Mounting Insulator Rear (2AZ-FE) Installation

Print

Preparation List



1. Install Engine Mounting Insulator Rear



  1. Install the engine mounting insulator RR with the 2 bolts and 2 nuts.

    Standard
    T = 95 N/m{ 969 kgf/cm }




  2. Install the engine mounting insulator RR to the engine mounting bracket RR with the bolt and nut.

    Standard
    T = 95 N/m{ 969 kgf/cm }



2. Connect Transmission Control Cable Assembly



  1. Install the transmission control cable support to the engine mounting insulator RR with the bolt.

    Standard
    T = 5.0 N/m{ 51 kgf/cm }



3. Install Engine Under Cover NO.2

  1. Install engine under cover No.2 with the 5 clips.



4. Install Engine Under Cover NO.1

  1. Install the engine under cover No.1 with the 6 bolts and 7 clips.
