  1. Inspection Using TaSCAN

    1. ECU Data Monitor


      1. Turn IG OFF.

      2. Connect SST (TaSCAN) to DLC3.

        SST
        09991-70200  

      3. Start the engine, select "Diagnosis" → "System Diagnosis/Chassis" → "System Name/IPA" → "ECU Data Monitor" on SST (TaSCAN) and select the item to be inspected.

        ■ NOTICE ■
        ECU Data Monitor values vary greatly due to slight measurement errors, differences in measurement environment, changes in the vehicle over time, etc., making it difficult to indicate a clear standard (judgment value). Therefore, a malfunction may exist even if values are within the reference range.
