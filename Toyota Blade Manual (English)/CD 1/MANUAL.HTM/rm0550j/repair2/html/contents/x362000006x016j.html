EFI System (2GR-FE) ECU Power Source System

Print

Preparation List


Circuit Description


  1. When the IG is turned ON, current from the MREL terminal of the engine control computer flows to the EFI MAIN relay, closing the EFI MAIN relay contacts and supplying power to the +B or +B2 terminal of the engine control computer.
