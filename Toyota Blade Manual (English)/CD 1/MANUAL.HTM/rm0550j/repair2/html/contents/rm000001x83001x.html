2. Install Rear Combination Light Socket & Wire Sub-assembly RH

  2. Engage the claw and install the tail light (rear combination light) socket & wire RH.



3. Install Rear Turn Signal Light Bulb

  1. Install the rear turn signal light bulb to the tail light (rear combination light) socket & wire RH.




  2. Turn in the direction indicated by the arrow in the illustration and install the rear turn signal light bulb together with the tail light (rear combination light) socket & wire RH.



4. Install Back-up Light Bulb

  1. Install the back-up light bulb to the tail light (rear combination light) socket & wire RH.




  2. Turn in the direction indicated by the arrow in the illustration and install the back-up light bulb together with the tail light (rear combination light) socket & wire RH.



5. Install Rear Combination Light Body Packing LH



  1. Install a new tail light (rear combination light) body packing LH.
