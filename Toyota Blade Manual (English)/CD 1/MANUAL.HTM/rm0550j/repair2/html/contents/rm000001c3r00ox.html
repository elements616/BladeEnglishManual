G-BOOK System Function Description

Print



  1. Diagnosis Function

    1. The HDD navigation system has a diagnosis function that can check the connection of and diagnose devices connected via AVC-LAN. (Inspection results are shown on the display)

    2. Each device that makes up the AVC-LAN is assigned a 3-digit number (16-base notation) called a device code (physical address).

    3. Each function (unit) inside the devices that make up the AVC-LAN is assigned a 2-digit number (16-base notation) called a logical address.
