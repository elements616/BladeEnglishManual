Engine Switch Installation

Print

Preparation List



1. Engine Switch Installation



  1. Install the engine switch to the switch hole base No.1.

    □ HINT □
    Check that the clips are fully engaged.



2. Switch Hole Base NO.1 Installation

  1. Connect the connector.




  2. Engage the 2 clips and 2 claws, and install the switch hole base No.1.



3. Install Instrument Panel Airbag Assembly LWR NO.1



  1. Connect the connector to the instrument lower airbag No.1.

    ■ NOTICE ■
    Securely lock the connector.




  2. Install the instrument lower airbag No.1 with the 6 claws and 2 guides.




  3. Install the instrument lower airbag No.1 with the 4 bolts.

    Standard
    T = 10 N/m{ 102 kgf/cm }



4. Install Instrument Panel Under Cover Sub-assembly NO.1



  1. Engage the 2 screws and claws, and install instrument panel under cover NO.1.



5. Install Steering Column Cover

■ NOTICE ■
If the installation procedure is incorrect, gaps may form in the column cover.




  1. Engage the 2 claws and pins, and install the steering column cover (upper side).




  2. Engage the 2 claws and install the steering column cover (lower side).




  3. Engage the 4 claws.




  4. Engage the claws.

    ■ NOTICE ■
    Push the bottom surface of the steering column cover (lower side) to securely engage the claws.



6. Install Steering Wheel Assembly



  1. Align the matchmarks and install the steering wheel assembly to the steering column assembly.

  2. Install the nut.

    Standard
    T = 50 N/m{ 510 kgf/cm }

  3. Connect each connector to the spiral cable.



7. Install Horn Button Assembly



  1. Connect the horn connector to the horn button assembly.

  2. Connect the airbag connector to the horn button assembly and lock it securely.

    ■ NOTICE ■
    Securely lock the airbag connector.




  3. Using a torx socket wrench (T30), install the horn button assembly to the steering wheel assembly with the 2 torx bolts.

    Standard
    T = 8.8 N/m{ 90 kgf/cm }



8. Install Steering Wheel Cover Lower NO.3



  1. Engage the claws and install the steering wheel cover lower No.3.



9. Install Steering Wheel Cover Lower NO.2



  1. Engage the claws and install the steering wheel cover lower No.2.



10. Install Instrument Panel Finish Panel Lower NO.2



  1. Push in the direction of the arrow shown in the illustration to engage the 2 clips and guide.




  2. Install instrument panel finish panel lower No.2 with the 2 screws <C>.



11. Install Instrument Panel Finish Panel Lower NO.1



  1. Push in the direction of the arrow shown in the illustration to engage the 2 clips and guide.




  2. Engage the 4 claws and 2 guides.




  3. Install instrument panel finish panel lower No.1 with the 2 screws <C>.



12. Install Instrument Panel Under Tray



  1. Engage the 4 claws and install the instrument panel under tray.



13. Install Box Bottom Mat


14. Install Console Box Insert FR NO.2



  1. Insert the guide.

  2. Engage the 3 claws and install the console box insert.



15. Install Console Box Insert



  1. Insert the guide.

  2. Engage the 3 claws to install console box insert front No.2.



16. Install Console Box Assembly Rear



  1. Engage the 4 claws.




  2. Install the console box assembly RR with the 4 bolts and 2 screws.



17. Install Console Box Carpet



  1. Install the console box carpet.



18. Install Instrument Panel Finish Panel LWR CTR



  1. Engage the 6 clips and 4 claws.




  2. Install the instrument panel finish panel LWR CTR with the 2 screws <C>.



19. Install Position Indicator Housing Assembly



  1. Connect the connector.




  2. Engage the 7 claws and install the position indicator housing assembly.

    ■ NOTICE ■
    Securely engage the claws.



20. Install Console Box Cover RR

  1. Connect the connectors.




  2. Engage the 4 clips to install the console box rear cover.



21. Install Shift Lever Knob



  1. Turn the shift lever knob in the direction of the arrow shown in the illustration to install it.



22. Install Instrument Panel Finish Panel End RH



  1. Engage the 4 clips and install the instrument panel finish panel end RH.



23. Install Instrument Panel Finish Panel End LH



  1. Engage the 4 clips and install the instrument panel finish panel end LH.



24. Install Instrument Cluster Finish Panel Assembly



  1. Engage the 2 claws and 9 clips, and install the instrument cluster finish panel.




  2. Remove the protective tape that was applied.
