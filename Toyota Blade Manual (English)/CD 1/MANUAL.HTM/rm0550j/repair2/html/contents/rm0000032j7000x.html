DTC B279A Immobiliser Communication Line (Stuck Hi)

Print

Preparation List


Circuit Description


The engine ECU (engine control computer) outputs this code when the communication line (EFIO - IMI) with the ID code box (immobiliser code computer) is stuck at Hi output.


DTC No.
DTC Detection Condition
Inspection Area
B279A
The communication line (EFIO - IMI) between the engine ECU (engine control computer) and the ID code box (immobiliser code computer) is stuck at Hi output
  1. Wire Harness
  2. ID Code Box (Immobiliser Code Computer)
  3. Engine ECU (Engine Control Computer)
