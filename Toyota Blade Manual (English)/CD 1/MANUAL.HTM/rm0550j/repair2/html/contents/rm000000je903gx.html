HDD Navigation System Function Inspection

Print


1. HDD Diagnosis

  1. Start Diagnosis

    □ HINT □
    For starting diagnosis and screen transitions, refer tofor reference.


    1. Start diagnosis and display the service inspection menu screen.

    2. Select "Diagnosis/Diagnostic Information Collection" on the service inspection menu screen to display the diagnosis/diagnostic information collection screen.




  2. HDD Diagnosis

    1. Perform HDD diagnosis.

      HDD Diagnosis Result Display Content 
      Display
      		Diagnosis Result
      Diagnosing
      		HDD diagnosis in progress
      NG
      		HDD malfunction present
      OK
      		No HDD malfunction

      □ HINT □
      1. It takes some time for the check to complete.
      2. If the vehicle interior is cold or hot, the HDD may not operate normally and "NG" may be displayed. Therefore, perform HDD diagnosis after placing the vehicle in a normal temperature environment and bringing the vehicle interior temperature to -20°C or more and 65°C or less.
      3. If the diagnosis result is "NG" even though the vehicle interior temperature is -20°C or more and 65°C or less, replace the navigation receiver assembly.



2. Panel/Steering SW Check

  1. Start Diagnosis

    □ HINT □
    For starting diagnosis and screen transitions, refer tofor reference.


    1. Start diagnosis and display the service inspection menu screen.

    2. Select "Function Check/Adjustment" on the service inspection menu screen.

    3. Select "Panel/Steering SW Check" on the function check/adjustment screen to display the panel/steering SW check screen.




  2. Panel and Steering Switch Check

    1. Operate each switch and check that it is displayed on the screen.

      Panel/Steering SW Check Screen Display Content 
      Display
      		Description
      Pressed Switch Name
      1. Displays the name of the pressed switch while it is pressed
      2. If multiple switches are pressed, "Multiple Switches" is displayed
      Operated Switch Name
      		Displays the name of the operated rotary switch (screen display is cleared after 1 seconds of no operation)
      Switch Rotation Direction
      		Displays the state of the operated rotary switch (screen display is cleared after 1 seconds of no operation)
      Back
      		Returns to the function check/adjustment screen

      □ HINT □
      1. If the check result for the switches on the navigation receiver assembly is abnormal, the navigation receiver assembly can be judged to be faulty.
      2. If the check result for the switches on the steering pad switch assembly is abnormal, it is necessary to check the steering pad switch assembly (3-spoke steering wheel) (see), steering pad switch assembly (4-spoke steering wheel) (see), spiral cable sub-assembly (see), and wire harness and connector (navigation receiver assembly - steering pad switch assembly) (see).



3. Touch SW Check

  1. Start Diagnosis

    □ HINT □
    For starting diagnosis and screen transitions, refer tofor reference.


    1. Start diagnosis and display the service inspection menu screen.

    2. Select "Function Check/Adjustment" on the service inspection menu screen.

    3. Select "Touch SW Check" on the function check/adjustment screen to display the display pressure-sensitive touch switch check screen.




  2. Touch Switch Check

    1. Touch the screen and check that a cross-shaped cursor is displayed at the touched location.

      Specified Condition
      Cursor is displayed at the touched location

      □ HINT □
      1. Once a location is judged as touched, the cursor remains displayed until another location is touched.
      2. If the touch SW check result is abnormal, the navigation receiver assembly can be judged to be faulty.

    1. Start diagnosis and display the service inspection menu screen.

    2. Select "Function Check/Adjustment" on the service inspection menu screen.

5. GPS Check

  1. Start Diagnosis

    □ HINT □
    For starting diagnosis and screen transitions, refer tofor reference.


    1. Start diagnosis and display the service inspection menu screen.

    2. Select "Function Check/Adjustment" on the service inspection menu screen.

    3. Select "GPS/Sensor Information" on the function check/adjustment screen to display the GPS check screen.




  2. GPS Check

    GPS Information Screen Display Contents 
    Display
    		Meaning
    Satellite Information
    		Displays "Satellite No.", "Elevation", "Azimuth", "Signal Level" and "Reception Status" of satellites captured by the antenna (up to 12 satellites)
    Date and Time
    		Displays date and time information obtained from the GPS receiver as "year", "month", "day", "hour", "minute" and "second"
    Position
    		Displays latitude and longitude of the current position as "degrees", "minutes" and "seconds"
    Reception Status 
    Display
    		Meaning
    In use
    		When the satellite is being used for positioning
    Receiving
    		When the satellite is captured but not used for positioning
    -
    		When the satellite cannot be captured
    Positioning Status 
    Display
    		Meaning
    2D
    		During 2-dimensional positioning
    3D
    		During 3-dimensional positioning
    NG
    		When positioning data cannot be used
    error
    		When a reception error occurs
    -
    		Other than above

    □ HINT □
    GPS information is updated every 1 seconds.



6. Sensor Check

  1. Start Diagnosis

    □ HINT □
    For starting diagnosis and screen transitions, refer tofor reference.


    1. Start diagnosis and display the service inspection menu screen.

    2. Select "Function Check/Adjustment" on the service inspection menu screen.

    3. Select "GPS/Sensor Information" on the function check/adjustment screen to display the GPS check screen.

    4. Select "Sensor Check" on the GPS check screen to display the sensor check screen.




  2. Sensor Check

    Sensor Check Screen Display Content 
    Item
    		Display Method
    		Navigation Receiver Assembly Signal Input Terminal
    SPD Signal Status
    		Displays SPD signal status (cumulative number of input pulses since this screen was displayed, and vehicle speed [km/h])
    		F3 (SPD) terminal
    Gyro Sensor Output Status
    		Displays gyro sensor output status (voltage value [V] and amount of change in heading [degrees] since this screen was displayed)
    		-
    Inclination Angle Sensor Output Status (*1)
    		Displays inclination angle sensor output status (amount of change in vehicle inclination angle [degrees] since this screen was displayed)
    		-
    Reset
    		Resets the gyro sensor relative heading and SPD signal pulse count display items and sets the display content to "0"
    		-

    □ HINT □
    1. The vehicle signals are updated every 1 seconds.
    2. *1: Displayed when the inclination angle sensor data becomes a valid value. (Not displayed when there is an inclination angle sensor malfunction or sensor data learning is incomplete)
    1. A DTC is output if there is a difference between the vehicle speed calculated from the GPS signal and the input SPD signal. (see)
    1. A DTC is output if there is a malfunction in the gyro sensor output voltage. (see)

      □ HINT □

      2. If the display vehicle signal check result is abnormal, inspect each terminal or the vehicle wire harness. (see)

10. Navigation Voice Guidance Setting Check (When Voice Guidance is Not Heard)

  1. Setting Inspection

    1. In the voice settings on the setup/edit screen (navigation), set the volume to maximum and check the voice output.

      Specified Condition
      "Guidance will be given at this volume" is announced

      □ HINT □
      In the following cases, voice guidance is not given even if the system is normal.
      1. When a destination has not been set. (Voice such as prefecture border guidance is output)
      2. When not driving on the route (no remaining distance display at the lower left of the current position screen). (Voice such as prefecture border guidance is output)
      3. When "Guidance in Other Modes" is not set. (Voice guidance is not given on screens other than the map screen)



11. Gyro Initialization Check (When Vehicle Position Mark Rotates)

  1. Operate Again

    1. Turn the IG OFF → ON and check whether it returns to normal.

      Specified Condition
      Return to Normal

      □ HINT □
      1. If ACC or IG is turned ON while the vehicle is rotating (such as on a turntable), the navigation receiver assembly memorizes the angular velocity at that time as the reference, so the vehicle position rotates even if the system is normal.
      2. In the above case, turning the IG OFF → ACC ON with the vehicle stopped returns it to normal.
