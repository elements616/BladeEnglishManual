DTC C1613 ACC Voltage Malfunction

Preparation List


Function Description


This DTC is output when the television camera controller determines through its self-diagnosis that the input ACC voltage is abnormal.


DTC No.
Diagnosis Description
Inspection Area
C1613
  1. ACC Voltage Drop
  2. ACC Voltage Rise
  1. Television Camera Controller
  2. Television camera controller power source system wire harness and connector
