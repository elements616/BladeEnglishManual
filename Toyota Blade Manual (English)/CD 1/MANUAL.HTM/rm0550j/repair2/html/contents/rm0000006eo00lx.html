  1. ECU Data Monitor (TaSCAN)

    1. With the IG OFF, connect SST (TaSCAN) to DLC3.

      SST
      09991-70200  

    2. Turn IG ON.

    3. Following the SST (TaSCAN) screen display, display the "ECU Data Monitor" screen and check the computer data.

    1. Active Test (TaSCAN)

      1. With the IG OFF, connect SST (TaSCAN) to DLC3.

        SST
        09991-70200  

      2. Turn IG ON.

      3. Following the SST (TaSCAN) screen display, display the "Active Test" screen and perform the active test.

        ■ NOTICE ■
        If the active test is performed many times in succession, the overheat protection function of the motor in the seat belt operates, "PCS Currently Unavailable" is shown on the multi-display in the combination meter assembly, and control stops. When the temperature drops and pre-crash seat belt control becomes possible again, the display disappears and the system returns to the controllable state.


        [System Selection Screen: Body → Pre-crash → Active Test] 
        Item Name
        		Test Details
        		Restrictions
        Driver Side Belt Motor
        		Operates driver side seat belt motor (Operate/Stop)
        		Does not operate even if requested when the seat belt is not fastened
        Front Passenger Side Belt Motor
        		Operates front passenger side seat belt motor (Operate/Stop)
        		Does not operate even if requested when the seat belt is not fastened
