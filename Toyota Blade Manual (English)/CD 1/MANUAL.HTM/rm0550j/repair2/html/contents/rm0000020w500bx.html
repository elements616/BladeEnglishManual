Exhaust Pipe Assembly (2GR-FE) Installation

Print

Preparation List



1. Install Exhaust Pipe Assembly Front



  1. Install the front exhaust pipe assembly with a new gasket and 2 nuts.

    Standard
    T = 62 N/m{ 632 kgf/cm }




  2. Install the exhaust pipe bracket with 2 bolts.

    Standard
    T = 21 N/m{ 214 kgf/cm }




  3. Using SST, install the oxygen sensor and connect the oxygen sensor connector.

    SST
    09224-00010  
    Standard
    T = 44 N/m{ 449 kgf/cm }



2. Install Exhaust Pipe Assembly Center



  1. Install the exhaust center pipe assembly with 2 new gaskets, 2 nuts and 2 bolts.

    Standard
    Bolt
    T = 62 N/m{ 632 kgf/cm }
    Nut
    T = 43 N/m{ 438 kgf/cm }




  2. Before installing the oxygen sensor body, twist it approximately 4 turns as shown in the illustration, then install it.




  3. Using SST, install the oxygen sensor.

    SST
    09224-00010  
    Standard
    T = 44 N/m{ 449 kgf/cm }



3. Center Exhaust Pipe Sub-assembly NO.2 Installation

  1. Compression Spring Inspection




    1. Using a vernier caliper, measure the free length of the compression spring.

      Limit
      41.5mm

      □ HINT □
      If it is less than the minimum, replace the spring with a new one.




  2. Install the gasket.

    1. Insert a new gasket into the center pipe assembly by hand as far as it will go.

    2. Place a piece of wood against the gasket and, using a hammer, gradually tap it in until it reaches the flange end face of the exhaust center pipe assembly.

      ■ NOTICE ■
      1. Do not install the gasket in the wrong direction.
      2. Do not damage the outer surface of the gasket.
      3. Do not reuse a gasket once it has been removed.
      4. Never push in the gasket by installing the center exhaust pipe sub-assembly NO.2 without first pushing it in sufficiently by hand.




  3. Install the exhaust center pipe assembly with 2 bolts and 2 compression springs.

    Standard
    T = 43 N/m{ 438 kgf/cm }

    ■ NOTICE ■
    After installation, check that there is no significant difference in the clearance between the flanges of the exhaust center pipe assembly and the center exhaust pipe sub-assembly NO.2 at the front, rear, left and right.



4. Install Front Floor Brace Center



  1. Install the 4 bolts and the front floor brace center.

    Standard
    T = 51 N/m{ 520 kgf/cm }



5. Install Exhaust Tail Pipe Assembly

  1. Compression Spring Inspection




    1. Using a vernier caliper, measure the free length of the compression spring.

      Limit
      38.5mm

      □ HINT □
      If it is less than the minimum, replace the spring with a new one.




  2. Install the gasket.

    1. Insert a new gasket into the exhaust center pipe assembly as far as it will go by hand.

      ■ NOTICE ■
      1. Do not install the gasket in the wrong direction.
      2. Do not damage the outer surface of the gasket.
      3. Do not reuse a gasket once it has been removed.
      4. Never push the gasket in by installing the exhaust pipe without first pressing it in sufficiently by hand.




  3. Install the exhaust tail pipe assembly with 2 bolts and 2 compression springs.

    Standard
    T = 43 N/m{ 438 kgf/cm }

    ■ NOTICE ■
    After installation, check that there is no significant difference in the clearance between the flanges of the exhaust center pipe assembly and exhaust tail pipe assembly at the front, rear, left and right.



6. Inspect for Exhaust Gas Leaks


  1. Check that there are no exhaust gas leaks from the locations shown in the illustration (exhaust pipe joints and each sensor installation area).
