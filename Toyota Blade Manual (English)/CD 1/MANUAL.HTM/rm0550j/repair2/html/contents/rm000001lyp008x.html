DTC U1002 Sub-network Communication Malfunction (CAN Gateway)

Print

Preparation List


Function Description


The CAN gateway ECU outputs the code when it cannot receive data from any of the V bus No.2 connected ECUs whose connection is stored in memory.

When a network malfunction (main line malfunction) occurs, the CAN gateway ECU may erase the stored code in order to restore communication.


DTC No.
DTC Detection Condition
DTC Output Related Items
U1002
Data cannot be received from any of the ECUs whose connection is stored in the CAN gateway ECU memory
  1. Main line (1) open or short circuit
  2. Short circuit in either branch wire (2) or (3)
  3. Open circuit in all branch wires (2) and (3)
  4. CAN J/C internal short or open circuit
  5. Poor connector terminal contact or contact pressure
  6. Network gateway computer (CAN gateway ECU) internal malfunction

Inspection Procedure


■ NOTICE ■
When measuring the resistance of the CAN bus, turn the ignition switch off, check that warning functions such as the key reminder warning system are not operating, and leave the vehicle for at least 1 minutes without operating the key or switches or opening and closing the doors before starting the measurement. If it is necessary to open a door during inspection, open it beforehand.


□ HINT □
  1. When inspecting each connector, before disconnecting it, push the connector case in the connecting direction and check that the connector is not loose or disconnected.
  2. When disconnecting a connector, check that the connector terminals and connector case are free of damage, deformation, corrosion, etc.
