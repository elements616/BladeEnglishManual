  1. Read DTC (Read Using TaSCAN)

    1. Turn IG OFF.

    2. Connect SST (TaSCAN) to DLC3.

      SST
      09991-70201  

    3. Start the engine, select "Diagnosis" → "Vehicle Diagnosis/All DTCs" or "Body" → "System Name/Navigation System" → "DTC" on the SST (TaSCAN) screen to display the DTC check screen.

    4. Check the diagnostic trouble codes.

      ■ NOTICE ■
      Always check DTCs with the engine running.

      □ HINT □
      1. If a malfunction code is displayed, refer to the Diagnostic Trouble Code Chart ().
      2. The navigation receiver assembly outputs DTCs for the following systems. If a DTC not listed in the HDD navigation system - Diagnostic Trouble Code Chart is output, refer to the other system.
        System Name
        		Reference
        Back Guide Monitor System
        ETC System
      3. After repair, check the DTCs again and confirm that no malfunction code is output.



    1. Clear DTC Memory (Clear Using TaSCAN)

      1. Turn IG OFF.

      2. Connect SST (TaSCAN) to DLC3.

        SST
        09991-70201  

      3. Start the engine, select "Diagnosis" → "Vehicle Diagnosis/All DTCs" or "Body" → "System Name/Navigation System" → "DTC" on the SST (TaSCAN) screen to display the DTC check screen.

      4. Select "Clear" and clear the DTCs following the screen instructions.

        4. Individual Diagnosis


          1. When the inspection result is "Replace" or "Check", select this display to move to the individual diagnosis screen.

          2. Check and record the content of the output DTCs.

            Individual Diagnosis Screen Display Contents  
            Display
            		Meaning
            Device Name
            		Name of target device
            Diagnostic Trouble Code (DTC)
            		Diagnostic Trouble Code (DTC)
            Current Code
            		Displays DTCs input during system inspection (up to 6 items)
            History Code
            		Displays diagnosis memory collection results and normal diagnosis notification contents (up to 6 items)
            Clear Diagnosis
            		Clears the diagnosis information of the target device and clears the display (press and hold for 3 seconds)

            ■ NOTICE ■
            The navigation receiver assembly stores up to 6 codes. If output of 6 or more codes is expected, check the DTCs using SST (TaSCAN).
