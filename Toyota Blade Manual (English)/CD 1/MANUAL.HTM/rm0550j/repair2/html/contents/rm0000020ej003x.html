Rear Seat Belt Assembly Inner (w/ Center) LH Installation

Print

Preparation List



1. Install Rear Seat Inner Belt Assembly (Center) LH



  1. Install the rear seat inner belt assembly (center) LH with the bolt.

    Standard
    T = 41 N/m{ 420 kgf/cm }

    ■ NOTICE ■
    1. Pay attention to the installation direction of the floor anchor.
    2. Be careful that the floor anchor does not ride up onto the locator.



2. Install Rear Seat Cushion Assembly

  1. Return the rear seat cushion assembly to its original position.




  2. Install the rear seat cushion assembly with the 2 bolts.

    Standard
    T = 42 N/m{ 428 kgf/cm }



3. Install Rear Seat Cushion Hinge Cover NO.2



  1. Engage the 4 claws and install the rear seat cushion hinge cover NO.2.



4. Install Rear Seat Cushion Hinge Cover NO.1



  1. Engage the 4 claws and install the rear seat cushion hinge cover NO.1.
