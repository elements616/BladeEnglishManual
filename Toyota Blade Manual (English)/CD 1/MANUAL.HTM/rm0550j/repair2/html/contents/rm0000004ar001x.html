Front Door Belt Moulding Assembly LH Installation

Print

Preparation List



1. Install Front Door Belt Moulding Assembly LH



  1. Engage the 6 claws to install the front door belt moulding assembly LH.



2. Install Front Door Glass Sub-assembly LH

  1. Connect the battery negative terminal and power window regulator master switch assembly, and move the front door window regulator RH to a position where the installation position of the front door glass RH is visible.

  2. Disconnect the battery negative terminal and power window regulator master switch assembly.




  3. Temporarily install the front door glass RH to the front door window regulator RH in the order shown in the illustration.

    ■ NOTICE ■
    Do not damage the front door glass RH.




  4. Install the front door glass RH with the 2 bolts.

    Standard
    T = 8.0 N/m{ 82 kgf/cm }



3. Install Front Door Service Hole Cover LH

  1. Apply butyl tape to the door panel side.

  2. Pass the front door lock remote control cable RH, rear door inside locking cable RH and each connector through a new front door service hole cover RH.




  3. Align a new front door service hole cover RH with the reference position on the front door panel and attach it.

    ■ NOTICE ■
    Attach the front door service hole cover RH so that there are no wrinkles or lifting, and press it down firmly.

  4. Connect the connector.



4. Install Front Door Glass Weatherstrip Inner LH



  1. Install the front door glass weatherstrip inner RH to the front door panel.



5. Install Front Door Inside Handle Sub-assembly LH



  1. Install the front door lock remote control cable RH and front door inside locking cable RH to the front door inside handle RH.




  2. Engage the 2 claws to install the front door inside handle RH to the front door trim board RH.



6. Install Front Door Trim Board Sub-assembly LH



  1. Engage the 4 claws to install the front door trim board RH to the front door glass weatherstrip inner RH.

  2. Engage the 9 clips to install the front door trim board RH to the front door panel.




  3. Install the 3 screws.



7. Install Door Assist Grip Cover LH



  1. Engage the 4 claws to install the door assist grip cover RH to the front door trim board RH.



8. Install Front Door Inside Handle Bezel LH



  1. Engage the 3 claws to install the front door inside handle bezel RH to the front door trim board RH.
