  1. ECU Data Monitor (TaSCAN)

    ■ NOTICE ■
    1. Data monitor values vary greatly due to slight measurement differences, differences in measurement environment, changes in the vehicle over time, etc., so it is difficult to give clear standard values (judgment values). Therefore, a malfunction may exist even if values are within the reference range.
    2. For subtle symptoms such as hesitation or rough idle, it is necessary to compare with data collected from a vehicle of the same model under the same conditions and to make an overall judgment from all data monitor items.

    1. With the IG OFF, connect SST (TaSCAN) to DLC3.

      SST
      09991-70200  

    2. Turn IG ON.

    3. Following the TaSCAN screen display, display the "ECU Data Monitor" screen and check the computer data.
