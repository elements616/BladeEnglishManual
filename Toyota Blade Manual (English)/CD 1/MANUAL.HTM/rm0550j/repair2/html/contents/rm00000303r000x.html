DTC C1AEE IPA Sensor Communication Circuit Malfunction

Print

Preparation List


Function Description


The television camera controller communicates with ultrasonic sensor NO.1 (FLS sensor) via ultrasonic sensor NO.1 (FRS sensor) and ultrasonic sensor NO.1 (FRS sensor). This DTC is output when the television camera controller's self-diagnosis determines that there is a malfunction in communication with ultrasonic sensor NO.1 (FLS sensor), which is connected via ultrasonic sensor NO.1 (FRS sensor) or ultrasonic sensor NO.1 (FRS sensor).


DTC No.
Diagnosis Description
Inspection Area
C1AEE
IPA Ultrasonic Sensor Communication Bus Malfunction
  1. Wire harness and connector between television camera controller and ultrasonic sensor NO.1 (FRS sensor)
  2. Wire harness and connector between ultrasonic sensor NO.1 (FRS sensor) and ultrasonic sensor NO.1 (FLS sensor)
  3. Ultrasonic sensor NO.1 (FRS sensor)
  4. Ultrasonic Sensor NO.1 (FLS Sensor)
  5. Television Camera Controller
