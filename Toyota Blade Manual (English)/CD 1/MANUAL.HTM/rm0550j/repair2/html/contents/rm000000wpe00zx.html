DTC P0724/95 STP Light Switch ON Malfunction

Print

Preparation List


Circuit Description


The stop light switch detects the operating condition of the brake pedal and outputs it to the engine control computer. The stop light switch is installed on the brake pedal bracket, and is connected to the engine control computer via the wire harness.

Using SST (TaSCAN), read the Freeze Frame Data. Freeze frame data records part of the engine operating condition when a malfunction occurs, and this information is useful when troubleshooting.
