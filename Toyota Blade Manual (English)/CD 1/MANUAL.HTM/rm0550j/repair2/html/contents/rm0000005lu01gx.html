SRS Airbag System Diagnostic Trouble Code Chart

Print


□ HINT □
  1. If a short to +B, short to ground or open circuit occurs somewhere in the airbag system ignition circuits, other malfunctions may not be output. In this case, other codes can be output by repairing or replacing the malfunctioning area for the currently output diagnostic trouble code and checking the diagnostic trouble codes again.
  2. If diagnostic trouble code B1000 is output, replace the airbag computer assembly with a new one.
  3. The marks for check mode compatible items are as follows. ○: Check mode compatible ×: Check mode not compatible
