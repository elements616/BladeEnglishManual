    1. Multi-information Display


      1. Multi-information Display Flowchart



        □ HINT □
        1. With IG ON, the monitor display priority is: PCS Wrn display > Initial Check display > DTC display > ACC display > warning display > drive monitor display. With IG OFF, only the warning display is shown.
        2. *1: In the initial state (when the battery is connected), the display starts from the clock display. (During normal operation of the IG switch, the display starts from the previous state)
        3. *2: Press the "DISP" switch to cycle through the drive monitor displays in order. (Including warnings and ACC displays inserted by interruption)
        4. *3: If the display switches to a higher priority display (warning display or DTC display) during clock setting, the display after the higher priority display is cancelled is used.
        5. *4: Pressing and holding the "DISP" switch for 0.8s or more resets the displayed value.
        6. *5: Pressing and holding the "DISP" switch for 1.0s or more switches to clock setting mode.



      2. Warning Display




        1. Warnings are scrolled automatically.

        2. When warnings occur, they are displayed in order from the lowest display priority level number.

        3. When multiple warnings occur, each warning is displayed at 2-second intervals. However, a newly occurring warning is displayed for 6 seconds the first time only.

          □ HINT □
          Warning items marked "initial display 2S" in the remarks are displayed for 2 seconds even when displayed for the first time.

        4. "Depress brake when starting" is not displayed on the meter with IG ON because the transmitting ECU does not send it with IG ON.
