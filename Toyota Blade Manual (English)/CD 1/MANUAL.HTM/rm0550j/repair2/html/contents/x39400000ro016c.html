DTC P2119/89 Electronic Throttle System Malfunction

Print

Preparation List


Circuit Description


  1. When this DTC is stored, the engine control computer cuts off the current to the throttle motor, and the throttle valve is returned to a predetermined opening angle (6.5°) by the return spring.
