CVT System [Super CVT-i] (K112/K112F) System Description

Print



  1. NAVI/AI-SHIFT (w/ Navigation)

    1. Vehicles with HDD navigation system perform NAVI AI-SHIFT control.

    2. When the [NAVI AI-SHIFT On/Off] switch on the navigation screen is set to [On], control is performed to select the gear suited to road and driving conditions.

    3. When the [NAVI AI-SHIFT On/Off] switch on the navigation screen is set to [Off], NAVI AI-SHIFT control is cancelled and normal control is performed.

    4. If a malfunction occurs in the system, NAVI AI-SHIFT control is cancelled and normal control is performed.

    5. When the [NAVI AI-SHIFT Control Level Strong/Weak] switch on the navigation screen is set to [Strong], control is performed to increase the amount of downshift, and when set to [Weak], control is performed to decrease the amount of downshift.
