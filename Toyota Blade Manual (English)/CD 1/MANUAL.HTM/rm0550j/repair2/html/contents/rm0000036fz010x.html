Step 1Symptom Check

  1. Take the action for the check items corresponding to the displayed message, and check that the problem is reproduced.

    Displayed Message
    		Cause
    		Items to Check
    "Information could not be obtained because the line is busy, etc." is displayed
    1. Other communication failure
    2. Mobile carrier differs from setting
    3. Connection retry count exceeded
    4. PPP authentication error
    5. Error other than PPP authentication
    6. No socket available
    7. No response from the center for a certain time after sending request
    8. HTTP error
    		Wait a while, operate again and check that the problem is reproduced (*1)
    "Cannot display because the line is busy, etc. Please wait a while before operating." is displayed
    		Wait a while, operate again and check that the problem is reproduced (*1)
    "Information could not be obtained because the line was disconnected" is displayed
    		Unexpected disconnection of telephone line
    		Wait a while, operate again and check that the problem is reproduced (*1)
    "Please check the telephone" is displayed
    1. Cannot make calls due to telephone settings
    2. No mobile phone number (SIM card not inserted, etc.)
    		Check that calls can be made from the telephone, operate again and check that the problem is reproduced
    "Telephone is not connected" is displayed
    		Telephone not connected
    		Re-register the telephone, operate again and check that the problem is reproduced
    "Outside service area. Please move to a service area." is displayed
    1. Out of service area
    2. Goes out of service area during communication
    		Move into the service area, operate again and check that the problem is reproduced

    □ HINT □
    *1: If this message occurs temporarily, it is due to radio wave conditions or base station congestion and is not a malfunction. (Explain to the customer and have them continue using it)
