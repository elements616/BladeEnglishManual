      Step 3DTC and Freeze Frame Data Check (see)

      1. Check and Record DTC and Freeze Frame Data

      2. Clear DTC and Freeze Frame Data

      3. Recheck DTC

        1. Based on the recorded DTC and freeze frame data, reproduce the problem symptom and check the DTCs again.

          □ HINT □
          1. When a DTC is output, refer to "Diagnostic Trouble Code Chart ()".
          2. If a CAN communication system malfunction code is output, troubleshoot and repair the CAN communication first. (see) However, if DTC U0100/65, U0123/62, U0124/95 or U0126/63 is output, perform the ECU data monitor (momentary interruption) inspection first. (see)
          3. If SST (TaSCAN) cannot communicate with the skid control computer (built into the actuator), inspect the CAN communication. (see)
          4. If the ABS warning light and VSC warning light do not output DTCs, check that the warning lights illuminate during the initial check immediately after IG ON; if the lights do not illuminate, inspect the light circuit, and if they illuminate, inspect between the DLC3 connector TC terminal ←→ TC terminal of the engine control computer. (The TC terminal input is passed in the order DLC3 → engine control computer → CAN communication → skid control computer (built into the actuator))
          5. If there is no response from the skid control computer (built into the actuator) by either SST (TaSCAN) or the multi-information display, inspect the actuator IG circuit.
