EFI System (2AZ-FE) DTC Check / Clear

Print


□ HINT □
  1. Using SST (TaSCAN), check mode as well as normal mode can be selected, which increases malfunction detection sensitivity compared to normal mode.
  2. Perform inspection in check mode when a malfunction is suspected in a sensor signal circuit but the normal code is output in normal mode.



  1. Pre-inspection Preparation

    1. Check that the throttle valve is fully closed.

    2. Move the shift lever to the N or P position.

    3. Turn the A/C OFF.



    1. DTC Check (Reading Using TaSCAN)

      1. Connect SST (TaSCAN) to DLC3.

        SST
        09991-70200  

      2. Following the SST (TaSCAN) screen display, display the [Diagnosis Function Menu] - [Mode Change] screen, select normal mode or check mode, and check the DTCs.

        □ HINT □
        If the SST (TaSCAN) display is abnormal,.



      1. DTC Check (Reading Using Check Engine Warning Light)

        ■ NOTICE ■
        1. Before reading DTCs, turn the IG ON and check that the check engine warning light comes on.
        2. Inspection in check mode cannot be performed.

        1. Turn IG OFF.




        2. Using SST (diagnosis check wire No.2), connect between terminals 13 (TC) ←→ 4 (CG) of the DLC3.

          SST
          09843-18040  

          ■ NOTICE ■
          1. Connecting the connector to the wrong position will cause a malfunction, so never make a mistake.
          2. Use only the dedicated diagnosis check wire No.2.



        3. Turn the IG ON and read the number of blinks of the check engine warning light.



          □ HINT □
          1. If no code is displayed (the light does not blink), an open in the TC terminal circuit or a computer malfunction is suspected.
          2. If the check engine warning light remains on, a short in the wire harness (pinched, etc.) or a computer malfunction is suspected.
          3. If a meaningless code is output, a computer malfunction is suspected.
          4. If the check engine warning light comes on at 1000r/min or more and no code is output, turn the IG OFF once and then inspect again.

        4. Remove the SST (diagnosis check wire No.2).



        1. Clearing DTC Memory (Clearing Using TaSCAN)

          1. Operate according to the SST (TaSCAN) screen display to display the [Diagnosis Function Menu] - [DTC Check] screen, and clear the DTCs.

            SST
            09991-70200  

            ■ NOTICE ■
            1. If they cannot be cleared, turn the IG OFF once and then try again.
            2. Do not clear DTCs using TaSCAN until the cause has been identified.



          1. Clearing DTCs (Clearing by Removing Fuse)



            1. Remove the EFI fuse (20A) and ETC-S fuse (10A), and reinstall the fuses after 60 seconds or more have elapsed.

              ■ NOTICE ■
              1. After inspecting and repairing the EFI system, always clear the DTC memory and then check that the normal code is output.
              2. Do not clear DTCs by battery clear (removing fuses) until the cause has been identified.



            1. Check Diagnosis Judgment Results (Checking Using TaSCAN)
              SST
              09991-70200  

              □ HINT □
              Perform a DTC output check after repairing a malfunctioning circuit indicated by DTC output, or during a reproduction test after clearing DTCs, etc.

              1. Following the SST (TaSCAN) screen display, display the [Diagnosis Judgment Result Check] screen, and select [Check by DTC] from the menu.

              2. On the next screen, enter the DTC to be checked.

              3. After execution (check start), perform a reproduction test for the relevant DTC and check the DTC judgment result.
