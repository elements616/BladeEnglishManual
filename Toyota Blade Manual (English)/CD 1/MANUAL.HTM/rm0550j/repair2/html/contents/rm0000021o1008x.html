Preparation List


Function Description


This DTC is output when the television camera controller self-diagnosis judges that the electric power steering system connected via CAN communication is invalid.


DTC No.
Diagnosis Description
Inspection Area
C1646
  1. EPS System Invalid Condition
  2. IPA → EPS Communication Malfunction
  1. CAN Communication System
  2. Electric Power Steering System
