Fog Light Assembly LH Installation

Print

Preparation List



1. Install Fog Light Assembly LH



  1. Install the fog light assembly LH with the screw.



2. Install Front Bumper Assembly

  1. Connect the connectors.




  2. Engage the 8 claws (4 each on LH/RH).




  3. Install the front bumper assembly with the 5 clips, 2 bolts and 6 screws.




  4. Install the pin hold clip.

    □ HINT □
    Install the RH side using the same procedure.



3. Install Radiator Grille Protector



  1. Install the 2 radiator grille protectors.



4. Install Radiator Upper Air Deflector

  1. Install the radiator upper air deflector with the 8 clips.



5. Preparation for Fog Light Aim Adjustment

  1. Adjust the tire pressure to the specified value. (see)

  2. Start the engine and keep the battery in a charging condition.



6. Adjust Fog Light Aim



  1. Turn the aiming screw from under the vehicle to adjust.

    □ HINT □
    Turning the screwdriver in the tightening direction moves the fog light aim up, and turning it in the loosening direction moves it down.



7. Inspect Fog Light Aim

Specified Condition
Illuminates within 40m
