Active Torque Control 4WD System Function Description

Print



  1. Diagnosis Function

    1. If a malfunction occurs in the Active Torque Control 4WD system, the 4WD warning light illuminates.

    2. The diagnosis results when a malfunction occurs are stored in the 4WD computer assembly, and the malfunction diagnosis results can be read.



    1. Sensor Check Function

      1. Test mode inspection of the speed sensors and yaw rate sensor can be performed using the test mode of the ABS with EBD & TRC & VSC & BA system.

        □ HINT □
        For the test mode procedure for the ABS with EBD & TRC & VSC & BA systemfor reference.



      1. Fail-safe Function

        1. When there is a malfunction in the Active Torque Control 4WD system sensor signals or electronically controlled coupling system, current to the transmission coupling assembly (linear solenoid SLC) is prohibited and the vehicle is put into front-wheel drive.

        2. If fail-safe occurs during 4WD control, 4WD control is gradually stopped so that vehicle behavior does not change suddenly.



        1. Safety Control Mode Function

          1. If excessive driving may damage the drive train, 4WD control is stopped, the vehicle is put into front-wheel drive, and the 4WD warning light blinks.

            □ HINT □
            As an advance warning of 4WD control stopping, the 4WD warning light blinks slowly, and when 4WD control is stopped, the 4WD warning light blinks quickly.

            ■ NOTICE ■
            If the 4WD warning light blinks, reduce vehicle speed, stop the vehicle, and do not stop the engine until the 4WD warning light goes off.

          2. When it is confirmed that the vehicle condition has stabilized, the 4WD control stop is automatically cancelled.
