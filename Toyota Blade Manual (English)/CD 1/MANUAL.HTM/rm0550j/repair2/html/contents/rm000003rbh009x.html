Preparation List


Function Description


The engine control computer performs shift control by controlling the inflow and outflow of CVT fluid to and from the primary pulley using the shift solenoids (DS1 and DS2).

The engine control computer detects how well the actual gear ratio follows the target gear ratio, and outputs P0746/62 and P0776/63 if it determines that there is a malfunction.

If DTCs for other shift solenoid (DS1 and DS2) circuits) are output at the same time, it is necessary to troubleshoot the DTCs other than P0746/62 and P0776/63 first.
