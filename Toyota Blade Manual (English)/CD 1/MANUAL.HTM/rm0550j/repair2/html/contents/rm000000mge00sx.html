Engine Immobiliser System Precautions

Print



    1.ID If any of the ID code box (immobiliser code computer), certification ECU (smart key computer assembly), steering lock ECU (steering lock actuator), engine ECU (engine control computer) or electronic key (electrical key transmitter) has been replaced, refer to the registration procedure in the reference section.

    □ HINT □
    If the certification ECU (smart key computer assembly) is replaced, the engine may not start due to a mismatch in the stored lock position with the steering lock ECU (steering lock actuator). After replacement, perform the following procedure.
    1. Move the shift lever to the P position.
    2. With the ignition switch OFF, open and close the driver side door once, then start the engine.



      2. Vehicle Battery Related

      1. Immediately after the battery has been disconnected and reconnected, smart unlock may not operate. In that case, perform a door unlock/lock once using the wireless operation, and smart unlock operation will be restored.

      2. When starting the engine with power supplied from another vehicle's battery because the battery is discharged, first move the shift lever to the P position and open and close the driver side door with the ignition switch OFF before starting.

      3. After the battery has been disconnected and reconnected, start the engine after opening and closing the driver side door and waiting 10 seconds or more.

        □ HINT □
        After the battery has been disconnected and reconnected, even if the engine does not start on the first attempt, the engine will start normally from the 2 attempt onward.
