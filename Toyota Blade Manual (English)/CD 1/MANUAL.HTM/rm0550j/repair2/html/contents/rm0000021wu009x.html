Preparation List


Circuit Description


  1. The smart key computer assembly (certification ECU) performs LIN communication with the immobiliser code computer (ID code box), steering lock actuator (steering lock ECU) and instrument panel junction block assembly (main body ECU), and stores this code when it detects a communication malfunction between ECUs or an open or short in the LIN communication line. Also, when communication between the ECUs returns to normal, the DTC is cleared and stored as a past DTC.

    ■ NOTICE ■
    When replacing the smart key computer assembly (certification ECU), steering lock actuator (steering lock ECU) or immobiliser code computer (ID code box), refer to the registration procedure in the reference section.
