DTC B15DF USB-BOX Connected Device Communication Malfunction

Print

Preparation List


Function Description


  1. This DTC is output when a malfunction occurs in communication between the multimedia interface computer and the USB memory or "iPod".


DTC.No.
Diagnosis Description
Inspection Point
B15DF
  1. When a communication error with the "iPod" or USB memory is detected
  2. When a malfunction in the "iPod" control software is detected
  1. USB memory or "iPod" connection cable
  2. A USB memory or "iPod"
  3. Multimedia Interface ECU


Inspection Procedure

Step 1Check Specifications

  1. Check how the customer's USB memory or "iPod" is connected to stereo jack adapter assembly NO.1.

Step 2Replace Connection Cable

  1. Disconnect the USB memory or "iPod" and connection cable from stereo jack adapter assembly NO.1.

  1. Turn the ignition OFF → ACC ON.

    □ HINT □
    The ignition must be turned OFF for the vehicle to recognize the reconnected USB memory or "iPod".

  1. Disconnect the connection cable from the USB memory or "iPod".

  1. Connect a normal connection cable to the USB memory or "iPod" and stereo jack adapter assembly NO.1.

Step 5Replace USB Memory or "iPod"

  1. Disconnect the USB memory or "iPod" from stereo jack adapter assembly NO.1.

  1. Turn the ignition OFF → ACC ON.

    □ HINT □
    When connecting a different USB memory or "iPod", the ignition must be turned OFF for the vehicle to recognize the connected device.

  1. Connect a normal USB memory or "iPod" to stereo jack adapter assembly NO.1.

    □ HINT □
    1. If using a USB memory, check with a different USB memory.
    2. If using an "iPod", check with a different "iPod".
